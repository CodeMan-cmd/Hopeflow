# 构图与镜头 · 国风二次元新国潮约束手册

> **本画风构图以东方美学为纲**：留白造意境、对称显古韵、写意取景，叠加电影级构图与光影层次（继承 R4/R5），呈现新国潮的东方电影感。

---

## 一、景别

| 景别 | 取景范围 | 用途 | 提示词 |
|---|---|---|---|
| 特写 | 面部/器物局部 | 情绪点、信物、剑穗 | 国风特写、器物细节 |
| 近景 | 头部至胸部 | 对话、情绪流转 | 国风近景、细腻笔触 |
| 中景 | 膝部以上 | 叙事主体、武打起势 | 国风中景、写意身段 |
| 全景 | 全身 | 服饰华美、人物与环境 | 国风全景、衣袂飘飘 |
| 远景 | 全身 + 山水大环境 | 山河意境、孤寂苍茫 | 国风远景、山水留白 |

---

## 二、机位与视角

| 机位 | 适用 | 提示词 |
|---|---|---|
| 平视（默认） | 客观叙事，端正从容 | 平视视角、eye level |
| 仰视 | 殿宇、高塔、人物威严 | 轻微仰视、殿宇仰拍 |
| 俯视 | 山川、集市、俯瞰人间 | 俯视、俯瞰山河 |
| 高机位远望 | 山水全景、人在画中 | 高机位远望、画中景 |
| 低机位 | 竹林、剑气、草叶视角 | 低机位、江湖视角 |

---

## 三、构图法则（东方美学侧重）

| 法则 | 说明 | 提示词 |
|---|---|---|
| 大面积留白 | 云/水/天空留白，计白当黑 | 大面积留白、意境留白 |
| 对称构图 | 殿宇/宫门/人物中轴对称 | 对称构图、中轴取景 |
| 三分法与疏密 | 主体偏置 + 疏密对比 | 三分法、疏密有致 |
| 框架构图 | 窗棂/回廊/门洞框景 | 框景构图、窗棂取景 |
| 对角线/斜势 | 山势/剑气/衣袂斜向取势 | 斜势构图、动态取势 |
| 层峦递进 | 远山近水前中后景层次 | 层峦递进、山水层次 |

---

## 四、镜头语言

| 维度 | 约束 |
|---|---|
| 运动 | 缓慢横移/推拉，如卷轴展开的节奏 |
| 焦点 | 主体清晰，背景适度虚化（电影质感） |
| 景深 | 电影级景深层次，前景/背景层次分明 |
| 转场 | 云雾遮挡、水墨晕染、衣袂翻飞转场 |
| 意境 | 镜头服务于"人在画中"的东方意境 |

---

```

```

## 六、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「国风二次元电影风格」（继承 R5） |
| R2 | 必须声明「新国潮美学 + 东方古韵」（继承 R3） |
| R3 | 构图必须绑定 1 个东方美学法则（留白/对称/框景等） |
| R4 | 必须声明「细腻笔触 + 电影质感」（继承 R4） |
| R5 | 镜头节奏须如卷轴展开，克制从容 |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁西方奇幻/哥特/维多利亚构图语言（继承 X3） |
| X2 | 严禁赛博朋克/科幻/过度现代构图（继承 X3） |
| X3 | 严禁粗劣线条/模糊画质/低精度镜头（继承 X4） |
| X4 | 严禁色彩混乱/风格不统一/审美崩坏（继承 X5） |
| X5 | 严禁写实摄影/3D 写实渲染镜头语言（继承 X1） |
