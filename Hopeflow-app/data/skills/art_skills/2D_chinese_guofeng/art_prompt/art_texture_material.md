# 材质与质感 · 国风二次元新国潮约束手册

> **本画风质感锚定于"赛璐璐平涂 + 细腻笔触"**：现代日式渲染技法呈现东方器物与传统织物的精致细节，线条墨色统一、色块平滑，禁粗劣低精度。

---

## 一、渲染质感描述

| 项目 | 约束 | 说明 |
|---|---|---|
| 基底质感 | 赛璐璐平涂 + 日式渲染 | 色块干净、过渡平滑（继承二级风格） |
| 线条质感 | 细腻流畅、墨黑或深棕 | 禁纯黑粗线条（继承硬约束色） |
| 上色方式 | 现代动画数字渲染 | 赛璐璐色块平滑渐变，禁断层溢出 |
| 材质精度 | 织物/器物细节可辨 | 绸缎、玉器、木纹、金属有细腻笔触 |
| 表面处理 | 精致温润 | 东方器物温润质感，非塑料非写实 |

## 三、画质硬约束

| 维度 | 等级要求 | 说明 |
|---|---|---|
| 线条 | 细腻流畅、墨黑或深棕 | 禁纯黑粗线条、禁断线毛边（继承硬约束色） |
| 颜色 | 中国传统色饱满统一 | 平滑渐变过渡，禁色块断层/色彩溢出 |
| 细节等级 | 高细节精致 | 衣纹/发饰/器物纹样精致，禁模糊低精度 |
| 渲染 | 赛璐璐平滑 | 数字渲染过渡自然，不塑料不写实 |
| 一致性 | 全画面统一 | 新国潮审美全局统一（继承 X5） |
