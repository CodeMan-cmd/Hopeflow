# 光影与氛围 · 国风二次元新国潮约束手册

> **本画风以东方古韵 + 电影质感的光影为灵魂**：赛璐璐平涂叠加日式渲染，月光、烛火、天光等东方意象光效承载意境，整体偏中性色温、新国潮色盘饱满而不艳俗。

---

## 一、光源方案

| 方案 | 光源特征 | 色块/层次建议 | 使用场景 | 提示词 |
|---|---|---|---|---|
| 晨雾天光 | 柔和漫射天光，云雾通透 | C1 月白主导，低对比 | 仙侠、山门、晨修 | 晨雾天光、月白通透、柔和赛璐璐 |
| 黄昏霞光 | 暖橙霞光铺染，金边勾勒 | C5 金黄 + C9 藤黄点缀 | 归途、江湖、离别 | 霞光暖调、金边勾勒、电影质感 |
| 月夜清辉 | 靛蓝夜空 + 局部月光暖点 | C4 靛蓝 + C6 墨黑 + C5 金黄点缀 | 月下对饮、夜行、诗意 | 月色清辉、靛蓝夜空、局部暖光 |
| 烛火/灯笼 | 暖橘烛光，明暗层次分明 | C3 朱红 + C5 金黄，暖调占位 | 宫廷、闺阁、节庆 | 烛火暖光、灯笼光影、暖调层次 |
| 庭院暮光 | 暮色渐沉 + 檐下灯光 | C8 赭石 + C10 灰紫过渡 | 庭院、家常、静夜 | 暮色庭院、檐下灯影、灰紫过渡 |
| 雪夜冷光 | 素雪反光 + 暖窗对比 | C1 月白 + C4 靛蓝，暖点窗灯 | 雪夜、思念、守候 | 雪夜冷光、暖窗点缀、冷暖对比 |

## 二、光比与明暗对比

| 维度 | 约束 | 说明 |
|---|---|---|
| 整体对比度 | 中 45-65%（建议区间） | 丰富层次感，不做极端大光比 |
| 阴影 | 同色系加深 | 禁黑色硬阴影，禁色块断层（继承硬约束色） |
| 高光 | 平滑渐变高光 | 赛璐璐色块平滑过渡，禁色彩溢出 |
| 层次 | 明暗 3-4 级 | 亮部/中间/影部/点缀逐级铺陈 |

---

## 三、色温约束（继承 prefix）

| 参数 | 值 |
|---|---|
| 整体色温 | 偏中性 5000-5600K（推荐） |
| 对比度 | 中 45-65%（建议区间） |
| 饱和度 | 中高 55-70%（建议区间） |

> 色相偏移 ±8°、饱和度偏移 ±10%、明度偏移 ±12%。例外镜头（高光时刻）可临时突破局部色彩，但不得突破严禁项。

## 五、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 每条提示词必须声明「国风二次元」风格锚定词（继承 R1） |
| R2 | 必须声明「赛璐璐平涂 + 日式动画渲染」（继承 R2） |
| R3 | 必须声明「细腻笔触 + 电影质感」（继承 R4） |
| R4 | 阴影必须为「同色系加深」，禁黑色硬阴影（继承硬约束色） |
| R5 | 必须绑定 1 个光源方案并指定主辅色 |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁高饱和荧光色/霓虹色/数码感光效（继承 X2） |
| X2 | 严禁写实摄影/3D 写实渲染/照片级光效（继承 X1） |
| X3 | 严禁西方奇幻/赛博朋克/过度现代光效（继承 X3） |
| X4 | 严禁色块断层/色彩溢出/黑色硬阴影（继承硬约束色） |
| X5 | 严禁色彩混乱/风格不统一的光氛围（继承 X5） |
