# 构图与镜头 · 90年代日式动画约束手册

> **本画风构图服务于怀旧治愈叙事**：以平视为主的日常视角、电影化的景别与留白、克制的运镜，重现 90 年代动画的胶片质感与生活气息。

---

## 一、景别

| 景别 | 取景范围 | 用途 | 提示词 |
|---|---|---|---|
| 特写 | 面部/局部 | 情绪爆发点、心动细节 | 手绘特写、面部细节 |
| 近景 | 头部至胸部 | 对话、日常交流 | 手绘近景、半身细节 |
| 中景 | 膝部以上 | 生活叙事主体 | 手绘中景、生活化构图 |
| 全景 | 全身 | 环境与人物关系 | 手绘全景、日常场景 |
| 远景 | 全身 + 环境 | 车站/街道/放学路的孤独感 | 手绘远景、留白空间 |

---

## 二、机位与视角

| 机位 | 适用 | 提示词 |
|---|---|---|
| 平视（默认） | 客观日常，怀旧基调 | 平视视角、eye level |
| 仰视 | 天空、樱花、教室窗光 | 轻微仰视、天空构图 |
| 俯视 | 俯看桌面、街角、散落物件 | 轻微俯视、生活俯拍 |
| 低机位 | 草地、河岸、奔跑视角 | 低机位、近地视角 |
| 主观视角 | 第一人称代入（看手/看窗） | 主观视角、POV |

---

## 三、构图法则（怀旧叙事侧重）

| 法则 | 说明 | 提示词 |
|---|---|---|
| 三分法 | 主体偏移三分线，留出环境呼吸 | 三分法、偏置主体 |
| 大留白 | 天空/墙面/海面留白制造孤独与怀念 | 大面积留白、空旷构图 |
| 前景遮挡 | 窗框/门框/电线杆作前景层次 | 前景遮挡、窗框构图 |
| 对角线 | 街道/铁轨/坡道引导视线 | 对角线构图、延伸感 |
| 地平线压低 | 天空占比大，情绪开阔 | 低地平线、天空留白 |
| 日常生活框架 | 门/窗/站台框取人物 | 框架构图、生活取景 |

---

## 四、镜头语言

| 维度 | 约束 |
|---|---|
| 运动 | 缓慢推拉、平移跟拍，节奏柔和 |
| 焦点 | 浅景深仅用于近景特写情绪点，主体清晰 |
| 景深 | 背景适度虚化，胶片式散景 |
| 转场 | 淡入淡出、叠化、摇镜扫过天空（90 年代常用） |
| 运镜情绪 | 静止长镜头承载怀旧，运动镜头克制不炫技 |

---

## 五、提示词模板（中文）

```
90年代日式动画电影感构图，手绘平涂，
{景别}，{机位}，{构图法则}，
{前景遮挡/留白描述}，主体置于{三分线/居中}，
柔和暖调，{光源方案}，电影感光影层次，
浅景深仅用于情绪特写，运镜{缓慢推拉/平移}，
画面温暖怀旧，{情绪关键词}，复古胶片质感
```

## 六、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「90年代日式动画风格」锚定词（继承 R1） |
| R2 | 必须声明「手绘质感 + 平涂上色」（继承 R2） |
| R3 | 构图必须绑定 1 个怀旧叙事法则（留白/前景/三分法等） |
| R4 | 运镜必须声明节奏克制，禁止炫技运镜 |
| R5 | 光线必须声明「柔和暖调 + 电影感光影层次」（继承 R5） |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁现代日系动画构图/新海诚式大广角空镜（继承 X1） |
