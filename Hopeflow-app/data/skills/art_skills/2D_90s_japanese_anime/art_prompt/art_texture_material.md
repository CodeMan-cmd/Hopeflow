# 材质与质感 · 90年代日式动画约束手册

> **本画风质感锚定于"手绘赛璐璐"**：平涂上色、均匀色影、清晰流畅线条，保留 90 年代动画的胶片颗粒与手绘温度，杜绝数字绘画的精致塑料感。

---

## 一、渲染质感描述

| 项目 | 约束 | 说明 |
|---|---|---|
| 基底质感 | 手绘平涂 | 90s 手绘动画感，非现代数字精修 |
| 上色方式 | 赛璐璐平涂 | 均匀色块 + 同色系色影，色阶分明 |
| 线条质感 | 清晰流畅、略有手绘粗细变化 | 非绝对机械均匀，保留手绘呼吸感 |
| 表面处理 | 亚光纸感 | 轻微胶片颗粒、非光滑 CG 质感 |
| 光感 | 柔和暖光层次 | 高光为暖白/暖黄，无强反光 |

## 三、画质硬约束

| 维度 | 等级要求 | 说明 |
|---|---|---|
| 线条 | 清晰流畅、可辨手绘 | 闭合清晰，允许轻微抖动，禁断线毛边 |
| 颜色 | 平涂均匀、色影同系 | 色块均匀不上溢，阴影与底色同色系 |
| 细节等级 | 中高细节 | 生活场景道具细节丰富，但保持平面化上色 |
| 颗粒度 | 轻微胶片颗粒 | 整体统一，不引入噪点污染 |
| 一致性 | 全画面统一 | 线条/上色/颗粒全片一致 |

---

## 四、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「手绘质感 + 平涂上色」（继承 R2） |
| R2 | 线条必须声明「精细流畅线条」（继承 R3/R4） |
| R3 | 阴影必须声明「自然阴影/同色系色影」，禁黑色硬影 |
| R4 | 必须声明「柔和暖色调」（继承 R3） |
| R5 | 必须包含「90年代日式动画风格」锚定词（继承 R1） |
