# 光影与氛围 · 90年代日式动画约束手册

> **本画风以手绘平涂为基底，叠加电影感光影层次**：光线柔和温暖、层次丰富但克制，保留 90 年代动画特有的怀旧通透感，严禁现代动画的强对比与数字光效。

---

## 一、光源方案

| 方案 | 光源特征 | 光比建议 | 使用场景 | 提示词 |
|---|---|---|---|---|
| 清晨柔光 | 窗边漫射晨光，均匀暖调 | 1:1.5 低对比 | 起床、上学、日常 | 柔和晨光、窗边漫射、暖调平涂 |
| 黄昏暖阳 | 低角度暖阳，拉长色影 | 1:2 中对比 | 放学、归途、心动 | 黄昏暖阳、琥珀色调、逆光暖调 |
| 夕阳轮廓光 | 逆光剪影 + 边缘暖光 | 1:2.5 中对比 | 告白、离别、浪漫 | 逆光轮廓、暖橙发丝光、怀旧氛围 |
| 月夜冷调 | 清冷月光为主、暖色点缀 | 1:1.5 低对比 | 独处、思考、夜谈 | 月色清冷、淡紫夜空、局部暖灯 |
| 室内暖灯 | 台灯/吊灯暖光，局部照明 | 1:2 中对比 | 咖啡馆、卧室、书房 | 暖灯照明、琥珀灯光、温馨室内 |
| 回忆柔焦 | 柔光雾化、轻微褪色 | 1:1 低对比 | 闪回、旧忆、梦境 | 柔焦回忆、轻微褪色、朦胧暖调 |

---

## 二、光比与明暗对比

| 维度 | 约束 | 说明 |
|---|---|---|
| 整体光比 | 中等（建议保持） | 明暗层次清晰，但不过分强烈，杜绝硬光切割 |
| 阴影 | 同色系加深的平涂色影 | 手绘赛璐璐式色影，禁用黑色硬阴影 |
| 高光 | 柔和暖色高光 | 眼睛高光、发丝高光用暖白/暖黄 |
| 层次 | 3 级明暗 | 亮部色 → 中间色 → 影部色，逐级过渡 |

---

## 三、色温约束（继承 prefix）

| 参数 | 值 |
|---|---|
| 整体色温 | 偏暖 4800-5200K（推荐） |
| 肤色色温 | 微暖 5000-5400K（推荐） |
| 对比度 | 中等（建议保持） |
| 饱和度 | 中低 50-70%（建议区间） |

> 色相偏移 ±8°、饱和度偏移 ±10%、明度偏移 ±12%。回忆/黄昏/情绪高潮镜头可更暖或更高饱和局部色块，但禁止高饱和荧光色与现代色彩语言入镜。

## 四、色调情绪与画面关键词

| 情绪场景 | 主色 | 辅色 | 画面关键词 |
|---|---|---|---|
| 日常温馨 | C1 暖黄 | C9 米白 + C5 高级灰 | 生活感、温暖、平静 |
| 心动瞬间 | C2 樱花粉 | C1 暖黄 + C10 暖橙 | 羞涩、靠近感、暧昧 |
| 黄昏浪漫 | C7 琥珀暖 | C10 暖橙 + C2 樱花粉 | 怀旧、浪漫、情感 |
| 夜晚月色 | C3 天空蓝 | C6 淡紫 + C1 暖黄 | 静谧、思考、独处 |
| 回忆/闪回 | C1 暖黄 | C6 淡紫 + C5 高级灰 | 怀旧、旧忆、梦幻 |
| 离别感伤 | C5 高级灰 | C3 天空蓝 + C1 暖黄 | 距离感、克制、静压 |

## 五、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 每条提示词必须声明「电影感光影层次」（继承 R5） |
| R2 | 必须声明「柔和暖调 + 手绘平涂质感」（继承 R2/R3） |
| R3 | 阴影必须为「同色系加深的色影」，禁用黑硬影 |
| R4 | 必须绑定 1 个光源方案并指定光比与主辅色 |
| R5 | 情绪切换优先调整光比与色温，再调整饱和度（继承 E3） |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁过度阴影/重对比/暗调黑暗（继承 X5） |
| X2 | 严禁高饱和荧光色/霓虹色光效（继承 X3） |
| X3 | 严禁现代日系动画光效（新海诚后期/MAPPA 质感，继承 X1） |
| X4 | 严禁 3D 渲染/CG/数字绘画光效（继承 X2） |
| X5 | 严禁光源杂乱/多色温混光，单镜头主光源不超过 1 个 |
