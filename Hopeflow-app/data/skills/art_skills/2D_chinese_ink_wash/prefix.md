## 二、全局色彩盘（风格基线）

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 墨色五色基线、中国传统色点缀、水墨写意 |
| L2 软约束 | 中 | 场景色、服饰色、点缀色可按墨韵微调 |
| L3 例外机制 | 低 | 特殊意境/高光时刻可临时突破局部色彩 |

| C5 | 清墨 | #C9C4B8 | 极淡墨色、雾霭、留白渐变 |
| C6 | 赭石 | #8A6A4B | 山石皴染、秋意、木质器物 |
| C7 | 花青 | #3B6B8F | 远山青黛、水色、冷调意境 |
| C8 | 朱砂 | #B03A2E | 印章、红日、梅点、点睛 |

### 硬约束色（默认锁定）

| 色项 | 对应色 | 规则 |
|---|---|---|
| 整体色调 | 墨色为主 + 中国传统色点缀 | 禁止高饱和荧光色 |
| 墨色层次 | 焦浓重淡清五级 | 禁止死黑一团/灰雾一片 |
| 晕染边缘 | 笔触自然渗化 | 禁止生硬色块边界 |
| 点缀色 | 朱砂/花青/石绿等传统色 | 单幅点缀不超过 2-3 色 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖米白 4300-4800K（推荐） | 宣纸暖白基调 |
| 对比度 | 低-中 30-50%（建议区间） | 墨色层次而非强对比 |
| 饱和度 | 低 15-35%（建议区间） | 墨色为主的低饱和 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|

| 饱和度偏移 | ±8% |
