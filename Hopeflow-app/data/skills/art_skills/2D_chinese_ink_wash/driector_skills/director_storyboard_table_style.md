# 分镜表水墨丹青约束 · 国风水墨丹青 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供国风水墨丹青风格在分镜表层面的约束规范。

---

## 二、墨色与氛围

- **墨韵统一** — 一场戏内墨色浓淡必须保持水墨晕染一致性，晕染自然渗化（禁止生硬色块），除非有明确的叙事转折（如暮色转月夜）
- **情绪墨盘绑定** — 每场戏至少绑定 1 个情绪墨盘（如山水清远/月夜孤寂/春日生机/秋意萧瑟/渔舟唱晚/仙踪缥缈），并在镜头组内保持主墨+辅色连续性，色彩取自核心色盘（宣白 #F5F0E6 / 焦墨 #171717 / 浓墨 #3A3A3A / 淡墨 #8C8C8C / 清墨 #C9C4B8 / 赭石 #8A6A4B / 花青 #3B6B8F / 朱砂 #B03A2E / 藤黄 #E3B341 / 石绿 #6B9B7C）
- **以墨代光规范** — 亮部以留白呈现，暗部以浓墨呈现；描述光影时须区分墨色浓淡与留白比例，晕染始终保持水墨动画质感
- **墨色浓淡与叙事阶段匹配** — 悲戚压抑段落使用重墨（焦墨 + 浓墨 + 花青冷调），禁用藤黄/朱砂暖点；山水清远/仙踪缥缈段落使用清墨留白（宣白 + 清墨 + 淡墨）；渔舟唱晚段落使用赭石染暮 + 藤黄孤灯
- **墨韵转场是高级手段** — 从暮色苍茫渐变到月夜清辉 = 时间流逝。在分镜表中标注墨色变化点，转场过程中墨色必须自然渗化过渡，禁止色块断层
- **水墨动画光效** — 允许合理使用淡入淡出、缓慢运镜等动画技法，但必须保持水墨丹青写意美学基调，禁止 3D 写实/CG 光效

---

## 三、环境动态

- **环境动态增加画面呼吸感** — 云气流动、水波晕开、落叶飘零、雨丝斜织、衣袂飘动、墨晕扩散。每 3-4 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **水墨环境元素优先** — 环境动态应选用水墨世界观内的元素：云雾、飞鸟、孤雁、落叶、花瓣、细雨、飞雪、舟楫、炊烟，禁止出现现代元素
- **水墨动态质感** — 环境动态元素（云雾/水波/落叶等）必须保持水墨晕染质感与写意笔触，禁止 3D 粒子特效或写实流体效果

---

## 四、水墨动作节奏

- **动作含蓄且带写意感** — 人物动作默认缓慢含蓄，起手投足如行笔般从容，可在关键帧上做写意夸张处理（如衣袂翻飞、发丝如墨流动），起身、转身、抬手应标注"缓慢/含蓄"
- **衣袂动态是核心画面资产** — 水墨服饰（宽袖、裙裾、披帛、飘带）的飘动是天然的动态资产，可在画面描述中加入衣袂/裙裾的墨韵流动，写意渲染下的服饰飘动应笔势连贯、留白疏朗
- **仪态约束** — 水墨人物的举止应符合东方古典气质：行走稳缓、举止含蓄内敛、不出现现代化的肢体语言（如耸肩、摊手）。写意角色可在微表情上略有夸张（眉梢舒展、唇角浅扬），但肢体动作仍需含蓄克制
- **简笔传神** — 动作设计以简笔传神为纲，一笔一势皆有情，禁止过度写实的动作细节堆砌

---

## 五、材质与质感约束

- **笔墨为锚** — 所有镜头中人物/服饰/道具/场景的渲染必须保持水墨写意质感，笔触流畅、晕染自然，禁止 3D 写实/CG 动画/照片级渲染
- **服饰材质** — 衣纹流畅 + 墨色留白的写意表现，纹理以笔法传达，墨韵层次分明
- **道具材质** — 山石皴法、器物简笔、点缀传神，均以水墨笔法呈现，禁止写实材质渲染
- **场景材质** — 皴法山石、晕染云雾、留白水面，材质带有宣纸渗化的自然肌理，禁止"塑料感"的全新无瑕材质

---

## 六、色彩约束

- **核心色盘锁定** — 分镜表中所有镜头的色彩必须取自核心色盘（C1-C10），色相偏移容差 ±8°，饱和度偏移 ±8%，明度偏移 ±15%
- **禁止荧光色** — 严禁高饱和荧光色/霓虹色/数码感强的色彩出现
- **墨色层次** — 焦浓重淡清五级分明，禁止死黑一团/灰雾一片
- **点缀色规则** — 朱砂/花青/石绿/藤黄等传统色单幅点缀不超过 2-3 色
- **整体色温** — 偏暖米白 4300-4800K 宣纸基调，对比度 30-50%，饱和度 15-35%（低饱和墨色体系）

---

## 七、运镜禁忌

- **禁用快速运镜** — 甩镜、急推、手持晃动与水墨丹青的行笔气韵冲突，情感高潮场景可适度加快运镜节奏但仍需保持画面从容
- **禁用花式转场** — 划屏、旋转、百叶窗等与本风格不兼容
- **禁用写实镜头语言** — 手持摇晃/纪录片式跟拍/鱼眼镜头等与水墨美学冲突，破坏宣纸画面的纯净感
- **禁用焦点透视强透视** — 远景必须使用散点透视或三远法，禁广角畸变

---

## 八、转场禁忌

| 禁忌类型 | 说明 |
|---|---|
| 生硬切转 | 场景/情绪切换禁用无墨色过渡的硬切 |
| 花式特效转场 | 划屏/旋转/百叶窗/闪白等与本风格不兼容 |
| 写实转场 | 3D 溶解/粒子爆炸/镜头穿墙等与水墨美学冲突 |
| 色块断层 | 转场过程墨色必须自然渗化，禁色块断层 |
| 节奏失控 | 转场过多过密，画面失去水墨呼吸感 |

- **正确做法**：优先使用墨晕/云遮/留白/笔势等水墨式转场，并在分镜表中标注墨色变化点
- **禁忌总纲**：一切与水墨行笔气韵冲突的转场手法均不得使用

## 九、分镜表快速检查清单

- [ ] 每场戏已绑定情绪墨盘（如山水清远/月夜孤寂），镜头组内主墨+辅色连续
- [ ] 色彩全部取自核心色盘（C1-C10），无荧光色、无死黑一团
- [ ] 镜头组内墨韵统一，晕染自然渗化，无生硬色块
- [ ] 每 3-4 个镜头至少安排一个环境动态镜头（云气/水波/落叶等）
- [ ] 人物动作标注「缓慢/含蓄」，衣袂飘动笔势连贯、留白疏朗
- [ ] 运镜全部为缓慢克制类，无快速甩镜/急推/手持晃动
- [ ] 转场均为水墨式转场（墨晕/云遮/留白/笔势），无花式转场
- [ ] 材质保持写意质感，无 3D 写实/CG/照片级渲染
- [ ] 整体色温/对比度/饱和度符合宣纸低饱和墨色体系
- [ ] 远景使用散点透视/三远法，无广角畸变
