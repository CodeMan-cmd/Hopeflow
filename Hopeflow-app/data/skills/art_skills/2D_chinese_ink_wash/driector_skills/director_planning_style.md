# 水墨丹青约束 · 国风水墨丹青 · 技法参考

---

## 一、墨色体系与画面基调

- **墨色基底** — 全片以核心色盘为基底：宣白（C1 #F5F0E6）、焦墨（C2 #171717）、浓墨（C3 #3A3A3A）、淡墨（C4 #8C8C8C）、清墨（C5 #C9C4B8）、赭石（C6 #8A6A4B）、花青（C7 #3B6B8F）、朱砂（C8 #B03A2E）、藤黄（C9 #E3B341）、石绿（C10 #6B9B7C），整体色温偏暖米白（4300-4800K），饱和度低（15-35%），呈现宣纸暖白的墨韵画面
- **墨色叙事对比** — 焦墨/浓墨（C2/C3）作为厚重/压抑/孤寂的视觉信号；留白与清墨（C1/C5）作为空灵/超脱/释然的信号；缀色（朱砂 C8、花青 C7、石绿 C10）作为情绪点与点睛信号。墨色浓淡切换应与故事弧线同步
- **墨色分配策略** — 悲戚孤绝段落用重墨（焦墨 + 浓墨 + 少量花青），禁朱砂暖点；仙踪缥缈/山水清远段落用清墨留白（宣白 + 清墨 + 淡墨）；渔舟唱晚/归意段落用赭石染暮 + 藤黄孤灯
- **墨盘先行原则** — 段落规划需先绑定情绪墨盘（山水清远/月夜孤寂/春日生机/秋意萧瑟/渔舟唱晚/仙踪缥缈等），再确定主墨+辅色与留白比例，避免"剧情对了但墨色不对"
- **禁用色域** — 高饱和荧光色、霓虹色、数码感强色彩均与本风格不兼容。色相偏移容差 ±8°，饱和度偏移 ±8%，明度偏移 ±15%

## 二、光影方案体系（以墨代光）

- **以墨代光** — 7 套明度方案对应不同情绪段落，导演规划阶段应在段落层面确定墨色浓淡基调方向，而非逐镜指定
- **留白即光** — 亮部以纸面留白呈现，禁白色高光笔触；暗部以浓墨呈现，禁黑色硬阴影
- **墨韵为锚** — 所有光影方案必须保持水墨晕染质感，墨色自然渗化，禁生硬色块

| 光影方案 | 方案名 | 墨色倾向 | 适用情绪 |
|---|---|---|---|
| A | 天光留白 | 宣白 + 淡墨 + 清墨 | 山水清远、晨景、释然 |
| B | 云雾缥缈 | 清墨 + 花青 + 留白 | 仙踪出尘、惊艳登场 |
| C | 孤灯暖点 | 浓墨主体 + 藤黄孤灯 | 夜间归意、温暖相依 |
| D | 月夜清辉 | 焦墨 + 清墨 + 月留白 | 月夜孤寂、思念独处 |
| E | 暮色苍茫 | 浓墨 + 赭石染暮 | 离别、归途、苍茫 |
| F | 雪意留白 | 大块宣白 + 枯墨微痕 | 清寂、禅意、空灵 |
| G | 重墨压抑 | 焦墨 + 浓墨 + 花青冷调 | 悲戚、压抑、氛围紧张 |

- **墨色分配** — 暖意段落（归意/相依）用赭石/藤黄点缀；悲戚压抑段落一律重墨冷调。导演可根据叙事需要调整浓淡切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述明度方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **笔墨为锚** — 国风水墨丹青的核心：宣纸质感、墨色晕染、写意笔触、浓淡干湿、皴法墨韵、留白意境
- **写意笔触 + 气韵生动** — 这是画面质感的锚点。不是写实摄影，不是 3D CG，是水墨动画加东方美学的融合
- **材质水墨化** — 所有服化道的材质必须以笔墨笔法呈现：山石用皴法、衣袍用勾勒留白、云雾用晕染渗化、器物用简笔点缀。禁止"3D 感"和"写实摄影感"
- **墨韵不等于糊** — 水墨丹青强调在写意基础上通过浓淡干湿、飞白渗化等手段增加气韵与空间感，而非糊成一片的"脏水墨"
- **留白克制** — 留白是构图资产，用于意境营造，不得因留白而让画面空无一物、失去叙事主体

## 四、水墨场景空间元素

水墨世界观特有的场景元素及其视觉叙事功能：

- **山峦/飞瀑/孤峰/江畔** — 留白与皴法的天然载体，景即情：云雾锁山 = 孤寂、飞瀑直下 = 壮阔、孤舟横渡 = 归隐、远山如黛 = 思念
- **亭台/草堂/竹篱/月门** — 借景留白的空间结构，窗棂/月门/枝隙 = 框景构图，制造"可望不可即"的层次
- **烟雨/云雾/暮霭/雪意** — 水墨世界的气象资产，烟雨 = 迷蒙/愁绪、云雾 = 仙意/出尘、暮霭 = 归意/苍茫、雪意 = 清寂/空灵
- **孤灯/渔火/烛光** — 水墨世界的暖点光源，孤灯一点 = 归意/温暖（方案C）、渔火点点 = 人间烟火
- **梅兰竹菊/枯枝/孤雁** — 意象化动植物，一枝入画、疏朗留白，承载品格隐喻
- **段落间用空镜留白过渡** — 水墨场景资产丰富（不同时段/天候/景别变体），段落衔接建议用山水空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（墨色突变、留白扩张、空镜隐喻）而非依赖对白解释
- **墨色层次** — 所有场景必须具备近实远虚的墨色层次，杜绝扁平；山水必须包含淡墨远山

## 五、古风乐器与环境音

水墨世界观下的声音元素约束：

### 乐器选择

- **古琴** — 开场定调/平稳段落/山水意境的核心乐器，空灵悠远，与水墨留白高度适配
- **箫** — 凄凉、孤寂、思念段落的补充乐器，与月夜孤寂/仙踪缥缈适配
- **笛** — 清亮明快的段落点缀，春日生机/渔舟唱晚的轻快载体
- **箜篌/古筝** — 缥缈仙气段落的铺底，与云雾缥缈意境搭配
- 弦乐铺底可增加电影感但不宜喧宾夺主

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 古琴独奏 或 古琴 + 箫 |
| 山水/清远/意境 | 古琴 + 笛 + 轻弦 |
| 孤寂渐浓 | 箫 + 古琴 |
| 情绪爆发/命运转折 | 古琴泛音 + 鼓点渐强 |
| 紧张/急促 | 笛声急促 + 鼓点衬底 |
| 温暖/归意/日常 | 笛 + 古筝 |
| 仙踪/缥缈 | 箜篌 + 古琴 + 风铃 |

### 水墨环境音

- **典型环境音层次** — 溪水潺潺 / 风过竹林 / 雨打芭蕉 / 檐滴 / 鸟鸣 / 衣料摩擦 / 笔墨行纸声 / 钟声远荡 / 落叶簌簌 / 舟楫欸乃
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音越克制，水墨意境越深远
