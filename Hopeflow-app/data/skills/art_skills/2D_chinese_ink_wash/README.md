# 国风水墨丹青风格说明

本风格专为"国风水墨丹青"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **水墨写意动画**：以中国水墨画技法为根基的动画风格，涵盖山水、花鸟、文人、仙侠等题材，参考《小蝌蚪找妈妈》等水墨动画的流动气韵
- **墨分五色**：焦、浓、重、淡、清五级墨色层次，浓淡干湿、皴擦点染，以墨代彩
- **宣纸留白意境**：淡雅宣纸质感、计白当黑、笔断意连，东方意境与空灵气韵
- **中国传统色点缀**：以墨色为主调，朱砂、花青、石绿、赭石、藤黄等传统色轻点成趣
- **写意笔触**：行笔如云、虚实相生，拒绝工笔细描与写实堆砌
- **水墨电影质感**：动态墨韵、运镜如行笔、意境为上的东方电影表达

## 适用范围

- 水墨丹青题材的AI美术生成（角色、场景、道具、分镜等）
- 需要水墨写意、留白意境、东方空灵的视觉创作
- 水墨动画、国风短片、诗意插画、概念设计

## 严禁内容

- 完全写实摄影/3D写实渲染/照片级真实感
- 西方油画厚涂/素描明暗体系/水彩水粉质感
- 高饱和荧光色/霓虹色/数码科技质感
- 画面满铺无留白/死黑一团/墨色混浊无层次
- 西方奇幻/哥特/赛博朋克/科幻元素
- 低俗恶搞/血腥恐怖/不符合东方雅韵的内容

## 核心技法关键词

| 技法 | 说明 | 应用 |
|---|---|---|
| 墨分五色 | 焦浓重淡清五级墨阶 | 一切画面的明度骨架 |
| 皴法墨韵 | 披麻皴/斧劈皴/点苔 | 山石肌理与质感 |
| 留白 | 计白当黑、以虚写实 | 天空、云气、水面 |
| 飞白 | 枯笔扫过纸面的露白 | 枯枝、疾风、苍茫感 |
| 晕染渗化 | 水墨在宣纸上自然扩散 | 云雾、衣袂、远山 |
| 浓淡干湿 | 笔中含墨量的变化 | 画面的节奏与虚实 |

## 核心色盘总览（C1-C10）

> 全风格色彩取自以下核心色盘（详见 `prefix.md`），色相偏移容差 ±8°：

| 序号 | 色名 | 色值 | 用途 |
|---|---|---|---|
| C1 | 宣白 | #F5F0E6 | 宣纸底色、留白、天空云气 |
| C2 | 焦墨 | #171717 | 最浓墨色、点睛、近景轮廓 |
| C3 | 浓墨 | #3A3A3A | 主山体、树干、衣纹主体 |
| C4 | 淡墨 | #8C8C8C | 远山、云烟、过渡层次 |
| C5 | 清墨 | #C9C4B8 | 极淡墨色、雾霭、留白渐变 |
| C6 | 赭石 | #8A6A4B | 山石皴染、秋意、木质器物 |
| C7 | 花青 | #3B6B8F | 远山青黛、水色、冷调意境 |
| C8 | 朱砂 | #B03A2E | 印章、红日、梅点、点睛 |
| C9 | 藤黄 | #E3B341 | 秋叶、暖光、点缀色 |
| C10 | 石绿 | #6B9B7C | 青绿山水点缀、荷叶 |

> 用法：以墨色（C1-C5）为画面骨架，传统色（C6-C10）单幅点缀不超过 2-3 色。

## 文件结构说明

本画风目录包含以下文件：

- `prefix.md` — 全局美学基础与风格基因（一级风格、色彩盘、硬约束色）
- `art_prompt/` — 各类美术提示词约束手册
  - `art_character.md` / `art_character_derivative.md` — 角色及其衍生
  - `art_scene.md` / `art_scene_derivative.md` — 场景及其衍生
  - `art_prop.md` / `art_prop_derivative.md` — 道具及其衍生
  - `art_composition_camera.md` — 构图与镜头
  - `art_lighting_atmosphere.md` — 光影与氛围
  - `art_texture_material.md` — 材质与质感
  - `art_storyboard_video.md` — 分镜视频提示词
- `driector_skills/` — 导演侧分镜技能
  - `director_planning_style.md` — 分镜规划
  - `director_storyboard.md` — 分镜提示词技法
  - `director_storyboard_table_style.md` — 分镜表约束
- `images/` — 风格示例图
- `README.md` — 本说明文件

## 使用流程

1. 生成角色/场景/道具资产 → 读取对应 `art_prompt/` 手册
2. 分镜规划 → 读取 `driector_skills/director_planning_style.md`
3. 分镜表生成 → 读取 `driector_skills/director_storyboard_table_style.md`
4. 分镜提示词 → 读取 `driector_skills/director_storyboard.md`
5. 视频分镜 → 读取 `art_prompt/art_storyboard_video.md`
6. 所有生成必须严格遵循 `prefix.md` 的全局规则

## 风格体验

在本风格下，您将体验到：

- 角色以简笔写意勾勒，衣袂如行云流水，面容淡墨点染、含蓄传神
- 场景留白深远，山峦浓淡相宜，云雾化于纸面，人在画中游
- 道具以笔触传达质感，一杆一笔、一叶一舟皆有墨韵
- 分镜与渲染均强调水墨流动感、写意意境、宣纸肌理
- 全片以墨色为骨、传统色为魂，飘逸空灵、气韵生动
