# 人物衍生资产生成 · 约束手册

## 一、叠加原则

1. **面容不变** — 叠加后五官必须与底模完全一致，禁止面容偏移
2. **姿态不变** — 保持底模自然站立姿态，禁止任何姿态/动作/体态变化
3. **逐层可控** — 每层独立描述，便于按层替换（换装不换妆）
4. **墨韵统一** — 所有服化元素服从水墨写意美学体系，质感不降
5. **纯服化范畴** — 仅叠加妆容/发型/服饰/配饰，禁止引入道具、场景、环境、动作

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 基础形象底模，不修改 |
| L1 | 妆容（决策层） | 先分析用户线索，再决策「素淡 / 清雅 / 点绛」强度 |
| L2 | 发型造型 | 束发/半束/散发 + 发饰 |
| L3+L4 | 中衣/外衣/主服 | 水墨长衫/长裙/道袍/蓑衣等 |
| L5 | 配饰 | 簪/佩/穗/绦/笠 |

> **范畴边界**：人物衍生资产仅包含 L0–L5（服化妆造），不含道具（伞/剑/笛等手持物）、场景环境、姿态动作。

## 三、妆容约束（L1）

> 底模虽为素颜，但衍生资产默认进入妆造流程，系统须分析用户线索后在素淡、清雅、点绛间决策强度。

| 线索类型 | 典型线索 | L1 决策 |
|---|---|---|
| 无明显面部线索 | 仅服饰/发型变化 | 素淡（近乎无妆） |
| 轻微面部线索 | 含笑、气色微提 | 清雅（极淡点染） |
| 明确日常线索 | 日常、出行、雅集 | 清雅（淡扫蛾眉） |
| 明确仪式线索 | 大婚、典礼、重要场合 | 点绛（朱唇黛眉） |

| 风格 | 适用场景 | 核心提示词 |
|---|---|---|
| 素淡无妆 | 日常、私密 | 素颜淡墨、清水出芙蓉 |
| 清雅淡妆 | 日常、雅集、初遇 | 淡扫蛾眉、朱砂微点 |
| 点绛妆 | 大婚、典礼、正式 | 黛眉朱唇、点绛如梅 |

> 底肤统一宣纸底调、淡墨晕染；朱砂/胭脂轻点点睛，禁高光笔触。判定原则：所有衍生资产都要有妆造，先看面部线索决定强度，道具/场景/姿态变化不得单独抬高妆容强度。

## 四、发型/服饰/配饰速查（L2-L5）

### 发型造型

| 造型 | 适用 | 提示词 |
|---|---|---|
| 高髻云鬓 | 正式、仙侠 | 高髻云鬓、简笔盘发 |
| 散发披肩 | 私密、隐逸 | 散发披肩、长发如墨 |
| 束发高马尾 | 侠客、行动 | 高束马尾、干练利落 |

### 服饰矩阵

| 风格 | 款式 | 适用 | 提示词 |
|---|---|---|---|
| 水墨长衫/长裙 | 素色、大块留白 | 文人、日常 | 水墨长衫、衣纹留白 |
| 道袍/蓑衣 | 宽袖道袍/蓑衣斗笠 | 仙侠、江湖 | 仙风道骨、江湖气韵 |
| 劲装 | 束身劲装 | 侠客、行动 | 束身劲装、线条利落 |

### 配饰

| 类型 | 约束 | 提示词 |
|---|---|---|
| 发簪/佩玉 | 竹木玉质、简素雅致 | 玉簪简素、腰间玉佩 |
| 剑穗/扇坠 | 流苏垂坠、缀色点睛 | 流苏垂坠、朱砂点睛 |

- 服饰主色以墨色为主 + 传统色点缀，衣纹写意、大块留白、多层叠穿层次分明
- 配饰简练雅致，禁繁复金饰堆砌

## 五、四视图设定图规范

| 位置 | 视图 | 角度 | 要求 |
|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 面部至锁骨，妆容/五官淡墨清晰 |
| 左二 | 正视图 | 正面 0° | 全身立像，服饰正面全貌 |
| 右二 | 侧视图 | 右侧 90° | 全身立像，服饰侧面层次 |
| 右一 | 后视图 | 后方 180° | 全身立像，发饰/背部服饰清晰 |

| 项目 | 约束 |
|---|---|
| 布局/背景 | 同一画面左至右四视图（建议 4:1 或 3:1）；宣白纯色 #F5F0E6 |
| 站姿/表情 | 自然站立（**禁止姿态变化**）；含蓄微表情符合妆容风格 |
| 光线/一致性 | 均匀柔光、水墨晕染过渡；四视图面容/妆容/发型/服饰/配饰完全一致 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 叠加后面容必须与底模一致 |
| R2 | 服饰必须用「衣纹流畅 + 墨色留白」，配饰简素雅致 |
| R3 | 必须输出四视图设定图，指定「宣白纯色背景」 |
| R4 | **仅输出提示词**；禁止场景描述/道具交互/姿态变化 |
| R5 | **L1 必须先分析再决策**，所有衍生资产至少使用素淡档 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 叠加后面容偏移 |
| X2 | 配饰繁复堆砌/现代饰品 |
| X3 | 复杂场景背景（必须纯色） |
| X4 | 四视图间服化妆造不一致 |
| X5 | 输出提示词以外的任何内容 |
| X6 | 加入场景描述/道具交互/姿态变化 |
| X7 | 未分析用户线索就直接套用固定妆容 |
