# 构图与镜头 · 国风水墨丹青约束手册

> **本画风构图以中国画美学为纲**：留白造意境、散点透视破焦点、三远法取势，叠加"运镜如行笔"的水墨动画镜头语言（继承 R3/R4）。

---

## 一、景别

| 景别 | 取景范围 | 用途 | 提示词 |
|---|---|---|---|
| 特写 | 面部/器物/梅枝局部 | 情绪点、意象点睛 | 水墨特写、淡墨点染 |
| 近景 | 头部至胸部 | 对话、含蓄情绪 | 水墨近景、写意笔触 |
| 中景 | 膝部以上 | 叙事主体、身段 | 水墨中景、衣袂飘动 |
| 全景 | 全身 | 人物入景、人在画中 | 水墨全景、人物入画 |
| 远景 | 全身 + 山水大境 | 山河意境、孤寂苍茫 | 水墨远景、山水留白 |

---

## 二、机位与视角（散点透视）

| 机位 | 适用 | 提示词 |
|---|---|---|
| 平视（默认） | 客观叙事、从容平和 | 平视视角、eye level |
| 高远 | 仰观山巅、高远取势 | 高远视角、仰观山巅 |
| 深远 | 穿堂入谷、纵深推进 | 深远视角、纵深取景 |
| 平远 | 远望江畔、辽阔疏朗 | 平远视角、远山如黛 |
| 俯瞰 | 江河村落、一览全局 | 俯瞰、鸟瞰山水 |

---

## 三、构图法则（中国画侧重）

| 法则 | 说明 | 提示词 |
|---|---|---|
| 大面积留白 | 计白当黑、以虚写实 | 大面积留白、计白当黑 |
| 对角取势 | 山势/枝干/衣袂斜向取势 | 对角构图、斜势取势 |
| 三段式山水 | 近景实、中景活、远景虚 | 三段式山水、近实远虚 |
| 框景 | 窗棂/门洞/枝隙框景 | 框景构图、枝隙取景 |
| 疏密对比 | 疏可走马、密不透风 | 疏密有致、疏密对比 |
| 之字布势 | 山径/水流之字蜿蜒 | 之字布势、蜿蜒取势 |

---

## 四、镜头语言

| 维度 | 约束 |
|---|---|
| 运动 | 缓缓横移/徐推/轻摇，如行笔展开长卷 |
| 焦点 | 虚实相生，焦外如墨晕模糊 |
| 景深 | 以墨色浓淡代替景深虚化，近浓远淡 |
| 转场 | 墨晕扩散、云气遮挡、留白停顿转场 |
| 意境 | 镜头服务于"人在画中游"的东方意境 |

---

## 五、提示词模板（中文）

```
水墨丹青写意构图，宣纸质感，墨色晕染，留白意境，
{景别}，{机位/透视}，{构图法则}，
{留白/疏密描述}，近实远虚，层次递进，
{光源方案}，以墨代光明度，写意笔触，
主体置于{留白/对角/三段式}，{前景/中景/远景描述}，
墨色{主色}+{辅色}，{情绪关键词}，气韵生动
```

## 六、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「水墨丹青 + 留白意境」（继承 R1/R3） |
| R2 | 必须声明「写意笔触 + 皴法墨韵」（继承 R4） |
| R3 | 构图必须绑定 1 个中国画法则（留白/对角/三段式等） |
| R4 | 远景必须使用散点透视或三远法，禁焦点透视 |
| R5 | 镜头节奏须如行笔展开，缓慢从容 |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁西方奇幻/哥特/赛博朋克构图语言（继承 X3） |
| X2 | 严禁写实摄影/3D 写实渲染镜头语言（继承 X1） |
| X3 | 严禁焦点透视强透视/广角畸变/鱼眼镜头 |
| X4 | 严禁满铺无留白/构图拥挤（继承 X5） |
| X5 | 严禁快速运镜/甩镜/急推/手持晃动 |
