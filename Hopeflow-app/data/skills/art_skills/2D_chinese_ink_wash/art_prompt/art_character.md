# 人物基础形象生成 · 约束手册

## 一、基础形象原则

1. **写意为魂** — 人物以水墨写意笔法勾勒，简笔传神，忌工笔堆砌
2. **底模即基础** — 素色水墨长衫/长裙打底，后续服化均为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **墨韵气质** — 无妆状态仍需体现角色气质（清逸/温润/孤傲）

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，淡墨点染、简练传神，不预设脸型/眼型/眉型/唇型 |
| 风格底色 | 水墨丹青、写意笔触、宣纸质感、墨色晕染、留白意境 |
| 气质 | 必须从角色描述提炼整体气质关键词（如清逸出尘/温润如玉/孤傲冷峻），并写入提示词 |
| 表情 | 中性微表情，含蓄内敛，符合角色气质 |

## 三、肤感约束

| 角色 | 项目 | 约束 | 提示词 |
|---|---|---|---|
| 女性 | 肤色/质感 | 宣纸底调、淡雅清透、笔触柔和 | 宣白底调、淡墨晕染、写意笔触、边缘晕染 |
| 男性 | 肤色/质感 | 宣纸底调、沉稳清朗、笔触利落 | 宣白底调、淡墨晕染、疏朗干净、柔和晕染 |
| 通用 | 光泽 | 水墨自然渗化、非高光 | 墨韵渗化、自然过渡、无油光 |

## 四、体型约束

| 角色 | 项目 | 约束 | 提示词 |
|---|---|---|---|
| 女性 | 身高/体态 | 默认 160-170cm，清瘦修长、削肩细颈 | {身高}cm tall、清瘦修长、削肩、体态轻盈 |
| 男性 | 身高/体态 | 默认 175-185cm，清瘦挺拔、肩线流畅 | {身高}cm tall、清瘦挺拔、肩线流畅、体态清朗 |
| 通用 | 比例 | 写意修长、不强调头身比 | 清瘦修长、飘逸身姿 |

## 五、基础发型约束

> 仅定义自然发型，发饰在服化衍生环节叠加。

| 角色 | 项目 | 约束 | 提示词 |
|---|---|---|---|
| 女性 | 发色/发长 | 墨色、长发及腰 | 墨色青丝、长发及腰、如墨渲染 |
| 女性 | 造型 | 自然散发、无发饰 | 长发自然散落、无发饰 |
| 男性 | 发色/发长 | 墨色、长发及肩或束发 | 墨色发丝、长发及肩、束发 |
| 男性 | 造型 | 自然散发或半束、无发冠 | 长发自然散落、半束长发 |
| 通用 | 发质 | 写意笔触、发丝如墨 | 写意发丝、墨韵流动、笔触流畅 |

## 六、基础服装约束

> 基础服装无特殊约束，女性为素色水墨长裙，男性为素色水墨长衫，大块留白、衣纹写意。正式服饰在服化衍生环节叠加。

- 服装风格统一，四视图款式完全一致，除面部/手部/颈部外基本覆盖
- 基础服装仅为安全打底，焦点在面容与气韵

## 七、四视图设定图规范

| 位置 | 视图 | 角度 | 要求 |
|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 头顶至锁骨，面部占60%+，五官淡墨清晰 |
| 左二 | 正视图 | 正面 0° | 全身立像，从头顶到脚底完整展示 |
| 右二 | 侧视图 | 右侧 90° | 全身立像，纯侧面轮廓清晰 |
| 右一 | 后视图 | 后方 180° | 全身立像，后脑/发尾/背部清晰 |

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图，建议 4:1 或 3:1 |
| 背景 | 宣白纯色 #F5F0E6 |
| 站姿/完整性 | 自然站立；全身立像从头到脚、特写从头到锁骨完整入画，严禁裁切 |
| 表情/光线 | 中性微表情；均匀柔光、水墨晕染过渡、无硬阴影 |
| 一致性 | 四视图的肤色/体型/发型/面容/基础服装完全一致 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜状态」 |
| R2 | 必须声明基础服装（女性：素色水墨长裙；男性：素色水墨长衫） |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「宣白纯色背景」与「四视图一致性」 |
| R5 | 必须声明角色身高（女性默认 160-170cm，男性默认 175-185cm） |
| R6 | 全身立像/特写必须完整入画，严禁裁切 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 基础服装以外的任何服装/配饰/妆容 |
| X2 | 正顶硬光/正底光/冷色光 |
| X3 | 西方油画厚涂/素描明暗/写实皮肤质感 |
| X4 | 复杂场景背景（必须纯色） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像/特写裁切头顶或脚底 |
