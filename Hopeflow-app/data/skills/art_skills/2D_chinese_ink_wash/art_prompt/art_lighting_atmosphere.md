# 光影与氛围 · 国风水墨丹青约束手册

> **本画风以"以墨代光"为光影灵魂**：不靠真实光源照明，而靠墨色浓淡与留白构建明度关系——亮部即留白、暗部即浓墨，光影让位于墨韵层次与东方意境。

---

## 一、光源方案

| 方案 | 光源特征 | 墨色/留白建议 | 使用场景 | 提示词 |
|---|---|---|---|---|
| 天光留白 | 漫射天光，亮部即留白 | C1 宣白主导 + C4 淡墨 | 山水、晨景、清远 | 天光漫射、亮部留白、淡墨远山 |
| 月夜清辉 | 墨色渐浓 + 月留白点 | C2 焦墨 + C5 清墨 + 月留白 | 月夜、孤寂、静思 | 月下墨浓、月色留白、清冷意境 |
| 孤灯暖点 | 墨色主体 + 孤灯暖点 | C3 浓墨 + C9 藤黄暖点 | 渔舟、茅舍、夜归 | 孤灯一点、暖色点缀、墨色沉沉 |
| 暮色苍茫 | 墨色渐沉 + 暮霭 | C3 浓墨 + C6 赭石 | 归途、离别、苍茫 | 暮霭沉沉、赭石染暮、墨色苍茫 |
| 雪意留白 | 大幅留白 + 淡墨微痕 | C1 宣白 + C5 清墨 | 雪景、清寂、禅意 | 雪地留白、淡墨微痕、空灵静谧 |
| 云雾缥缈 | 墨晕扩散 + 云气弥漫 | C5 清墨 + C7 花青 | 仙踪、山巅、出尘 | 云雾缥缈、墨晕扩散、清墨氤氲 |

## 二、明度体系（以墨代光）

| 明度层级 | 墨色 | 功能 | 说明 |
|---|---|---|---|
| 亮部 | C1 宣白 / C5 清墨 | 留白即光 | 以纸面留白表现亮部，禁白色高光笔触 |
| 中间调 | C4 淡墨 | 过渡层次 | 由浓到淡自然渗化，禁生硬断层 |
| 暗部 | C3 浓墨 / C2 焦墨 | 墨色即影 | 以墨色浓淡代阴影，禁黑色硬阴影 |
| 点缀 | C8 朱砂等传统色 | 点睛之笔 | 单点少量，提神醒气 |

---

## 三、色温约束（继承 prefix）

| 参数 | 值 |
|---|---|
| 整体色温 | 偏暖米白 4300-4800K（推荐） |
| 对比度 | 低-中 30-50%（建议区间） |
| 饱和度 | 低 15-35%（建议区间） |

> 色相偏移 ±8°、饱和度偏移 ±8%、明度偏移 ±15%。例外镜头（高光时刻）可临时突破局部色彩，但不得突破严禁项。

## 四、色调情绪与画面关键词

| 情绪场景 | 主色 | 辅色 | 画面关键词 |

| 山水清远 | C1 宣白 + C4 淡墨 | C7 花青 + C2 焦墨 | 清远、空灵、旷达 |

## 五、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 每条提示词必须声明「水墨丹青」风格锚定词（继承 R1） |
| R2 | 必须声明「宣纸质感 + 墨色晕染」（继承 R2） |
| R3 | 必须声明「以墨代光」的明度留白体系 |
| R4 | 亮部必须用留白表现，禁白色高光笔触 |
| R5 | 必须绑定 1 个光源方案并指定主辅墨色 |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁高饱和荧光色/霓虹色/数码感光效（继承 X2） |
| X2 | 严禁写实摄影/3D 写实渲染/照片级光效（继承 X1） |
| X3 | 严禁西方油画明暗法/聚光灯舞台光效（继承 X5） |
| X4 | 严禁黑色硬阴影/生硬色块/晕染失控（继承 X4） |
| X5 | 严禁满铺无留白的光氛围（继承 X5） |
