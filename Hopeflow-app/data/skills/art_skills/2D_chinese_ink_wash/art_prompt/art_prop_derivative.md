# 道具衍生状态生成 · 约束手册

---

## 一、衍生原则

1. **造型锚定** — 道具核心造型/轮廓在所有状态中可识别
2. **状态可读** — 状态差异必须一目了然，观众能立即区分
3. **叙事服务** — 每种状态变体服务于特定剧情节点
4. **墨韵逻辑** — 损伤/老化状态以笔墨笔法呈现，符合水墨语境
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现

---

## 二、状态类型

### 2.1 使用状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 新墨 | 笔意崭新、墨色清亮 | 所有道具 | 新墨初成、笔意鲜明 |
| 日常用 | 微磨损、墨色渐润 | 器物/文房/兵器 | 使用痕迹、墨色温润 |
| 古旧 | 明显年代感、泛黄斑驳 | 器物/信物/卷轴 | 纸面泛黄、古旧斑驳 |

### 2.2 损伤状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 微损 | 小裂纹/小缺口/笔痕缺 | 瓷器/玉佩/兵器 | 细微裂纹、笔痕残缺 |
| 破损 | 明显裂缝/断裂/残缺 | 瓷器/卷轴/兵器 | 裂缝明显、断裂残缺 |
| 残片 | 仅剩部分/碎片 | 瓷器/玉佩/信物 | 残片、碎片、仅存半块 |

### 2.3 特殊状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 墨渍 | 墨迹洒染、晕开 | 卷轴/纸张/信物 | 墨渍晕染、墨迹斑斑 |
| 浸水 | 水渍湿润、纸面渗化 | 卷轴/信物/纸张 | 浸水湿润、纸张渗化 |
| 焦损 | 焦黑边缘、火烧痕迹 | 卷轴/信物/木质品 | 边缘焦黑、火烧痕迹 |
| 发光/灵蕴 | 内在灵光、墨韵流转 | 信物/法器/玉石 | 灵光内蕴、墨韵流转 |
| 包裹/封存 | 布/木盒包裹 | 信物/秘物 | 锦布包裹、木盒封存 |

### 2.4 环境适应状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 雪覆 | 积雪覆盖、留白意趣 | 器物/兵器/舟楫 | 雪覆留白、寒意入画 |
| 雨湿 | 雨水湿润、墨色洇开 | 纸/布/木质品 | 雨湿洇墨、水痕斑驳 |
| 苔染 | 青苔斑驳、岁月痕迹 | 山石器物/兵器 | 青苔点染、岁月痕迹 |
| 尘覆 | 积尘蒙灰、模糊轮廓 | 旧物/信物 | 尘覆蒙灰、轮廓朦胧 |

## 三、状态变体画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单状态图：与设定图正面图一致；状态对比图：同画面并排 2-3 种状态 |
| 背景 | 宣白纯色 #F5F0E6（与设定图一致） |
| 光线 | 均匀柔光，水墨晕染过渡，无硬阴影 |
| 比例 | 道具占画面主体 70%+ |
| 一致性 | 对比图角度/光线/背景完全一致，仅状态不同 |

## 四、墨韵状态变化规则

| 材质 | 新墨 → 日常用 | 日常用 → 古旧 | 损伤表现 |
|---|---|---|---|
| 纸卷 | 墨色清亮 → 微泛黄 | 泛黄 → 脆裂 | 撕裂/焦损/墨渍 |
| 陶瓷 | 釉面清润 → 微磨损 | 磨损 → 暗沉 | 裂纹/碎裂/缺口 |
| 木器 | 木纹清晰 → 包浆 | 包浆 → 暗沉 | 开裂/断裂/虫蛀 |
| 金属 | 墨色如新 → 微锈 | 锈蚀 → 斑驳 | 缺口/断裂/卷刃 |
| 玉石 | 温润通透 → 微磨损 | 磨损 → 微裂 | 裂纹/碎裂/缺角 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 道具核心造型/轮廓在所有状态中可识别 |
| R2 | 状态变化须符合水墨语境与物理逻辑 |
| R3 | 必须使用四宫格（2×2）布局：正面 + 侧面 + 背面 + 特写 |
| R4 | 必须指定「宣白纯色背景」，均匀柔光 |
| R5 | 必须包含「水墨丹青 + 写意笔触」关键词 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 状态变化后道具不可识别 |
| X2 | 违反物理逻辑的损伤（玉石生锈等） |
| X3 | 过度血腥/恐怖的损伤描绘 |
| X4 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X5 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X6 | 出现暗示人物存在的元素（如手持痕迹、佩戴视角、使用姿态） |
