# 道具图像生成 · 约束手册

---

## 一、道具设计原则

1. **功能可读** — 道具用途一目了然，造型服务于功能
2. **笔意传质** — 材质以笔墨笔法呈现，皴擦点染传达质感
3. **水墨一致** — 所有道具符合水墨世界观，禁现代工业元素
4. **尺度明确** — 通过参照物或标注暗示道具真实尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现

## 二、道具分类与美学约束

### 2.1 文房类

| 项目 | 约束 | 提示词 |
|---|---|---|
| 类型 | 笔/墨/纸/砚/镇纸/笔架 | {文房类型}，水墨文房 |
| 材质 | 竹/木/玉/石/陶瓷 | 竹制笔杆、瓷质砚台 |
| 质感 | 简笔勾勒、墨色点缀 | 笔毫如墨、砚台温润 |
| 点缀 | 朱砂印章可点睛 | 朱砂点印、气韵生动 |

### 2.2 古器物类

| 项目 | 约束 | 提示词 |

| 质感 | 皴擦表现粗糙、勾勒表现轮廓 | 皴擦质感、线条勾勒 |
| 风格 | 水墨写意 | 淡墨点染、写意呈现 |

### 2.3 山水意象类

| 项目 | 约束 | 提示词 |
|---|---|---|
| 类型 | 折扇/灯笼/笛箫/蓑笠/舟楫 | {意象道具}，山水意象 |

| 点缀 | 可加朱砂/藤黄小点 | 缀色轻点、提神醒气 |

### 2.4 兵器类

| 项目 | 约束 | 提示词 |

### 2.5 自然意象类

| 项目 | 约束 | 提示词 |

## 三、多角度设定图规范

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构/装饰 | back view |
| 右下 | 细节特写 | 局部放大 | 笔触纹理/工艺细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 宣白纯色 #F5F0E6 |
| 光线 | 均匀柔光，水墨晕染过渡，无硬阴影 |
| 比例 | 每格道具占格内主体 70%+ |
| 投影 | 允许极淡墨色投影 |
| 画面比例 | 建议 1:1 |

## 五、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「宣白纯色背景」 |
| R2 | 必须明确道具类型与笔法表现 |
| R3 | 道具造型必须符合水墨世界观 |
| R4 | 必须为「四宫格」布局：正面 + 侧面 + 背面 + 特写 |
| R5 | 必须包含「水墨丹青 + 写意笔触」关键词 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 道具与人物同画面（本环节为纯道具图） |
| X3 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X4 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X5 | 出现暗示人物存在的元素（如手持痕迹、佩戴视角、使用姿态） |
| X6 | 现代工业元素出现在水墨道具中 |
