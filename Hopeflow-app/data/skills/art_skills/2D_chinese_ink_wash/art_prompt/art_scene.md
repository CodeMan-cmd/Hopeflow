# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，景即情、情即景
2. **留白纵深** — 以留白与墨色浓淡构建纵深，近实远虚
3. **墨韵至上** — 山石皴法、云气晕染、水面留白，笔笔见墨韵
4. **写意为锚** — 一切画面以水墨写意为标准，拒绝写实/CG/油画质感

| 季节 | 主色 | 辅色 | 提示词 |

| 春 | C1 宣白 + C8 朱砂 | C10 石绿 + C9 藤黄 | 桃红点点、淡墨新绿 |
| 夏 | C1 宣白 + C3 浓墨 | C10 石绿 + C7 花青 | 墨荷碧叶、浓荫如墨 |
| 秋 | C6 赭石 + C4 淡墨 | C9 藤黄 + C2 焦墨 | 赭石染秋、黄叶飘零 |
| 冬 | C1 宣白 + C5 清墨 | C2 焦墨 + C7 花青 | 雪留白意、枯枝寒墨 |

## 三、场景类型

### 3.1 山水类

| 维度 | 约束 | 提示词 |
|---|---|---|
| 类型 | 层峦/飞瀑/江畔/孤峰 | {山水类型}，水墨山水 |
| 笔法 | 皴法山石、墨叶点染 | 披麻皴、点苔、墨韵层次 |
| 留白 | 云气水面大幅留白 | 云气留白、水天一色 |
| 纵深 | 近实远虚、淡墨远山 | 近浓远淡、远山如黛 |
| 意象 | 孤舟/飞鸟/渔翁可入画 | 孤舟横渡、飞鸟几点 |

### 3.2 园林屋舍类

| 维度 | 约束 | 提示词 |
|---|---|---|
| 类型 | 亭台/草堂/书斋/竹篱 | {屋舍类型}，水墨园林 |
| 笔法 | 屋宇简笔勾勒、芭蕉竹石点染 | 简笔屋宇、竹影墨叶 |
| 留白 | 院墙月门留白借景 | 月门借景、留白通透 |
| 氛围 | 隐逸雅致、烟火清淡 | 隐逸之气、清净雅致 |

### 3.3 气象类

| 维度 | 约束 | 提示词 |
|---|---|---|
| 类型 | 烟雨/云雾/雪景/月夜/暮霭 | {气象}，水墨气象 |
| 雨 | 雨丝淡墨、晕染迷蒙 | 烟雨迷蒙、雨丝如墨 |
| 雾 | 清墨氤氲、渗化弥漫 | 云雾氤氲、清墨弥漫 |
| 雪 | 大块留白、淡墨微痕 | 雪意留白、淡墨轻扫 |
| 月 | 墨浓月白、对比清冷 | 墨色沉沉、月留白处 |

## 四、主视图规范

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 平远/深远/高远三远法取景 | hero shot、representative angle |
| 视点 | 默认人眼平视高度 | eye level（默认） |
| 构图 | 留白疏朗、三段式山水 | balanced composition、negative space |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/笔法/墨色/光线统一 |
| 光线 | 以墨代光，明度留白逻辑一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中远景墨色层次」 |
| R2 | 山水场景必须使用三远法或散点透视 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示墨色层次与留白 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含水墨丹青关键词（ink wash painting / rice paper texture） |
| R7 | 必须包含墨韵特征（写意笔触 / 浓淡干湿 / 以墨代光） |
| R8 | 必须包含留白意境，禁止满铺无留白 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无墨色层次 |
| X4 | 植被/气象与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 写实/CG/油画/水彩水粉质感（禁用 3D render、CGI、Unreal Engine 等词） |
| X8 | 墨色混浊无层次、死黑一团 |
| X9 | 满铺无留白、无晕染、无笔触特征 |
