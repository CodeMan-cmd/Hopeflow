# 场景衍生资产生成 · 约束手册

---

## 一、衍生原则

1. **空间一致** — 山势/建筑结构/布局/墨色基调在所有变体中保持一致
2. **景别驱动** — 同一场景通过不同景别展示不同叙事功能
3. **时段切换** — 同一空间在不同时段呈现不同墨色浓淡
4. **天候变化** — 同一空间在不同天气下呈现不同墨韵情绪
5. **写意为锚** — 所有变体必须保持水墨写意质感，拒绝写实/CG/油画感

---

## 二、景别变体

| 景别 | 范围 | 叙事功能 | 提示词 |
|---|---|---|---|
| 大全景 | 场景全貌 + 留白大境 | 建立空间感、定位 | extreme wide shot、墨色大境 |
| 全景 | 场景完整呈现 | 展示空间结构 | wide shot、全景 |
| 中景 | 场景局部区域 | 聚焦功能区 | medium shot、中景 |
| 近景 | 场景细部 | 笔触/氛围道具特写 | close shot、近景 |
| 特写 | 极局部细节 | 皴法纹理/关键意象 | extreme closeup、特写 |

### 景别衍生规范

| 从基准图衍生 | 保持不变 | 允许变化 |
|---|---|---|
| 大全景 → 全景 | 山势、整体布局 | 视角收窄、留白减少 |
| 全景 → 中景 | 笔法、墨色、光线 | 裁切聚焦、墨色微调 |
| 中景 → 近景 | 笔法、墨色 | 细节强化、留白简化 |
| 近景 → 特写 | 皴法纹理 | 极近观察、笔触清晰 |

---

## 三、时段变体

| 时段 | 视觉特征 | 提示词 |
|---|---|---|
| 清晨 | 清墨弥漫、淡墨远山 | 晨雾清墨、淡墨微染 |
| 正午 | 墨色清朗、留白明亮 | 天光留白、墨色清朗 |
| 黄昏 | 赭石染暮、墨色渐沉 | 暮色赭染、墨色苍茫 |
| 月夜 | 墨色浓厚、月留白点 | 月色留白、墨色沉沉 |
| 雪夜 | 大块留白、枯墨微痕 | 雪夜留白、枯墨清寂 |

### 时段衍生规范

| 从基准时段衍生 | 保持不变 | 变化项 |
|---|---|---|
| 日间 → 黄昏 | 山势/布局/笔法 | 赭石染暮、墨色加深 |
| 日间 → 月夜 | 山势/布局/笔法 | 墨色浓厚、月留白点 |
| 日间 → 雪夜 | 山势/布局 | 留白扩大、枯墨微痕 |

---

## 四、天候变体

| 天候 | 视觉特征 | 提示词 |
|---|---|---|
| 晴 | 留白明亮、墨色清透 | 晴空留白、墨色清透 |
| 阴 | 墨色均匀、层次柔和 | 阴天淡墨、层次柔和 |
| 雾 | 清墨弥漫、渗化朦胧 | 雾锁清墨、渗化朦胧 |
| 雨 | 雨丝淡墨、晕染迷蒙 | 烟雨晕染、雨丝如墨 |
| 雪 | 留白覆盖、淡墨微痕 | 雪意留白、淡墨轻扫 |

### 天候衍生规范

| 从基准天候衍生 | 保持不变 | 变化项 |
|---|---|---|
| 晴 → 雾 | 山势/布局 | 清墨弥漫、渗化朦胧 |
| 晴 → 雨 | 山势/布局 | 雨丝淡墨、晕染迷蒙 |
| 晴 → 雪 | 山势/布局 | 留白扩大、枯枝霜痕 |

## 五、角度变体

> 衍生图相对参考图，可在以下角度维度上切换。调用方会传入参考图 + 目标角度描述，本文件只定义角度语汇与一致性约束。

| 角度 | 描述 | 提示词 |
|---|---|---|
| 正面/前视 | 视线朝向场景正面 | front view、eye level |
| 侧面（左/右） | 朝场景左/右侧 90° 平视 | left side view / right side view |
| 背面/后视 | 朝场景背面 180° | back view |
| 俯瞰 | 高位俯瞰，一览山水全局 | high angle、bird's eye view |
| 仰观 | 低位仰望，高远取势 | low angle、high-distance view |
| 近景推进 | 同方向推进，聚焦局部 | push-in、closer angle |
| 自由角度 | 调用方自定义角度 | 按 `{目标角度}` 注入 |

### 角度衍生规范

| 项目 | 约束 |
|---|---|
| 参考一致性 | 山势/建筑结构/布局/笔法/墨色/光线必须与参考图一致 |
| 视点 | 同一场景中心点，仅角度切换 |
| 光照逻辑 | 以墨代光明度逻辑不变，角度切换后墨色浓淡同步重算 |
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景空间结构与墨色基调在所有变体中保持一致 |
| R2 | 时段变体必须调整墨色浓淡与留白 |
| R3 | 天候变体必须适配笔法与留白表现 |
| R4 | 衍生图必须为「单画面」，不得拼接多视图/网格/分屏 |
| R5 | 衍生图必须与参考图保持结构/笔法/墨色一致，仅按指定角度切换视点 |
| R6 | 场景图中**严禁出现任何人物** |
| R7 | 根据用户提供的信息自行判断变化维度，未提及维度留空省略 |
| R8 | 必须包含水墨丹青关键词（ink wash painting / rice paper texture） |
| R9 | 必须包含墨韵特征（写意笔触 / 浓淡干湿 / 以墨代光） |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 变体间山势/建筑结构/布局不一致 |
| X2 | 天候与季节矛盾（夏天飞雪等） |
| X3 | 变体间笔法/墨色突变 |
| X4 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X5 | 画面被拼接成多视图/网格/分屏布局 |
| X6 | 写实/CG/油画/水彩水粉质感（禁用 3D render、CGI 等词） |
| X7 | 墨色混浊无层次、死黑一团 |
| X8 | 满铺无留白、无晕染、无笔触特征 |
