# 视频提示词 · 视觉风格约束

生成视频提示词时，必须注入以下视觉风格标签：

| 模式 | 风格标签 |
|------|----------|
| **通用多参模式（英文）** | `Chinese ink wash animation, ink painting style, rice paper texture, brush ink diffusion, negative space composition, ethereal oriental mood` |
| **通用首尾帧模式（英文）** | `Chinese ink wash animation, ink painting style, rice paper texture, brush ink diffusion, negative space composition, ethereal oriental mood, smooth ink transition` |
| **Seedance 2.0（中文）** | `水墨丹青动画，水墨写意，宣纸质感，墨色晕染，留白意境，浓淡干湿，飘逸空灵` |

> **风格标签行**：无论多参/首尾帧/Seedance 何种模式，画面描述中必须保留一行完整风格标签（水墨丹青动画，水墨写意，宣纸质感，墨色晕染，留白意境，浓淡干湿，飘逸空灵）。

---

## 一、动态墨韵注入

水墨动画的灵魂在于"墨在动"。视频提示词必须在画面描述中注入动态墨韵元素：

| 动态类型 | 提示词 | 适用 |
|---|---|---|
| 墨晕扩散 | 墨色在宣纸上缓缓晕开、晕染扩散 | 转场、情绪点、记忆闪回 |
| 云气流动 | 云雾在留白处缓缓流动、聚散离合 | 山水空镜、仙踪场景 |
| 笔势游走 | 线条如行笔般游走、墨随笔势 | 场景建立、意象浮现 |
| 飞白扫过 | 枯笔飞白扫过纸面 | 疾风、落叶、情绪转折 |
| 墨滴入水 | 一滴墨落入清水、缓缓化开 | 片头、章节开场 |

## 二、分镜视频通用模板（中文）

```
水墨丹青动画，水墨写意，宣纸质感，墨色晕染，留白意境，浓淡干湿，飘逸空灵，
{景别}，{运镜：如缓缓横移/缓慢推近}，
{画面主体与动作描述}，
{墨色层次描述：如远山淡墨、近树浓墨}，
{留白描述}，{动态墨韵元素}，
{情绪关键词}，写意笔触，气韵生动，
水墨动画电影质感，画面无字幕、无水印、无标题叠字
```

## 三、转场墨韵处理

| 转场类型 | 提示词 |
|---|---|
| 墨晕转场 | 画面化作一滴墨晕开、淡出至宣白 |
| 云遮转场 | 云雾涌起遮住画面、再散开进入下一幕 |
| 留白转场 | 画面渐隐入大面积留白、气息停顿 |
| 笔势转场 | 线条如一笔挥过、画面被笔势带走 |

## 四、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须注入水墨风格标签（多参/首尾帧/Seedance 三选一） |
| R2 | 每段画面必须声明墨色层次与留白 |
| R3 | 转场必须使用水墨式转场（墨晕/云遮/留白/笔势） |
| R4 | 运镜须缓慢克制，如行笔般从容 |
| R5 | 必须声明「水墨动画电影质感」 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 快速甩镜/急推/手持晃动 |
| X2 | 写实摄影/3D 渲染/照片级画面 |
| X3 | 荧光色/霓虹/数码特效光效 |
| X4 | 画面满铺无留白、墨色混浊 |
| X5 | 西式转场（划屏/旋转/百叶窗） |

## 五、运镜节奏建议

| 节奏类型 | 建议 | 适用 |
|---|---|---|
| 缓推 | 如行笔般徐徐推近，突出情绪 | 人物特写、情绪点 |
| 横移 | 横向缓慢移动，如画卷展开 | 场景建立、山水空镜 |
| 上移 | 纵向缓慢上移，留白渐显 | 山势展现、意境收束 |
| 静帧 | 长时间静帧 + 墨韵流动 | 留白呼吸、情绪停顿 |
| 拉远 | 缓缓拉远，画面归于留白 | 章节收尾、余韵 |

- 全片运镜基调为「缓」：单镜头运镜以慢为主，忌快忌晃
- 情绪高潮可适度加快至「缓中带势」，但不得突破水墨行笔气韵
- 转场前 1-2 秒放慢运镜，为墨晕/云遮转场留出余韵
