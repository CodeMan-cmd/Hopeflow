# 材质与质感 · 国风水墨丹青约束手册

> **本画风质感锚定于"宣纸墨韵 + 笔墨笔触"**：一切材质以水墨笔法呈现，笔触渗化、飞白枯润，禁写实材质、禁塑料感、禁油画厚涂。

---

## 一、渲染质感描述

| 项目 | 约束 | 说明 |
|---|---|---|
| 基底质感 | 宣纸肌理 + 水墨晕染 | 纸面微有纤维纹理，墨色渗入纸中 |
| 笔触质感 | 写意笔触、浓淡干湿 | 行笔有势，笔断意连，禁均匀平涂 |
| 墨色层次 | 焦浓重淡清五级 | 由浓到淡自然渗化，禁生硬断层 |
| 材质精度 | 以笔法传质感 | 山石皴法、树干勾勒、水面波纹笔 |
| 表面处理 | 飞白留痕 | 枯笔飞白、渗化边缘，非光滑非写实 |

## 三、画质硬约束

| 维度 | 等级要求 | 说明 |
|---|---|---|
| 笔触 | 写意流畅、笔势连贯 | 禁断线毛边、禁均匀涂鸦感 |
| 墨色 | 五色层次分明 | 焦浓重淡清过渡自然，禁死黑/灰雾 |
| 细节等级 | 简而传神 | 以笔法传神不堆细节，禁低精度糊弄 |
| 晕染 | 自然渗化 | 边缘有渗化墨痕，禁生硬色块 |
| 一致性 | 全画面统一 | 水墨写意审美全局统一（继承 X5） |

## 五、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「水墨丹青」风格锚定词（继承 R1） |
| R2 | 必须声明「宣纸质感 + 墨色晕染」（继承 R2） |
| R3 | 必须声明「写意笔触 + 皴法墨韵」（继承 R4） |
| R4 | 材质必须用笔墨笔法呈现，禁写实材质渲染 |
| R5 | 必须声明「浓淡干湿 + 留白意境」（继承 R3） |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁写实摄影/3D 写实渲染/照片级材质（继承 X1） |
| X2 | 严禁高饱和荧光色/霓虹色/数码感材质（继承 X2） |

| X5 | 严禁粗劣线条/笔触生硬/低精度（继承 X6） |
