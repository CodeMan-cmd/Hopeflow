# 材质与质感 · 约束手册

---

## 一、渲染质感描述

1. **黏土肌理** — 表面呈现黏土捏塑的颗粒肌理，材质细节清晰可见，拒绝光滑 CG 表面
2. **手指压痕可见** — 捏塑痕迹、指腹按压纹理保留，强调手工制作感
3. **奇幻 3D 卡通** — 造型走奇幻卡通路线，形体圆润可爱，但保持定格黏土的手工语言
4. **暖调哑光** — 材质在暖光下呈温润哑光质感，禁止塑料反光与油腻高光

## 二、材质锚词清单

| 部位 | 锚词（中） | 锚词（英） |
|---|---|---|
| 黏土本体 | 黏土肌理、材质颗粒感 | clay texture、grainy clay surface |
| 手工痕迹 | 手指压痕、捏塑痕迹 | finger prints、hand-sculpted marks |
| 面部 | 3D 卡通脸、柔和五官 | 3D cartoon face、soft features |
| 发丝 | 黏土造型发、手工发束痕迹 | clay hair、sculpted hair strands |
| 服饰 | 黏土布料质感、褶皱捏塑感 | clay fabric、sculpted folds |
| 道具/场景 | 黏土材质、拼贴质感 | clay props、handmade set |
| 整体 | 手工质感、材质颗粒 | handcrafted feel、material grain |

## 三、画质硬约束

| 参数 | 硬约束 |
|---|---|
| 分辨率 | 8K 超高清渲染 |
| 材质特征 | 黏土肌理清晰、手指压痕可见 |
| 表面处理 | 温润哑光，禁止光滑塑料反光 |
| 纹理 | 材质颗粒感细腻可辨 |
| 光照 | 暖调光影层次、柔和浅景深 |
| 色彩 | 中低饱和 60-75%，色盘 C1-C10 内取色 |

---

## 四、必守

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「定格动画风格 + 黏土质感」风格锚定词 |
| R2 | 必须声明「手指压痕可见 + 黏土肌理材质」 |
| R3 | 面部必须声明「3D 卡通角色 + 柔和浅景深」 |
| R4 | 发丝必须声明「黏土造型 + 手工痕迹保留」 |
| R5 | 材质锚词至少选用黏土本体/手工痕迹/发丝中两类 |

## 五、严禁

| 编号 | 严禁 |
|---|---|
| X1 | 现代3D动画风格/皮克斯/迪士尼后期质感 |
| X2 | 光滑塑料/现代 CG 渲染表面 |
| X3 | 高饱和荧光色/霓虹色材质 |
| X4 | 低精度建模/粗糙贴图/纹理模糊 |
| X5 | 面部变形/比例失调/肢体异常 |
| X6 | 现代材质元素（金属拉丝/钢化玻璃等） |
