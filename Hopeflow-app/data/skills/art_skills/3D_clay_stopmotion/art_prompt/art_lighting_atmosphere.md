# 光影与氛围 · 约束手册

---

## 一、光影基调

1. **电影感光影层次** — 以定格动画电影的布光为基准，暖调主导，明暗层次细腻
2. **暖调治愈** — 光色以奶油黄/琥珀暖/暖橙为主轴，氛围温暖怀旧，拒绝冷灰阴郁
3. **柔和浅景深** — 布光配合浅景深，前后景柔化，突出黏土主体的手工质感
4. **手工光感** — 光需照亮黏土肌理与手指压痕，呈现棚拍定格动画的细腻质感

---

## 二、光源方案

| 编号 | 光源类型 | 作用 | 提示词 |
|---|---|---|---|
| L1 | 暖调主光 | 奠定温暖基调，柔和铺光 | soft warm key light、奶油黄主光 |
| L2 | 补光 | 填充黏土暗部，保留肌理 | gentle fill light、柔和补光 |
| L3 | 轮廓光 | 勾勒黏土形体轮廓 | warm rim light、暖色轮廓光 |
| L4 | 烛火/炉火光 | 室内暖光、怀旧氛围 | 烛光暖调、炉火摇曳光 |
| L5 | 魔法氛围光 | 奇幻场景光点光晕（C6 淡紫） | 魔法光点、彩色光晕 |
| L6 | 黄昏/夕阳 | 暖橙逆光，温馨感 | 夕阳暖光、金色逆光 |

---

## 三、光比与明暗对比

| 参数 | 约束值 | 说明 |
|---|---|---|
| 光比 | 中等光比为主 | 明暗层次清晰，但不过分强烈 |
| 对比度 | 中等（建议保持） | 保留黏土材质颗粒过渡 |
| 阴影 | 柔和阴影 | 暗部保留肌理细节，禁止死黑 |
| 高光 | 柔和高光 | 黏土表面温润反光，禁油腻镜面 |
| 层次 | 前中后景光感分层 | 配合浅景深柔化背景 |

## 四、色温范围

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 4500-5000K（推荐） | 温暖怀旧主基调 |
| 肤色色温 | 微暖 4800-5200K（推荐） | C1 奶油黄 #F5E6D0 有生命感 |
| 夜晚场景 | 冷调打底 5500-6500K + 暖光点缀 | C6 淡紫 + 暖色灯光点缀 |

| 情绪场景 | 主色 | 辅色 | 氛围关键词 |

| 心动瞬间 | C2 陶土红 #C96E5A | C10 暖橙 #E8C890 | 中近景提暖、肤色微红、暧昧 |
| 奇幻魔法 | C6 淡紫 #D0C4D6 | C7 琥珀暖 #C9A96E | 魔法光点、彩色光晕、梦幻神秘 |
| 户外自然 | C8 薄荷绿 #9DC2A5 | C1 奶油黄 #F5E6D0 | 自然暖调、清新开阔 |

| 夜晚梦境 | C6 淡紫 #D0C4D6 | C3 天空蓝 #87AEC9 | 冷调为主、暖色点缀、静谧 |

## 六、必守

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「电影感光影层次 + 暖调主导」 |
| R2 | 光须照亮黏土肌理与手指压痕 |
| R3 | 必须包含「柔和浅景深」光影氛围 |
| R4 | 每镜头绑定情绪场景主色+辅色 |
| R5 | 光源方案至少声明主光+补光 |

## 七、严禁

| 编号 | 严禁 |
|---|---|
| X1 | 现代3D动画风格打光（皮克斯/迪士尼后期） |
| X2 | 光滑塑料反光/现代 CG 渲染光感 |
| X3 | 高饱和荧光色/霓虹色光效 |
| X4 | 暗调压抑/恐怖片式硬光 |
| X5 | 无光影层次、平光死白 |
| X6 | 现代场景/现代建筑光源元素 |
