# 材质与质感 · 约束手册（真人都市写实）

> 质感来自「真人写实摄影」的光学记录——皮肤看得到毛孔与绒毛、针织衫看得出绒感、咖啡杯沿留着唇印、桌面有生活的痕迹。一切材质都必须真实、现代、被使用过，杜绝塑料感与AI假面。

---

## 一、摄影质感描述（替代渲染术语）

| 质感域 | 摄影表达 | 禁止的渲染表达 |
|---|---|---|
| 皮肤 | 可见毛孔、细纹、自然血色、微瑕 | 光滑、完美肌肤、蜡像质感 |
| 发丝 | 根根分明、自然蓬松或垂落、层次清晰 | 建模发块、假发感 |
| 面料 | 纹理可辨（针织绒感/棉麻肌理/皮质纹路）、褶皱符合动态 | 无缝贴图、样板衣 |
| 环境 | 墙面使用痕迹、地面磨损、玻璃反射与指纹 | 全新道具感、样板间 |
| 器物 | 手机屏幕反光、咖啡杯水汽、物件日常损耗 | 出厂新物、无痕道具 |

## 二、材质锚词清单（可直接注入提示词）

| 材质 | 中文锚词 | 英文锚词 |
|---|---|---|
| 针织/毛衣 | 绒感、肌理、垂坠 | knit texture, soft wool |
| 棉麻衬衫 | 棉麻肌理、自然褶皱 | cotton texture, natural wrinkles |
| 皮质 | 纹路、使用折痕 | leather grain, creases |
| 玻璃 | 反射、水汽、指纹 | glass reflections, mist |
| 金属（不锈钢/铝合金） | 冷银灰、拉丝、氧化 | brushed metal, oxidation |
| 木质/家居 | 木纹、哑光、生活痕迹 | wood grain, matte |
| 屏幕 | 反光、指纹、亮面 | screen glare, fingerprints |

> 材质色值锚定：暖色材质用 C7 琥珀暖 #C9A96E、C10 米灰 #E5DED3；冷色材质用 C5 高级灰 #8A8A8A、C6 冷蓝 #5E7485、C8 金属银 #C0C7CE。

## 三、画质硬约束

| 编号 | 约束 |
|---|---|
| H1 | 皮肤必须「真人真实感」：细腻但保留毛孔纹理，禁磨皮/蜡像/塑料感 |
| H2 | 发丝必须「根根分明 + 发丝细腻渲染」（R4） |
| H3 | 面料/器物/墙面必须「纹理细节超清晰」（R5） |
| H4 | 现代道具须有真实使用感：手机反光、杯沿痕迹、桌面散落 |
| H5 | 严禁 AI 感：过度锐化、塑料光泽、对称完美、无生活气息 |

## 四、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「真人写实摄影」锚定词 |
| R2 | 必须声明「强对比度 + 极致细节」 |
| R3 | 面部必须「面容细腻渲染 + 皮肤细腻」且保留毛孔微质感 |
| R4 | 服饰必须指定真实现代材质锚词（针织/棉麻/皮质等），禁无质感色块 |
| R5 | 环境必须带使用痕迹，禁样板间式干净 |

## 五、严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 卡通/动漫/插画质感（赛璐璐色块、描边、平面贴图感） |
| X2 | 高饱和荧光色/霓虹材质/电子合成色 |
| X3 | 古风/古装/传统建筑材质（绸缎汉服、油纸伞、青瓦木构） |
| X4 | 过度磨皮塑料感、零毛孔蜡像脸、AI 假面、对称僵笑 |
| X5 | 低分辨率/模糊/噪点爆炸/严重伪影/抠图白边/拼接断层 |
