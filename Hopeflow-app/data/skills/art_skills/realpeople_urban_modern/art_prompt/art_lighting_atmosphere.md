# 光影与氛围 · 约束手册（真人都市写实）

> 都市的光是生活的光——清晨窗光落在餐桌上、台灯在深夜圈出暖岛、霓虹夜景在街头流转。整体偏暖 5200-5800K 的现代主基调，强对比度明暗鲜明，氛围直白温暖、现代生活感，甜宠向以「冷底 + 暖点」承载心动。

---

## 一、光源方案（按场景与情绪取用）

| 编号 | 光源 | 色温区间 | 光质特征 | 适用场景 |
|---|---|---|---|---|
| L1 | 日光（窗光/天光） | 5200-5800K | 暖白通透、窗光柔化、阴影柔和 | 居家、咖啡厅、办公窗边 |
| L2 | 台灯/落地灯 | 2700-3200K | 暖调点光源、暗部丰富、圈出暖岛 | 深夜独白、居家对话、阅读 |
| L3 | 街灯/路灯 | 2800-4000K | 暖橙或暖白、夜色包裹 | 街头漫步、夜晚归家、相遇 |
| L4 | 霓虹夜景 | 冷蓝 C6 #5E7485 托举 | 暖光源主导、背景冷色托举 | 都市夜生活、商圈、约会 |
| L5 | 屏幕光（手机/电脑） | 冷白或暖白面光 | 照亮一侧脸颊、现代生活符号 | 办公、独处、睡前 |

> 光源使用规则：单镜头主光源不超过 1 个；霓虹/屏幕光只作背景或辅助，禁作人物主光；所有光须有物理出处。

## 二、光比与明暗对比

| 参数 | 约束 | 说明 |
|---|---|---|
| 对比度 | 强（必守 R2） | 明暗反差鲜明，现代高级调 |
| 高光 | 不过曝死白 | 保留层次，禁廉价滤镜感 |
| 暗部 | 保留细节 | 禁死黑无层次 |
| 饱和度 | 中低 40-60% | 现代高级色调，禁荧光 |

## 三、色温范围（对齐 prefix 全局色彩盘）

| 维度 | 基准 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 5200-5800K | 温暖现代主基调 |
| 肤色色温 | 微暖 5200-5600K | 暖白但有生命感 |
| 暖光落点 | C7 琥珀暖 #C9A96E | 台灯/夕照/暖光灯 |
| 冷光落点 | C6 冷蓝 #5E7485 | 夜晚背景、窗外光、屏幕冷光 |

## 四、色调情绪与画面关键词

| 情绪场景 | 光配方 | 画面关键词 |
|---|---|---|
| 初次相遇 | 冷基底 + 局部暖光，强对比不过曝 | 自然、生活感、偶遇 |
| 心动信号 | 中近景提暖，肤色微升温，背景低饱和 | 温暖、靠近感、暧昧 |
| 工作场景 | 明暗层次清晰，灰色调为主 | 专业、克制、距离感 |
| 冲突争执 | 整体降饱和，冷暖反差拉大，阴影加深 | 紧张、对抗、距离 |
| 约会甜蜜 | 局部提饱和，暖光强调亲密（禁荧光） | 浪漫、亲密、心动 |
| 夜生活 | 暖光源主导，背景冷色托举，保留暗部 | 霓虹、都市、节奏感 |

## 五、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「真人写实摄影」锚定词 + 指定光源出处（窗/台灯/街灯/屏幕） |
| R2 | 必须声明「强对比度 + 极致细节」 |
| R3 | 甜宠向默认「冷底 + 暖点」：冷色铺底，暖光落人物关系焦点 |
| R4 | 高光保留层次、暗部保留细节，禁过曝死白与死黑 |
| R5 | 单镜头主色不超过 2 个，情绪切换先调光比色温再调饱和度 |

## 六、严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 卡通/动漫/二次元/插画光效（描边、赛璐璐色块、轮廓光） |
| X2 | 高饱和荧光色/霓虹溢色/死亡芭比粉/廉价滤镜感 |
| X3 | 古风/古装/汉服/传统建筑光环境（烛火油灯、宫灯） |
| X4 | 过度磨皮塑料感、蜡像脸、AI 假面（光越柔越要保留皮肤纹理） |
| X5 | 无源均匀光、全局亮、正顶硬光/正底光/彩色光 |
