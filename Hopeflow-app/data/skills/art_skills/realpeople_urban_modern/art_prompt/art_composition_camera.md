# 构图与镜头 · 约束手册（真人都市写实）

> 镜头是都市叙事的眼睛——固定机位记录生活本真、手持微晃带进呼吸、长焦窥视隔桌望见心动。构图服务于「直白温暖」的甜宠表达：人物在空间里自然存在，不摆拍、不炫技，画面现代、明亮、有生活气。

---

## 一、景别体系

| 景别 | 叙事功能 | 都市写实特征 |
|---|---|---|
| 大特写 | 情绪爆发点 | 眼神、指尖、咖啡杯沿、手机屏幕 |
| 近景 | 情感凝视 | 面部微表情、甜宠心动时刻 |
| 中近景 | 互动与对话 | 腰部以上，咖啡厅对坐、街头并肩 |
| 中景 | 人物关系 | 办公室、居家空间的人物关系 |
| 全景 | 环境氛围 | 商场、街道、人物的融入感 |
| 空镜 | 情绪缓冲 | 无人物，城市生活细节留白 |

## 二、机位与视角（摄影机语法）

| 手法 | 视觉心理 | 都市写实使用场景 |
|---|---|---|
| 固定机位 | 冷静观察、生活本真 | 居家日常、办公、空镜 |
| 手持微晃 | 在场感、情绪介入 | 街头行走、心动靠近、情绪起伏 |
| 稳定器/滑轨 | 流畅流动、空间交代 | 人物登场、商场漫步、场景过渡 |
| 长焦窥视 | 拉近情感、隔景观察 | 隔着人群/咖啡杯望见对方 |
| 俯拍 | 温柔俯瞰、日常细节 | 桌面特写、低头微笑、餐点俯视 |
| 仰拍 | 现代建筑感、人物挺拔 | 写字楼仰角、人物力量感 |

## 三、构图法则

| 法则 | 应用 | 提示词示例 |
|---|---|---|
| 三分法 | 人物置交点，都市空间留白 | 三分法构图、人物居画面一侧 |
| 框架构图 | 门窗/玻璃/楼梯/货架套住人物 | 以落地窗为前景框架 |
| 引导线 | 街道、扶梯、轨道延伸牵引视线 | 街道纵深引导视线 |
| 前景虚化 | 人群/绿植/咖啡杯做前景 | 前景人群虚化 |
| 平视亲近 | 与人物同高的平视机位，甜宠亲近感 | 平视视角、亲密自然 |

## 四、镜头语言

- 推：从环境推入人物近景，情绪靠近
- 拉：人物走远，镜头拉开，生活留白
- 摇：横摇扫过咖啡厅/办公室，交代空间
- 焦点偏移：前景虚化 → 人物清晰，心动递进
- 主观视点：模拟人物所见，代入感强（看向对方、望向窗外）

## 五、中文提示词模板

```
真人写实摄影，都市写实纪实，强对比度，极致细节，
{景别}，{机位手法}，{构图法则}，
{光源与色温：如窗光暖白5200K/台灯暖光}，
{现代都市空间：办公室/咖啡厅/居家/街头/商场}，
{人物情绪与关系}，甜宠氛围，直白温暖，现代生活感，
平视视角，浅景深/深景深（按叙事选择），
面容细腻渲染，皮肤细腻，发丝根根分明，纹理细节超清晰
```

## 六、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「真人写实摄影」锚定词 + 指定景别与机位 |
| R2 | 必须声明「强对比度 + 极致细节」 |
| R3 | 构图须有都市空间感：框架/引导线/前景虚化/平视择一 |
| R4 | 机位须有叙事意图：固定/手持/稳定器/长焦/俯仰/焦点偏移择一 |
| R5 | 人物自然体态、非僵硬摆拍，画面禁文字水印 |

## 七、严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 卡通/动漫/二次元分镜感（广角夸张透视、鱼眼畸变） |
| X2 | 古风/古装/汉服/传统建筑构图元素 |
| X3 | 赛博朋克/科幻/异世界架空都市 |
| X4 | 人物面部变形/多指/肢体异常/恐怖谷 |
| X5 | 人物正对镜头僵硬摆拍、对称傻站、模特感 |
