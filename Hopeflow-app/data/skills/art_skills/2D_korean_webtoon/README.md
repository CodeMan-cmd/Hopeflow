# 韩漫条漫风格说明

本风格专为"韩漫条漫"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **韩式言情漫画**：以韩国 webtoon（条漫）为载体的言情漫画风格，涵盖现代都市、校园青春、奇幻言情等题材
- **高颜值精致五官**：大眼长睫、精致脸型、完美肌肤，强调"颜值经济"的视觉魅力
- **细腻渐变上色**：柔和渐变代替硬色块，头发/皮肤/衣物的过渡自然通透
- **柔光氛围**：柔和光源、梦幻光晕、浪漫氛围感，情绪张力拉满
- **条漫竖屏构图**：webtoon format 垂直分镜，画面纵向延展、阅读节奏明快
- **浪漫言情基调**：心动、甜蜜、治愈、虐恋的言情情绪贯穿始终

## 适用范围

- 韩漫条漫题材的AI美术生成（角色、场景、道具、分镜等）
- 需要高颜值、柔光氛围、竖屏条漫构图的视觉创作
- 现代都市/校园/奇幻言情漫画、短剧、插画创作

## 严禁内容

- 低质量糙线条/涂鸦感/草稿线/线稿未完成感
- 恐怖/惊悚/血腥/重口/猎奇内容
- 完全写实摄影/3D写实渲染/照片级真实感
- 美式漫画粗黑描边/日式赛璐璐硬阴影
- 高饱和荧光色/俗艳配色/审美崩坏
- 低俗色情/性暗示/物化内容

## 核心视觉元素

| 元素 | 说明 | 应用 |
|---|---|---|
| webtoon 竖屏 | 垂直条漫分镜，纵向阅读 | 分镜、构图、运镜 |
| 玻璃高光 | 眼中/发丝/水面的晶莹光点 | 角色特写、浪漫时刻 |
| 柔光光晕 | 逆光/侧光的柔和光斑 | 心动氛围、告白场景 |
| 粉彩渐变 | 蜜桃粉/香芋紫的柔和过渡 | 上色、氛围光 |
| 精致配饰 | 项链/耳环/发饰的精致细节 | 角色造型、时尚感 |

## 核心色盘总览（C1-C10）

> 全风格色彩取自以下核心色盘（详见 `prefix.md`），色相偏移容差 ±8°：

| 序号 | 色名 | 色值 | 用途 |
|---|---|---|---|
| C1 | 象牙白 | #FFF8F0 | 肤色底、高光、留白 |
| C2 | 蜜桃粉 | #F5C6C0 | 腮红、唇色、柔和点缀 |
| C3 | 玫瑰粉 | #E58BA6 | 浪漫主色、花瓣、少女感 |
| C4 | 香芋紫 | #B49BD6 | 梦幻氛围、奇幻魔法、渐变 |
| C5 | 雾霾蓝 | #9FB8D4 | 冷调背景、制服、忧郁氛围 |
| C6 | 焦糖棕 | #8B5E3C | 发色、暖调、肤色阴影 |
| C7 | 蜜糖金 | #E8C77F | 阳光、高光、暖调点缀 |
| C8 | 墨棕黑 | #3A2E2A | 线条、轮廓、发色底 |
| C9 | 薄荷绿 | #9FD0BE | 清新点缀、植物、制服 |
| C10 | 珍珠灰 | #C9C4C8 | 阴影过渡、建筑、中性调 |

> 用法：整体偏暖粉彩基调（5200-5800K），线条用墨棕黑/柔棕，禁纯黑粗描边与高饱和荧光色。

## 文件结构说明

本画风目录包含以下文件：

- `prefix.md` — 全局美学基础与风格基因（一级风格、色彩盘、硬约束色）
- `art_prompt/` — 各类美术提示词约束手册
  - `art_character.md` / `art_character_derivative.md` — 角色及其衍生
  - `art_scene.md` / `art_scene_derivative.md` — 场景及其衍生
  - `art_prop.md` / `art_prop_derivative.md` — 道具及其衍生
  - `art_composition_camera.md` — 构图与镜头
  - `art_lighting_atmosphere.md` — 光影与氛围
  - `art_texture_material.md` — 材质与质感
  - `art_storyboard_video.md` — 分镜视频提示词
- `driector_skills/` — 导演侧分镜技能
  - `director_planning_style.md` — 分镜规划
  - `director_storyboard.md` — 分镜提示词技法
  - `director_storyboard_table_style.md` — 分镜表约束
- `images/` — 风格示例图
- `README.md` — 本说明文件

## 使用流程

1. 生成角色/场景/道具资产 → 读取对应 `art_prompt/` 手册
2. 分镜规划 → 读取 `driector_skills/director_planning_style.md`
3. 分镜表生成 → 读取 `driector_skills/director_storyboard_table_style.md`
4. 分镜提示词 → 读取 `driector_skills/director_storyboard.md`
5. 视频分镜 → 读取 `art_prompt/art_storyboard_video.md`
6. 所有生成必须严格遵循 `prefix.md` 的全局规则

## 风格体验

在本风格下，您将体验到：

- 角色拥有高颜值精致五官，皮肤通透白皙，发型与穿搭时尚精致
- 场景精致细腻，都市/校园/奇幻背景柔光弥漫，氛围感十足
- 道具时尚考究，甜品饮品、精致配饰细节清晰
- 分镜与渲染均强调竖屏条漫构图、细腻渐变、柔光氛围与浪漫言情情绪
