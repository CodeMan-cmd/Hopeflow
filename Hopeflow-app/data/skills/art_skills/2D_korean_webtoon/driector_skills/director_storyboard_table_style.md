# 分镜表韩漫条漫约束 · 韩漫条漫 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。以下仅提供韩漫条漫风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **柔光渐变统一** — 一场戏内光影方案必须保持细腻渐变一致性，阴影使用同色系柔和渐变（禁止硬阴影），除非有明确的叙事转折（如暖灯熄灭→霓虹夜话）
- **情绪色盘绑定** — 每场戏至少绑定 1 个情绪场景（如甜蜜约会/都市日常/奇幻魔法/校园青春/雨夜心绪/告白心动），并在镜头组内保持主色+辅色连续性，色彩取自核心色盘（象牙白 #FFF8F0 / 蜜桃粉 #F5C6C0 / 玫瑰粉 #E58BA6 / 香芋紫 #B49BD6 / 雾霾蓝 #9FB8D4 / 焦糖棕 #8B5E3C / 蜜糖金 #E8C77F / 墨棕黑 #3A2E2A / 薄荷绿 #9FD0BE / 珍珠灰 #C9C4C8）
- **光源角度规范** — 正给镜头光源默认 38.5° 斜射柔光（细腻渐变质感），侧给镜头根据画面需要调整。描述光影时须区分正给/侧给的角度差异，光影渲染始终保持柔光渐变质感
- **冷暖色调与叙事阶段匹配** — 甜蜜约会/告白段落使用粉色暖调（玫瑰粉 + 蜜桃粉 + 蜜糖金），禁用冷蓝主调；虐恋/忧郁段落使用冷调柔光（雾霾蓝 + 珍珠灰 + 香芋紫），禁用暖橙光；都市夜归段落使用霓虹光斑（香芋紫 + 雾霾蓝）
- **光影转场是高级手段** — 从侧窗透光渐变到暖灯私语 = 日转夜的时间流逝。在分镜表中标注光影变化点，转场过程中渐变必须平滑过渡，禁止色块断层
- **氛围渲染技法** — 允许合理使用光晕（glow）、光斑（bokeh）、柔焦（soft focus）、逆光轮廓等氛围技法，但必须保持韩漫细腻渐变的美学基调，禁止 3D 写实/CG 光效

---

## 三、环境动态

- **环境动态增加画面呼吸感** — 花瓣飘落、光点漂浮、发丝飘动、雨丝斜织、咖啡热气、窗帘微动。每 3-4 个镜头至少安排一个有环境动态的镜头，避免画面"死"掉
- **韩漫环境元素优先** — 环境动态应选用韩漫言情世界观内的元素：樱花、光点、雨丝、雪片、霓虹、热气、泡泡、飘带，禁止出现与世界观冲突的元素
- **渐变动态质感** — 环境动态元素（花瓣/光点/雨丝等）必须保持细腻渐变质感与精致线条，禁止 3D 粒子特效或写实流体效果

---

## 四、韩漫动作节奏

- **动作细腻且带动感** — 人物动作默认细腻优雅，但可在关键帧上做言情夸张处理（如回眸时发丝飘动、心动时指尖轻触），起身、转身、抬手应标注"轻柔/缓慢"
- **发丝与衣角动态是核心画面资产** — 韩漫角色发丝、衣角的飘动是天然的动态资产，可在画面描述中加入发丝轻扬、衣角微动的动态，渐变渲染下的发丝飘动应层次分明、柔光点缀
- **仪态约束** — 韩漫人物的举止应符合精致时尚气质：动作优雅大方、姿态自然从容，不出现夸张的卡通式肢体语言。言情角色可在微表情上略有夸张（眼睛弯月、脸颊泛粉），但肢体动作仍需精致克制
- **头身比一致** — 动作设计中角色必须保持 8-9 头身的模特比例，禁止因动态姿势而破坏头身比

---

## 五、材质与质感约束

- **细腻渐变为锚** — 所有镜头中人物/服饰/道具/场景的渲染必须保持细腻渐变质感，线条精致流畅，禁止 3D 写实/CG 动画/照片级渲染
- **服饰材质** — 缎面/针织/牛仔/蕾丝的质感用细腻渐变表现，纹理必须超清晰，衣服质感清晰，渐变平滑
- **道具材质** — 玻璃通透、金属高光、织物细腻、食物光泽，均以细腻渐变 + 玻璃高光呈现，禁止写实材质渲染
- **场景材质** — 玻璃幕墙、木质地板、植被花木的材质细腻渐变，背景柔焦虚化，禁止粗糙塑料感材质

---

## 六、色彩约束

- **核心色盘锁定** — 分镜表中所有镜头的色彩必须取自核心色盘（C1-C10），色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%
- **禁止荧光色** — 严禁高饱和荧光色/霓虹俗艳色的色彩出现
- **线条颜色** — 墨棕黑或柔棕，禁止纯黑粗描边
- **阴影色** — 同色系柔和渐变，禁止硬阴影/赛璐璐色块
- **整体色温** — 偏暖 5200-5800K 柔和基调，对比度 40-60%，饱和度 45-65%（柔和粉彩盘）

---

## 七、运镜禁忌

- **禁用快速运镜** — 甩镜、急推、手持晃动与韩漫的浪漫氛围冲突，心动/告白场景可适度加快运镜节奏但仍需保持画面柔美
- **禁用花式转场** — 划屏、旋转、百叶窗等与本风格不兼容
- **禁用写实镜头语言** — 手持摇晃/纪录片式跟拍/鱼眼镜头等与韩漫美学冲突，破坏细腻渐变的画面纯净感
- **禁用恐怖惊悚手法** — 突然惊吓/诡异构图/血腥镜头等与本风格严禁项冲突

---

## 八、转场禁忌

| 禁忌类型 | 说明 |
|---|---|
| 生硬切转 | 场景/情绪切换禁用无柔光过渡的硬切 |
| 花式特效转场 | 划屏/旋转/百叶窗/闪白等与本风格不兼容 |
| 写实转场 | 3D 溶解/粒子爆炸/镜头穿墙等与韩漫美学冲突 |
| 渐变断层 | 转场过程光影渐变必须平滑，禁色块断层 |
| 节奏失控 | 转场过多过密，画面失去浪漫呼吸感 |

- **正确做法**：优先使用柔光/花瓣/光点/特写等韩漫式转场，并在分镜表中标注光影变化点
- **禁忌总纲**：一切与韩漫浪漫柔美氛围冲突的转场手法均不得使用

## 九、分镜表快速检查清单

- [ ] 每场戏已绑定情绪场景（如甜蜜约会/雨夜心绪），镜头组内主色+辅色连续
- [ ] 色彩全部取自核心色盘（C1-C10），无高饱和荧光/俗艳配色
- [ ] 镜头组内柔光渐变统一，阴影同色系柔和过渡，无硬阴影
- [ ] 每 3-4 个镜头至少安排一个环境动态镜头（花瓣/光点/雨丝等）
- [ ] 人物动作标注「轻柔/缓慢」，发丝衣角动态层次分明
- [ ] 运镜全部为柔和缓慢类，无快速甩镜/急推/手持晃动
- [ ] 转场均为韩漫式转场（柔光/花瓣/光点/特写），无花式转场
- [ ] 材质保持细腻渐变质感，无 3D 写实/CG/照片级渲染
- [ ] 整体色温/对比度/饱和度符合柔和粉彩盘
- [ ] 角色保持 8-9 头身模特比例，线条为墨棕黑/柔棕，无纯黑粗描边
