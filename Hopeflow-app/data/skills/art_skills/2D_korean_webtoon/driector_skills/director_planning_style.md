# 韩漫条漫约束 · 韩漫条漫 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以核心色盘为基底：象牙白（C1 #FFF8F0）、蜜桃粉（C2 #F5C6C0）、玫瑰粉（C3 #E58BA6）、香芋紫（C4 #B49BD6）、雾霾蓝（C5 #9FB8D4）、焦糖棕（C6 #8B5E3C）、蜜糖金（C7 #E8C77F）、墨棕黑（C8 #3A2E2A）、薄荷绿（C9 #9FD0BE）、珍珠灰（C10 #C9C4C8），整体色温偏暖（5200-5800K），饱和度中（45-65%），呈现柔和粉彩的浪漫画面
- **冷暖叙事对比** — 暖色（玫瑰粉 C3、蜜桃粉 C2、蜜糖金 C7）作为心动/甜蜜/治愈的视觉信号；冷色（雾霾蓝 C5、香芋紫 C4、珍珠灰 C10）作为忧郁/心事/梦幻的视觉信号。冷暖切换应与故事弧线同步，而非随意混用
- **冷暖分配策略** — 甜蜜约会/告白段落使用粉色暖调（玫瑰粉 + 蜜桃粉 + 蜜糖金）；都市日常/校园青春段落使用清透调（象牙白 + 薄荷绿 + 雾霾蓝）；奇幻魔法段落使用梦幻调（香芋紫 + 雾霾蓝 + 光点）；虐恋/雨夜段落使用冷调（雾霾蓝 + 珍珠灰 + 香芋紫）
- **色盘先行原则** — 段落规划需先绑定情绪场景（甜蜜约会/都市日常/奇幻魔法/校园青春/雨夜心绪/告白心动等），再确定主色+辅色与柔光方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、霓虹俗艳色、数码感强色彩均与本风格不兼容。色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%

## 二、光影方案体系

- **光影即氛围** — 7 套柔光方案对应不同情绪段落，导演规划阶段应在段落层面确定柔光基调方向，而非逐镜指定
- **柔光渐变为锚** — 所有光影方案必须保持细腻渐变质感，阴影使用同色系柔和渐变，禁止硬阴影，允许光晕/光斑/柔焦等氛围渲染
- **光源角度** — 正给镜头默认 38.5° 斜射柔光（细腻渐变质感），侧给镜头可适当调整

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 柔光甜蜜 | 象牙白 + 玫瑰粉 + 蜜糖金 | 甜蜜约会、治愈温馨、心动时刻 |
| B | 清透日常 | 象牙白 + 薄荷绿 + 雾霾蓝 | 都市日常、校园青春、清新治愈 |
| C | 逆光心动 | 蜜糖金轮廓光 + 光晕 | 黄昏心动、告白、离别 |
| D | 霓虹夜话 | 香芋紫 + 雾霾蓝光斑 | 都市夜归、心事、重逢 |
| E | 暖灯私语 | 蜜糖金 + 玫瑰粉暖调 | 夜间私语、亲密升温、暧昧 |
| F | 月光童话 | 香芋紫 + 雾霾蓝冷调光点 | 奇幻魔法、月下约定、唯美 |
| G | 雨夜心绪 | 雾霾蓝 + 珍珠灰冷调，无暖光 | 虐恋、忧郁心事、氛围压抑 |

- **冷暖光分配** — 暖色光（蜜糖金/玫瑰粉/蜜桃粉）适用于正向情感/浪漫段落；虐恋/忧郁段落一律冷调柔光。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述柔光方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **细腻渐变为锚** — 韩漫条漫的核心：细腻渐变上色、柔光氛围、精致线条、玻璃高光、通透皮肤
- **高颜值 + 氛围感** — 这是画面质感的锚点。不是写实摄影，不是 3D CG，是韩式言情漫画的精致美学
- **材质精致化** — 所有服化道的材质必须以细腻渐变呈现：发丝渐变柔亮、缎面光泽柔和、金属高光精致、玻璃通透带光晕。禁止"3D 感"和"写实摄影感"
- **皮肤质感** — 象牙白底调、细腻渐变、柔光肤感、通透白皙、玻璃高光点缀。禁止死白/蜡感/油光/过曝
- **精致不等于堆砌** — 韩漫强调在精致基础上的氛围感与呼吸感，画面清透干净，而非杂乱堆砌的高饱和堆色

## 四、韩漫场景空间元素

韩漫世界观特有的场景元素及其视觉叙事功能：

- **咖啡厅/窗边座位/落地窗** — 天然的框景与柔光载体，制造"偷看/偶遇/对话"的浪漫场景，以精致渐变呈现玻璃通透质感
- **樱花道/天台/海边/游乐园** — 浪漫氛围的天然载体，景即情：樱花飘落 = 心动、天台日落 = 告白、海边漫步 = 治愈、游乐园 = 甜蜜
- **教室/图书馆/走廊** — 校园青春的框架场景，窗光 = 清透青春（方案B）、黄昏走廊 = 心动偶遇（方案C）
- **霓虹街道/公寓窗灯/便利店** — 都市夜戏的光源载体，霓虹 = 心事/都市（方案D）、暖灯 = 私语/治愈（方案E）
- **奇幻城堡/魔法森林/星空** — 奇幻言情的梦幻载体，光点漂浮 = 魔法（方案F）、月光 = 唯美约定
- **段落间用氛围空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/景别变体），段落衔接建议用氛围空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（柔光突变、特写切入、空镜隐喻）而非依赖对白解释
- **前中后景层次** — 所有场景必须具备前/中/后景，背景柔焦虚化，杜绝扁平；前景可加光斑/花瓣增加氛围感

## 五、音乐与环境音

韩漫言情世界观下的声音元素约束：

### 乐器选择

- **钢琴** — 心动/浪漫/治愈段落的核心乐器，柔美清澈，与柔光氛围高度适配
- **弦乐** — 情感渐浓段落的铺底，小提琴/大提琴适合虐恋与深情
- **吉他** — 校园/日常/清新段落的轻快载体
- **流行抒情** — 告白/高潮段落的情绪载体，节奏感带动心动
- 电子轻音乐可增加梦幻感但不宜喧宾夺主

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/日常 | 钢琴独奏 或 吉他 + 轻弦 |
| 心动/暧昧/甜蜜 | 钢琴 + 轻弦 + 心跳声点 |
| 告白/高潮 | 钢琴 + 弦乐 + 流行抒情 |
| 虐恋/心痛 | 大提琴 + 钢琴，低沉渐强 |
| 奇幻/梦幻 | 电子轻音乐 + 竖琴 |
| 校园/青春/清新 | 吉他 + 尤克里里 |
| 都市/夜戏 | 钢琴 + 爵士点缀 + 氛围音 |

### 韩漫环境音

- **典型环境音层次** — 咖啡厅杯碟轻响 / 街道车流远声 / 雨滴敲窗 / 风铃轻响 / 心跳声 / 翻书声 / 樱花飘落 / 霓虹电流微响 / 手机提示音 / 脚步声由远及近
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音越细腻，韩漫氛围越沉浸
