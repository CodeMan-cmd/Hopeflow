# 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **颜值即核心** — 高颜值精致五官是韩漫的灵魂，大眼长睫、精致脸型
2. **底模即基础** — 素色基础服装 + 素颜，后续服化均为叠加层
3. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一
4. **氛围气质** — 无妆状态仍需体现角色气质（清纯/温柔/高冷/元气）

---

## 二、面容约束

> 不再固定五官特征参数，由角色描述（性别/年龄/性格/气质）驱动 AI 自由生成五官，保证人物间外观差异化。

| 项目 | 约束 |
|---|---|
| 五官 | 由角色描述自然推导，高颜值精致取向：大眼睛、长睫毛、高鼻梁、精致脸型 |
| 风格底色 | 韩漫条漫、webtoon 风格、细腻渐变上色、柔光氛围 |
| 气质 | 必须从角色描述提炼整体气质关键词（如清纯温柔/高冷禁欲/元气可爱），并写入提示词 |
| 表情 | 中性微表情，符合角色气质，眼中有光 |

## 六、基础服装约束

> 基础服装无特殊约束，女性为素色连衣裙或基础上衣，男性为素色衬衫或 T 恤，颜色以基础色为主，无花纹装饰。正式服饰在服化衍生环节叠加。

- 服装风格统一，确保后续服饰叠加无色彩干扰
- 除面部/手部/颈部外基本覆盖，四视图服装款式完全一致
- 基础服装仅为安全打底，焦点在面容与气质

---

## 七、四视图设定图规范

| 位置 | 视图 | 角度 | 要求 |
|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 头顶至锁骨，面部占60%+，五官精致清晰 |
| 左二 | 正视图 | 正面 0° | 全身立像，从头顶到脚底完整展示 |
| 右二 | 侧视图 | 右侧 90° | 全身立像，纯侧面轮廓清晰 |
| 右一 | 后视图 | 后方 180° | 全身立像，后脑/发尾/背部清晰 |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图，建议 4:1 或 3:1 |
| 背景 | 象牙白纯色 #FFF8F0 |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂 |
| 完整性 | 全身立像从头到脚完整入画、特写从头到锁骨完整入画，严禁裁切 |
| 表情 | 中性微表情，眼中有光 |
| 光线 | 均匀柔光，细腻渐变过渡，无硬阴影 |
| 一致性 | 四视图的肤色/体型/发型/面容/基础服装完全一致 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「素颜状态」 |
| R2 | 必须声明基础服装（女性：素色连衣裙；男性：素色衬衫） |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「象牙白纯色背景」与「四视图一致性」 |
| R5 | 必须声明角色身高（女性默认 160-170cm，男性默认 175-188cm）与八至九头身模特比例 |
| R6 | 全身立像/特写必须完整入画，严禁裁切 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 基础服装以外的任何服装/配饰/妆容 |
| X2 | 正顶硬光/正底光/冷色光 |
| X3 | 糙线条/涂鸦感/未完成线稿感 |
| X4 | 复杂场景背景（必须纯色） |
| X5 | 夸张表情/动态姿势 |
| X6 | 全身立像/特写裁切头顶或脚底 |
