# 构图与镜头 · 韩漫条漫约束手册

> **本画风构图以"webtoon 竖屏 + 特写美学"为纲**：垂直条漫分镜、情绪特写为主、氛围感构图，叠加细腻渐变与柔光氛围（继承 R3/R4）。

---

## 一、景别

| 景别 | 取景范围 | 用途 | 提示词 |
|---|---|---|---|
| 大特写 | 眼睛/嘴唇/手指局部 | 情绪爆发、心动细节 | 大特写、眼神特写、玻璃高光 |
| 特写 | 面部 | 颜值展示、情绪流转 | 韩漫特写、精致五官 |
| 近景 | 头部至胸部 | 对话、心动氛围 | 韩漫近景、柔光氛围 |
| 中景 | 膝部以上 | 叙事主体、互动 | 韩漫中景、身姿细节 |
| 全景 | 全身 | 穿搭展示、场景融入 | 韩漫全景、时尚造型 |

---

## 二、机位与视角

| 机位 | 适用 | 提示词 |
|---|---|---|
| 平视（默认） | 客观叙事、平等交流 | 平视视角、eye level |
| 仰视 | 人物气场、心动仰望 | 轻微仰视、仰望视角 |
| 俯视 | 俯拍视角、温柔凝视 | 俯视视角、温柔俯拍 |
| 侧后方 | 偷看视角、暧昧感 | 侧后方视角、偷看视角 |
| 肩越视角 | 对话场景、沉浸感 | 过肩视角、over shoulder |

---

## 三、构图法则（条漫侧重）

| 法则 | 说明 | 提示词 |
|---|---|---|
| 竖屏三段 | 垂直方向分上中下叙事 | webtoon 竖屏、纵向三段 |
| 特写留白 | 面部居中 + 周围柔光留白 | 面部居中、柔光留白 |
| 三分法 | 主体偏置 + 氛围空间 | 三分法构图、氛围留白 |
| 引导线 | 街道/栏杆/视线引导 | 引导线构图、视线引导 |
| 框架构图 | 门框/窗框/手部框景 | 框架构图、窗框取景 |
| 对称构图 | 镜像对称、仪式感 | 对称构图、中轴取景 |

---

## 四、镜头语言

| 维度 | 约束 |
|---|---|
| 运动 | 缓慢推近/轻柔上移/缓缓横移，条漫滚动式节奏 |
| 焦点 | 主体清晰，背景柔焦虚化（梦幻感） |
| 景深 | 大光圈浅景深，光斑虚化背景 |
| 转场 | 柔光光晕、花瓣飘落、光点散开、特写淡出转场 |
| 意境 | 镜头服务于"氛围感"与"心动感" |


## 六、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「韩漫条漫 + webtoon 竖屏构图」（继承 R1/R2） |
| R2 | 必须声明「细腻渐变上色 + 柔光氛围」（继承 R3） |
| R3 | 构图必须绑定 1 个条漫法则（竖屏三段/特写留白等） |
| R4 | 特写镜头必须声明「高颜值精致五官」（继承 R4） |
| R5 | 竖屏镜头须纵向延展叙事，节奏明快 |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁横屏漫画式多格杂乱构图 |
| X2 | 严禁美式漫画粗黑描边构图语言（继承 X4） |
| X3 | 严禁写实摄影/3D 写实渲染镜头语言（继承 X3） |
| X4 | 严禁糙线条/涂鸦感/构图杂乱（继承 X1） |
| X5 | 严禁快速运镜/甩镜/急推/手持晃动 |
