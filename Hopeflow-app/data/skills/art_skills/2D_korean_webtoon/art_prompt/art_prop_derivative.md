# 道具衍生状态生成 · 约束手册

---

## 一、衍生原则

1. **造型锚定** — 道具核心造型/轮廓在所有状态中可识别
2. **状态可读** — 状态差异必须一目了然，观众能立即区分
3. **叙事服务** — 每种状态变体服务于特定剧情节点
4. **渐变逻辑** — 损伤/老化状态以细腻渐变呈现，符合现代/奇幻语境
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁出现任何人物、手部、肢体，道具不可处于被持有/佩戴/握持状态，必须以静物陈列方式独立呈现

---

## 二、状态类型

### 2.1 使用状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 崭新 | 完好无损、光泽如新 | 所有道具 | 崭新、完好无损、光泽如新 |
| 日常使用 | 微磨损、自然使用感 | 生活用品/书本/手机 | 日常使用痕迹、自然磨损 |
| 陈旧 | 明显年代感、色泽渐旧 | 旧物/信件/古籍 | 古旧感、泛黄、岁月痕迹 |

### 2.2 损伤状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 微损 | 小划痕/小缺口/轻微磨损 | 手机/杯子/首饰 | 细微划痕、轻微缺口 |
| 破损 | 明显裂缝/断裂/破碎 | 杯子/相框/手机 | 裂缝明显、碎裂、断裂 |
| 褪色 | 颜色褪去、渐变变淡 | 照片/布料/书本 | 褪色、颜色渐淡、旧化 |

### 2.3 特殊状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 发光/魔法 | 内在能量、光晕渐变 | 魔法书/水晶球/符文石 | 微微发光、光晕渐变、梦幻光效 |
| 浸水/湿润 | 水渍、湿润反光 | 信件/纸张/布料 | 浸水湿润、水渍反光 |
| 燃烧/焦损 | 焦黑边缘、火烧痕迹 | 信件/木质品/照片 | 边缘焦黑、火烧痕迹 |
| 包裹/封存 | 礼盒/丝带/信封包裹 | 礼物/信物/戒指 | 礼盒包装、丝带系结 |
| 贴纸/装饰 | 贴纸、装饰点缀 | 手机/手账/水杯 | 贴纸点缀、装饰可爱 |

### 2.4 环境适应状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 雪覆 | 积雪覆盖 | 户外道具/伞具 | 雪花覆盖、积雪、冬日感 |
| 雨湿 | 雨水湿润 | 伞/书/布料 | 雨水湿润、水珠、潮湿感 |
| 花瓣覆 | 花瓣飘落覆盖 | 桌面道具/礼物 | 花瓣覆盖、浪漫氛围 |
| 晨露 | 露珠凝结 | 植物/花束/玻璃杯 | 露珠晶莹、晨露微光 |

## 三、状态变体画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单状态图：与设定图正面图一致；状态对比图：同画面并排 2-3 种状态 |
| 背景 | 象牙白纯色 #FFF8F0（与设定图一致） |
| 光线 | 均匀柔光，细腻渐变，无硬阴影 |
| 比例 | 道具占画面主体 70%+ |
| 一致性 | 对比图角度/光线/背景完全一致，仅状态不同 |

---

## 四、材质状态变化规则

| 材质 | 崭新 → 日常 | 日常 → 陈旧 | 损伤表现 |
|---|---|---|---|
| 玻璃 | 通透如新 → 微划痕 | 划痕 → 微雾化 | 裂纹/碎裂/缺口 |
| 金属 | 亮光泽 → 微磨损 | 磨损 → 氧化暗淡 | 划痕/凹陷/断裂 |
| 纸张 | 平整崭新 → 微折痕 | 折痕 → 泛黄脆化 | 撕裂/焦损/水渍 |
| 布料 | 崭新平整 → 微皱 | 皱褶 → 褪色旧化 | 撕裂/污渍/磨损 |
| 食物 | 新鲜光泽 → 微失水 | 失水 → 干瘪变色 | 融化/变形/变质 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 道具核心造型/轮廓在所有状态中可识别 |
| R2 | 状态变化须符合物理逻辑与世界观 |
| R3 | 必须使用四宫格（2×2）布局：正面 + 侧面 + 背面 + 特写 |
| R4 | 必须指定「象牙白纯色背景」，均匀柔光 |
| R5 | 必须包含「韩漫条漫 + 细腻渐变」关键词 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 状态变化后道具不可识别 |
| X2 | 违反物理逻辑的损伤（玻璃生锈等） |
| X3 | 恐怖/血腥/重口的损伤描绘 |
| X4 | 出现任何人物形象，包括全身、半身、局部（手、手指、手臂等肢体） |
| X5 | 道具处于被持有、握持、佩戴、使用中的状态 |
| X6 | 出现暗示人物存在的元素（如手持痕迹、佩戴视角、使用姿态） |
