# 材质与质感 · 韩漫条漫约束手册

> **本画风质感锚定于"细腻渐变 + 柔光"**：发丝渐变、皮肤通透、衣物质感细腻，玻璃高光点缀精致细节，禁糙线条、禁硬色块、禁塑料感。

---

## 一、渲染质感描述

| 项目 | 约束 | 说明 |
|---|---|---|
| 基底质感 | 细腻渐变 + 柔光渲染 | 色块平滑过渡、光影柔和（继承二级风格） |
| 线条质感 | 精致流畅、柔棕墨线 | 禁纯黑粗描边、禁糙线毛边 |
| 上色方式 | 数字渐变上色 | 发丝/皮肤/衣物渐变自然，禁断层 |
| 材质精度 | 细节精致可辨 | 发丝、织物、首饰有细腻笔触 |
| 表面处理 | 通透柔光 | 皮肤通透、玻璃高光，非塑料非写实 |

## 三、画质硬约束

| 维度 | 等级要求 | 说明 |
|---|---|---|
| 线条 | 精致流畅、柔棕墨线 | 禁纯黑粗描边、禁糙线毛边、禁草稿线 |
| 颜色 | 粉彩盘饱满统一 | 渐变平滑过渡，禁色块断层/色彩溢出 |
| 细节等级 | 高细节精致 | 发丝/五官/服饰细节精致，禁模糊低精度 |
| 渲染 | 柔光渐变 | 数字渐变过渡自然，不塑料不写实 |
| 一致性 | 全画面统一 | 韩漫审美全局统一（继承 X5） |
