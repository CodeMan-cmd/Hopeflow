# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，氛围即剧情
2. **层次纵深** — 所有场景必须具备前/中/后景，背景柔焦
3. **质感至上** — 玻璃/金属/植被/水面的材质渐变必须清晰细腻
4. **韩漫为锚** — 一切画面以韩漫条漫为标准，拒绝写实/CG/美式漫画质感；追求细腻渐变、柔光氛围、精致背景

## 三、场景类型

### 3.1 都市类

| 维度 | 约束 | 提示词 |
|---|---|---|
| 类型 | 街道/咖啡厅/公寓/办公室/天台 | {都市场景}，现代都市 |
| 材质 | 玻璃/金属/混凝土/木质 | 玻璃幕墙、木质地板 |
| 色调 | 粉彩盘 + 柔和光线 | 柔和色调、清透光线 |
| 氛围 | 都市感 + 治愈氛围 | 都市治愈、氛围感 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、后景{元素} |

### 3.2 校园类

| 维度 | 约束 | 提示词 |
|---|---|---|
| 类型 | 教室/操场/图书馆/走廊/樱花道 | {校园场景}，青春校园 |
| 材质 | 木质课桌/玻璃窗/书本 | 木质课桌、玻璃透光 |
| 色调 | 薄荷绿 + 象牙白 + 暖阳 | 青春色调、阳光明媚 |
| 氛围 | 清纯青春、心动萌发 | 校园青春、心动氛围 |
| 光效 | 侧窗透光、光斑洒落 | 窗光斑驳、阳光洒落 |

### 3.3 奇幻类

| 维度 | 约束 | 提示词 |
|---|---|---|
| 类型 | 魔法城堡/森林/星空/异世界 | {奇幻场景}，梦幻奇幻 |
| 材质 | 水晶/藤蔓/星尘/魔法光 | 水晶通透、藤蔓缠绕 |
| 色调 | 香芋紫 + 雾霾蓝 + 蜜糖金 | 梦幻色调、光点漂浮 |
| 氛围 | 唯美梦幻、童话质感 | 梦幻唯美、童话氛围 |
| 光效 | 魔法光晕、光点漂浮 | 光晕渐变、光点漂浮 |

### 3.4 浪漫类

| 维度 | 约束 | 提示词 |
|---|---|---|
| 类型 | 樱花大道/海边/游乐园/天台日落 | {浪漫场景}，浪漫氛围 |
| 材质 | 花瓣/海水/灯光/晚霞 | 花瓣飘落、海面波光 |
| 色调 | 玫瑰粉 + 蜜糖金 + 香芋紫 | 浪漫色调、柔光弥漫 |
| 氛围 | 心动告白、浪漫治愈 | 浪漫心动、氛围感十足 |
| 光效 | 逆光轮廓、金色光晕 | 逆光光晕、夕阳金辉 |

## 四、主视图规范

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，最能体现场景主体与氛围 | hero shot、representative angle |
| 视点 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或三分法，前/中/后景清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 9:16 竖屏（或按调用方设定） |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 背景必须柔焦虚化，营造氛围感 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含韩漫条漫关键词（Korean webtoon style / soft gradient shading） |
| R7 | 必须包含柔光氛围特征（细腻渐变 / 柔光光效 / 背景柔焦） |
| R8 | 材质必须细腻渐变过渡，禁止硬色块/塑料感 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 写实/CG/美式漫画/卡通质感（禁用 3D render、CGI 等词） |
| X8 | 材质粗糙/硬色块/无渐变过渡 |
| X9 | 恐怖/惊悚/重口的场景氛围 |
