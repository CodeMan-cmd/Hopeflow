# 视频提示词 · 视觉风格约束

生成视频提示词时，必须注入以下视觉风格标签：

| 模式 | 风格标签 |
|------|----------|
| **通用多参模式（英文）** | `Korean webtoon style, vertical manhwa composition, soft gradient shading, dreamy light glow, pretty face, romantic mood, high detail` |
| **通用首尾帧模式（英文）** | `Korean webtoon style, vertical manhwa composition, soft gradient shading, dreamy light glow, pretty face, romantic mood, high detail, smooth soft transition` |
| **Seedance 2.0（中文）** | `韩漫条漫风格，webtoon竖屏构图，细腻渐变上色，柔光氛围，高颜值精致五官，浪漫言情氛围` |

> **风格标签行**：无论多参/首尾帧/Seedance 何种模式，画面描述中必须保留一行完整风格标签（韩漫条漫风格，webtoon竖屏构图，细腻渐变上色，柔光氛围，高颜值精致五官，浪漫言情氛围）。

## 一、浪漫氛围注入

韩漫视频的灵魂在"氛围"。视频提示词必须在画面描述中注入浪漫氛围元素：

| 氛围类型 | 提示词 | 适用 |
|---|---|---|
| 柔光光晕 | 逆光柔光晕开、光斑漂浮 | 心动时刻、告白场景 |
| 花瓣飘落 | 粉色花瓣缓缓飘落 | 甜蜜约会、唯美转场 |
| 玻璃高光 | 眼中/发丝晶莹高光闪烁 | 角色特写、眼神戏 |
| 光点漂浮 | 微光点点漂浮空中 | 奇幻魔法、梦幻氛围 |
| 风吹发丝 | 微风拂动发丝、衣角轻扬 | 初见、离别、心动 |


## 三、转场氛围处理

| 转场类型 | 提示词 |
|---|---|
| 柔光转场 | 画面被柔光光晕包裹、缓缓消散进入下一幕 |
| 花瓣转场 | 花瓣飘落覆盖画面、散开进入下一幕 |
| 光点转场 | 光点汇聚成光幕、光幕散开转场 |
| 特写转场 | 从眼睛特写淡出、进入回忆/幻想场景 |

## 四、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须注入韩漫风格标签（多参/首尾帧/Seedance 三选一） |
| R2 | 每段画面必须声明细腻渐变与柔光氛围 |
| R3 | 转场必须使用浪漫式转场（柔光/花瓣/光点/特写） |
| R4 | 竖屏镜头须纵向延展，强调 webtoon 叙事节奏 |
| R5 | 必须声明「韩漫高清渲染 + 柔光质感」 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 快速甩镜/急推/手持晃动 |
| X2 | 写实摄影/3D 渲染/照片级画面 |
| X3 | 糙线条/涂鸦感/未完成线稿感 |
| X4 | 恐怖/惊悚/血腥/重口画面 |
| X5 | 美式粗描边/赛璐璐硬阴影/荧光色 |

## 五、运镜节奏建议

| 节奏类型 | 建议 | 适用 |
|---|---|---|
| 缓推 | 轻柔缓慢推近，聚焦情绪 | 心动特写、告白时刻 |
| 上移 | 纵向缓慢上移，展现竖屏构图 | 场景建立、身高对比 |
| 侧移 | 横向轻柔侧移，跟随主体 | 行走、互动场景 |
| 环绕 | 极缓环绕，柔光轻旋 | 高光时刻、氛围渲染 |
| 静帧 | 静帧 + 光点/花瓣动态 | 情绪定格、暧昧氛围 |

- 全片运镜基调为「柔」：单镜头运镜以慢为主，忌快忌晃
- 心动/告白场景可适度加快至「柔中带情绪」，但不得破坏浪漫柔美
- 转场前 1-2 秒放慢运镜，为柔光/花瓣转场留出余韵
