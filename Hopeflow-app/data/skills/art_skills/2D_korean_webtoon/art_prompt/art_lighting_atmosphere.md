# 光影与氛围 · 韩漫条漫约束手册

> **本画风以"柔光氛围"为光影灵魂**：柔和光源、渐变过渡、光晕梦幻，光影为浪漫言情情绪服务，禁止硬阴影与强对比。

---

## 一、光源方案

| 方案 | 光源特征 | 渐变/光晕建议 | 使用场景 | 提示词 |
|---|---|---|---|---|
| 柔光漫射 | 漫射柔光，无硬影 | C1 象牙白主导，渐变平滑 | 日常、约会、治愈 | 柔光漫射、渐变平滑、温馨氛围 |
| 侧窗透光 | 窗侧柔光，明暗过渡 | C5 雾霾蓝 + C7 蜜糖金过渡 | 教室、咖啡厅、室内 | 侧窗柔光、光影过渡、静谧氛围 |
| 逆光轮廓 | 逆光剪影 + 轮廓光晕 | C7 蜜糖金轮廓光 + 光晕 | 黄昏心动、离别、告白 | 逆光轮廓、金色光晕、氛围感 |
| 霓虹夜景 | 城市夜景 + 霓虹光斑 | C4 香芋紫 + C5 雾霾蓝光斑 | 都市夜归、心事、重逢 | 霓虹光斑、夜景柔光、都市氛围 |
| 烛光/暖灯 | 暖色灯烛，温馨暧昧 | C7 蜜糖金 + C3 玫瑰粉暖调 | 夜间私语、亲密、告白 | 暖灯柔光、暧昧氛围、温馨渐变 |
| 月光童话 | 清冷月光 + 光点漂浮 | C4 香芋紫 + C5 雾霾蓝冷调 | 奇幻、月下约定、魔法 | 月光清冷、光点漂浮、梦幻氛围 |

## 二、光比与明暗对比

| 维度 | 约束 | 说明 |
|---|---|---|
| 整体对比度 | 中 40-60%（建议区间） | 细腻层次，不做大光比 |
| 阴影 | 同色系柔和渐变 | 禁硬阴影/赛璐璐色块（继承硬约束色） |
| 高光 | 玻璃质感柔光高光 | 眼中/发丝/水面晶莹光点 |
| 层次 | 明暗 3-4 级渐变 | 亮部/中间/暗部逐级渐变过渡 |

---

## 三、色温约束（继承 prefix）

| 参数 | 值 |
|---|---|
| 整体色温 | 偏暖 5200-5800K（推荐） |
| 对比度 | 中 40-60%（建议区间） |
| 饱和度 | 中 45-65%（建议区间） |

> 色相偏移 ±8°、饱和度偏移 ±10%、明度偏移 ±12%。例外镜头（高光时刻）可临时突破局部色彩，但不得突破严禁项。

## 五、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 每条提示词必须声明「韩漫条漫」风格锚定词（继承 R1） |
| R2 | 必须声明「细腻渐变上色 + 柔光氛围」（继承 R3） |
| R3 | 阴影必须为「同色系柔和渐变」，禁硬阴影（继承硬约束色） |
| R4 | 高光必须为「玻璃质感柔光高光」，禁过曝死白 |
| R5 | 必须绑定 1 个光源方案并指定主辅色 |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁高饱和荧光色/霓虹俗艳光效（继承 X5） |
| X2 | 严禁写实摄影/3D 写实渲染/照片级光效（继承 X3） |
| X3 | 严禁美式粗描边/赛璐璐硬阴影光效（继承 X4） |
| X4 | 严禁过曝死白/光斑脏乱/渐变断层（继承 X1） |
| X5 | 严禁恐怖/惊悚/血腥氛围光效（继承 X2） |
