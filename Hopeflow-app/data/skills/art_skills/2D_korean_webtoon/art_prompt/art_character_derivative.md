# 人物衍生资产生成 · 约束手册

## 一、叠加原则

1. **面容不变** — 叠加后五官必须与底模完全一致，禁止面容偏移
2. **姿态不变** — 保持底模自然站立姿态，禁止任何姿态/动作/体态变化
3. **逐层可控** — 每层独立描述，便于按层替换（换装不换妆）
4. **风格统一** — 所有服化元素服从韩漫精致美学体系
5. **质感不降** — 叠加后渐变质感标准不低于底模
6. **纯服化范畴** — 仅叠加妆容/发型/服饰/配饰，禁止引入道具、场景、环境、动作

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 基础形象底模，不修改 |
| L1 | 妆容（决策层） | 先分析用户线索，再决策「裸妆 / 清透妆 / 精致妆」强度 |
| L2 | 发型造型 | 直发/卷发/扎发/编发 + 发饰 |
| L3 | 内搭 | 替换素色基础内搭 |
| L4 | 外衣/主服 | 都市时尚/学院制服/连衣裙/晚礼服等 |
| L5 | 配饰 | 项链/耳环/手链/发饰/腰带 |

> **范畴边界**：人物衍生资产仅包含 L0–L5 层级（服化妆造），不包含道具（手机/咖啡/花束/雨伞等手持物）、场景环境、姿态动作，这些属于其他资产类型的范畴。

## 三、妆容约束（L1）

> 角色底模虽为素颜，但衍生资产默认进入妆造流程：先解析用户面部线索，在裸妆/清透妆/精致妆之间决策强度与风格。道具、场景、姿态变化不得单独抬高妆容强度。

### 线索到妆容映射

| 线索类型 | 典型线索 | L1 决策 |
|---|---|---|
| 无明显面部强调线索 | 仅服饰/发型变化 | 裸妆（伪素颜） |
| 轻微面部线索 | 轻柔、含笑、气色微提 | 清透妆（极淡） |
| 明确日常线索 | 日常、外出、约会 | 清透妆（自然清透） |
| 明确正式线索 | 晚宴、典礼、红毯 | 精致妆（时尚精致） |

### 妆容风格矩阵

| 风格 | 适用场景 | 核心提示词 |
|---|---|---|
| 伪素颜裸妆 | 日常、初遇、校园 | 伪素颜、天生好皮、清透自然 |
| 清透桃花妆 | 约会、心动、甜蜜 | 桃花妆、眼尾微红、唇色水润 |
| 韩系精致妆 | 晚宴、正式、走秀 | 精致妆容、眼线流畅、唇色饱满 |
| 复古红唇妆 | 复古、港风、氛围 | 红唇复古、气场十足 |
| 元气少女妆 | 日常、活泼、元气 | 元气妆容、腮红自然、眼妆明亮 |

**通用底肤（所有妆容共享）** — 质感：细腻渐变、通透白皙 → 细腻渐变、通透白皙、柔光肤感；白度：象牙白底调、通透不惨白 → 象牙白底调、通透自然；高光：玻璃质感柔光高光 → 玻璃高光、鼻梁高光、自然透亮；禁止：死白/蜡感/油光/过曝

## 四、发型造型约束（L2）

### 造型类型

| 造型 | 描述 | 适用 | 提示词 |
|---|---|---|---|
| 长直发 | 垂顺长发、清纯 | 清纯、校园 | 长直发、垂顺柔亮 |
| 波浪卷发 | 大波浪卷、浪漫 | 约会、浪漫 | 大波浪卷、浪漫卷发 |
| 高马尾 | 高束马尾、元气 | 运动、元气 | 高马尾、活力利落 |
| 双麻花 | 双麻花辫、可爱 | 可爱、日常 | 双麻花辫、清纯可爱 |
| 慵懒卷 | 微卷慵懒、氛围 | 日常、氛围 | 慵懒微卷、氛围感 |

**发饰** — 风格：精致时尚、与服饰配套 → 精致发饰、时尚搭配；材质：珍珠/缎带/金属 → 珍珠发夹、缎带蝴蝶结；细节：细腻线条、渐变上色 → 细节精致、渐变上色

## 五、服饰约束（L3+L4）

### 服饰矩阵

| 风格 | 款式 | 适用 | 提示词 |
|---|---|---|---|
| 都市时尚 | 风衣/西装/针织衫 | 都市、职场 | 都市时尚、简约精致 |
| 学院制服 | 衬衫+百褶裙/西装制服 | 校园 | 学院制服、青春气息 |
| 连衣裙 | 碎花裙/吊带裙/长裙 | 约会、日常 | 连衣裙、柔美浪漫 |
| 休闲卫衣 | 卫衣/牛仔裤 | 日常、运动 | 休闲卫衣、舒适自然 |
| 晚礼服 | 礼服裙/西装礼服 | 晚宴、正式 | 晚礼服、华丽精致 |

**服饰通用约束** — 主色：粉彩盘为默认 → 柔和色调衣服、精致服饰；材质：缎面/针织/牛仔/蕾丝 → 缎面光泽、针织纹理；质感：渐变必须清晰 → 衣服质感清晰、渐变平滑；细节：高颜值穿搭、时尚感 → 时尚穿搭、细节精致

## 六、配饰约束（L5）

**配饰** — 项链：锁骨链/吊坠、精致 → 锁骨链、精致吊坠；耳环：耳钉/耳坠、小巧精致 → 精致耳环、小巧灵动；手链：细链/串珠、秀气 → 精致手链、秀气别致；发饰：发夹/发带/发箍 → 精致发饰、时尚点缀；腰带：皮带/腰链、勾勒腰线 → 精致腰带、勾勒腰线

## 七、四视图设定图规范

| 位置 | 视图 | 角度 | 要求 |
|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 面部至锁骨，妆容/五官精致清晰 |
| 左二 | 正视图 | 正面 0° | 全身立像，服饰正面全貌 |
| 右二 | 侧视图 | 右侧 90° | 全身立像，服饰侧面层次 |
| 右一 | 后视图 | 后方 180° | 全身立像，发饰/背部服饰清晰 |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图，建议 4:1 或 3:1 |
| 背景 | 象牙白纯色 #FFF8F0 |
| 站姿 | 自然站立，**禁止任何姿态变化** |
| 表情 | 符合妆容风格的微表情（如清透妆→含笑、精致妆→淡然） |
| 光线 | 均匀柔光，细腻渐变，无硬阴影 |
| 一致性 | 四视图的面容/妆容/发型/服饰/配饰完全一致 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 叠加后面容必须与底模一致 |
| R2 | 妆容/发型/服饰/配饰风格统一，服从韩漫精致美学体系 |
| R3 | 服饰必须用「衣服质感清晰 + 渐变平滑」；配饰必须「精致时尚 + 细节精细」 |
| R4 | 必须输出四视图设定图（人像特写+正视图+侧视图+后视图），指定「象牙白纯色背景」与「四视图一致性」 |
| R5 | 仅输出提示词，禁止输出速查表/分层方案等非提示词内容 |
| R6 | L1 先解析用户面部线索再决策妆容强度；所有衍生资产均需妆造，至少裸妆档 |
| R7 | 禁止场景描述与道具交互——场景属独立资产类型，不包含手持物/交互物 |
| R8 | 姿态保持不变，禁止任何动作/体态/姿势变化 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 叠加后面容偏移 |
| X2 | 配饰过于简单/粗糙/低质 |
| X3 | 妆容/服饰风格互相冲突 |
| X4 | 复杂场景背景或场景描述——必须纯色，禁止街景/雨景/室内/天气等 |
| X5 | 四视图间服化妆造不一致，或输出提示词以外的任何内容 |
| X6 | 加入任何道具交互（手持手机/咖啡/花束等）或改变底模姿态（行走/回眸/举手/奔跑等） |
| X7 | 未分析用户线索就直接套用固定妆容；低俗色情/性暗示的妆容服饰表达 |
