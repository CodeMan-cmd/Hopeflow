# 材质与质感 · 约束手册

---

## 一、渲染质感描述

1. **高精度 3D 建模** — 模型细节精准，建筑/服饰/器物结构严谨，杜绝低模粗糙
2. **PBR 物理材质渲染** — 金属/玉石/织物/木质按物理属性反馈光照，质感真实细腻
3. **传统工艺质感** — 材质呈现中式工艺美学：木纹包浆、玉润光泽、绢纱垂感、鎏金辉光
4. **岁月痕迹** — 木面使用痕迹、石面风化青苔、织物自然褶皱，拒绝全新无瑕 CG 感

---

## 二、材质锚词清单

| 部位 | 锚词（中） | 锚词（英） |
|---|---|---|
| 玉石 | 玉石通透、温润光泽 | jade translucency、warm jade luster |
| 金属 | 鎏金辉光、细腻金属反光 | gold sheen、fine metal reflection |
| 织物 | 暗纹刺绣、绢纱垂感、织锦纹理 | brocade texture、silk drape |
| 木质 | 檀木纹理、漆面包浆 | wood grain、lacquer patina |
| 石材 | 汉白玉质感、风化纹理 | white marble texture、weathered stone |
| 瓷器 | 釉面光泽、青花发色 | glaze sheen、celadon glaze |
| 整体 | PBR 物理材质、纹理清晰可辨 | PBR materials、ultra-detailed textures |

---

## 三、画质硬约束

| 参数 | 硬约束 |
|---|---|
| 分辨率 | 8K 超高清渲染，纹理清晰可辨 |
| 建模精度 | 高精度建模，禁止低模/粗糙拓扑 |
| 材质体系 | 必须声明 PBR 物理材质渲染 |
| 光影反馈 | 体积光、环境光遮蔽、全局光照 |
| 纹理细节 | 木纹/石纹/布纹/玉质纤毫毕现 |
| 色彩 | 中国传统色调（C1-C10 色盘内取色） |

---

## 四、必守

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「3D 渲染风格 + PBR 材质 + 高精度建模」 |
| R2 | 必须声明「中国传统色彩 + 东方美学」质感基调 |
| R3 | 材质锚词至少选用玉石/金属/织物/木质中两类 |
| R4 | 材质必须带岁月痕迹/工艺感，禁止全新无瑕 |
| R5 | 必须声明「纹理清晰可辨」画质锚定词 |

## 五、严禁

| 编号 | 严禁 |
|---|---|
| X1 | 写实摄影/照片级真实感材质 |
| X2 | 低精度建模/粗糙贴图/塑料质感 |
| X3 | 高饱和荧光色/数码感强材质 |
| X4 | 西方奇幻/赛博朋克/现代材质元素 |
| X5 | 材质过新无岁月感（全新 CG 塑料感） |
| X6 | 色彩混乱/光影错误/透视错误 |
