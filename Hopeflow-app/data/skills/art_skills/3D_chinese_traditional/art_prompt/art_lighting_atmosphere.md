# 光影与氛围 · 约束手册

---

## 一、光影基调

1. **电影级光影渲染** — 以影视级布光为标准，追求体积光、环境光遮蔽、景深虚化等电影渲染效果
2. **东方意境** — 光需烘托虚实相生、留白写意的东方美学氛围，拒绝生硬直白的现代打光
3. **自然+人工结合** — 自然光（日光/月光）为基底，辅以烛光/灯笼等人文光源，禁止单光源硬光
4. **典雅华丽** — 光色取中国传统色调，暖光典雅、冷光清幽，整体和谐不刺眼

---

## 二、光源方案

| 编号 | 光源类型 | 作用 | 提示词 |
|---|---|---|---|
| L1 | 自然主光 | 日光/月光奠定基调 | 自然光照、日光漫射、月光清辉 |
| L2 | 体积光 | 穿透云雾/窗棂的光柱 | volumetric lighting、体积光、丁达尔光 |
| L3 | 烛火/灯笼光 | 室内暖光、宫灯点缀 | 烛光摇曳、灯笼暖光 |
| L4 | 轮廓光（剪影光） | 勾勒人物与飞檐轮廓 | 逆光轮廓、侧逆光勾勒 |
| L5 | 氛围散射光 | 雾气/烟岚中的柔光 | 雾气弥漫、柔光漫射、空气透视 |
| L6 | 天光补光 | 冷调暗部补光（C4 靛蓝系） | 冷调天光、环境光遮蔽 |

## 三、光比与明暗对比

| 参数 | 约束值 | 说明 |
|---|---|---|
| 光比 | 中低光比为主 | 柔和过渡，武侠肃杀场景可适度拉高 |
| 对比度 | 中 45-65%（建议区间） | 丰富层次感，避免灰蒙或死黑 |
| 阴影 | 阴影柔和带色相倾向 | 暗部偏 C4 靛蓝/C6 墨黑，拒绝纯黑死沉 |
| 体积感 | 环境光遮蔽（AO） | 墙角/檐下/衣褶处自然压暗 |
| 明暗层次 | 前中后景层次分明 | 空气透视，远景虚化雾化 |

## 四、色温范围

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏中性 4800-5500K（推荐） | 自然光主基调 |
| 暖光源 | 烛光/灯笼 3200-3800K | 宫廷华贵、节日喜庆场景 |
| 冷光源 | 月夜 6000-7000K | 月夜清幽、武侠肃杀场景 |

## 六、必守

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「电影级光影渲染」 |
| R2 | 必须包含「体积光 + 环境光遮蔽」 |
| R3 | 自然光+人工光结合，禁止单光源硬光 |
| R4 | 光色须取自中国传统色调，拒绝荧光色 |
| R5 | 每镜头绑定情绪场景主色+辅色，明暗层次清晰 |

## 七、严禁

| 编号 | 严禁 |
|---|---|
| X1 | 写实摄影/照片级真实感打光 |
| X2 | 高饱和荧光色/霓虹色/数码感光效 |
| X3 | 西方奇幻/赛博朋克/现代都市光源元素 |
| X4 | 单光源硬光、光影方向错误 |
| X5 | 色彩混乱/对比失控/画面灰蒙 |
| X6 | 光比过平无层次（无体积光无暗部） |
