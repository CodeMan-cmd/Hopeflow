# 材质与质感 · 2D扁平风约束手册

> **本画风材质即"无材质"**：一切物体以纯色色块 + 简洁线条呈现，拒绝纹理、渐变、光泽、肌理、立体感。质感描述以「矢量插画/扁平色块/哑光」等词锚定。

---

## 一、渲染质感描述

| 项目 | 约束 | 说明 |
|---|---|---|
| 基底质感 | 矢量插画感 | flat illustration / vector art，边缘干净利落 |
| 表面处理 | 哑光纯色 | matte finish、无光泽、无反光、无高光 |
| 填充方式 | 单色填充 | solid fill、纯色填充，一块一色 |
| 边界处理 | 清晰线稿 | 均匀一致的轮廓线，无晕染无毛边 |
| 光影质感 | 无 | 无阴影无渐变无光影，靠明度色块对比 |

---

## 二、材质锚词清单

> 可直接注入提示词使用（中英文均可，英文优先）。

| 锚词（中） | 锚词（英） | 用途 |
|---|---|---|

| 无渐变 | flat colors / no gradients | 填色否定锚词 |
| 无阴影 | no shadows / minimal shadows | 光影否定锚词 |
| 几何造型 | geometric shapes | 形体语言 |

---

## 三、画质硬约束

| 维度 | 等级要求 | 说明 |
|---|---|---|
| 线条 | 均匀一致、粗细适中 | 轮廓闭合，无断线无毛边，无粗细突变 |
| 颜色 | 色块边界清晰、无溢色 | 纯色填充不混色，色块之间边缘锐利 |
| 细节等级 | 低复杂度、细节简化 | 剔除纹理、花纹、肌理级细节，只留形状级信息 |
| 边缘 | 硬边、矢量切边 | 无柔边、无羽化、无抗锯齿过度 |
| 一致性 | 全画面统一 | 风格/色块语言/线稿风格全局统一 |

---

## 四、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「无纹理、无渐变、纯色填充」（继承 R2/R5） |
| R2 | 表面必须声明「哑光/无光泽/无高光」 |
| R3 | 线条必须声明「清晰线条 + 均匀一致」（继承 R4） |
| R4 | 面部必须声明「几何造型 + 简洁线条」（继承 R3） |
| R5 | 必须包含「2D扁平风 + Flat Design」锚定词（继承 R1） |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁 3D 渲染/CG/写实质感（继承 X1） |
| X2 | 严禁纹理/渐变/阴影/光影（继承 X2） |
| X3 | 严禁高光/反光/金属光泽/玻璃折射等光泽语言 |
| X4 | 严禁复杂细节/精细纹理/写实背景（继承 X5） |
| X5 | 严禁立体感/体积感/浮雕/凹凸贴图感（继承 X6） |
| X6 | 严禁颜色溢出/混色/渐变溢出，色块必须纯净独立 |
