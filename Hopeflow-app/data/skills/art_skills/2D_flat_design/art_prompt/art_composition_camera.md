# 构图与镜头 · 2D扁平风约束手册

> **本画风以几何构成为第一法则**：画面是色块与形状的编排，无景深、无透视、无镜头光学效果。镜头语言退化为「色块层级编排 + 几何引导线」。

---

## 一、景别

| 景别 | 取景范围 | 用途 | 提示词 |
|---|---|---|---|
| 特写 | 面部/局部（无裁切畸形） | 情绪点、关键道具 | 扁平特写、几何脸型 |
| 近景 | 头部至胸部 | 对话、心动瞬间 | 扁平近景、色块上身 |
| 中景 | 膝部以上 | 日常叙事 | 扁平中景、色块半身 |
| 全景 | 全身 | 体态与服装展示 | 扁平全景、几何全身 |
| 远景 | 全身 + 环境 | 环境关系、留白感 | 扁平远景、色块环境 |

> 扁平风没有景深虚化与焦点，景别只决定色块占比与信息层级。

---

## 二、机位与视角

| 机位 | 适用 | 提示词 |
|---|---|---|
| 平视（默认） | 绝大多数镜头，客观冷静 | eye level、正面平视 |
| 轻微仰视 | 人物高大感/崇敬 | 轻微仰视、low angle 弱化 |
| 轻微俯视 | 人物弱小感/俯瞰关系 | 轻微俯视、high angle 弱化 |
| 正侧面/四分之三侧 | 轮廓展示、几何剪影 | 侧面轮廓、几何剪影 |

> **扁平风视角保持克制**：允许轻微俯仰但不得出现强烈透视（三点透视、鱼眼、广角畸变），场景仍须保持平面化。

---

## 三、构图法则（几何构成侧重）

| 法则 | 说明 | 提示词 |
|---|---|---|
| 几何构成 | 圆/方/三角等基本形组织画面，色块边缘清晰 | 几何构成、色块分割 |
| 三分法 | 主体落在三分线交点 | 三分法构图 |
| 对称均衡 | 左右色块重量平衡（不要求镜像） | 均衡构图 |
| 留白 | 纯净白色块/浅色块作呼吸空间 | 大面积留白 |
| 色块分层 | 前/中/后景色块明度递进 | 前景{色}、中景{色}、后景{色} |
| 引导线 | 用道路/栏杆/直线元素引导视线（几何线而非透视线） | 几何引导线 |

---

## 四、镜头语言

| 维度 | 约束 |
|---|---|
| 运动 | 平移/推拉等简化运镜，无甩镜、无手持晃动、无变速 |
| 焦点 | 无景深虚化、无浅景深，全画面同清晰度（扁平逻辑） |
| 景深 | 严禁景深，前后景仅用明度差区分 |
| 转场 | 用色块切换/形状变换转场，不用光效转场 |

---

## 五、提示词模板（中文）

```
2D扁平风插画构图，Flat Design，
{景别}，{机位}，几何构成，
主体位于{三分法交点/居中}，前中后景：{色块A}、{色块B}、{色块C}明度递进，
{留白描述}，{引导线描述}，
无景深，无透视，无阴影，无渐变，纯色填充，
画面简洁现代，色块对比清晰，{情绪关键词}
```

---

## 六、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 每条构图提示词必须声明「几何构成 + 色块分层」 |
| R2 | 必须声明「无景深、无透视、无光影」 |
| R3 | 前/中/后景必须通过色块明度区分，禁用空气透视（继承 R2） |
| R4 | 视角默认平视，俯仰幅度克制且不产生透视畸变 |
| R5 | 必须包含「2D扁平风 + Flat Design」锚定词（继承 R1） |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁景深虚化/浅景深/焦点模糊（继承 X2/X6） |
| X2 | 严禁三点透视/鱼眼/广角畸变/透视引导线（继承 X6） |
| X3 | 严禁甩镜/手持晃动/快速变焦等电影运镜 |
| X4 | 严禁画面分割失焦：无主色块、色块混淆不清（继承 X5） |
| X5 | 严禁拼图/多视图/网格分屏构图 |
