# 光影与氛围 · 2D扁平风约束手册

> **本画风无阴影、无渐变、无光影**。光感一律通过「纯色块明度对比」与「平光逻辑」表达：用不同明度的平涂色块模拟昼夜/情绪，严禁使用光源方向、投影、辉光等写实光影语言。

---

## 一、氛围光方案（色块逻辑替代光源）

> 扁平风不刻画"光从哪里来"，只声明"当前处于什么光氛围"，用明度与色块冷暖表达。

| 方案 | 色块构成 | 明度逻辑 | 使用场景 | 提示词 |
|---|---|---|---|---|
| 白昼平光 | C3 纯净白 + C8 浅黄 + C10 薄荷绿 | 高亮低对比，全画面均亮 | 日常、治愈、通勤 | 纯色高亮、平光氛围、bright flat daylight |
| 黄昏暖调 | C8 浅黄 + C2 活力橙 + C9 米白 | 中高亮，暖色块占比提升 | 心动、告别、放课后 | 扁平暖色块、黄昏色板、flat sunset palette |
| 夜晚静谧 | C6 淡紫 + C1 明快蓝 + C2 活力橙点缀 | 低明度为主，冷色块铺底 | 夜景、思考、独处 | 扁平夜色、冷色块打底、flat night palette |
| 回忆闪回 | C8 浅黄 + C5 高级灰 + C7 暖粉 | 低对比，色块轻度褪色感 | 回忆、旧忆、梦境 | 扁平褪色感、低对比色块、faded flat colors |
| 心动升温 | C7 暖粉 + C2 活力橙 + C9 米白 | 中对比，暖粉色块主导 | 告白、靠近、甜蜜 | 扁平暖粉氛围、心动色块、flat pink mood |
| 冷调疏离 | C1 明快蓝 + C5 高级灰 + C6 淡紫 | 高对比，冷色块主导 | 离别、克制、静压 | 扁平冷调、距离感色块、flat cool mood |

## 二、明度对比与层次

| 维度 | 约束 | 说明 |
|---|---|---|
| 对比度 | 中等偏高（建议保持） | 色块间明度差清晰，但不过分强烈，杜绝黑白硬怼 |
| 明度层级 | 单镜头 3-4 个明度层级 | 主色块 1 个、辅助色块 1-2 个、点缀色块 1 个 |
| 层次手段 | 纯色块并置 | 前景亮色块 + 中景主色块 + 后景暗色块（或反之） |
| 肤色明度 | 微暖 5800-6200K 观感 | C3 纯净白 + C9 米白基准，允许小幅明度微调 |

---

## 三、色温约束（继承 prefix）

| 参数 | 值 |
|---|---|
| 整体色温 | 中性 5500-6500K（推荐） |
| 肤色色温 | 微暖 5800-6200K（推荐） |
| 饱和度 | 中高 70-90%（建议区间） |

> 色相偏移 ±8°、饱和度偏移 ±10%、明度偏移 ±12%，例外镜头（浪漫/高潮）可临时提暖或提饱和局部色块，但不得突破严禁项。

## 四、色调情绪与画面关键词

| 情绪场景 | 主色块 | 辅色块 | 画面关键词 |
|---|---|---|---|
| 日常温馨 | C9 米白 | C3 纯净白 + C5 高级灰 | 生活感、温暖、平静 |
| 心动瞬间 | C7 暖粉 | C2 活力橙 + C9 米白 | 羞涩、靠近感、暧昧 |
| 浪漫场景 | C7 暖粉 | C2 活力橙 + C8 浅黄 | 甜蜜、温暖、情感 |
| 夜晚静谧 | C6 淡紫 | C1 明快蓝 + C2 活力橙 | 静谧、神秘、思考 |
| 离别感伤 | C5 高级灰 | C1 明快蓝 + C6 淡紫 | 距离感、克制、静压 |
| 重逢释怀 | C9 米白 | C7 暖粉 + C2 活力橙 | 回温、释然、治愈 |

## 五、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 每条提示词必须绑定 1 个「氛围光方案」并声明其纯色块构成 |
| R2 | 光感必须用「纯色块明度对比」表达，声明「无阴影、无渐变、无光影」 |
| R3 | 单镜头主色块不超过 2 个，点缀色块 1 个，避免颜色叙事失焦 |
| R4 | 必须指定「2D扁平风 + Flat Design」锚定词与「平光逻辑」 |
| R5 | 情绪切换优先调整色块冷暖与明度，再调整饱和度 |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁光源方向/投影/阴影/辉光/体积光等写实光影语言（继承 X2） |
| X2 | 严禁渐变、晕染、柔光、光晕效果（继承 X2） |
| X3 | 严禁高饱和荧光色/霓虹色氛围（继承 X3） |
| X4 | 严禁 3D 透视、景深、空气感等深度描述（继承 X6） |
| X5 | 严禁复杂细节/精细纹理/写实背景（继承 X5） |
| X6 | 严禁单色怼死（画面只剩一个色块明度）导致失去层次 |
