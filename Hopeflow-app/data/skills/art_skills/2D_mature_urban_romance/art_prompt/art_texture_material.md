# 材质与质感 · 成熟都市言情二次元动画约束手册

> **本画风质感介于赛璐璐动画与现代电影之间**：赛璐璐上色 + 清晰线条为底，纹理细节超清晰（继承 R5），都市道具材质真实可感，整体低饱和高级灰调。

---

## 一、渲染质感描述

| 项目 | 约束 | 说明 |
|---|---|---|
| 基底质感 | 赛璐璐动画上色 | cel shading 为主，色影同色系 |
| 线条质感 | 清晰锐利 | 轮廓明确、无模糊抖动（继承 R2） |
| 材质精度 | 纹理细节超清晰 | 织物/金属/玻璃/木质纹理可辨（继承 R5） |
| 表面处理 | 细腻柔和 | 皮肤柔光，道具材质真实 |
| 光感 | 低调光影 | 局部高光锐利，暗部细腻过渡 |

## 三、画质硬约束

| 维度 | 等级要求 | 说明 |
|---|---|---|
| 线条 | 清晰锐利、粗细均匀 | 禁模糊断线，轮廓闭合干净 |
| 颜色 | 低饱和冷调为主 | 高级灰调，暖色仅点缀 |
| 细节等级 | 高细节 | 都市材质/衣物纹理/发丝层次清晰 |
| 肤质 | 细腻柔光 | 冷白/暖白肤色，非塑料感 |
| 一致性 | 全画面统一 | 材质语言与光影逻辑全局统一 |

---

## 四、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「赛璐璐上色 + 清晰线条」（继承 R2） |
| R2 | 必须声明「纹理细节超清晰」（继承 R5） |
| R3 | 面部必须声明「面容细腻渲染 + 皮肤细腻」（继承 R3） |
| R4 | 发丝必须声明「层次分明 + 发丝细腻渲染」（继承 R4） |
| R5 | 必须声明「二次元动画风格」锚定词（anime style / cel shading，继承 R1） |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁真人写实/摄影/3D 渲染/CGI 材质（继承 X1） |
| X2 | 严禁高饱和荧光/霓虹材质（继承 X2） |
| X3 | 严禁现代元素材质入镜（手机屏幕/电脑屏显/现代标识，继承 X3） |
| X4 | 严禁面部变形/多指/肢体异常（继承 X4） |
| X5 | 严禁裸体/暴露/透视/暗示性材质描述（继承 X5） |
