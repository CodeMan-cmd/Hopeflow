# 光影与氛围 · 成熟都市言情二次元动画约束手册

> **本画风以戏剧化低调光影为灵魂**：大光比、暗部深沉、局部强光勾勒情绪焦点，整体低饱和冷调铺底、琥珀暖光落在人物关系焦点，形成「冷底 + 暖点」的甜宠电影感。

---

## 一、光源方案

| 方案 | 光源特征 | 光比建议 | 使用场景 | 提示词 |
|---|---|---|---|---|
| 咖啡馆暖灯 | 低角度台灯光源，局部暖光 | 1:4 大光比 | 初见、暧昧、对话 | 戏剧化台灯暖光、局部照明 |
| 黄昏逆光 | 落地窗逆光，轮廓金边 | 1:3 中大光比 | 重逢、情绪高点 | 逆光轮廓、琥珀边缘光 |
| 都市夜景 | 冷调城市光 + 窗内暖点 | 1:3 中大光比 | 夜归、独处、思念 | 冷调城市光、玻璃反光暖点 |
| 月光窗纱 | 清冷月光透过纱帘，柔中带硬 | 1:2.5 中光比 | 夜间心事、耳语 | 月光纱帘、冷白光影 |
| 办公室顶光 | 顶部冷白硬光，克制压抑 | 1:3 中大光比 | 职场、对峙、误会 | 冷调顶光、克制暗部 |
| 烛光/灯带 | 暖色微光，低照度氛围 | 1:4 大光比 | 仪式感、告白、夜宴 | 烛光暖点、微光氛围 |

## 二、光比与明暗对比

| 维度 | 约束 | 说明 |
|---|---|---|
| 整体对比度 | 强（建议保持） | 明暗反差鲜明，戏剧化低调光影（继承 R6） |
| 暗部 | 青灰/墨黑深色影，保留细节 | 禁止死黑一片，暗部须可辨 |
| 高光 | 琥珀暖局部高光 | 落在面部/手部/关系焦点，不铺满 |
| 冷暖逻辑 | 冷底 + 暖点（继承 E4） | 环境冷色铺底，暖光落在人物关系焦点 |

## 三、色温约束（继承 prefix）

| 参数 | 值 |
|---|---|
| 整体色温 | 偏冷 5800-7000K（推荐） |
| 肤色色温 | 微暖 5200-5600K（推荐） |
| 饱和度 | 中低 30-50%（建议区间） |
| 对比度 | 强（建议保持） |

> 色相偏移 ±8°、饱和度偏移 ±10%、明度偏移 ±12%。婚礼/灯会/回忆/情绪高潮镜头可更暖或更高饱和局部色块，但禁止霓虹荧光与现代色彩语言入镜。

## 四、色调情绪与画面关键词

| 情绪场景 | 主色 | 辅色 | 画面关键词 |
|---|---|---|---|
| 初见心动（克制甜） | C1 冷白肤 | C5 烟霞粉 + C8 银灰 | 清冷、呼吸感、微甜 |
| 暧昧升温（亲密拉近） | C5 烟霞粉 | C7 琥珀暖 + C10 素白 | 软焦、耳语感、贴近 |
| 分离误会（冷疏压抑） | C6 青灰 | C1 冷白肤 + C9 中性灰 | 距离感、克制、静压 |
| 重逢释怀（泪感回暖） | C1 冷白肤 | C7 琥珀暖 + C5 烟霞粉 | 回温、释然、湿润空气 |
| 夜宴灯会（浪漫流光） | C7 琥珀暖 | C6 青灰 + C3 浅蓝 | 流光、灯影、人潮中对视 |
| 梦境回忆（写实化） | C1 冷白肤 | C6 青灰 + C3 浅蓝 | 空灵、旧忆感、真实可拍 |

## 五、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 每条提示词必须声明「戏剧化低调光影」（继承 R6） |
| R2 | 必须声明「赛璐璐上色 + 清晰线条」（继承 R2） |
| R3 | 必须遵循「冷底 + 暖点」冷暖逻辑（继承 E4） |
| R4 | 必须绑定 1 个光源方案并指定光比 |
| R5 | 暗部必须保留细节，严禁死黑 |
| R6 | 情绪切换优先调整光比与色温，再调整饱和度（继承 E3） |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁高饱和荧光色/霓虹色光效（继承 X2） |
| X2 | 严禁真人写实/摄影/3D/CGI 光效（继承 X1） |
| X3 | 严禁现代元素入镜（手机屏幕/电脑屏显/现代标识发光，继承 X3） |
| X4 | 严禁过曝高光/大面积亮白失衡 |
| X5 | 严禁光源杂乱、多色温混光，单镜头主光源不超过 1 个 |
