# 材质与质感 · 约束手册

---

## 一、渲染质感描述

1. **赛璐珞质感** — 3D 渲染呈现动画赛璐珞上色质感，色彩明快通透，杜绝写实照片颗粒
2. **清晰轮廓线** — 角色与物体边缘轮廓线清晰流畅，强化卡通比例下的形体识别
3. **高细节材质** — 材质纹理细腻真实（写实材质方向），但比例与光影保持卡通化
4. **柔和暖调** — 所有材质在暖光下呈现温暖质感，杜绝冷灰塑料感与油腻反光

---

## 二、材质锚词清单

| 部位 | 锚词（中） | 锚词（英） |
|---|---|---|
| 皮肤 | 柔光肌、暖白皮、皮肤细腻通透 | soft skin、peach skin、translucent skin |
| 发丝 | 发丝根根分明、丝缕清晰、赛璐珞发质 | hair strands、detailed hair、clear hair outline |
| 织物 | 布料纹理清晰、自然垂褶 | fabric texture、natural folds |
| 金属/饰品 | 细腻金属光泽、柔和高光 | fine metal sheen、soft specular |
| 场景材质 | 木质/玻璃/路面纹理清晰 | detailed wood/glass/road textures |
| 整体 | 高细节材质、纹理清晰可辨 | high-detail textures、clear textures |

---

## 三、画质硬约束

| 参数 | 硬约束 |
|---|---|
| 分辨率 | 8K 超高清渲染 |
| 建模精度 | 高精度 3D 建模，禁止 low-poly 低模 |
| 纹理 | 纹理清晰可辨，禁止模糊贴图 |
| 轮廓 | 轮廓线清晰流畅（cel outline） |
| 光照 | 柔和光影层次，禁止硬光死黑 |
| 色彩 | 暖色调为主，C1-C10 色盘内取色 |

---

## 四、必守

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「3D 动画渲染 + 赛璐珞质感」风格锚定词 |
| R2 | 必须声明「清晰轮廓线 + 高细节材质」 |
| R3 | 面部必须声明「写实材质与卡通比例结合 + 柔和光影」 |
| R4 | 发丝必须声明「清晰轮廓线 + 自然光影层次」 |
| R5 | 材质锚词至少选用皮肤/发丝/织物中两类 |

## 五、严禁

| 编号 | 严禁 |
|---|---|
| X1 | 写实渲染/照片级真实感材质 |
| X2 | 光滑塑料/油腻 CG 反光/玻璃质感皮肤 |
| X3 | 暗调重阴影下丢失纹理细节 |
| X4 | 高饱和荧光色/霓虹色材质 |
| X5 | 低精度建模/粗糙贴图/纹理模糊 |
| X6 | 面部变形/比例失调/肢体异常倾向词 |
