# 光影与氛围 · 约束手册

---

## 一、光影基调

1. **电影级打光** — 一切画面以电影级布光为标准，追求柔和光影层次，拒绝平光死白与硬光切割
2. **暖调治愈** — 光色以暖橙/琥珀暖为主轴，整体明快温暖，杜绝冷灰阴郁
3. **赛璐珞透光** — 光需带出赛璐珞质感的通透感，阴影柔和、轮廓线清晰，写实材质与卡通比例在光下统一
4. **现代都市光** — 光源须符合现代都市场景逻辑（街灯/窗光/橱窗/霓虹质感柔光），禁止架空光源

---

## 二、光源方案

| 编号 | 光源类型 | 作用 | 提示词 |
|---|---|---|---|
| L1 | 主光（Key Light） | 奠定明暗基调，柔和暖光为主 | soft warm key light、暖调主光 |
| L2 | 补光（Fill Light） | 填充暗部、降低光比 | gentle fill light、柔和补光 |
| L3 | 轮廓光（Rim Light） | 勾勒发丝与轮廓线，增强立体 | warm rim light、暖色轮廓光 |
| L4 | 氛围光（Ambient） | 场景环境光，对应 C9 米白/C10 暖黄 | 暖调环境光、自然漫射 |
| L5 | 特效光（Accent） | 黄昏霞光/街灯/橱窗等局部光斑 | 黄昏逆光、灯光光斑、bokeh 光斑 |
| L6 | 冷调点缀光（Cool Accent） | 夜晚街景 C3 天空蓝/C6 淡紫点缀 | 冷调点缀光、蓝紫氛围光 |

---

## 三、光比与明暗对比

| 参数 | 约束值 | 说明 |
|---|---|---|
| 光比 | 主光:补光 ≈ 2:1 ~ 3:1 | 柔和过渡，禁止高反差硬光 |
| 明暗对比 | 中等（建议保持） | 明暗层次清晰但不过分强烈 |
| 阴影 | 柔和阴影（soft shadow） | 边缘过渡自然，禁止重阴影/死黑 |
| 高光 | 局部高光点缀 | 发丝/眼神/金属反光处提亮 |
| 背光 | 允许逆光霞光 | 黄昏浪漫场景常用，配轮廓光 |

---

## 四、色温范围

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 4800-5200K（推荐） | 温暖治愈主基调 |
| 肤色色温 | 微暖 5000-5400K（推荐） | C1 暖橙 #F5A673 有生命感 |
| 夜景色温 | 冷调打底 5500-6500K + 暖色灯光点缀 | C3 天空蓝 + C6 淡紫，暖色点缀 |

---

## 五、色调情绪与画面关键词

| 情绪场景 | 主色 | 辅色 | 氛围关键词 |
|---|---|---|---|
| 日常温馨 | C10 暖黄 #F5E6D0 | C9 米白 #F5F0E8 | 生活感、温暖、平静、柔和暖光 |
| 心动瞬间 | C2 樱花粉 #F4D5D5 | C1 暖橙 #F5A673 | 羞涩、暧昧、粉调柔光、中近景提暖 |
| 黄昏浪漫 | C7 琥珀暖 #C9A96E | C1 暖橙 #F5A673 | 逆光霞光、轮廓光、温暖浪漫 |
| 夜晚街景 | C3 天空蓝 #87AEC9 | C6 淡紫 #D0C4D6 | 都市、静谧、暖色灯光点缀 |
| 室内日常 | C10 暖黄 #F5E6D0 | C5 高级灰 #8A8A8A | 居家、舒适、暖光柔焦 |
| 离别感伤 | C5 高级灰 #8A8A8A | C3 天空蓝 #87AEC9 | 距离感、克制、降饱和冷暖反差 |

## 六、必守

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「电影级打光 + 柔和光影层次」 |
| R2 | 必须包含「暖调治愈」氛围锚定词，整体偏暖 4800-5200K |
| R3 | 必须符合现代都市场景光源逻辑 |
| R4 | 每镜头至少指定 1 个情绪场景并绑定主色+辅色 |
| R5 | 光源方案至少声明主光+补光，可叠加轮廓光/氛围光 |

## 七、严禁

| 编号 | 严禁 |
|---|---|
| X1 | 写实渲染/照片级真实感打光 |
| X2 | 暗调/重阴影/过度对比/死黑死白 |
| X3 | 高饱和荧光色/霓虹色光效 |
| X4 | 正顶硬光/正底光/彩色光污染 |
| X5 | 赛博朋克/蒸汽朋克/架空西幻光源元素 |
| X6 | 无光源逻辑、光照方向混乱 |
