# 暗黑科幻画风（Dark Sci-Fi）

## 风格定位

暗黑科幻画风专为反乌托邦题材短剧打造，核心特征：**冷峻工业质感与生物异化融合**。画面以暗黑工业风（Dark Industrial）、赛博义体（Cybernetic Prosthetics）、霓虹阴霾（Neon Haze）与金属锈蚀（Corroded Metal）为基底，通过阴郁高对比光影（Moody High-Contrast Lighting）营造压抑、冷漠且危险四伏的未来世界。适用于科技惊悚叙事、世界观氛围渲染及反乌托邦情节推进。

## 适用类型

| 类型 | 说明 | 时长 |
|------|------|------|
| 反乌托邦都市 | 巨型霓虹都市中的贫富割裂、雨夜荒街与压抑建筑群 | 15-30s |
| 义体改造人 | 半人半机械的角色设定，体现异化与身份焦虑 | 10-20s |
| 生化异变体 | 基因编辑与机械融合的生命体，展现失控科技后果 | 15-25s |
| 废土求存 | 文明崩坏后的废墟世界，废弃物与幸存者叙事 | 20-40s |

## 严禁内容

- 明亮治愈的温馨色调（高饱和糖果色、幼儿卡通感）
- 纯写实无科幻元素的现实题材
- 无叙事逻辑的抽象视觉堆砌
- 中国传统古风水墨基调的直接套用
- 纯黑白极简风格（缺少层次与氛围铺垫）
