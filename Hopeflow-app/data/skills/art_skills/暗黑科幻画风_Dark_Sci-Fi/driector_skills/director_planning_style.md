# 暗黑科幻画风约束 · 导演规划技法

---

## 〇、全局视觉原则

暗黑科幻的核心是**冷峻工业质感与生物异化融合的反乌托邦未来美学**。在导演规划阶段，必须始终锚定以下视觉基调：

- **暗黑工业风**：锈蚀金属、裸露管线、油腻污渍、沉重的工业结构
- **赛博义体**：机械与血肉的共生体，义肢/植入体/外露接头
- **霓虹阴霾**：在压制性的黑暗中，冷色霓虹光晕浮动、反射在湿漉表面
- **生物机械融合**：有机体与无机物互为侵犯，异变、排异、感染
- **反乌托邦**：压抑的制度性空间，贫富割裂，人变成系统的零件
- **金属锈蚀**：时间与衰败在材质上的沉积
- **阴郁高对比光影**：极暗环境中锐利光源刺破画面，形成强烈明暗分割
- **废土气息**：文明残骸、尘埃、风沙、废弃物

同时，**严格禁止**以下方向，避免偏离风格识别：

- ❌ 明亮治愈的温馨色调（高饱和糖果色、幼儿卡通感）
- ❌ 纯写实无科幻元素的现实题材
- ❌ 无叙事逻辑的抽象视觉堆砌
- ❌ 中国传统古风水墨基调的直接套用
- ❌ 纯黑白极简风格（缺少层次与氛围铺垫）

## 一、模板选择

导演规划阶段首先确定暗黑科幻短剧的叙事模板。模板决定整体结构、节奏与视觉段落。

| 模板 | 结构 | 适用场景 | 时长 |
|------|------|---------|------|
| **反乌托邦都市** | 城市面貌铺陈(3s) -> 主角困境揭示(4s) -> 冲突升级(5s) -> 命运抉择(4s) -> 阴霾收尾(2s) | 巨型霓虹都市中的贫富割裂、雨夜荒街与压抑建筑群 | 15-25s |
| **义体改造人** | 义体登场(2s) -> 能力展露(3s) -> 异化挣扎(5s) -> 爆发对抗(5s) -> 身份留白(3s) | 半人半机械的角色设定，体现异化与身份焦虑 | 15-25s |
| **生化异变体** | 异变前状态(2s) -> 失控变异(4s) -> 恐怖展露(5s) -> 猎杀/逃亡(6s) -> 残骸余烬(3s) | 基因编辑与机械融合的生命体，展现失控科技后果 | 15-25s |
| **废土求存** | 废墟全景(3s) -> 幸存者线索(3s) -> 危机逼近(4s) -> 绝境求生(5s) -> 风沙掩埋(3s) | 文明崩坏后的废墟世界，废弃物与幸存者叙事 | 15-25s |

---

## 二、核心视觉主角设计

### 选择原则

- **机械与血肉共生** - 主角或核心形象必须在同一视觉载体上同时呈现工业机械与生物有机质感，例如破损义肤下露出金属骨骼、肌肉组织与管线缠绕。
- **有"异化痛点"** - 主角的恐惧、挣扎或威胁来自自身改造失控或环境压迫（义体排异、记忆丢失、生化突变、资源匮乏）。
- **环境即角色** - 反乌托邦都市的街道、废土废墟、实验室等环境空间拥有与主角同等重要的叙事地位，规划时需赋予环境明确的视觉情绪和动态细节。

### 设计要素

| 要素 | 说明 |
|------|------|
| 主角类型 | 义体改造人 / 生化异变体 / 废土幸存者 / 反乌托邦城市底层居民 |
| 视觉核心 | 金属锈蚀与生物组织融合、破损义体、外露机械结构、霓虹冷光反射 |
| 异化特征 | 机械义肢、植入体、变异器官、外露线路、生物附着物、非人瞳孔 |
| 面部风格 | 冷峻、疲惫、麻木、危险或焦虑，眼神嵌入高对比光源，少笑意 |
| 色彩倾向 | 铁灰、枪黑、暗蓝、锈红、荧光绿/紫（仅作点缀） |

## 三、色调与氛围规划

### 反乌托邦都市模板色调

| 段落 | 色调 | 氛围 |
|------|------|------|
| 城市面貌铺陈 | 暗蓝+霓虹紫 | 冷峻、压抑、繁华下的颓败 |
| 主角困境揭示 | 阴郁灰蓝+湿冷 | 低沉、无助、机械感 |
| 冲突升级 | 高对比黑影+警示红 | 紧张、暴力、不安 |
| 命运抉择 | 冷白+刺目霓虹 | 冷静、残酷、选择时刻 |
| 阴霾收尾 | 黑青+雾霾 | 无尽循环、希望渺茫 |

### 义体改造人模板色调

| 段落 | 色调 | 氛围 |
|------|------|------|
| 义体登场 | 工业灰+冷光 | 展示机械质感，冷静疏离 |
| 能力展露 | 幽蓝+脉冲光 | 力量感、非人感 |
| 异化挣扎 | 暗红+闪烁 | 痛苦、失控、身份焦虑 |
| 爆发对抗 | 高对比橙红 | 激烈、暴戾、混乱 |
| 身份留白 | 黑+苍白 | 虚无、孤独、异化 |

### 生化异变体模板色调

| 段落 | 色调 | 氛围 |
|------|------|------|
| 异变前状态 | 苍白+实验室白 | 受控、压抑 |
| 失控变异 | 腐绿+锈褐 | 恶心、危险、不可逆 |
| 恐怖展露 | 血红+暗紫 | 恐惧、压迫 |
| 猎杀/逃亡 | 暗黑+闪烁红光 | 追逐、窒息 |
| 残骸余烬 | 灰烬+烟熏 | 毁灭、余悸 |

### 废土求存模板色调

| 段落 | 色调 | 氛围 |
|------|------|------|
| 废墟全景 | 土黄+铁灰 | 苍凉、死寂 |
| 幸存者线索 | 暖黄微光 | 一丝希望、却暗藏危险 |
| 危机逼近 | 冷蓝+褐雾 | 警惕、压迫 |
| 绝境求生 | 高对比沙暴色 | 挣扎、混乱 |
| 风沙掩埋 | 昏黄+黑 | 徒劳、宿命 |

## 四、资产规划

### 基础资产

- **环境场景** - 巨型都市霓虹街景、工业废墟、地下实验室、废土荒漠
- **核心主角** - 义体改造人/生化异变体的角色设定图（正侧背三视图），保存生物机械融合细节
- **光影氛围** - 暗黑工业风打光参考，霓虹光晕、锈蚀纹理、雾气粒子

### 衍生资产

| 模板 | 衍生资产 |
|------|---------|
| 反乌托邦都市 | 贫富割裂的空间道具（飞行车/垃圾堆）、湿漉雨夜路面、全息广告牌、密布管线建筑 |
| 义体改造人 | 义体部件特写、排异反应特效、不同改装程度替换件、身份识别芯片 |
| 生化异变体 | 变异过程关键帧、机械附着物、猎杀场景道具、污染源容器 |
| 废土求存 | 废弃载具、辐射污染标记、幸存者装备、沙暴天气层 |

## 五、全自动执行要点

暗黑科幻画风模式下，导演规划完成后：

1. **自动进入阶段2** - 不等待用户逐条确认，直接分析衍生资产
2. **自动进入阶段3** - 如有衍生资产则生成图片，无则跳过
3. **自动进入阶段4** - 构建简化版分镜表（按模板结构拆分5个分镜）
4. **自动进入阶段5** - 写入分镜面板
5. **自动进入阶段6** - 生成分镜图
6. **完成后通知用户** - 告知分镜图已开始生成，引导用户去视频工作台

用户只需在**导演规划完成后确认一次**，后续全自动执行。
