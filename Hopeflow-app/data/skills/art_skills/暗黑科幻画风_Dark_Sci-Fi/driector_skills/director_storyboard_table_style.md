# 分镜表风格 · 暗黑科幻画风

---

## 分镜拆分原则

暗黑科幻分镜表按**叙事场景**拆分，每个分镜承载一个明确的氛围/情绪节点：

### 反乌托邦都市模板（10-15s，3-4个分镜）

| 分镜 | 内容 | 时长 | 资产 |
|------|------|------|------|
| 1 | 巨型霓虹都市俯瞰，雨夜荒街，压抑建筑群冷光笼罩 | 2-3s | 都市全景 |
| 2 | 主角穿行于霓虹阴霾中，义体部件金属锈蚀反光 | 4-5s | 主角（义体状态） |
| 3 | 贫富割裂对照，高塔光鲜与底层废墟同框 | 3-4s | 主角+都市反差场景 |
| 4 | 主角隐入阴暗角落，眼神冷峻回望，霓虹映照半脸 | 2-3s | 主角（阴郁高对比光影） |

### 义体改造人模板（8-15s，3-4个分镜）

| 分镜 | 内容 | 时长 | 资产 |
|------|------|------|------|
| 1 | 义体细节特写，机械关节与血肉接缝处锈蚀/渗液 | 2-3s | 义体部件特写 |
| 2 | 主角半机械半人脸，瞳孔异常亮起，望向镜头 | 3-4s | 主角（义体觉醒状态） |
| 3 | 义体失控，机械臂扭曲伸展，生物组织被金属挤压异化 | 4-5s | 主角（异化状态） |
| 4 | 主角压制异变，面罩落下，金属与血肉界限模糊 | 2-3s | 主角（压抑状态） |

### 生化异变体模板（15-30s，5-6个分镜）

| 分镜 | 内容 | 时长 | 资产 |
|------|------|------|------|
| 1 | 实验室废墟，培养槽碎裂，粘稠液体与锈蚀管道交错 | 3s | 废墟场景 |
| 2 | 异变体初现，生物组织与机械骨架融合扭曲 | 4-5s | 异变体（初生状态） |
| 3 | 异变体追击，画面高对比光影闪烁，锈蚀金属与肉块飞溅 | 5-6s | 异变体+追逃场景 |
| 4 | 反转揭示：异变体保留人类意识，眼神流露痛苦 | 4-5s | 异变体（意识状态） |
| 5 | 失控高潮，机械骨骼外翻，生物组织崩解，废土气息弥漫 | 4-5s | 异变体（崩解状态） |
| 6 | 残余机械残骸冒烟，空旷废墟定格，阴霾压下 | 2-3s | 废墟残骸 |

## 字段约束

| 字段 | 约束 |
|------|------|
| videoDesc | 描述暗黑科幻场景+角色异化状态，必须包含氛围关键词（压抑/冷峻/危险） |
| prompt | 注入画风锚定词（暗黑工业风/生物机械融合/霓虹阴霾/金属锈蚀）+光影描述+异化动作描述 |
| track | 都市模板=1组；义体模板=1组；异变体=按角色/场景分组 |
| duration | 单镜不超过8s，总时长按模板范围 |
| associateAssetsIds | 关联角色本体+义体/异化状态+废墟场景资产 |

## 质量门检查项

- [ ] 分镜数量符合模板结构（3-6个）
- [ ] 每个分镜有明确的氛围/情绪/异化动作描述
- [ ] 生物机械融合描述完整（金属+生物组织+异化细节）
- [ ] 光影描述符合阴郁高对比基调（霓虹/冷光/阴影层次）
- [ ] 资产关联正确（角色本体+异化状态+废墟场景）
