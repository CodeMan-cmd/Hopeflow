# 暗黑科幻道具设定图生成 · 约束手册

---

## 一、道具设计原则

1. **功能可读** — 道具用途一目了然，造型服务于暗黑科幻叙事（义体改造/生化异变/废土生存）
2. **写实工业质感** — 金属锈蚀、机械拼接、生物组织融合的摄影写实材质，禁卡通/2D
3. **世界观一致** — 道具符合暗黑科幻的反乌托邦/生物机械融合/废土气息世界观
4. **尺度明确** — 通过参照结构或构图暗示道具真实尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁人物/手部/肢体，道具处于静物陈列状态

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态，机械/生物结构清晰 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/接口结构完整可读 | side view |
| 左下 | 背面图 | 背面 180° | 背部结构/线缆/植入接口可见 | back view |
| 右下 | 细节特写 | 局部放大 | 锈蚀纹理/生物组织/机械咬合细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 深灰纯色 #2A2A2A |
| 光线 | 冷调侧光，柔和渐变，阴影清晰 |
| 比例 | 每格道具占格内主体 70%+ |
| 画面比例 | 建议 1:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「深灰纯色背景 #2A2A2A」 |
| R2 | 必须明确道具所属类别（义体/生化/废土/反乌托邦日常） |
| R3 | 必须明确道具材质与状态（锈蚀/战损/生物融合等） |
| R4 | 必须为「四宫格」布局：正面 + 侧面 + 背面 + 特写 |
| R5 | 必须包含摄影写实 + 风格锚定词（dark industrial / bio-mechanical / neon haze / corroded metal） |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景（仅允许纯色背景） |
| X2 | 出现任何人物形象（含手/肢体） |
| X3 | 道具处于被持有/佩戴/植入/使用状态 |
| X4 | 卡通/动漫/2D/扁平插画风格 |
| X5 | 明亮治愈的温馨色调（高饱和糖果色、幼儿卡通感） |
| X6 | 纯写实无科幻元素的现实题材 |
| X7 | 无叙事逻辑的抽象视觉堆砌 |
| X8 | 中国传统古风水墨基调的直接套用 |
| X9 | 纯黑白极简风格（缺少层次与氛围铺垫） |
| X10 | 与暗黑科幻世界观冲突的明亮商业产品渲染风格 |
