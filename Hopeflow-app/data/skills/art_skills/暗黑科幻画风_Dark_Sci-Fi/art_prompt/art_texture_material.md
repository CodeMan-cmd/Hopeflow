# 材质与质感 · 暗黑科幻画风约束手册

> **本画风质感锚定于"dark industrial + bio-mechanical fusion"**：金属锈蚀、废墟污染与生物组织自然共生，禁明亮治愈、纯色扁平、无逻辑堆砌。

---

## 一、渲染质感描述

| 项目 | 约束 | 说明 |
|---|---|---|
| 基底质感 | 暗黑工业风（dark industrial） | 锈蚀金属、混凝土废墟、油腻污染 |
| 材质融合 | 生物机械融合（bio-mechanical fusion） | 有机组织与机械部件自然嵌合，非生硬拼接 |
| 光影氛围 | 阴郁高对比光影（moody high-contrast lighting） | 强明暗对比，霓虹阴霾，暗部细节保留 |
| 表面处理 | 金属锈蚀、磨损、液体残留 | 腐蚀痕迹、划痕、油污、有机黏液 |
| 色彩倾向 | 低饱和金属色 + 局部霓虹点缀 | 灰黑钢青、铁锈红、霓虹青紫，禁用高饱和糖果色 |
| 细节精度 | 纹理/锈蚀/生物纤维清晰可辨 | 微距级材质细节，无塑料假面感 |

## 三、常见材质约束

| 材质 | 渲染要求 | 提示词 |
|---|---|---|
| 金属（钢/铁） | 锈蚀、磨损、冷光泽 | rusted steel, worn metal, cold reflections |
| 生物组织 | 湿润肌理、血管状纤维 | organic tissue, wet texture, vascular fibers |
| 塑料/橡胶（义体） | 老化裂纹、污渍 | aged rubber, cracked plastic, grime |
| 玻璃（霓虹灯管） | 破碎、积尘、辉光 | fractured glass, dust, neon glow |
| 混凝土/砖石 | 裂缝、苔藓、污痕 | cracked concrete, grimy brick, stains |
| 纤维（线缆/织物） | 磨损、油浸、撕裂 | frayed cables, oil-soaked fabric, torn edges |

## 四、生物异化融合约束

| 项目 | 约束 | 提示词 |
|---|---|---|
| 过渡 | 生物组织与机械部件自然嵌入 | seamless tissue-to-metal integration |
| 比例 | 机械与有机面积均衡或有机突显 | balanced organic-mechanical ratio |
| 细节 | 血管、筋腱与线缆结构可辨 | visible veins, sinews, and cables |
| 色彩 | 血肉暖色与金属冷色混合 | warm flesh tones with cold metal hues |
| 表面 | 湿滑黏液与干涸锈迹共存 | wet biofilm, dried rust patch |

## 六、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「dark industrial aesthetic」风格锚定词 |
| R2 | 必须声明「bio-mechanical fusion」材质融合 |
| R3 | 必须声明「moody high-contrast lighting」光影约束 |
| R4 | 必须包含锈蚀、磨损或污染等表面细节 |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 明亮治愈的温馨色调（高饱和糖果色、幼儿卡通感） |
| X2 | 纯写实无科幻元素的现实空间 |
| X3 | 无叙事逻辑的抽象视觉堆砌 |
| X4 | 传统古风水墨或纯黑白极简风格（缺层次与氛围） |
| X5 | 干净无菌的现代化实验室质感（破坏废土气息） |
