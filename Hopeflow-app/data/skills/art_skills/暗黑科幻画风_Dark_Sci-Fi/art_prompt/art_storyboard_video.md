## 暗黑科幻分镜专用提示词规则

### 1. 场景与氛围

- **压抑环境** - 废弃工业建筑、雨夜荒街、巨型霓虹广告牌、弥散烟尘、积水倒影
- **冷峻光影** - 高对比明暗交替，冷色主调，光源来源为霓虹灯、应急灯、电弧焊光
- **废土质感** - 地表积水、金属锈蚀、破损管线、机械残骸、生物黏液、油污与血迹混杂

### 2. 角色与生物

- **义体改造人** - 半人半机械，肢体外露金属骨架，接缝处渗血或机油，动作带有机械迟滞
- **生化异变体** - 基因编辑与机械融合的生命体，皮肤与金属共生，眼睛散发异常冷光
- **角色情绪** - 冷漠、警惕、恐惧、绝望、麻木，避免明亮开心的表情

### 3. 动态与转场

- **慢速压迫推进** - 镜头缓慢推向主体，延长呼吸感，强化无力与窒息
- **闪烁转场** - 通过霓虹灯闪烁、信号干扰、电子噪点完成场景切换
- **记忆深渊** - 画面扭曲，色彩从冷暗进一步加深至黑色，环境细节腐蚀分解，主角陷入过往创伤
- **惊醒突变** - 剧烈震动或电击样闪切，回到现实，但画面依然阴郁压抑，光影不变

### 4. 叙事镜头

- **身份焦虑** - 特写义体接口、破碎镜面中半张机械化的脸、被改造后失去的人类皮肤纹理
- **失控科技** - 机械肢体不自主痉挛，生物组织排斥发出焦味，系统界面乱码闪烁
- **废土求存** - 慢镜头穿行于废墟，幸存者用废旧零件拼装求生工具，远处防空警报响起
- **都市割裂** - 高空俯瞰霓虹巨城，底层面影被立交桥阴影吞没，摩天楼顶部透出冰冷的权贵灯火

## 禁止事项

- 避免明亮治愈的温馨色调（高饱和糖果色、幼儿卡通感）
- 避免纯写实无科幻元素的现实题材
- 避免无叙事逻辑的抽象视觉堆砌
- 避免直接套用中国传统古风水墨基调
- 避免纯黑白极简风格（缺少层次与氛围铺垫）

## 分镜提示词示例

```
镜头1（全景）：雨夜废弃工厂，水洼反射着断裂的霓虹管，远处一个义体人拖着重物缓慢行走。
风格：暗黑工业风，赛博义体，霓虹阴霾，金属锈蚀，阴郁高对比光影，废土气息。
动态：慢速推进，雨滴落在金属接缝处冒起白烟。
```

```
镜头2（特写）：义体人的手部接口渗出黑色机油，手指不受控地抽搐，同时面部半边金属面板下的眼皮猛地睁开。
风格：生物机械融合，反乌托邦，阴郁高对比光影。
动态：镜头从手部缓慢上移，突然电子噪点闪过，切换到下一场景。
```
