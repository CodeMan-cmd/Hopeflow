# 暗黑科幻角色（拟人/写实角色）基础设定图生成 · 约束手册

---

## 一、基础形象原则

1. **角色本体** — 角色必须具有完整可辨识的主体结构（人形义体/生化异变体/废土幸存者），禁止抽象无叙事逻辑的视觉堆砌
2. **风格锚定** — 整体形象必须同时呈现「暗黑工业质感」与「生物异化融合」，非纯写实现实题材、非明亮治愈风格
3. **材质对撞** — 金属义体部件、锈蚀钢材、有机生物组织、人造皮肤在同一角色上形成冲突感与压迫感
4. **世界观叙事** — 角色外观须能直接暗示其所处反乌托邦世界的生存状态（贫富割裂/改造失控/废土求存）
5. **四视图一致** — 角色本体外形/机械部件分布/材质纹理/颜色搭配/生物异化区域跨视图高度统一
6. **阴郁基调** — 角色姿态与表情具有冷峻、压抑、警惕或异化的叙事张力，服务于科技惊悚与反乌托邦氛围

---

## 二、生物机械特征约束

| 项目 | 约束 | 提示词 |
|---|---|---|
| 义体部件 | 半人半机械，明确区分机械改造部位与有机组织部位 | cybernetic prosthetics on limbs and torso, visible mechanical joints |
| 材质融合 | 金属与生物组织自然过渡，边缘有锈蚀/筋膜/线缆外露 | biomechanical fusion, corroded metal fused with organic tissue |
| 机械细节 | 义体表面管线、齿轮、液压结构清晰可见 | exposed hydraulic pistons, bundled cables, segmented armor plates |
| 异化特征 | 生物异变体须展示基因编辑或失控变异的体征（多肢体/外骨骼/发光器官） | bio-mutated physique, mutated exoskeleton, glowing organic nodes |
| 锈蚀做旧 | 金属部位有磨损、锈迹、划痕，使用痕迹明显 | weathered surface, rust stains, scratches, worn paint |
| 霓虹点缀 | 义体缝隙或异化器官处允许微弱霓虹光源，形成阴霾氛围中的高光 | faint neon glow in mechanical seams, neon haze accent |

---

## 三、摄影写实质感约束

| 项目 | 约束 | 提示词 |
|---|---|---|
| 渲染 | 摄影写实（非卡通/非2D/非动漫），如真实电影剧照质感 | photorealistic render, cinematic film still quality |
| 光影 | 阴郁高对比光影，明暗交界锐利，大面积阴影辅以局部强光 | moody high-contrast lighting, deep shadows, directional rim light |
| 氛围 | 工业废墟/废土气息通过材质反光、尘埃颗粒、雾气呈现 | dystopian atmosphere, industrial grime, dust particles in air |
| 色彩 | 低饱和冷色调为主（钢青/铁灰/暗褐），霓虹作为局部点缀色 | desaturated cold color palette, steel blue, iron gray, muted brown |
| 细节 | 金属拉丝、皮肤毛孔、锈蚀纹理、机械磨损超清晰 | hyperreal material detail, fine texture, metal grain, skin pores |
| 景深 | 角色主体清晰，背景环境使用适当景深虚化 | shallow depth of field, character in sharp focus |

## 四、多视图设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左一 | 面部/头部特写 | 正面平视 | 眼部义体、呼吸面罩或异化头部特征清晰呈现 | face closeup, front view, detailed facial modifications |
| 左二 | 正视图 | 正面 0° | 角色完整正面形态，机械部件与有机组织分布清楚 | front view, full body, symmetrical composition |
| 右二 | 侧视图 | 右侧 90° | 角色侧面轮廓、义体背甲、外露线缆结构清晰 | side view, profile, back-mounted hardware visible |
| 右一 | 背视图 | 后方 180° | 背部机械结构、脊柱外骨骼/供能装置清晰呈现 | back view, rear view, spinal exoskeleton and power unit |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图 |
| 背景 | 深灰渐变纯色背景（#1A1A1A 至 #2B2B2B），烘托暗黑工业氛围，禁止写实场景 |
| 站姿 | 放松站立姿态，双手自然下垂，重心稳定，无需额外道具支撑 |
| 表情 | 中性冷峻表情，眼神略带警惕或麻木，符合反乌托邦叙事定位 |
| 光线 | 侧前方主光 + 微弱轮廓光（可带淡青/霓虹色），高对比、硬阴影 |
| 一致性 | 四视图角色本体/义体部件/生物异化部位/颜色材质/光源方向完全一致 |
| 画面比例 | 建议 4:1 或 3:1 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「摄影写实」风格（photorealistic），禁卡通/2D/动漫渲染 |
| R2 | 必须同时包含「暗黑工业风」与「生物机械融合」双重风格锚定 |
| R3 | 必须描述「义体/机械部件」具体部位及材质（金属/线缆/液压结构） |
| R4 | 必须指定「深灰渐变背景」以烘托反乌托邦氛围 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 必须包含风格锚定词（dark sci-fi, dystopian, biomechanical fusion, corroded metal, moody high-contrast lighting） |
| R7 | 必须指定「阴郁高对比光影」为照明基调 |
| R8 | 必须明确角色类型（义体改造人/生化异变体/废土幸存者等） |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 明亮治愈的温馨色调（高饱和糖果色/浅色调/柔光儿童感） |
| X2 | 纯写实无科幻元素的现实题材（无义体/无异化/无未来感） |
| X3 | 无叙事逻辑的抽象视觉堆砌（纯形状/无角色结构） |
| X4 | 中国传统古风水墨基调的直接套用（水墨晕染/工笔/留白意境） |
| X5 | 纯黑白极简风格（缺少层次与氛围铺垫） |
| X6 | 卡通/动漫/2D/扁平插画/游戏概念图风格 |
| X7 | 多个义体部件凭空悬浮、无物理连接 |
| X8 | 生物组织与机械部件生硬拼接、无过渡融合 |
| X9 | 写实场景背景替代纯色背景（必须纯色） |
| X10 | 角色本体跨视图不统一（部件位置/颜色/异化区域漂移） |
