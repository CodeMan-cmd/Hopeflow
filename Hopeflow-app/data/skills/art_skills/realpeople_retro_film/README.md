# 真人复古胶片风格说明

本手册专为"真人复古胶片"题材视觉创作打造，所有美术提示词、视觉规范和生成内容严格限定于真人实拍摄影的复古胶片美学体系——这是**真人实拍**，不是动画、不是3D渲染。

---

## 一、风格核心定义

**真人复古胶片**是以 80-90 年代胶片摄影美学为基准的真人实拍视觉风格体系。其核心特征为：

- **真人实拍质感**：以真人影视级摄影为锚点，画面呈现真实人物的皮肤纹理、毛发细节、自然表情与体态——摄影机拍下的，不是计算机生成的
- **胶片颗粒质感**：可见而克制的胶片颗粒——银盐晶体在光线下形成的自然纹理，赋予画面"照片呼吸感"与时光厚度
- **复古色调**：暖棕/褪色/轻微色偏的怀旧色彩——泛黄的暖调、低饱和的褪色感、胶卷特有的色彩偏移（绿偏/洋红偏），拒绝现代数码的干净锐利
- **暗角与时光感**：镜头边缘的自然暗角、柔和的胶片高光、轻微的光晕散射——每一帧都像从旧相册里翻出来的照片
- **80-90 年代质感**：时代背景下的真实器物、服饰、街景、人物状态——老式汽车、磁带机、胶片相机、港风穿搭、怀旧街景
- **电影感布光**：以自然光与暖调人工光为主——黄昏的金色、钨丝灯的暖黄、窗光的斜射，电影感的明暗层次

### 创作理念

1. **"胶片即时间"** — 胶片颗粒、褪色与色偏不是瑕疵，而是时间的纹理。每一帧都自带"过去"的属性，让观众直接进入记忆
2. **"真实即怀旧"** — 复古不是做旧道具堆砌，而是真实的人物在真实的时代空间里自然地生活。真实感是复古氛围的地基
3. **"光讲旧故事"** — 黄昏的斜光、钨丝灯的暖黄、午后的窗光——光是复古叙事的核心，用光的色温讲年代的故事
4. **"克制即高级"** — 复古色调是克制的——低饱和、微褪色、轻微色偏，拒绝滤镜式的粗暴做旧与高饱和廉价的"复古滤镜感"

## 二、目标受众与应用场景

### 目标受众

| 受众群体 | 核心需求 |
|---|---|
| 影视/广告创作者 | 快速产出 80-90 年代质感的真人实拍概念图、剧照、氛围参考 |
| 摄影师/导演 | 获取胶片质感创作的灵感与视觉参考、拍摄前调性确定 |
| AI视觉创作者 | 系统化学习真人复古胶片风格的提示词方法论 |
| 内容创作者 | 产出怀旧质感的短视频封面、图文配图、账号视觉风格 |

### 应用场景

- **AI图像生成**：人物肖像、复古场景、时代道具、胶片光影、电影剧照式画面
- **AI视频生成**：适配 Doubao-Seedance 等AI视频平台，产出 80-90 年代质感的真人短片
- **分镜与叙事可视化**：以复古胶片感画面呈现分镜脚本，直观传达时代氛围
- **品牌/个人视觉体系**：怀旧风格的品牌视觉、个人作品集风格统一

## 三、视觉风格定位

**"胶片颗粒 · 复古色调 · 真人实拍 · 80-90年代时光感"**

| 维度 | 定位标准 |
|---|---|
| 人物质感 | 真人实拍级——真实皮肤纹理、毛孔可见、自然表情与体态，杜绝磨皮与假面感 |
| 胶片颗粒 | 可见而克制的 35mm 胶片颗粒，暗部颗粒略重、高光柔和，拒绝数字噪点 |
| 复古色调 | 暖棕主调、低饱和褪色、轻微色偏（绿偏/洋红偏）、泛黄的怀旧感 |
| 暗角光晕 | 镜头边缘自然暗角、柔和的高光滚落、轻微光晕散射 |
| 时代元素 | 80-90 年代真实器物/服饰/街景/人物状态，拒绝现代数码元素 |
| 电影感布光 | 自然光与暖调人工光调度，电影级的明暗层次与色彩科学 |

## 四、严禁内容（优先级最高）

1. **非摄影媒介**：3D渲染/CG建模/次世代游戏引擎/动画/2D手绘/插画/二次元/低多边形等一切非真人实拍影像质感
2. **卡通动漫质感**：卡通/动漫/漫画/Q版/赛璐璐——本风格是真人实拍，不是动画
3. **现代数码感**：高饱和荧光色/数码锐利感/手机摄影感/现代电子屏幕质感/纯净无颗粒的数码色
4. **非时代世界观**：赛博朋克/科幻未来/星际太空/架空奇幻/中世纪等非 80-90 年代时代背景
5. **技术质量缺陷**：低分辨率/模糊/噪点爆炸/变形/畸形肢体/五官扭曲/抠图感/过度磨皮/假面感
6. **内容合规红线**：暴露/低俗/暗示性/暴力血腥/违法内容/歧视性表达/政治敏感元素

## 五、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载 `prefix.md` 中的全局风格锚定，锁定真人复古胶片质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带负面提示词，规避现代数码感、卡通感与风格偏差
4. **"真人实拍"身份恒定**：任何生成都必须明确"真人实拍摄影 + 胶片质感"，禁止滑向3D渲染或卡通
