# 人物衍生资产生成 · 约束手册（真人复古胶片）

---

## 一、造型逻辑——给一个时代的人做造型

> 真人复古胶片的衍生造型不是在"模型上换装"，而是给一个80-90年代的真实人物做造型——化妆师在真人脸上工作、发型师用真实工具处理真实头发、造型师从衣架上取下一件那个年代被穿过的衣服——然后胶片摄影机拍下这一切。

1. **底模恒定** — 面容、体型是角色识别的核心锚点，任何造型衍生不得改变底模
2. **年代即造型** — 复古造型的第一标准是"属于那个年代"——80-90年代的港风穿搭、复古妆容、时代发型，拒绝现代时尚元素
3. **妆容是"第二层皮肤"** — 妆容与真实皮肤融合、可见皮肤纹理、非面具感
4. **衣服是"穿在身上"的** — 自然褶皱、穿脱痕迹、那个年代的面料质感
5. **四角度一致** — 同一人物不同角度的衍生造型完全一致，呈现为同一人物的连续造型记录

---

## 二、造型层级

| 层级 | 内容 | 真人复古胶片的理解 |
|---|---|---|
| L0 | 底模 | 基础形象底模——素颜、基础发型、基础服装。不修改 |
| L1 | 妆容 | 化妆师在真人脸上的工作——按场景决策强度，保留真实皮肤 |
| L2 | 发型造型 | 那个年代的发型师做的发型——吹整/烫卷/编发/盘发 |
| L3 | 内搭 | 贴身层——衬衫/背心/打底衫，替换基础款 |
| L4 | 主服 | 外套/连衣裙/西装/工装——决定整体复古风格 |
| L5 | 配饰 | 那个年代的配饰——手表/耳环/丝巾/眼镜/包袋 |

> **范畴边界**：仅造型层面。不包含道具（相机/电话/磁带等手持物）、场景环境、姿态动作。

## 三、妆容——那个年代的化妆师工作（L1）

> 妆容是"第二层皮肤"——胶片摄影机必须能透过妆容看见底下的真实皮肤。

### 场景→妆容强度映射

| 场景 | 妆容强度 | 核心意图 |
|---|---|---|
| 居家/晨起 | 素肌级——无妆容痕迹 | 真实的皮肤质感、未经修饰的面孔 |
| 日常通勤 | 日常级——轻妆 | 得体的精致、不引人注意 |
| 约会/聚会 | 场合级——看得出化了妆 | 有存在感的妆容、港风韵味 |
| 盛典/婚礼 | 盛典级——完整精致妆容 | 为镜头设计的妆，底妆仍可见真实皮肤 |

### 复古妆容要点（女性）

| 强度 | 妆容意图 | 提示词 |
|---|---|---|
| 素肌级 | 不化妆——暖调素颜皮肤 | 素颜、暖调真实皮肤、无妆容痕迹、毛孔自然可见 |
| 日常级 | 轻妆——裸色唇、淡眉 | 极淡裸色唇、自然眉形、皮肤真实质感、非假面 |
| 场合级 | 港风复古妆——红唇+自然眉眼 | 复古红唇（哑光砖红）、自然眉眼、皮肤纹理可见 |
| 盛典级 | 完整复古妆——精致眼妆+红唇 | 复古精致妆容、深邃眼线、哑光红唇、底妆保留皮肤质感 |

### 男性妆容

> 男性妆容的最高标准是"看不出来化了妆"——素肌级为默认，镜头特写时极淡均匀肤色。

## 四、发型——那个年代的发型师作品（L2）

### 女性复古发型

| 发型 | 描述 | 适配气质 |
|---|---|---|
| 港风大波浪 | 蓬松黑发大波浪、层次丰富、微乱有复古感 | 清冷港风/成熟风韵 |
| 复古盘发 | 低盘发/发髻、碎发环绕、温婉年代感 | 温婉怀旧/成熟风韵 |
| 麻花辫 | 单侧或双麻花、松紧适中、复古少女感 | 复古少女/温婉怀旧 |
| 波波头 | 齐肩内扣短发、复古少女发型 | 复古少女/清冷港风 |
| 低马尾 | 后颈低束、松而不散、随手扎起的松弛感 | 市井烟火/日常 |

### 男性复古发型

| 发型 | 描述 | 适配气质 |
|---|---|---|
| 港风短发 | 利落短发、微乱有型、自然走向 | 港风硬朗 |
| 复古中分 | 中分短发、发丝自然、书卷气 | 儒雅怀旧 |
| 背头 | 向后梳理、微乱不油、成熟气质 | 港风硬朗/成熟 |
| 平头/寸头 | 极短利落、头皮可见、自然发际线 | 市井质朴 |

> 头发在胶片机前的真实状态：碎发自然散落、发根自然蓬松、发尾自然毛躁、逆光下头发半透明暖色轮廓——杜绝假发套、杜绝僵硬定型。

## 八、人物肖像系列——四角度规范

| 位置 | 角度 | 景别 | 摄影要求 |
|---|---|---|---|
| 左一 | 正面近景 | 头顶至锁骨 | 妆容细节、皮肤纹理、发型质感清晰可见 |
| 左二 | 正面0° | 全身 | 穿搭全貌、服装垂坠与层次、配饰完整 |
| 右二 | 右侧90° | 全身 | 侧面轮廓+穿搭侧面层次 |
| 右一 | 后方180° | 全身 | 后脑发型、背部穿搭、包袋后侧 |

### 画面规范

| 项目 | 摄影要求 |
|---|---|
| 布局 | 同一画面从左至右并排四个角度，间距均匀 |
| 背景 | 中灰无缝背景纸 #B0B0B0，无光斑无渐变 |
| 站姿 | 保持底模站姿——重心偏移的自然站姿 |
| 光线 | 棚拍柔光——柔光箱主光+双侧补光，光比约1:2至1:3 |
| 质感 | 35mm胶片质感、轻微颗粒、暖棕复古色调、轻微暗角 |
| 一致性 | 四角度为同一人物同一次造型的连续胶片摄影记录 |
| 画面比例 | 建议 4:1 或 16:4 |

## 十、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 叠加后面容必须与底模一致——造型服务于面孔，不遮蔽面孔 |
| R2 | 妆容必须与真实皮肤融合——非假面、皮肤纹理仍可见 |
| R3 | 发型必须呈现真实发质——碎发、发根蓬度、非假发套 |
| R4 | 服装必须有真实穿着痕迹——自然褶皱、面料垂坠、非样板衣 |
| R5 | 配饰必须有日常佩戴感——有使用痕迹、自然贴合 |
| R6 | 必须输出四角度肖像系列（近景特写+正面+侧面+背面全身） |
| R7 | 必须指定「中灰无缝背景纸 #B0B0B0」 |
| R8 | 必须声明「80-90年代复古造型 + 非3D非CG非卡通」核心锚定 |
| R9 | 必须声明「35mm胶片质感 + 暖棕复古色调」 |
| R10 | **仅输出提示词**——不输出分析过程、方案对比等一切非提示词内容 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「3D渲染 / 3D建模 / CG / PBR材质 / UE引擎 / Blender」等一切CG术语 |
| X2 | 严禁「卡通 / 动漫 / 漫画 / 二次元 / 2D手绘 / 赛璐璐」等非摄影媒介 |
| X3 | 严禁「过度磨皮 / 硅胶脸 / 蜡像假面 / 零毛孔 / AI感平滑皮肤」 |
| X4 | 严禁「假发套 / CG发丝 / 头发僵硬整齐 / 无碎发」 |
| X5 | 严禁「现代时尚 / 现代发型 / 2020s潮流 / 现代数码设备」 |
| X6 | 严禁「高饱和荧光色 / 现代数码锐利色 / 纯净数码感」 |
| X7 | 严禁「模特对称站姿 / 走秀pose / 夸张动作」 |
| X8 | 严禁「古风 / 古装 / 仙侠 / 武侠 / 民国 / 赛博朋克 / 科幻」等非80-90年代着装 |
| X9 | 严禁「暴露 / 透视 / 低俗 / 擦边 / 暴力血腥」 |
| X10 | 严禁「水印 / 文字 / LOGO / 签名 / 边框 / AI生成痕迹」 |
