# 场景衍生资产生成 · 约束手册（真人复古胶片）

---

## 一、衍生原则

> 真人复古胶片的场景衍生是"同一个80-90年代场所，站在不同位置、在不同时间、不同天气下再次被胶片摄影机拍下"——空间锚定不变，变化的是光、是氛围、是时间的故事。

1. **空间锚定** — 同一场景的核心空间结构在所有变体中必须可辨认。换了角度、变了光线、变了天气——但一看就知道"还是那个地方"
2. **焦段叙事** — 同一场景用不同焦段拍出不同的事。广角说"这个老城的时代感"，中焦说"看看这个角落"，长焦说"远处有什么旧事"
3. **时段即情绪** — 晨光的老街和黄昏的老街是同一个空间、两种情绪。时段变了、光变了、色温变了——胶片色调也随之变化
4. **天气即故事** — 同一条街，晴天是日常，雨天是惆怅，雪天是记忆。天气变化必须是真实的光学和环境变化，不是换天空贴图
5. **单视图摄影** — 每一个衍生变体都是一张独立的单张全景照片，与原场景设定图同空间、同风格

## 二、焦段与构图变体——同一个空间的不同目光

| 变体 | 焦段 | 范围 | 叙事功能 | 提示词 |
|---|---|---|---|---|
| 广角全貌 | 24-28mm | 场景全貌+周边环境 | 建立空间定位、呈现老城的时代全貌 | 广角全貌、完整空间+环境关系、全景深f/8-f/11 |
| 标准全景 | 35mm | 场景完整呈现 | 人眼等价视角、客观记录这个场所 | 35mm标准全景、人眼视角、场所完整面貌 |
| 中景聚焦 | 50mm | 核心功能区/最具辨识度的局部 | 聚焦空间的"心脏"——老店的柜台、巷口的转角 | 50mm中景聚焦、空间的核心叙事区域 |
| 近景细节 | 85mm | 一处局部——一扇旧窗、一盏路灯、一面斑驳墙 | 视线引向空间的叙事细节——旧招牌、晾晒的衣物 | 85mm近景、空间的叙事细节、浅景深 |

### 焦段衍生规则

| 从广角全貌衍生 | 保持不变 | 变化项 |
|---|---|---|
| 广角→标准全景 | 空间结构、光源逻辑、时段天气 | 焦段收窄至35mm、画面范围缩小、透视更近人眼 |
| 标准全景→中景聚焦 | 材质质感、光线方向、色调 | 焦段收窄至50mm、聚焦核心区域、景深适度变浅 |
| 中景→近景细节 | 材质纹理、光线方向 | 焦段85mm、极浅景深、背景自然虚化 |

## 三、时段变体——时间给空间的胶片色调

| 时段 | 光的配方 | 空间的情绪变化 | 提示词 |
|---|---|---|---|
| 清晨 | 低角度暖白晨光、薄雾漫射、胶片颗粒细腻 | 静谧、蓄势、老城刚醒来 | 清晨场景、低角度晨光斜入、薄雾漫射、旧时光苏醒 |
| 上午 | 日光升高、泛白的高光、色彩略褪 | 秩序的建立——老城的日间默认 | 上午日光、空间明亮泛白、胶片高光柔和 |
| 正午 | 顶光为主、阴影短、色彩泛白褪色 | 暂停感——日复一日的顶点 | 正午顶光、泛白高光、短暂松弛 |
| 午后 | 日光偏西、暖调渐强、斜光长影 | 慵懒、时间变慢、暖调渐浓 | 午后斜光、长阴影、暖调渐强、慵懒温暖 |
| 金色时刻 | 极暖低角度金橙光、长影、一切镀旧金 | 珍惜——一天中最珍贵的暖 | 金色时刻、暖金斜光、旧金镀边、转瞬即逝 |
| 蓝调时刻 | 天空深蓝紫、自然光极暗、旧灯初亮 | 过渡——白天已尽、夜晚未接管 | 蓝调时刻、旧灯初亮、冷暖共存、诗意 |
| 深夜 | 仅靠旧式人工光——街灯/店铺灯/窗灯 | 孤独或私密——老城安静了 | 深夜场景、街灯暖黄、暗角浓、静谧 |

### 时段衍生规则

| 从基准时段衍生 | 保持不变 | 变化项 |
|---|---|---|
| 日间→黄昏（金色时刻） | 空间结构、家具/物品位置 | 色温暖化至3000-3500K、阴影拉长、亮面镀金调、旧灯点亮 |
| 日间→夜间 | 空间结构、家具/物品位置 | 曝光降低、旧式灯光全亮、窗外从白昼变夜景、暗角加深 |
| 室内日间→室内深夜 | 空间结构、陈设位置 | 仅留极少光源（一盏台灯/窗外路灯）、大范围沉入暗部 |

## 四、天候变体——天气给空间的情绪

| 天候 | 空间变化 | 情绪 | 提示词 |
|---|---|---|---|
| 晴天 | 光影锐利、材质清晰、胶片颗粒细腻 | 日常、明亮、开放 | 晴天场景、阳光充沛、光影分明 |
| 多云/阴 | 柔光无硬影、整体偏灰冷、光线均匀 | 克制、平静、或是压抑的前兆 | 阴天柔光、无硬阴影、光线均匀漫射、灰冷调 |
| 薄雾 | 远景自然虚化、近景清晰、空气有湿度 | 朦胧、不确定、诗意、记忆感 | 薄雾场景、远景渐隐、近景清晰、记忆的朦胧 |
| 小雨 | 湿地面反光、玻璃雨痕、空气清冷湿润 | 忧郁、沉思、浪漫、回忆 | 细雨场景、湿地面反光、玻璃雨痕、清冷湿润 |
| 大雨 | 雨幕浓厚、室外可见度降低、水洼溅射 | 隔绝——室内是避难所 | 大雨场景、雨幕厚重、水洼溅射、隔绝感 |
| 雨后 | 万物湿润、反光清晰、空气清透 | 新生、清透、情绪的洗涤 | 雨后场景、湿润反光、空气清透、万物被洗过 |
| 小雪 | 雪花飘落、薄白、暖光透过雪幕 | 静谧、温柔、旧忆 | 小雪场景、飘雪、薄白、暖光透过飘雪 |
| 大雪 | 积雪覆盖、世界被白色简化 | 孤寂或浪漫——记忆的留白 | 大雪场景、积雪覆盖、世界被白色简化 |

### 天候衍生规则

| 从晴天衍生 | 保持不变 | 变化项 |
|---|---|---|
| 晴→薄雾 | 空间结构、建筑外观、物品位置 | 增加雾气分层、远景虚化、饱和度降低、光源柔和 |
| 晴→小雨 | 空间结构、建筑外观、物品位置 | 增加雨丝、玻璃雨痕、地面湿滑反光、色调偏冷 |
| 晴→雪 | 空间结构、建筑外观、物品位置 | 增加飘雪/积雪、色调偏冷白、暖光源对比提升 |
| 室内晴天→室内雨天 | 空间结构、陈设位置 | 窗外变雨景、窗玻璃雨痕、室内光变暗偏冷 |

## 五、单视图摄影规范——所有衍生变体共享

| 项目 | 摄影要求 |
|---|---|
| 空间结构 | 与原场景设定图**同一空间**——建筑结构/陈设/物品位置原则上不变 |
| 焦段 | 按变体类型使用 24mm/35mm/50mm/85mm |
| 景深 | 广角→全景深f/8-f/11；中景→f/4-f/5.6；近景→f/2.8 |
| 光源 | 时段对应太阳高度和色温、天气对应大气散射、室内对应窗光和旧式灯 |
| 质感 | 35mm胶片质感、轻微颗粒、暖棕复古色调、轻微暗角——所有变体保持 |
| 人物 | **所有变体严禁出现任何人物、人影、人体轮廓** |
| 画面比例 | 16:9或3:2宽幅，与原场景设定图一致 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景空间结构在所有衍生变体中必须保持可辨认——同一个地方，不能变成另一个地方 |
| R2 | 时段变体的光源必须符合真实物理——太阳高度角决定色温和阴影长度 |
| R3 | 天候变体必须同步适配材质表面的真实物理变化——雨痕/积水反光/积雪 |
| R4 | 必须是「单张全景摄影」——单视图、非2×2四视图、非多角度 |
| R5 | 必须声明光源来源——光从哪儿来、色温多少——不能是无来源的全局照明 |
| R6 | 必须保持原空间的岁月痕迹——时段和天候衍变不能"洗掉"磨损与斑驳 |
| R7 | 必须保持「35mm胶片质感 + 暖棕复古色调 + 暗角」的风格底线 |
| R8 | **所有变体严禁出现任何人物、人影、人体轮廓** |
| R9 | 必须声明「真人实拍 + 非3D非CG」核心锚定 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁空间结构发生不可辨认的改变——换了时段/天气/焦段不能"换了地方" |
| X2 | 严禁「3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 体积光 / AO」等一切CG术语 |
| X3 | 严禁「2D手绘 / 插画 / 卡通 / 二次元」等非摄影媒介 |
| X4 | 严禁「四视图 / 2×2网格 / 多角度 / turnaround」——仅单张 |
| X5 | 严禁「现代建筑 / LED屏 / 智能手机时代 / 科幻 / 赛博朋克」等现代元素 |
| X6 | 严禁「出现任何人物 / 人影 / 人体轮廓 / 剪影」 |
| X7 | 严禁「天空贴图替换式换天 / PS合成感 / 滤镜套用」——天气变化须真实 |
| X8 | 严禁「光源来源不明 / 无方向的全局均匀照明」 |
| X9 | 严禁「时段变体不调整旧式灯光开关和亮度」——傍晚必须亮灯、深夜不能全亮 |
| X10 | 严禁「天候变体抹除空间的岁月痕迹」——雨后的墙仍然斑驳、雪下的地面仍有磨损 |
| X11 | 严禁「高饱和荧光色 / 现代数码锐利色 / 纯净数码感」 |
| X12 | 严禁「过曝死白 / 暗部死黑 / 无层次」 |
| X13 | 严禁「水印 / 文字 / LOGO / 签名 / 边框 / AI生成痕迹」 |
