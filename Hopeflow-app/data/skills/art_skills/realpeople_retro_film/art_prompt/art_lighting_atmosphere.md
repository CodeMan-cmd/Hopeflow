# 光影与氛围 · 约束手册（真人复古胶片）

> 光不是"打上去的"，是"从旧时光里长出来的"——黄昏的金色从老窗斜射、钨丝灯在深夜亮起暖黄、午后的日光穿过窗帘泛成褪色的米黄。本画风用摄影机与胶片说话，不用渲染引擎——光必须有出处、有方向、有色温，画面必须读作"胶片摄影机拍下的"。

---

## 一、光源方案（复古胶片光源色谱）

| 编号 | 光源 | 色温（K） | 光色特征 | 复古场域 |
|---|---|---|---|---|
| L1 | 晨光（日出后1h） | 3500-4500 | 低角度暖金漫射、薄雾扩散 | 老城苏醒、早市热气、晨雾街道 |
| L2 | 上午天光 | 5000-6000 | 泛白的日光、胶片高光柔和 | 老式办公室、泛黄的窗光 |
| L3 | 金色时刻（日落前1h） | 2800-3500 | 珍贵暖调、长影、一切镀旧金 | 怀旧回忆段落的首选光源 |
| L4 | 蓝调时刻（日落后20min） | 8000-10000 | 深邃蓝紫、旧灯初亮 | 过渡、内心独白、旧忆尾声 |
| L5 | 钨丝灯/白炽灯 | 2700-3200 | 标志性的暖黄，旧时光的体温 | 老屋室内、台灯、黄昏室内 |
| L6 | 老式街灯（钠灯） | 2000-2200 | 暖橙黄、旧城夜晚的体温 | 老城巷弄、深夜独行、回忆质感 |
| L7 | 日光灯管 | 4000-5000 | 冷漠但时代感的白光 | 老办公室、食堂、教室 |
| L8 | 烛光/煤油灯 | 1800-2200 | 极暖摇曳、旧时代的温柔 | 停电夜、怀旧片段、温情时刻 |

> 光源规则：每镜必选一个主光源并说清"光从哪来"；旧灯/霓虹仅作背景环境光，禁作主光直射人物。

## 二、光比与明暗对比

| 参数 | 约束 | 说明 |
|---|---|---|
| 对比度 | 中低反差（胶片柔和反差） | 高光柔和滚落、暗部有层次不压死 |
| 高光 | 不过曝死白、柔和滚落 | 胶片高光的泛白质感 |
| 暗部 | 有层次不纯黑 | 暗部颗粒略重、保留细节 |
| 人面光比 | 主光:环境光自洽 | 光源方向、色温、软硬须物理自洽 |
| 暗角 | 轻微至中度 | 镜头边缘自然暗角，加强怀旧感 |

## 三、色调情绪与画面关键词

| 情绪场景 | 光的配方 | 画面关键词 |
|---|---|---|
| 怀旧日常 | 窗光漫射 + 泛白米黄 | 日常、温暖、时光感、低饱和 |
| 黄昏浪漫 | 金色时刻斜光 + 旧金镀边 | 浪漫、温情、金色记忆 |
| 岁月怅惘 | 柔光雾化 + 降饱和 + 轻微色偏 | 追忆、怅惘、旧时光 |
| 市井烟火 | 多光源混杂（钨丝暖+日光灯冷） | 热闹、真实、人间味 |
| 旧城夜色 | 钠灯街灯暖黄 + 暗角浓 | 夜色、旧城、孤寂温暖 |
| 深夜独处 | 单光源（台灯/窗外路灯）孤岛式照明 | 脆弱、真实、一个人的时刻 |

## 四、必守规则

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影/真人实拍」为锚——画面读作"胶片摄影机拍下的" |
| P2 | 必须指定光源出处、方向、色温、软硬（窗/钨丝灯/街灯/日光灯管） |
| P3 | 必须从复古光源色谱取光（晨光/金色时刻/蓝调/钨丝灯/钠灯等） |
| P4 | 必须声明「35mm胶片颗粒 + 暖棕复古色调 + 轻微暗角」 |
| Q3 | 高光不得过曝死白、暗部不得死黑无层次 |
| Q5 | 色彩调性与情绪匹配：低饱和褪色、暖棕克制、不溢色 |

## 五、严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁一切 CG 术语：3D渲染/CG/UE/Blender/次世代建模/PBR材质/体积光/环境光遮蔽（AO）/光线追踪 |
| X2 | 卡通/插画/动画/二次元光效 |
| X3 | 高饱和荧光色/霓虹溢色/现代数码锐利色/纯净无颗粒数码感 |
| X4 | 无源均匀光、全局亮、说不清光从哪来 |
| X5 | 现代LED屏幕光/手机屏幕光/现代数码设备光源 |
| X6 | 古风/古装/仙侠/武侠等非80-90年代光环境；仙侠玄幻发光体 |
