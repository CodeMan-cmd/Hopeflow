# 道具衍生状态生成 · 约束手册（真人复古胶片）

---

## 一、衍生原则

> 真人复古胶片的道具衍生不是"材质切换"，而是"同一件老物件在不同时间被胶片摄影机再次拍到时，它变成了什么样"——磨损是时间在物品上写的日记，褪色是岁月留下的签名。

1. **造型锚定** — 道具核心造型、轮廓在所有状态中必须可识别。一台用了多年的老收音机，虽然外壳泛黄、旋钮松动，但一看就知道是原来那台
2. **状态可读** — 新旧、完整/破损、干/湿——一眼即可区分。状态差异来自真实的时间与物理逻辑
3. **叙事服务** — 道具的状态就是一场未拍出的前戏——停摆的挂钟暗示一段停滞的时间、泛黄的照片暗示封存多年的记忆、磨损的信件暗示被反复阅读
4. **渐进合理** — 老化遵循真实材料的物理规律：纸先黄后脆再裂、金属先氧化后锈蚀、塑料先泛黄后脆化
5. **单视图静物摄影** — 衍生状态仅需一张静物照。与原道具设定图同机位、同光线、同背景——仅状态发生变化

## 二、状态类型

### 2.1 使用-时间状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 较新 | 购入不久——轻微使用、少量磨损、光泽尚存 | 所有道具 | 轻微使用痕迹、少量磨损、光泽尚存、非全新非崭新 |
| 日常使用 | 使用了一段时间——均匀磨损、自然包浆、触感区有光泽 | 随身物件/生活器物 | 正常使用痕迹、握持处包浆、边角微磨损、日常使用状态 |
| 重度使用 | 用了很多年——明显磨损、色泽暗淡、密集划痕、包浆厚重 | 老相机/旧手表/长期使用的器物 | 重度使用痕迹、密集划痕、包浆厚重、但仍能使用 |
| 陈旧 | 年代感强烈——褪色、氧化、包浆厚重、材质老化、轻微形变 | 老照片/旧票据/祖传器物 | 强烈年代感、自然褪色氧化、包浆厚重、岁月印记 |

### 2.2 损伤状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 微损 | 小裂纹/浅划痕/局部磨损——不影响主体识别 | 搪瓷杯/木盒/玻璃瓶 | 细微裂纹、浅划痕、边角微缺口、主体完整 |
| 破损 | 明显裂缝/碎裂/局部缺失——结构受损但整体可辨认 | 掉瓷的搪瓷杯/裂口的磁带盒 | 明显裂缝、局部缺失、结构受损、主体仍可识别 |
| 残片 | 仅剩碎片/核心部分——大面积缺失，保留识别特征 | 撕掉一半的照片/碎唱片 | 残片状态、仅存核心部分、可识别原物的轮廓 |

### 2.3 环境痕迹状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 蒙尘 | 放了一段时间没动——表面薄灰、光泽被灰层覆盖 | 阁楼旧物/柜顶老物件 | 表面薄灰覆盖、边角积尘、光泽被柔化、被搁置的痕迹 |
| 淋雨/浸水 | 被雨淋过/泡过水——表面水珠、纸张浸湿起皱、金属水渍 | 书信/书/帆布包 | 表面水珠、纸张浸湿微皱、墨迹微洇、金属水渍 |
| 日晒褪色 | 长期暴露在阳光下——颜色变浅、纸张发黄、塑料发脆变色 | 窗边物件/户外旧物 | 日晒褪色、颜色不均变浅、纸张发黄、塑料变色发脆 |
| 烟熏/油渍 | 厨房/老屋环境痕迹——油渍、烟熏黄、使用环境的气息 | 厨房器物/老屋旧物 | 烟熏泛黄、油渍痕迹、老屋的生活气息 |

### 2.4 情感-叙事状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 被翻阅/翻旧 | 页角翻毛、封面折痕、被认真读过 | 书/日记/相册 | 页角翻旧起毛、封面自然折痕、翻阅千百次的痕迹 |
| 被珍藏/封存 | 用布/盒/信封包裹，精心对待 | 信物/照片/首饰 | 精心包裹封存、包装有岁月痕迹、被珍藏的证据 |
| 被遗弃/遗忘 | 落满灰、被压在角落、无人问津 | 旧手机（大哥大）/旧玩具/旧信 | 落满灰尘、被压在杂物下的痕迹、无人问津的孤寂 |
| 被贴身珍爱 | 触感区被反复接触打磨出光泽 | 怀表/钢笔/戒指/票夹 | 触感区特殊包浆、贴身珍爱之物、体温留下的痕迹 |

## 三、单视图摄影规范

> 衍生状态仅需单张静物摄影。同一机位、同一光线、同一背景——仅道具状态变化。

| 项目 | 摄影要求 |
|---|---|
| 背景 | 素灰无缝背景纸 #B0B0B0，或纯木桌面/旧布面——与原道具设定图完全一致 |
| 光线 | 与原道具设定图完全一致的暖调窗光或柔光箱设置。光位、光比、色温不变 |
| 角度 | 与原道具设定图完全一致的机位和角度 |
| 景深 | 浅景深 f/2.8-f/5.6，与原图一致 |
| 构图 | 道具居中独立陈列，占画面主体70%+，完整入画无裁切 |
| 质感 | 35mm胶片质感、轻微颗粒、暖棕复古色调、轻微暗角 |
| 画面比例 | 1:1 正方形或 4:3，与原图一致 |

## 四、材质状态变化——时间在老物件上的痕迹

| 材质 | 较新 → 日常使用 | 日常 → 陈旧 | 损伤表现 |
|---|---|---|---|
| 搪瓷 | 釉面光泽 → 微磨损、局部掉瓷点 | 掉瓷面积扩大、釉面暗淡 | 掉瓷露黑、裂纹、缺口 |
| 金属（铁/铝） | 光泽尚存 → 氧化斑点、边角磨损 | 氧化斑驳、锈蚀初现、色泽暗沉 | 锈斑、凹痕、断裂 |
| 塑料 | 色泽尚鲜 → 轻微泛黄、微划痕 | 泛黄明显、变脆、光泽消失 | 裂纹、断裂、崩边 |
| 纸质 | 纸色尚白 → 边缘微黄、微卷 | 泛黄明显、变脆、边缘卷翘 | 撕裂、缺角、浸湿起皱 |
| 皮革 | 光泽尚存 → 弯折包浆、五金微氧化 | 包浆厚重、色泽暗沉、边角磨损 | 开裂、皮面剥落、五金锈蚀 |
| 木质 | 漆面尚亮 → 漆面微磨损、边角圆润 | 漆面剥落、木色暗沉、包浆温润 | 开裂、缺口、虫蛀痕迹 |
| 玻璃 | 通透微黄 → 划痕、水渍指印 | 通透度下降、边缘磨损 | 裂纹、崩角、缺片 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 道具核心造型/轮廓在所有状态中必须可识别 |
| R2 | 状态变化必须符合真实材料的物理逻辑——纸先黄后脆、金属先氧化后锈蚀 |
| R3 | 必须是「单张静物摄影」——单视图、非2×2四宫格、非turnaround |
| R4 | 必须与原道具设定图保持同一机位、同一光线、同一背景 |
| R5 | 必须指定非全新非样板的状态痕迹（除非状态本身是"较新"） |
| R6 | 老化程度应有叙事合理性——伤痕要有"发生过什么"的暗示 |
| R7 | 必须声明「真人实拍产品摄影 + 非3D非CG + 胶片质感」核心锚定 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁状态变化后道具不可识别，严禁擅自修改核心造型 |
| X2 | 严禁违反物理逻辑的状态变化（塑料包浆、玻璃腐蚀等反物理表现） |
| X3 | 严禁「3D渲染 / 3D建模 / CG / PBR材质 / UE引擎 / Blender」等一切CG术语 |
| X4 | 严禁「卡通 / 动漫 / 二次元 / 2D手绘」等非摄影媒介 |
| X5 | 严禁「多角度 / 四视图 / 2×2网格 / turnaround」——仅单张 |
| X6 | 严禁「现代数码设备 / 科幻 / 赛博朋克 / 高饱和荧光色」 |
| X7 | 严禁「发光 / 激活 / 能量光效 / 魔法 / 异能 / 科幻特效」——真实老物件不会发光 |
| X8 | 严禁「出现人物 / 手部 / 手指 / 肢体」 |
| X9 | 严禁「道具被持有 / 握持 / 佩戴 / 使用中」的状态 |
| X10 | 严禁「悬浮 / 抠图白底 / 无投影 / 无承载面」 |
| X11 | 严禁「水印 / 文字 / LOGO / 签名 / 边框 / AI生成痕迹」 |
