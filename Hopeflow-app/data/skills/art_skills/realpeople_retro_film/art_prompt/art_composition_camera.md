# 构图与镜头 · 约束手册（真人复古胶片）

> 画质不取决于渲染分辨率，取决于「胶片摄影机怎么在场」。三脚架锁定让时间自己说话、肩扛手持把呼吸带进画面、轨道车沿老街滑过旧时光、老式变焦镜头推近又拉远——这是胶片时代的摄影机语法，不是镜头引擎。

---

## 一、景别体系

| 景别 | 叙事功能 | 复古胶片特征 |
|---|---|---|
| 大特写 | 情绪爆发点 | 眼神、手指、旧物件表面（搪瓷缸缺口、老照片折痕） |
| 近景 | 情感凝视 | 面部微表情、胶片颗粒下的皮肤纹理 |
| 中近景 | 互动与对话 | 腰部以上，兼顾表情与手势 |
| 中景 | 人物关系 | 全身入画，人物与老空间共存 |
| 全景 | 环境氛围 | 人物占比较小，老城街景叙事为主 |
| 空镜 | 情绪缓冲 | 无人物，旧物件/老城景观留白 |

## 二、镜头焦段（胶片时代的镜头性格）

| 焦段 | 叙事性格 | 典型应用 |
|---|---|---|
| 28mm 广角 | 环境吞噬人物、老城纵深 | 老街空镜、巷弄尽头的孤独身影 |
| 35mm 小广角 | 主观视点、纪实感 | 街头跟随、日常行走、市井记录 |
| 50mm 标准 | 人眼等价、客观注视 | 肖像、双人对话、情感凝视 |
| 85mm 中长焦 | 压缩空间、背景虚化 | 特写、隔着街道的凝望 |
| 135mm 长焦 | 极端压缩、窥视感 | 人群中隔离的个体、旧时光里的远眺 |

## 三、机位与运动（胶片摄影机语法）

| 手法 | 视觉心理 | 使用场景 |
|---|---|---|
| 三脚架固定机位 | 冷静、观察、让时间自己说话 | 日常场景、对话、空镜留白 |
| 肩扛手持微晃 | 在场感、呼吸感 | 情绪波动、街头行走、亲密跟随 |
| 轨道车横移 | 缓慢流动、旧时光的滑过感 | 人物登场、老街漫游、过渡 |
| 变焦推拉 | 注意力聚焦或抽离（老式变焦头的机械感） | 情绪升温、揭示信息、告别抽离 |
| 俯拍 | 命运感、渺小 | 老城俯瞰、结局回望 |
| 仰拍 | 压迫或纪念 | 旧建筑压迫、人物力量感 |

## 四、构图法则

| 法则 | 应用 |
|---|---|
| 三分法 | 人物置于交点，老城背景留白 |
| 框架构图 | 老式门框/窗框/骑楼廊柱/楼梯井套住人物 |
| 引导线 | 老街纵深、铁轨延伸、架空电线连排牵引视线 |
| 前景遮挡 | 晾晒衣物虚化前景、老式栏杆隔出窥视感 |
| 暗角收边 | 画面边缘自然暗角，把视线收拢向中心人物 |

## 五、镜头语言

- 推：老式变焦头从街景推入人物近景，孤独感放大
- 拉：人物转身走入巷弄，镜头拉开留白
- 跟：肩扛手持跟随行走，纪实在场感
- 焦点偏移：前景虚化 → 主角清晰，叙事重心转移
- 剪影：蓝调时刻/逆光下人物轮廓化，克制的告别

## 七、必守规则

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影/真人实拍」为锚——画面读作"胶片摄影机拍下的" |
| Q1 | 必须声明摄影机在场方式：三脚架固定/肩扛手持/轨道车/变焦推拉 |
| Q2 | 景深必须有叙事意图，焦点偏移引导注意力 |
| Q3 | 高光不过曝死白、暗部不死黑无层次 |
| Q4 | 必须声明颗粒质感：35mm胶片颗粒 + 轻微暗角 |
| P4 | 必须声明「35mm胶片颗粒 + 暖棕复古色调 + 轻微暗角」 |
