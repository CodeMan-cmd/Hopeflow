# 场景图像生成 · 约束手册（真人复古胶片）

---

## 一、场景美学原则

> 真人复古胶片的场景不是"被建模的空间"，而是"80-90年代被胶片摄影机选中的真实场所"——老城的街巷、怀旧的室内、泛黄的日光。空间本身就是一个时代的容器。

1. **空间即年代** — 一个场景必须让观众一眼读出年代——老式建筑、旧招牌、时代器物、泛黄的墙面。场景是80-90年代世界观的视觉证据
2. **真实的光，不是渲染的光** — 场景的光来自真实的日光（穿过门窗）、真实的灯光（钨丝灯、日光灯管、街灯）——光的色温和方向必须在物理上说得通
3. **被使用过的空间** — 真实的场景不整洁——墙面斑驳、地面磨损、器物蒙尘、生活的痕迹。一个没有岁月痕迹的空间不是复古胶片
4. **复古色调统一** — 场景色彩遵循低饱和暖棕褪色——泛黄的日光、褪色的墙面、旧橙的黄昏——胶片色偏与暗角是场景的呼吸
5. **单视图全景全貌** — 一张照片装下整个场地的完整信息。广角或标准焦段，全景深，正面展示空间全貌与纵深——不是四视图分割

## 三、室内场景——怀旧的生活空间

### 空间摄影规范

| 维度 | 摄影要求 | 提示词 |
|---|---|---|
| 风格 | 80-90年代真实中国室内——老式家具、水泥地或木地板、泛黄的墙、时代的器物 | 80-90年代真实室内、真人实拍摄影、时代的空间 |
| 光源逻辑 | 明确的光源来源——窗光是哪个方向的窗、灯是哪盏灯（钨丝灯/日光灯管） | {窗光方向}自然光为主、{老式灯光}为辅、光的方向可追溯 |
| 空间层次 | 前/中/后景——前景（门框/家具边缘/窗帘）画框感、中景是空间主体、后景是空间延伸 | 前景{画框元素}、中景{空间主体}、后景{空间延伸} |
| 材质与表面 | 墙面泛黄斑驳、地面磨损、家具包浆——一切材质呈现在胶片机下 | 墙面泛黄斑驳、地面自然磨损、家具使用包浆 |
| 镜头选择 | 24-35mm，全景深 f/8-f/11，空间纵深完整 | 广角24-35mm、全景深、空间纵深完整 |

## 五、单视图全景摄影规范

| 项目 | 摄影要求 |
|---|---|
| 空间呈现 | 单张照片完整呈现场景全貌——24-35mm、纵深/宽度/高度一张画面全部可见 |
| 构图 | 前景（门框/窗/栏杆/树枝/电线）画框 → 中景主体 → 后景纵深延伸 |
| 景深 | 全景深 f/8-f/11，从前到后清晰 |
| 人物 | **严禁出现任何人物、人影、人体轮廓**——场景是"空的"，但空有叙事 |
| 质感 | 35mm胶片质感、轻微颗粒、暖棕复古色调、轻微暗角、低饱和褪色 |
| 比例 | 建议 16:9 或 3:2 宽幅 |

### 空的场景如何叙事

| "空"的类型 | 画面线索 | 叙事暗示 |
|---|---|---|
| 刚下班 | 桌上半杯茶、椅子没推回、台灯还亮着 | 刚才有人在这里，现在走了 |
| 人去楼空 | 墙上挂钩痕迹、地面积尘的轮廓、老物件蒙尘 | 曾经有人住过，已经搬走了 |
| 日常静止 | 沙发上的毛毯随意搭着、茶几上的搪瓷杯 | 生活的常态、此刻无人入镜 |
| 深夜场所 | 空荡的老街只有路灯亮着、店铺卷帘门紧闭 | 城市睡着了、记忆还醒着 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单张全景摄影」——单视图、非2×2四视图、非多角度 |
| R2 | 必须使用广角镜头（24-35mm）、全景深 f/8-f/11、完整空间纵深 |
| R3 | 光源必须可追溯——日光方向与时刻匹配、旧式灯光位置色温合理 |
| R4 | 场景必须有前/中/后景空间层次 |
| R5 | 必须有「80-90年代时代辨识度」——旧建筑/旧招牌/老物件/时代元素 |
| R6 | 必须有「岁月痕迹」——墙面斑驳/地面磨损/家具包浆，非样板间 |
| R7 | **严禁出现任何人物、人影、人体轮廓、剪影** |
| R8 | 必须声明「真人实拍 + 35mm胶片质感 + 暖棕复古色调 + 非3D非CG」核心锚定 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 体积光 / AO」等一切CG术语 |
| X2 | 严禁「2D手绘 / 插画 / 卡通 / 二次元」等非摄影媒介 |
| X3 | 严禁「四视图 / 2×2网格 / 多角度 / turnaround」——仅单张 |
| X4 | 严禁「现代建筑 / 摩天楼 / 玻璃幕墙 / LED广告屏 / 智能手机时代」等现代元素 |
| X5 | 严禁「赛博朋克 / 科幻 / 架空奇幻 / 异世界」等非80-90年代世界观 |
| X6 | 严禁「出现任何人物 / 人影 / 人体轮廓 / 剪影」 |
| X7 | 严禁「样板间 / 售楼处效果图 / 全新无痕 / 无岁月痕迹」 |
| X8 | 严禁「光源来源不明 / 全局均匀照明 / 无方向的光」 |
| X9 | 严禁「高饱和荧光色 / 现代数码锐利色 / 纯净无颗粒数码感」 |
| X10 | 严禁「过曝死白 / 暗部死黑 / 无层次 / 画面扁平」 |
| X11 | 严禁「水印 / 文字 / LOGO / 签名 / 边框 / AI生成痕迹」 |
