# 道具图像生成 · 约束手册（真人复古胶片）

---

## 一、道具设计原则

> 真人复古胶片的道具不是"被建模的物体"，而是"80-90年代被真实使用过的老物件"——它在某个人手里待过、在某张桌上放过、在某段时间里活过。胶片摄影机拍下的是它的此刻，也是它的往事。

1. **物品即时代** — 每一件道具都是时代的证据——胶片相机、老式电话、磁带机、暖水瓶、搪瓷杯——观众一眼就能认出"这是那个年代的东西"
2. **使用痕迹优先于完美品相** — 复古道具必须有"被用过"的证据——磨损、包浆、褪色、划痕。全新的、刚拆封的、样板级别的道具一律不出现
3. **年代准确性** — 道具必须是80-90年代真实存在的物品——拒绝无年代的架空物、拒绝现代数码产品
4. **材质即真实** — 不是渲染参数，而是胶片摄影机拍下的真实材质行为——搪瓷的釉面、塑料的注塑纹理、金属的氧化、木质的包浆
5. **单视图静物摄影** — 道具以单张静物产品摄影方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物摄影规范

| 项目 | 摄影要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线位置独立陈列，完整入画，无裁切 |
| 背景 | 素灰无缝背景纸 #B0B0B0（哑光），或纯木桌面/旧布面，根据道具属性选择 |
| 光线 | 自然窗光或单灯柔光——暖调侧光，光影柔和、方向明确、无硬阴影 |
| 景深 | 浅景深 f/2.8-f/5.6，道具主体清晰，前后微虚化 |
| 投影 | 道具与承载面之间的自然接触阴影，方向与主光源一致 |
| 质感 | 35mm胶片质感、轻微颗粒、暖棕复古色调、轻微暗角 |
| 画面比例 | 建议 1:1 正方形或 4:3 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单张静物摄影」——单视图、非多角度、非2×2四宫格 |
| R2 | 必须指定「素灰背景纸 #B0B0B0」或「纯木桌面/旧布面」等真实承载面 |
| R3 | 必须指定光源逻辑——自然窗光或柔光箱，光影方向明确、投影自然 |
| R4 | 道具必须有「使用痕迹」——非全新、非样板品相、非未拆封 |
| R5 | 道具必须为「80-90年代真实器物」——拒绝现代数码产品与架空物 |
| R6 | 必须声明「真人实拍产品摄影 + 非3D非CG」核心锚定 |
| R7 | 必须声明「35mm胶片质感 + 暖棕复古色调 + 暗角」 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质」等一切CG术语 |
| X2 | 严禁「2D手绘 / 插画 / 卡通 / 二次元」等非摄影媒介 |
| X3 | 严禁「全新未拆封 / 样板品相 / 无使用痕迹 / 完美品相」的道具 |
| X4 | 严禁「智能手机 / 平板 / 现代数码设备 / 高清屏幕 / 科幻 / 赛博朋克」 |
| X5 | 严禁「高饱和荧光色 / 现代数码锐利色 / 纯净数码感」 |
| X6 | 严禁「多角度 / 四视图 / 2×2网格 / turnaround」——仅单张 |
| X7 | 严禁「出现人物 / 手部 / 手指 / 肢体」 |
