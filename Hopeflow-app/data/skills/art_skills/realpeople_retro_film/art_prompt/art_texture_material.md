# 材质与质感 · 约束手册（真人复古胶片）

> 质感来自「胶片对光的记录」，不是材质贴图。搪瓷缸的缺口、木门的包浆、老墙皮的斑驳、铁皮暖水瓶的磕痕——每一处痕迹都是被时光用过的证据。一切质感都以"胶片摄影机拍到过"为准，拒绝任何渲染词汇。

---

## 一、摄影质感描述（以摄影机与胶片说话）

| 质感域 | 摄影表达 | 禁止的渲染表达 |
|---|---|---|
| 皮肤 | 毛孔、细纹、痣、自然肤色不均、暖棕肤色 | 光滑、磨皮、零毛孔蜡像 |
| 发丝 | 被风吹乱、碎发自然、发尾毛躁 | 建模整齐发块、假发感 |
| 面料 | 洗旧褪色、领口变形、布面起球、磨损发白 | 无缝贴图、完美样板衣 |
| 环境 | 墙皮斑驳、桌面磕痕、器物包浆、地面磨损 | 样板间、出厂新物 |
| 颗粒 | 35mm胶片颗粒（细腻不规则）+ 暗角 + 褪色 | 数字噪点爆炸、伪影 |

## 二、材质锚词清单（可直接注入提示词）

| 材质 | 中文锚词 | 英文锚词 |
|---|---|---|
| 老墙皮 | 斑驳剥落、水渍、苔痕 | weathered plaster, peeling paint |
| 木门/木器 | 包浆、磕痕、漆面龟裂 | aged wood, patina, cracked varnish |
| 搪瓷/铁皮 | 缺口、磕碰、锈斑 | enamel wear, rust spots |
| 旧布料 | 洗旧褪色、起球、线头 | faded fabric, pilling |
| 皮革 | 使用包浆、弯折痕 | worn leather, creases |
| 纸质 | 泛黄、折痕、卷边 | aged paper, yellowed, curled edges |
| 玻璃 | 手印、尘垢、雨痕 | smudged glass, streaks |
| 金属 | 氧化、锈迹、划痕 | oxidized metal, scratches |

> 材质色值锚定复古色盘：老墙褪色米黄、旧木深褐、搪瓷暖白、铁皮锈褐——一切取色于 C1-C10，低饱和、暖调、褪色，杜绝崭新现代材质感。

## 三、画质硬约束

| 编号 | 约束 |
|---|---|
| H1 | 皮肤必须「真人毛孔可见」，禁磨皮/蜡像/塑料感/AI假面 |
| H2 | 发丝自然状态优先，禁建模感整齐发块 |
| H3 | 服饰必须有"被穿过多年"的痕迹：洗旧褪色、褶皱、起球、领口变形 |
| H4 | 场景必须有"被用了很多年"的证据：墙皮斑驳、器物包浆，禁样板间 |
| Q4 | 必须声明颗粒质感偏好：35mm胶片颗粒 + 轻微暗角 + 暖棕褪色 |

## 四、必守规则

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影/真人实拍」为锚——画面读作"胶片摄影机拍下的" |
| P3 | 皮肤保留真实质感，杜绝塑料磨皮与 AI 感假面 |
| P4 | 发丝呈现自然状态，杜绝建模感整齐发块 |
| P5 | 服饰体现"穿过"的痕迹，杜绝全新样板衣感 |
| P6 | 场景有"被使用过"的证据，杜绝样板间 |

## 五、严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁 CG 术语：3D渲染/CG/UE/Blender/次世代建模/PBR材质/体积光/环境光遮蔽（AO）/光线追踪 |
| X2 | 卡通/插画/动画/二次元质感（赛璐璐色块、描边） |
| X3 | 过度磨皮/塑料假人感/零毛孔蜡像脸/AI感假面/对称僵笑 |
| X4 | 全新道具感、样板间感、无生活痕迹、崭新现代材质感 |
| X5 | 低分辨率/模糊/噪点爆炸/严重伪影/抠图白边/拼接断层 |
