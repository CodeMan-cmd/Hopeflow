# 分镜表真人复古胶片约束 · 80-90年代胶片实拍 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。

---

## 二、Seedance 2.0 描述铁律

> 真人复古胶片分镜表中所有描述必须遵守以下翻译原则——将"导演意图"翻译为"AI可执行的物理指令"。

| 禁止的抽象表达 | Seedance 2.0 具象替换 |
|---|---|
| 她很怀旧 | 眉眼低垂，目光失焦望向窗外老街，嘴角自然下沉，右手无意识地摩挲搪瓷缸边缘 |
| 黄昏很美 | 金色时刻阳光从左侧老窗45°斜入（约3200K暖金），在地面投下窗框的长方形光斑，边缘有轻微暗角 |
| 老街很热闹 | 临街店铺钨丝灯暖黄全亮（约2800K），三位行人沿街缓步走动，其中一位推着老式自行车，摊贩的煤炉冒着热气 |
| 他转身离开 | 向右缓慢旋转约90度，面朝画面右侧，右脚先迈出约0.6米，左脚跟进，衣摆随之摆动，全程约2秒 |
| 气氛很压抑 | 日光灯管冷白硬光（约4500K）单光源侧打，房间其余部分深暗但有微弱轮廓可见，光比约1:8 |
| 风吹动晾衣绳 | 晾衣绳上的一件白衬衫被风吹起约20cm，随即回落，反复约2秒一个周期，衣角轻微晃动 |

## 三、光影与氛围——Seedance 2.0 物理光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如有人拉灭钨丝灯、日落后天光亮过室内灯、从室内走到老街）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）
[光源] 主光：{光源类型}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}

### 3.3 情绪 → 光源矩阵

| 情绪 | 光源配方（Seedance 2.0 可直接填入） | 视觉关键词 |
|---|---|---|
| 怀旧日常 | 大面积窗光漫射（4500-5500K），窗帘柔化泛白米黄。光比约1:1.5低反差 | 低反差、泛黄、岁月静好 |
| 黄昏浪漫 | 金色时刻斜光（2800-3500K）侧打，暗部暖棕补光。光比约1:3 | 暖金镀边、长影、珍贵 |
| 市井烟火 | 多光源混杂——钨丝灯暖黄（2700-3200K）为主，日光灯冷白（4500K）局部对冲。光比约1:5 | 暖调主导、热闹、人间味 |
| 雨夜怅惘 | 湿青石板路面反射钠灯街灯暖橙光斑（2200K），环境冷调（6000K天空漫射）。光比约1:6 | 冷暖共存、诗意、孤寂 |
| 时代冷感 | 日光灯管冷白硬光（4000-5000K）单光源，大光比约1:8，暗部深但有细节 | 压抑、克制、年代冷感 |
| 深夜独处 | 单一钨丝台灯（2800-3200K）孤岛式照明，面部一侧亮一侧暗。光比约1:8 | 极简光源、私密脆弱 |

### 3.4 冷暖色调与叙事阶段

- **暖光主导**（2000-3500K）：温情怀旧、市井烟火、黄昏浪漫、深夜私密
- **冷光主导**（4000-5000K+）：时代冷感、克制疏离、日间办公室冷白
- **冷暖共存**：过渡时刻（蓝调时刻+初亮旧灯）、雨夜（冷环境+暖光斑）
- **光源变化 = 叙事信号**：窗外天空从日间泛白渐变至金色时刻=时间流逝；从日光灯管办公室走进钠灯街灯下的老街=场景与情绪的切换

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约3200K` 优于 `暖光`
- 光比数字帮助模型建立明暗意识：`光比约1:4` 优于 `柔和的阴影`
- 光源必须有明确来源：`从画面左侧老窗45°斜入` 优于 `侧光`
- 环境光的反射路径描述：`湿路面反射钠灯街灯暖橙黄光斑` 优于 `地面有暖色反光`

## 四、环境动态——让画面呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。静态对话戏也不例外——至少有一个镜头里老式吊扇在转、搪瓷缸的热气在升腾、晾衣绳上的衣物被风吹动。

### 4.2 80-90年代环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| 老屋室内 | 老式吊扇缓慢旋转、煤炉水壶口蒸汽缓缓上升、老挂钟的钟摆匀速摆动、窗帘被微风轻鼓约10cm后回落（约2秒周期）、收音机指示灯忽明忽暗 |
| 老城街巷 | 晾衣绳上衣物被风吹动、远处行人在巷口走过、老式自行车慢速骑过画面中景、摊贩煤炉的青烟袅袅上升、电线上的麻雀飞走 |
| 旧商店/小卖部 | 老式吊扇转动、玻璃罐糖果在钨丝灯下的反光、柜台上的算盘珠被拨动、门口门帘被出入的人掀起又落下 |
| 录像厅/电影院 | 放映机光束里的尘埃缓慢浮动、暗红丝绒座椅的褶皱、散场后空荡的座位、门口灯箱的荧光灯管偶尔闪烁 |
| 绿皮火车 | 车窗外的田野和电线杆飞速掠过、车厢吊扇慢转、桌上搪瓷缸里的水面随车身晃动、站台人流缓缓移动 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`晾衣绳上的衬衫被风吹起约20cm，每秒约2-3次微幅晃动` 优于 `衣服在动`
- 光源动态与空间光源逻辑一致：`云朵遮住太阳时，老窗窗光面积缩小约40%，持续约3秒后恢复`
- 禁止无来源的动态：没有风=晾衣绳不动。室内没有开窗=没有风

## 五、人物动作节奏——Seedance 2.0 物理逻辑具象化

### 5.1 动作描述铁律

所有人物动作必须描述：**轨迹 + 速度/时长 + 身体部位协调 + 对周围物体的影响**。

### 5.2 年代动作具象库

| 动作 | Seedance 2.0 可执行描述 |
|---|---|
| 起身 | 双手撑住老式木椅扶手，膝盖向前移动，0.5秒后身体重心前移至双脚，再1秒后站直——全程约2秒，站直后衣摆自然垂落 |
| 倒茶 | 右手提起搪瓷暖水瓶，瓶身倾斜约45度，热水注入搪瓷缸，水面从缸底上升至三分之二处，蒸汽从缸口缓缓升起——全程约3秒 |
| 骑车 | 老式自行车从画面左侧进入，速度约每秒2.5米，车铃偶尔响起，车轮碾过路面带起轻微扬尘，约4秒后骑出画面右侧 |
| 看老照片 | 双手捧起泛黄老照片，拇指在折痕处轻轻抚过，目光从照片边缘移到中心人物，眼中有钨丝灯暖光点，照片边缘微微卷起 |
| 推门进入 | 右手握住木门把手向下转动约30度，向内推开门约70度角，门轴发出吱呀声，身体随门进入，右脚先跨过门槛——全程约2秒 |
| 拨算盘 | 右手食指和中指交替拨动算盘珠，珠子碰撞发出清脆声响，目光沿数字移动——全程约4秒 |

### 5.3 动作节奏与叙事场景

- **怀旧叙事/文戏**：动作沉稳克制，每个微动作标注时长和轨迹。节奏舒缓——不是慢，是"不赶"
- **情绪波动场景**：动作幅度和速度略微增加。人物可能在对话中不自觉加快拨弄旧物的频率、呼吸带动肩膀起伏更明显
- **冲突场景**：动作干脆利落，但仍有物理轨迹。推搡须具体到"右手推在对方左肩前方，对方重心向后偏移约20cm"
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、"做了个手势"等含糊描述

### 5.4 服饰动态

真人服饰的动态是画面的天然资产——不是"布料模拟参数"，而是"洗旧的碎花裙摆随步伐左右轻摆约10cm""衬衫衣角被风吹起约20度角""围巾一端从肩头滑落"。在分镜表画面描述中标注服饰的动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息
水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景
人物与场景的关系：距{固定物}{数值}米
（若双人以上）人物A与B的相对距离和朝向

### 6.2 站位衔接示例
【片段A尾部】
A站在老式柜台前，距柜台约0.5米，面朝店员B，位于画面中央偏右，距镜头约3米。
柜台后为铁皮货架，钨丝灯暖光从上方洒下。
A右手将搪瓷缸放在柜台上，缸距A约20cm。

【片段B开头】
A的搪瓷缸刚从手中放下约10cm，缸仍在柜台上。A仍站在柜台前（位置未变）。
窗外天色已从黄昏转为蓝调时刻——天空深蓝紫，街边钠灯街灯已亮起。
店内钨丝灯仍亮（约3000K），暖黄光照在A的左侧脸颊。

### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 她走近了 | A从画面背景（距镜头约5米、门框位置）向镜头方向匀速行走4步（约3米），停在距镜头约2米处——耗时约4秒 |
| 两人面对面 | A位于画面中央偏左（距镜头约3米），B位于画面中央偏右（距镜头约3米），两人面对面，相距约0.8米 |
| 从室内到老街 | A从老屋内（距镜头约3米）走向门口，推开木门（门向内旋转约80度），右脚跨过门槛，进入室外老街——钠灯街灯暖橙光瞬间取代室内钨丝灯光 |

## 七、运镜规范——Seedance 2.0 摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 三脚架固定 | 摄影机固定不动，画面静止 | 对话、日常、空镜留白、情绪凝视 |
| 肩扛手持微晃 | 摄影机有轻微不规则晃动（幅度约±2cm），模拟手持拍摄的呼吸感 | 情绪波动、街头行走、亲密跟随 |
| 轨道车横移 | 摄影机平滑匀速横移，无晃动 | 老街漫游、人物登场、空间展示 |
| 变焦缓推 | 摄影机向主体缓慢推进，推进速率约每秒0.3米 | 情绪升温、真相逼近、注意力聚焦 |
| 变焦缓拉 | 摄影机向后缓慢拉远，拉远速率约每秒0.3米 | 离别、收束、揭示全貌 |
| 摇镜 | 摄影机原地水平/垂直旋转 | 视线转移、空间关系交代 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（推拉速率超过每秒1米）
- 超过3秒的剧烈手持晃动（除非主观受击/眩晕叙事）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 现代稳定器流动感、无人机航拍、摄影机无理由的360度旋转

### 7.3 胶片时代运镜哲学

- 三脚架固定是第一选择——让观众看到真实的人在旧时光里自然地存在
- 肩扛手持微晃在情绪段落使用——但晃动幅度不超过电影纪实风格的常规范围
- 运动镜头的起幅和落幅必须平稳，运动过程匀速——禁止突然加速或急停

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 时间流逝、平行叙事。例：A处窗外的金色时刻 → B处窗外的金色时刻 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：老屋门关上的瞬间 → 火车站台门打开的瞬间 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示 |
| 焦点转场 | 前镜焦点从主体移至背景，后镜从模糊背景中逐渐聚焦主体 | 空间切换、注意力的转移 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克）
- 无叙事逻辑的旋转/缩放转场
- 同一场戏内使用超过两种转场方式

## 九、音画同步规划（Seedance 2.0 专属）

### 9.1 环境音标注规范

每场戏标注 1-2 个核心环境音，写在分镜表的环境音列：

| 场景 | 建议环境音 |
|---|---|
| 老屋室内 | 老挂钟滴答 / 吊扇转动 / 收音机年代广播 |
| 老城街巷日间 | 自行车铃铛 / 沿街叫卖 / 麻雀叫 |
| 老城街巷雨夜 | 雨打瓦片和青石板 / 偶尔驶过的老式汽车 |
| 旧商店 | 算盘拨动 / 吊扇转动 / 玻璃罐轻碰 |
| 录像厅/电影院 | 放映机运转 / 门口宣传喇叭 / 散场人声 |
| 绿皮火车 | 车轮与铁轨的节奏声 / 车厢广播 / 汽笛 |

### 9.2 音画同步标注

在分镜表中对关键音画同步点做标注：
- `t=2s` 搪瓷缸放上木桌时缸底与桌面接触的轻响声
- `t=5s` 木门推开的铰链吱呀声——人物进入老屋，老街的嘈杂被隔绝瞬间变小
- `t=8s` 远处传来火车汽笛——人物抬头望向窗外约1秒

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新空间首次出现——让观众看清楚这是什么地方 | 老屋全景：八仙桌、旧挂历、墙皮斑驳、窗光洒下 |
| 情绪缓冲 | 高情绪段落后的喘息 | 雨滴沿老窗玻璃滑落，速度约每秒2cm，窗外老街模糊 |
| 时间流逝 | 暗示时间过去了 | 同一扇老窗外的天空从泛白天光渐变至金色时刻 |
| 隐喻留白 | 以物代情 | 桌上搪瓷缸，缸口热气已散尽，杯壁有旧茶渍 |
| 转场衔接 | 前后两个空间的自然过渡 | 老式吊扇慢转——前一场的旧商店，下一场是老屋 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+质感+动态的描述铁律：黄昏金色时刻阳光从左侧老窗斜入（约3200K），在八仙桌上投下窗框的光斑，
光斑随窗外云朵移动而缓慢变化宽度和位置，约5秒后完全变暗——一朵云挡住了太阳。
桌面有木纹磕痕和一圈旧茶渍，墙皮斑驳，旧挂历微微卷边。
