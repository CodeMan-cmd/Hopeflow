# 分镜提示词 · 真人复古胶片 · 风格专属技法

---

## 适用范围

本 Skill 专用于**真人复古胶片**风格的分镜提示词生成，适配怀旧剧情、市井生活、年代成长、复古爱情、老城记忆等80-90年代真人实拍题材的分镜创作。

---

## 一、摄影机前的情绪——面孔、眼神、微表情

> 真人复古胶片的情绪不来自"渲染参数"，而来自真人演员在胶片摄影机前的微表情，在颗粒与暗角中被时光定格。

| 情绪输入 | 面容描述 | 眼神描述 | 微表情补充 |
|---|---|---|---|
| 怅惘 / 怀旧 | 眉眼低垂，面部肌肉松弛 | 目光涣散失焦，望向老街或老照片 | 嘴角自然下沉，表情怅然不刻意 |
| 温柔 / 温情 | 眉目舒展，面部柔和 | 眼神温润专注，像在听旧时光说话 | 嘴角自然微扬，不是笑，是有温度 |
| 倔强 / 隐忍 | 面部线条微微绷紧，不夸张 | 眼神锐利但不过度，注视有力 | 下颌收紧，表情克制，咽下话 |
| 惊讶 / 触动 | 眼尾微抬，眉毛自然上扬 | 眼神骤然聚焦，瞳孔微扩 | 嘴角微启，表情鲜活不夸张 |
| 沉思 / 追忆 | 神情淡然，眼部周围肌肉放松 | 目光放远失焦，像在看但不在看 | 可能轻抚旧物或指节轻叩桌面 |
| 喜悦 / 鲜活 | 眼角自然笑纹，眼型微弯 | 眼神明亮有光，眼角有笑意牵动 | 嘴角上扬，面颊微红，生动不夸张 |
| 疲惫 / 倦怠 | 眼窝微陷，面部整体松弛 | 目光朦胧，眼皮微沉 | 眉眼低垂，可能的黑眼圈，表情松弛 |
| 决绝 / 告别 | 面部线条清晰，下颌微抬 | 眼神笔直向前，不回避不躲闪 | 嘴角抿紧，目光里有克制的不舍 |

## 二、摄影机前的光——光源逻辑与氛围

### 2.1 胶片时代的光源时刻

| 时刻 | 光源行为 | 色温与色调 | 空间氛围 |
|---|---|---|---|
| 清晨 | 低角度暖金日光，从老窗斜入室内，晨雾在光里浮动 | 3500-4500K暖白，空气微冷 | 老城苏醒、早市热气、一切尚未开始 |
| 上午天光 | 日光升高，泛白清亮，阴影柔和；窗光面积最大 | 5000-6000K泛白 | 日常运转、泛黄窗光下的旧空间 |
| 金色时刻 | 极低角度暖金漫射，长影到极致，一切镀上旧金 | 2800-3500K极暖 | 转瞬即逝的珍贵、怀旧回忆段落的唯一光源 |
| 蓝调时刻 | 日落后天空深蓝紫，旧灯刚刚亮起 | 8000-10000K天空+暖点旧灯 | 过渡、诗意、白天已尽夜晚未接管 |
| 钨丝灯夜 | 台灯/钨丝灯的单点暖黄，其余沉入暗部 | 2700-3200K暖黄 | 孤独或私密、深夜老屋的体温 |
| 旧城雨夜 | 钠灯街灯暖橙黄，湿路面反射拉长的光斑 | 2000-2200K暖橙 | 怅惘、孤寂、旧忆被雨水洇开 |

### 2.2 情绪光影

| 情绪基调 | 光线配方 | 摄影约束 |
|---|---|---|
| 怀旧日常 | 大面积窗光漫射（4500-5500K），窗帘柔化泛白米黄，无硬阴影 | 低反差、35mm颗粒、暗角轻微，浅景深突出人物 |
| 黄昏浪漫 | 金色时刻斜光（2800-3500K）侧打，人物边缘镀旧金 | 光比约1:3，高光柔和滚落，暗部暖棕有细节 |
| 市井烟火 | 多光源混杂——钨丝暖（2800K）+ 日光灯冷白（4500K）对冲 | 暖调主导、冷光局部对冲，肩扛手持的临场感 |
| 雨夜独处 | 湿路面反射钠灯暖橙光斑（2200K），其余沉入冷暗 | 冷暖共存，单点暖光源在人脸上，暗部有颗粒层次 |
| 时代冷感 | 日光灯管冷白硬光（4000-5000K）单光源侧打，深阴影 | 大光比约1:8，硬光勾勒轮廓，暗部压深但有细节 |
| 深夜脆弱 | 单一钨丝台灯（2800-3200K）孤岛式照明，面部一侧亮一侧暗 | 极简光源，暗部丰富有细节，光比可到1:8 |

## 四、摄影机语法——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 28mm广角 | 环境包围人物、老城纵深与个体渺小 | 老街空镜、巷弄尽头的身影 |
| 35mm小广角 | 主观视点、纪实感、人与环境共存 | 街头行走、市井跟随、日常记录 |
| 50mm标准 | 人眼等价、客观的注视、最诚实的镜头 | 人物肖像、双人对话、情感凝视 |
| 85mm中长焦 | 压缩空间、拉近情感距离、背景虚化 | 特写、隔着街道的凝望、偷窥视角 |
| 135mm长焦 | 将人物从旧时光中剥离、远距离注视 | 人群中隔离的个体、远眺、叙事的距离感 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴唇/手指/旧物件细节 | 情绪爆发点、旧物揭示、感官聚焦 |
| 近景 | 头顶至胸部以上 | 人物情感、对话反应、微表情 |
| 中近景 | 头顶至腰部 | 人物互动、手势动作、身体语言 |
| 中景 | 头顶至膝盖上下 | 人物与老空间的初级关系、多人同框 |
| 全景 | 人物全身+部分环境 | 人物在旧空间中的位置、行动路线 |
| 空镜 | 空间全貌，无人物或人物极小 | 空间叙事、情绪缓冲、隐喻留白 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 三脚架固定 | 冷静观察，让时间自己说话 | 日常场景、对话、空镜留白 |
| 肩扛手持微晃 | 在场感、呼吸感、主观介入 | 情绪波动、街头行走、亲密跟随 |
| 轨道车横移 | 缓慢流动、旧时光的滑过感 | 人物登场、老街漫游、过渡 |
| 变焦缓推 | 注意力逐渐聚焦、情绪趋近 | 对话升温、真相逼近、情感推进 |
| 变焦缓拉 | 拉开距离、揭示全貌、情绪抽离 | 离别、章节收束、空间展示 |
| 摇镜 | 视线转移、空间关系交代 | 人物视线引导、老街与老街的关系 |

## 五、固定风格锚定词

**摄影锚定（必选）：**

真人实拍摄影，80-90年代复古胶片电影剧照，老城旧时光，电影级胶片摄影，暖棕褪色复古色调，35mm胶片颗粒，轻微色偏，暗角，真实色彩科学

**人物质感（含人物镜头时必选）：**

真人写实摄影质感，真实皮肤纹理毛孔可见，不磨皮不硅胶脸，发丝自然质感有碎发，服饰面料纹理可见有洗旧穿着痕迹，自然微表情，真实肢体语言

**场景质感（含场景镜头时必选）：**

80-90年代场景实拍摄影，真实岁月痕迹（墙皮斑驳/器物包浆/地面磨损），光源方向明确可追溯，胶片颗粒与暗角自然，非样板间非效果图

**风格收尾（固定）：**

真人写实摄影，80-90年代复古胶片质感，胶片电影画面，非3D非渲染非CG

**画质锁定词（模式A · Seedream）：**

真人摄影高清画质，胶片电影画面质感，画面无字幕、无水印、无标题叠字、无UI元素

**模式B（英文）默认：**

live-action retro film photography, 35mm film grain, warm brown faded color, vintage tone, subtle color cast, vignette, real human skin texture, cinematic film look, no subtitles, no captions, no watermark, no title overlay, no UI elements

**负向词（模式B 必须包含，置于提示词末尾）：**

no 3D render, no CGI, no Unreal Engine, no Blender, no PBR material, no game engine, no 2D cartoon, no anime, no illustration, no hand drawn, no plastic skin, no wax face, no airbrushed, no poreless skin, no silicone face, no ancient Chinese style, no traditional costume, no cyberpunk, no sci-fi, no modern digital device, no smartphone, no LED screen glow, no high saturation, no neon, no fluorescent, no subtitles, no captions, no watermark, no title overlay, no UI text

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 3D渲染 / 3D建模 / CG / UE引擎 / Blender / PBR材质 / 次世代建模 / 体积光 / 环境光遮蔽 / 光线追踪
- ❌ 2D手绘 / 插画 / 动画 / 二次元 / 漫画 / Q版 / 赛璐璐
- ❌ 写实摄影（英文禁止 photorealistic / realistic rendering——真人复古胶片是"真人实拍摄影"，不是"拟真渲染"）
- ❌ 过度磨皮 / 塑料假面 / 零毛孔 / 硅胶脸 / 蜡像感 / AI感平滑
- ❌ 古风 / 古装 / 汉服 / 仙侠 / 武侠 / 民国及更早 / 赛博朋克 / 科幻 / 西方奇幻 / 中世纪
- ❌ 智能手机 / 高清屏幕 / 现代数码设备 / LED屏幕光
- ❌ 高饱和荧光色 / 霓虹溢色 / 现代数码锐利色 / 廉价滤镜感
- ❌ 人体结构错误 / 肢体畸形 / 面部崩坏 / 比例失调
