## 二、核心色盘（风格基线，不是硬锁）

> 目标：统一审美而非限制创作。真人复古胶片的色彩以暖棕褪色为基底、低饱和怀旧为方向、轻微色偏为记忆感。

### 核心色盘 C1-C10

| 序号 | 色名 | 色值 | 用途 |
|---|---|---|---|
| C1 | 暖棕 | #8B6F47 | 画面主基调、肤色暖调、木质器物 |
| C2 | 褪色米黄 | #D8C3A5 | 墙面、纸品、泛白的高光区、日光 |
| C3 | 旧橙 | #C96F4A | 夕阳、钨丝灯光、暖调点缀 |
| C4 | 褐红 | #7C3F34 | 砖墙、红裙、老物件、深色点缀 |
| C5 | 墨绿 | #4A5547 | 军装、老绿漆、树木、冷调点缀 |
| C6 | 靛蓝 | #3D4654 | 牛仔裤、夜空、冷调阴影 |
| C7 | 褪色灰 | #9A948C | 水泥墙、胶片灰阶、中性过渡 |
| C8 | 泛黄白 | #EFE6D2 | 高光基底、白色衣物的胶片泛黄 |
| C9 | 暗金 | #B8912F | 金属件、首饰、黄昏高光 |
| C10 | 深褐 | #3E2F23 | 暗部、阴影、剪影、老木 |

### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 整体色调：暖棕褪色基底、低饱和、轻微色偏——不可偏离 |
| L2 软约束 | 中 | 场景色、服饰色、点缀色优先参考色盘，可按镜头微调 |
| L3 例外机制 | 低 | 特殊段落（如夜晚霓虹旧灯）可临时突破局部色彩，但需保留胶片质感 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 4500-5500K（推荐） | 复古暖调主基调 |
| 肤色色温 | 微暖 5000-5500K（推荐） | 暖棕调肤色、泛黄的胶片感 |
| 对比度 | 中低 40-55%（建议区间） | 柔和的胶片反差，暗部有层次 |
| 饱和度 | 中低 35-55%（建议区间） | 低饱和怀旧、褪色感 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：黄昏、霓虹旧灯、情绪高潮镜头可使用更暖或更饱和的局部色块；但禁止高饱和荧光色、现代数码色与鲜艳滤镜色。

## 四、风格越界判定

> 当画面出现以下信号，说明已偏离真人复古胶片风格：

| 越界信号 | 说明 |
|---|---|
| 皮肤像硅胶 | 磨皮过度失去真人质感——立即停用"光滑""完美肌肤"类词汇 |
| 色彩鲜艳刺眼 | 饱和度超标、现代数码色——回归低饱和褪色与暖棕基底 |
| 画面过于干净锐利 | 无颗粒无暗角、手机摄影感——加入胶片颗粒、暗角与柔和高光 |
| 光源来源不明 | 画面亮但说不清光从哪来——补全光源逻辑 |
| 出现现代电子元素 | 智能手机/高清屏幕/现代数码设备——80-90年代世界观没有这些 |
| 色调像滤镜APP | 统一的"复古滤镜"廉价感——回归光源色温驱动的胶片色彩 |
