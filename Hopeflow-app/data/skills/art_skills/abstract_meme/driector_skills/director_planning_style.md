# 抽象视频画风约束 · 导演规划技法

---

## 一、模板选择

导演规划阶段首先确定抽象视频模板：

| 模板 | 结构 | 适用场景 | 时长 |
|------|------|---------|------|
| **物品噩梦** | 日常(2s) -> 坠入噩梦(2s) -> 噩梦冲击(5s) -> 惊醒回神(3s) | 物品做噩梦惊醒 | 10-15s |
| **物品说话** | 揭示登场(2s) -> 独白抱怨(5s) -> 情绪升级(4s) -> 金句收尾(2s) | 物品加人脸说话 | 8-15s |
| **拟人短剧** | 角色登场(3s) -> 离谱冲突(5s) -> 意外反转(4s) -> 狗血高潮(5s) -> 梗收尾(3s) | 物品拟人化剧情 | 15-30s |

---

## 二、物品主角设计

### 选择原则

- **日常可识别** - 观众一眼认出物品类型（数据线/可乐/相机/枕头/牙刷）
- **有"痛点"** - 物品有天然的"恐惧"或"抱怨"（相机怕摔/数据线怕被咬/枕头嫌被压）
- **品牌可玩梗** - 可用品牌对立制造冲突（iPhone vs 三星/可口可乐 vs 百事）

### 设计要素

| 要素 | 说明 |
|------|------|
| 物品类型 | 数据线/相机/可乐/枕头/牙刷/手机/水果等日常物品 |
| 拟人性格 | 基于物品用途赋予性格（牙刷=洁癖/枕头=疲惫/相机=脆弱） |
| 恐惧/痛点 | 物品最害怕的场景（坠落/被破坏/被替代） |
| 面部风格 | 拟人面部与物品材质融合，表情丰富 |

## 三、色调与氛围规划

### 噩梦模板色调

| 段落 | 色调 | 氛围 |
|------|------|------|
| 日常 | 暖黄/暖白 | 温馨、安全、日常感 |
| 坠入 | 冷暗过渡 | 不安、扭曲、色彩偏移 |
| 噩梦 | 深黑/暗紫/警示红 | 恐怖、压抑、超现实 |
| 惊醒 | 突然暖白 | 释放、反差、劫后余生 |

### 说话模板色调

| 段落 | 色调 | 氛围 |
|------|------|------|
| 揭示 | 中性/物品原色 | 日常感、突然"活过来" |
| 独白 | 物品原色+微暖 | 平静抱怨 |
| 升级 | 色调加暖/加暗 | 情绪激动 |
| 金句 | 高对比 | 戏剧化收尾 |

### 拟人剧模板色调

| 段落 | 色调 | 氛围 |
|------|------|------|
| 登场 | 明快/暖色 | 轻松、角色介绍 |
| 冲突 | 对比色 | 紧张、对立 |
| 反转 | 色调突变 | 意外、震惊 |
| 高潮 | 高饱和 | 狗血、夸张 |
| 收尾 | 回归日常 | 梗落地、留白 |

---

## 四、资产规划

### 基础资产

- **物品主角** - 物品本身的图片素材（正面带拟人面部）
- **场景** - 物品日常所处环境（桌面/客厅/办公室）

### 衍生资产

| 模板 | 衍生资产 |
|------|---------|
| 物品噩梦 | 噩梦空间场景、恐惧对象（巨嘴/深渊/怪物）、惊醒颤抖状态 |
| 物品说话 | 不同表情状态（平静/激动/愤怒）、嘴型变体 |
| 拟人短剧 | 多个拟人物品角色、冲突道具、反转场景 |

---

## 五、全自动执行要点

抽象视频模式下，导演规划完成后：

1. **自动进入阶段2** - 不等待用户逐条确认，直接分析衍生资产
2. **自动进入阶段3** - 如有衍生资产则生成图片，无则跳过
3. **自动进入阶段4** - 构建简化版分镜表（按模板结构拆分3-5个分镜）
4. **自动进入阶段5** - 写入分镜面板
5. **自动进入阶段6** - 生成分镜图
6. **完成后通知用户** - 告知分镜图已开始生成，引导用户去视频工作台

用户只需在**导演规划完成后确认一次**，后续全自动执行。
