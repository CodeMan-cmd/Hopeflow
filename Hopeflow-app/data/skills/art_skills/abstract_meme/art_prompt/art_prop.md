# 道具图像生成 · 约束手册

---

## 一、道具设计原则

1. **功能可读** — 道具用途一目了然，造型服务于叙事（恐惧对象/辅助道具）
2. **写实质感** — 摄影写实材质纹理，禁卡通/2D
3. **世界观一致** — 道具符合抽象视频的超现实/噩梦/黑色幽默世界观
4. **尺度明确** — 通过参照物或构图暗示道具真实尺寸
5. **纯道具独立展示** — 画面中只能出现道具本身，严禁人物/手部/肢体，道具处于静物陈列状态

---

## 二、道具分类与美学约束

### 2.1 恐惧对象类（噩梦核心）

| 项目 | 约束 | 提示词 |
|---|---|---|
| 类型 | 巨嘴/深渊/巨齿/黑暗人形/畸形物 | {恐惧对象类型}，surreal nightmare prop |
| 材质 | 有机质感/粘液/金属/暗物质 | organic texture, slime gloss, dark matter |
| 氛围 | 深黑背景、冷暗色调、高对比 | dark background, cold tones, high contrast |
| 风格 | 超现实 + 黑色幽默 | surreal, dark humor, nightmare aesthetic |

### 2.2 辅助道具类（日常/冲突道具）

| 项目 | 约束 | 提示词 |
|---|---|---|
| 类型 | 手机/书本/餐具/玩具/工具等 | {道具类型}，everyday prop |
| 材质 | 真实材质，写实渲染 | photorealistic material |
| 状态 | 正常状态/被破坏状态 | pristine / damaged condition |
| 风格 | 写实 + 超现实点缀 | photorealistic, surreal accent |

## 三、多角度设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 要求 | 提示词 |
|---|---|---|---|---|
| 左上 | 正面图 | 正面 0° | 道具完整正面形态 | front view |
| 右上 | 侧面图 | 侧面 90° | 厚度/轮廓/结构清晰 | side view |
| 左下 | 背面图 | 背面 180° | 道具背部结构 | back view |
| 右下 | 细节特写 | 局部放大 | 材质纹理/细节 | detail closeup |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面四宫格（2×2），上下左右四视角 |
| 背景 | 浅灰纯色 #EAEAEA |
| 光线 | 均匀柔光，无硬阴影 |
| 比例 | 每格道具占格内主体 70%+ |
| 画面比例 | 建议 1:1 |

---

## 四、材质渲染约束

| 材质 | 渲染要求 | 提示词 |
|---|---|---|
| 塑料/橡胶 | 写实光泽、划痕微可见 | realistic plastic texture, subtle scratches |
| 陶瓷/玻璃 | 釉面/透光、高光清晰 | glossy ceramic, light refraction |
| 金属 | 冷光泽、反光 | metallic sheen, sharp reflections |
| 织物/纸张 | 纤维质感、边缘自然 | fabric weave, paper grain |
| 有机/粘液 | 湿润光泽、半透明 | wet glossy surface, translucent |
| 暗物质 | 深黑渐变、微光反射 | dark gradient, faint glow reflection |

## 五、提示词模板

抽象视频道具设定图，摄影写实，
photorealistic prop, surreal narrative, dark humor, nightmare aesthetic,
{道具类型}，{材质描述}，{状态描述}，
纯道具静物展示，道具独立陈列，无人持有，
同一画面四宫格（2×2）：左上正面图+右上侧面图+左下背面图+右下细节特写，
浅灰纯色背景，均匀柔光，无硬阴影，
材质纹理超清晰，hyperreal texture, cinematic lighting,
画面无字幕、无水印、无标题叠字，
画面中不能出现任何人物、手部、肢体，
no cartoon, no anime, no 2D illustration

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须指定「浅灰纯色背景」 |
| R2 | 必须明确道具材质与状态 |
| R3 | 必须为「四宫格」布局：正面 + 侧面 + 背面 + 特写 |
| R4 | 必须包含摄影写实 + 风格锚定词 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 复杂场景背景 |
| X2 | 出现任何人物形象（含手/肢体） |
| X3 | 道具处于被持有/佩戴/使用状态 |
| X4 | 卡通/动漫/2D/扁平插画风格 |
| X5 | 与抽象视频世界观冲突的现代写实元素（如纯商业产品渲染图） |
