### 色彩使用层级

| 层级 | 约束强度 | 说明 |
|---|---|---|
| L1 硬约束 | 高 | 角色识别核心：肤色（C1暖肤橙）、发色（C4焦糖棕）、主服底色审美方向 |

### 色温约束

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 4800-5500K（推荐） | 明亮温暖主基调 |
| 肤色色温 | 微暖 5000-5400K（推荐） | 皮肤通透有血色，C1 暖肤橙基底 |
| 对比度 | 中等柔和（建议保持） | 阴影软而有层次，禁死黑死白 |
| 饱和度 | 高 70-85%（建议区间） | 动画电影鲜明通透的色调特征 |

### 容差与例外

| 项目 | 建议容差 |
|---|---|
| 色相偏移 | ±8° |
| 饱和度偏移 | ±10% |
| 明度偏移 | ±12% |

> 例外场景：奇幻魔法、庆典高潮可使用更高饱和或局部光效色；但禁止高饱和荧光色污染与暗黑压抑色调。

## 三、全局约束规则

### 必守规则（所有技能继承）

| 编号 | 规则 |
|---|---|
| R1 | 必须包含「欧美3D动画电影 / 三维动画电影成片质感」风格锚定词 |
| R2 | 必须声明「圆润饱满造型 + 夸张生动的表情与表演」 |
| R3 | 必须声明「明亮饱和色彩 + 柔和全局光照 + 三点布光」 |
| R4 | 必须声明「次表面散射（SSS）+ 丰富材质细节（毛发/布料/皮肤）」 |
| R5 | 必须明确「动画电影」媒介身份，禁止真人实拍/照片写实倾向 |

### 严禁项（所有技能继承，优先级最高）

| 编号 | 严禁内容 |
|---|---|
| X1 | 严禁「真人实拍 / 照片写实 / 真人演员 / live-action / photorealistic 皮肤毛孔写实」——本风格是动画电影不是真人电影 |
| X2 | 严禁「恐怖谷 / 惊悚 / 血腥 / 暗黑哥特 / 阴森瘆人」——全年龄友好是底线 |
| X3 | 严禁「低多边形 / 粗糙建模 / 模糊贴图 / 劣质3D / 塑料死板无光影」 |
| X4 | 严禁「2D手绘 / 赛璐璐平涂 / 日式二次元 / 厚涂插画 / 漫画描边」等非3D媒介 |
| X5 | 严禁「高饱和荧光色 / 霓虹溢色 / 廉价电子色 / 色彩污染」 |
| X6 | 严禁「肢体畸形 / 手指融合 / 五官崩坏 / 表情僵硬无表演」 |

## 四、风格越界判定

> 当画面出现以下信号，说明已偏离欧美3D动画电影风格：

| 越界信号 | 说明 |
|---|---|
| 皮肤像真人照片 | 出现写实毛孔、真人质感——本风格皮肤是SSS通透的卡通化皮肤 |
| 造型出现锐利尖角 | 角色/器物轮廓尖锐冷硬——回归圆润饱满、去锐角 |
| 表情像真人一样收敛 | 表演幅度不足——动画电影的表情必须夸张可读 |
| 画面灰暗压抑 | 整体暗调、重阴影——回归明亮通透、柔和全局光照 |
| 材质塑料死板 | 无SSS、无毛发细节、无布料褶皱——丰富材质是底线 |
