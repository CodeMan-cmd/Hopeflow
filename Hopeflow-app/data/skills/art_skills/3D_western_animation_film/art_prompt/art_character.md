# 人物基础形象生成 · 约束手册（欧美3D动画电影）

---

## 一、角色设计原则

> 欧美3D动画电影角色的起点是"设计一个让观众想拥抱的角色"，不是"复刻一个真人"。造型服务于亲和力与表现力——圆润是第一原则，夸张是第二原则。

1. **圆润即亲和** — 角色轮廓去锐角、去棱角，脸颊饱满圆润、肢体曲线流畅，整体呈现"可以捏一下"的弹性感。禁止尖锐冷硬的造型语言
2. **夸张即表达** — 头身比偏Q（大头小身）、眼睛大而灵动、表情幅度夸张——情绪必须一眼可读，0.5秒内传达给观众
3. **造型即灵魂** — 剪影（Silhouette）必须独特可辨——一个剪影就能认出是谁，这是动画电影角色设计的黄金标准
4. **四视图一致** — 面容/体型/发型/基础服装跨视图高度统一，同一角色在不同角度呈现为同一个"动画角色"
5. **媒介身份恒定** — 一切设计语言服务于"三维动画电影角色"，禁止真人写实、禁止2D平涂

---

## 二、面容约束

> 五官由角色描述（性别/年龄/性格/气质）驱动，但必须落在"动画电影五官"的审美框架内——大眼睛、柔和线条、夸张可读的表情肌理。

### 通用要求

| 项目 | 约束 |
|---|---|
| 五官风格 | 动画电影风格五官——眼型偏大偏圆、线条圆润柔和、允许适度夸张（大眼/圆鼻头/夸张嘴型），禁止写实解剖比例 |
| 眼睛 | 灵动的眼眸——瞳孔大而有神、虹膜色彩清晰、眼中有高光点（catchlight），是角色情绪的第一载体 |
| 表情肌理 | 眉毛/嘴角/脸颊具备夸张形变的表演能力——可大幅上扬、下垂、鼓起，但整体保持可爱友好基调 |
| 风格底色 | 欧美3D动画电影渲染、高精度建模、SSS皮肤、柔和全局光照 |
| 气质 | 必须从角色描述提炼气质关键词（如机灵勇敢/憨厚忠诚/傲娇女王），并写入提示词 |
| 表情 | 中性微表情，符合角色气质，带一丝动画角色的"生动感" |

## 三、肤感约束

> 动画电影皮肤是"通透的卡通皮肤"——SSS散射让皮肤呈现温暖的血色感，但不是真人毛孔写实。

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 肤色 | 暖调白皙基底，通透有血色 | 暖调白皙皮肤、通透有血色、动画电影肤色 |
| 光泽 | SSS次表面散射、柔滑自然光泽 | 次表面散射SSS、柔滑通透光泽、非哑光 |
| 质感 | 卡通化柔滑皮肤——细腻无毛孔、边缘柔和 | 高精度建模、卡通化柔滑皮肤、无写实毛孔 |
| 细节 | 脸颊自然红晕（C2樱桃红）、关节处柔和过渡 | 脸颊自然红晕、皮肤通透光感 |

### 男性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 肤色 | 健康暖调基底，可略深于女性 | 健康暖调肤色、通透有血色、动画电影肤色 |
| 光泽 | SSS次表面散射、自然光泽 | 次表面散射SSS、自然柔和光泽 |
| 质感 | 卡通化柔滑皮肤，下颌可带夸张轮廓 | 高精度建模、卡通化柔滑皮肤、柔和边缘 |
| 细节 | 可有轻微夸张的胡茬纹理（材质化） | 卡通化胡茬细节、材质层次丰富 |

## 四、体型约束

> 动画电影体型的核心是"比例夸张但结构可信"——Q版头身比、圆润的肢体曲线、弹性感。

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 头身比 | 3.5-4.5 头身（Q版/偏Q），或按角色设定 | 4 heads tall proportion、圆润Q版比例 |
| 身体曲线 | 圆润饱满的线条——脸圆、手圆、脚圆 | 圆润饱满的动画体型、柔和的肢体曲线 |
| 手部 | 圆润短小的手指，指节柔和 | 圆润短指、柔和指节、动画造型手 |
| 体态 | 弹性活泼的动画体态，重心动态 | 弹性生动的动画体态、动态重心 |

### 男性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 头身比 | 4-5 头身（偏Q），或按角色设定 | 4.5 heads tall proportion、圆润Q版比例 |
| 身体曲线 | 圆润但不失力量感——宽肩圆肚、肢体粗圆 | 圆润饱满的动画体型、柔和而有力量的曲线 |
| 手部 | 圆润粗短的手指，握拳有力 | 圆润短指、有力握拳、动画造型手 |
| 体态 | 憨厚或机灵的动画体态，动作幅度大 | 弹性生动的动画体态、夸张表演倾向 |

## 五、发型约束

> 动画电影发型是"造型化的头发"——发丝逐缕可见（物理毛发），蓬松有层次，可夸张但可辨识。

### 女性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 焦糖棕（C4）/金棕/深棕，允许红棕/浅金等角色化发色 | {发色}、动画电影角色发色 |
| 发长 | 按角色设定：齐耳短发/锁骨发/中长发/长发/夸张长辫 | {发长}、造型化发型 |
| 发质 | 物理毛发渲染——发丝逐缕可见、蓬松有层次、有绒毛碎发 | 物理毛发渲染、发丝逐缕、蓬松层次 |
| 造型 | 自然散发，可带夸张发饰感（动画角色常有标志性发型） | 自然散发、标志性动画发型 |

### 男性

| 项目 | 约束 | 提示词 |
|---|---|---|
| 发色 | 焦糖棕（C4）/黑棕/金棕，允许银白/红棕等角色化发色 | {发色}、动画电影角色发色 |
| 发长 | 按角色设定：寸头/利落短发/碎发/中长发/夸张发型 | {发长}、造型化发型 |
| 发质 | 物理毛发渲染——发丝蓬松、有自然走向、发旋可见 | 物理毛发渲染、发丝蓬松、自然走向 |
| 造型 | 自然发型，可带夸张的动画式定型（如冲天发梢） | 自然发型、标志性动画发型 |

## 六、基础服装约束

> 基础服装为安全打底——造型简洁、色彩明快、贴合动画角色剪影，正式服装在角色衍生环节叠加。

- 女性：素色圆领上衣 + 基础短裤/长裤，色彩取 C8 奶油白/C9 珊瑚橙/C3 晴朗蓝等明快色
- 男性：素色基础上衣 + 基础长裤，色彩取 C8 奶油白/C5 柠檬黄/C10 靛青蓝等明快色
- 面料有动画化的柔和褶皱与垂坠，纹理清晰可辨，无品牌标识、无大面积印花

## 七、四视图设定图规范

| 位置 | 视图 | 角度 | 景别 | 要求 |
|---|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 头顶至锁骨 | 面部占60%+，眼睛高光、表情肌理、SSS肤感清晰可见 |
| 左二 | 正视图 | 正面0° | 全身立像 | 面对镜头、双臂自然、头顶到脚底完整展示 |
| 右二 | 侧视图 | 右侧90° | 全身立像 | 纯侧面轮廓、圆润剪影、头顶到脚底完整展示 |
| 右一 | 后视图 | 后方180° | 全身立像 | 后脑发型、背部、发尾清晰，头顶到脚底完整展示 |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图，间距均匀 |
| 背景 | 素灰纯色 #B8B8B8，无场景无光斑 |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂，带动画角色的生动感 |
| 光线 | 均匀柔光：前方柔光箱主光 + 双侧补光，柔和全局光照，无硬阴影 |
| 一致性 | 四视图的肤色/体型/发型/面容/基础服装完全一致 |
| 画面比例 | 建议 4:1 或 3:1 |

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须为「中性微表情」+ 动画角色生动感，禁止写实表情 |
| R2 | 必须声明基础服装（明快色、无印花），禁止直接出现复杂服装 |
| R3 | 必须声明「无发饰、无配饰」 |
| R4 | 必须指定「素灰纯色背景 #B8B8B8」 |
| R5 | 必须指定「四视图一致性」 |
| R6 | 全身立像必须从头到脚完整展示，严禁裁切 |
| R7 | 必须声明「欧美3D动画电影 + 次表面散射SSS + 圆润饱满造型」锚定词 |
| R8 | 人像特写必须从头顶到锁骨完整展示，严禁裁切头顶 |

| 编号 | 严禁 |
|---|---|
| X1 | 基础服装以外的任何服装/配饰/妆容 |

| X3 | 锐利棱角造型/冷硬线条——必须圆润饱满 |
| X4 | 低多边形/粗糙建模/模糊贴图 |

| X8 | 复杂场景背景（必须纯色） |
