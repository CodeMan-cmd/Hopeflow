# 光影与氛围 · 约束手册（欧美3D动画电影）

> 欧美3D动画电影的光是"温柔的舞台光"——柔和全局光照（GI）铺底、三点布光塑造角色、高光柔和滚落、阴影软而有层次。光永远站在希望一边，即使夜晚也保持可见度与温暖。

---

## 一、光影基调

1. **柔和全局光照（GI）** — 光线在场景中自然反弹漫射，阴影软而有层次、无死黑死角——动画电影光影的第一基底
2. **三点布光** — 角色与主体采用主光+补光+轮廓光的三点布光，立体感清晰、轮廓分明、情绪可读
3. **明亮通透** — 整体曝光明亮、色彩饱和，拒绝灰暗压抑与高对比暗调
4. **高光柔和** — 高光柔和滚落（soft roll-off），不过曝死白；暗部有层次不死黑
5. **温暖取向** — 光色以暖调为主轴（C5柠檬黄/C9珊瑚橙/C8奶油白），冷调用于背景与夜晚点缀

---

## 二、光源方案

| 编号 | 光源类型 | 作用 | 提示词 |
|---|---|---|---|
| L1 | 主光（Key Light） | 奠定明暗基调，柔和暖光为主 | soft warm key light、暖调主光 |
| L2 | 补光（Fill Light） | 填充暗部、降低光比、柔化阴影 | gentle fill light、柔和补光 |
| L3 | 轮廓光（Rim Light） | 勾勒角色轮廓与毛发边缘，增强立体 | warm rim light、暖色轮廓光 |
| L4 | 环境光（Ambient/GI） | 全局光照反弹，场景明亮通透 | soft global illumination、柔和全局光照 |
| L5 | 光斑光（Dappled） | 树冠/窗棂投下的柔和光斑 | soft dappled light、柔和光斑 |
| L6 | 魔法光（Magic） | 奇幻道具/魔法场景的柔和光效 | soft magic glow、柔和魔法光晕 |
| L7 | 冷调点缀（Cool Accent） | 夜晚月光、冷调背景点缀 | cool moonlight accent、冷月点缀 |

---

## 三、光比与明暗对比

| 参数 | 约束值 | 说明 |
|---|---|---|
| 光比 | 主光:补光 ≈ 2:1 ~ 3:1 | 柔和过渡，禁止高反差硬光 |
| 明暗对比 | 中等偏亮 | 明暗层次清晰但整体明亮通透 |
| 阴影 | 柔和阴影（soft shadow） | 边缘过渡自然，禁重阴影/死黑 |
| 高光 | 柔和滚落的高光 | 皮肤/毛发/金属反光处提亮，不过曝 |
| 暗部 | 有层次不死黑 | 夜晚场景保留物体轮廓可见度 |

---

## 四、色温范围

| 参数 | 值 | 说明 |
|---|---|---|
| 整体色温 | 偏暖 4800-5500K（推荐） | 明亮温暖主基调 |
| 肤色色温 | 微暖 5000-5400K（推荐） | C1 暖肤橙有血色通透感 |
| 夜景色温 | 冷调打底 5500-6500K + 暖灯点缀 | 月光冷调 + 暖色灯光，宁静温暖 |

---

## 五、色调情绪与画面关键词

| 情绪场景 | 主色 | 辅色 | 氛围关键词 |
|---|---|---|---|
| 日常温馨 | C8 奶油白 | C5 柠檬黄 + C9 珊瑚橙 | 温暖、治愈、平静、柔和全局光 |
| 欢乐庆典 | C5 柠檬黄 | C2 樱桃红 + C9 珊瑚橙 | 热闹、欢快、高亮、色彩饱满 |
| 冒险旅途 | C3 晴朗蓝 | C6 薄荷绿 + C10 靛青蓝 | 开阔、自由、通透天光 |
| 童话梦幻 | C7 薰衣草紫 | C2 樱桃红 + C5 柠檬黄 | 奇幻、浪漫、柔和魔法光晕 |
| 温馨夜晚 | C10 靛青蓝 | C5 柠檬黄 + C8 奶油白 | 宁静、温馨、暖灯点缀 |
| 离别感伤 | C10 靛青蓝 | C3 晴朗蓝 + C5 柠檬黄点缀 | 不舍、克制、冷底暖点 |

## 六、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「柔和全局光照（GI）+ 三点布光」 |
| R2 | 必须包含「明亮通透、色彩饱和」氛围锚定词 |
| R3 | 必须声明「阴影软而有层次、高光柔和滚落、暗部不死黑」 |
| R4 | 每镜头至少指定 1 个情绪场景并绑定主色+辅色 |
| R5 | 光源方案至少声明主光+补光，可叠加轮廓光/环境光 |

---

## 七、严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 真人实拍/照片写实打光（真实电影摄影布光） |
| X2 | 灰暗压抑/重阴影/高对比暗调/死黑死白 |
| X3 | 高饱和荧光色/霓虹溢色光效 |
| X4 | 正顶硬光/正底光/恐怖光源/彩色光污染 |
| X5 | 恐怖/惊悚/哥特的阴森光效 |
| X6 | 无光源逻辑、光照方向混乱、全局均匀亮 |
