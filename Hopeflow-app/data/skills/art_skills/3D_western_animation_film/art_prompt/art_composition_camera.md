# 构图与镜头 · 约束手册（欧美3D动画电影）

> 欧美3D动画电影的镜头是"虚拟摄影机"——它不需要物理实拍的限制，但必须遵循动画电影的语言：景别服务于表演、运镜服务于情绪、构图服务于故事。镜头风格在"戏剧化"与"亲和感"之间取得平衡。

---

## 一、景别体系

| 景别 | 叙事功能 | 欧美3D动画电影特征 |
|---|---|---|
| 大特写 | 情绪爆发点、关键表情 | 大眼睛的瞳孔特写、夸张表情的形变细节、情绪峰值 |
| 近景 | 情感凝视、表演细节 | 面部夸张表情、眉眼神态、嘴巴形变 |
| 中近景 | 互动与对话 | 腰部以上，夸张手势与表情同框 |
| 中景 | 人物关系、动作叙事 | 全身入画，弹性动作与角色关系共存 |
| 全景 | 环境氛围、角色与空间关系 | 童话场景全貌、角色在场景中的位置 |
| 空镜 | 情绪缓冲、世界观展示 | 无人物，场景本身的童话感与氛围 |

---

## 二、镜头焦段（虚拟摄影机性格）

| 焦段 | 叙事性格 | 典型应用 |
|---|---|---|
| 24-28mm 广角 | 环境的辽阔与童话感、角色与环境的关系 | 小镇全貌、森林纵深、宏大场景 |
| 35mm 小广角 | 主观视点、身临其境 | 角色行走跟随、室内对话 |
| 50mm 标准 | 客观注视、角色表演的忠实记录 | 动画表演展示、双人对话 |
| 85mm 中长焦 | 压缩空间、拉近情感、背景虚化 | 角色特写、情感凝视、夸张表情捕捉 |
| 135mm+ 长焦 | 极端压缩、窥视感 | 远处的秘密、童话世界的细节发现 |

---

## 三、机位与运动（动画虚拟摄影机语法）

| 手法 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定机位 | 冷静、让表演自己说话 | 对话、表情表演展示 |
| 缓推 | 注意力聚焦、情绪趋近 | 情绪升温、真相逼近、魔法时刻 |
| 缓拉 | 拉开距离、揭示全貌 | 场景建立、离别、章节收束 |
| 环绕 | 360度展示角色/场景、戏剧感 | 角色登场、重要道具展示、情感高点 |
| 跟拍 | 与角色同行、冒险陪伴 | 行走跟随、追逐、探索 |
| 升降 | 揭示空间关系、宏观视角 | 童话世界俯瞰、场景宏伟感 |
| 手持微晃 | 紧张/动感/纪实感（克制使用） | 追逐、打闹、高能段落 |

---

## 四、构图法则

| 法则 | 应用 |
|---|---|
| 三分法 | 角色置于交点，场景留白展示童话氛围 |
| 框架构图 | 圆窗/拱门/树枝/花丛套住角色——童话感画框 |
| 引导线 | 弯曲小路、旋转楼梯、河流延伸牵引视线 |
| 前景遮挡 | 圆润前景（花朵/玩具/建筑边缘）增加纵深与趣味 |
| 对称构图 | 童话建筑的对称美学、庄重与稳定 |
| 斜角构图 | 追逐/混乱段落的动感倾斜 |

---

## 五、镜头语言

- 推：从场景全貌推入角色近景，情绪放大
- 拉：角色转身汇入场景，镜头拉开留白
- 环绕：角色发现魔法时刻，镜头半环绕表达惊叹
- 焦点偏移：前景虚化→角色清晰，叙事重心转移
- 低角度仰拍：英雄登场、角色的力量感与崇高感
- 高角度俯拍：角色渺小感、命运的注视（童话式）

## 七、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「欧美3D动画电影 + 虚拟摄影机」锚定，非真人实拍 |
| R2 | 必须声明景别+焦段+机位手法三要素 |
| R3 | 运镜必须服务于表演与情绪，禁止无叙事目的的花哨运镜 |
| R4 | 构图必须遵循动画电影法则（框架/引导线/前景遮挡等） |
| R5 | 景深必须有叙事意图，焦点偏移引导注意力 |
| R6 | 高光不过曝、暗部不死黑，明亮通透 |

---
