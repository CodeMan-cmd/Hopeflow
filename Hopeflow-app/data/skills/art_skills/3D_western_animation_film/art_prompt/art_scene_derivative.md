# 场景衍生资产生成 · 约束手册（欧美3D动画电影）

---

## 一、衍生原则

> 欧美3D动画电影的场景衍生是"同一个动画场景，在不同焦段、不同时段、不同天气、不同剧情氛围下再次被渲染"——空间结构锚定不变，变化的是观看方式与情绪。

1. **空间锚定** — 同一场景的核心空间结构在所有变体中必须可辨认。换了角度、变了光线、变了天气——但一看就知道"还是那个地方"
2. **焦段叙事** — 同一场景用不同焦段呈现，说出不同的事。广角说"这个世界的辽阔与童话感"，中焦说"看看这个角落"，长焦说"远处有什么秘密"
3. **时段即情绪** — 晨光的小镇和黄昏的小镇是同一个空间、两种情绪。时段变了、光变了，场景的叙事功能也变了
4. **天气即故事** — 同一条街，晴天是日常，雨天是浪漫或忧郁，雪天是童话。天气变化必须是真实的光学与环境变化，不是换天空贴图
5. **单视图全景** — 每一个衍生变体都是一张独立的单张全景画面，与原场景设定图同空间、同风格

## 二、焦段与构图变体——同一个空间的不同目光

| 变体 | 焦段 | 范围 | 叙事功能 | 提示词 |
|---|---|---|---|---|
| 广角全貌 | 24-28mm | 场景全貌+周边环境 | 建立空间定位、呈现童话世界的辽阔 | 广角全貌、完整空间+环境关系、大场面童话感 |
| 标准全景 | 35mm | 场景完整呈现 | 客观呈现这个空间的完整面貌 | 标准全景、场景的完整面貌、中性视角 |
| 中景聚焦 | 50mm | 核心功能区/最具辨识度的局部 | 聚焦空间的"心脏"——小镇广场、城堡大门、森林空地 | 中景聚焦、空间的核心叙事区域 |
| 近景细节 | 85mm | 空间中的一处局部 | 一扇圆窗、一盏暖灯、一座喷泉——视线引向叙事细节 | 近景细节、圆润局部、浅景深突出主体 |

### 焦段衍生规则

| 从广角全貌衍生 | 保持不变 | 变化项 |
|---|---|---|
| 广角→标准全景 | 空间结构、光源逻辑、色彩方案 | 焦段收窄至35mm、画面范围缩小但不改变空间 |
| 标准全景→中景聚焦 | 材质质感、光线方向、色调 | 焦段收窄至50mm、聚焦核心区域、景深适度变浅 |
| 中景→近景细节 | 材质纹理、光线方向、色彩 | 焦段85mm、极浅景深、背景自然虚化 |

## 三、时段变体——时间给空间的妆容

| 时段 | 光的配方 | 空间的情绪变化 | 提示词 |
|---|---|---|---|
| 清晨 | 低角度暖白晨光、薄雾漫射、空间微凉 | 静谧、蓄势、童话世界刚醒来 | 清晨场景、低角度晨光、薄雾漫射、世界苏醒的安静 |
| 上午 | 日光升高、通透明亮、色彩饱和 | 秩序的建立——童话世界的"默认"状态 | 上午日光、空间明亮通透、色彩鲜明 |
| 正午 | 顶光、阴影短、阳光最盛 | 活力顶点——最明亮的时刻 | 正午阳光、空间全亮、阴影短而柔和 |
| 午后 | 日光偏西、暖调渐强、斜光长影 | 慵懒温暖——一天中最长的那段 | 午后斜光、长阴影、暖调渐强 |
| 金色时刻 | 极暖低角度金橙光、长影、一切镀金边 | 珍惜——一天中最珍贵的温暖 | 金色时刻、暖金斜光、所有表面镀金边 |
| 夜晚 | 月光+暖色灯光（灯笼/路灯/窗灯） | 宁静温馨——暖光点缀、童话夜 | 夜晚场景、月光冷调+暖灯点缀、宁静温馨 |
| 奇幻夜 | 月光+魔法光效（柔和光斑） | 神秘但明亮的奇幻感 | 奇幻夜晚、柔和魔法光斑、神秘不阴森 |

### 时段衍生规则

| 从基准时段衍生 | 保持不变 | 变化项 |
|---|---|---|
| 日间→金色时刻 | 空间结构、建筑外观、色彩方案 | 光源色温暖化、阴影拉长、亮面镀金调、灯光逐步点亮 |
| 日间→夜晚 | 空间结构、建筑外观、色彩方案 | 整体曝光降低、暖色灯光全亮、月光冷调打底 |
| 日间→奇幻夜 | 空间结构、建筑外观 | 魔法光效出现、薰衣草紫/柠檬黄光斑点缀 |

## 四、天候变体——天气给空间的情绪

| 天候 | 空间变化 | 情绪 | 提示词 |
|---|---|---|---|
| 晴天 | 光影锐利、材质清晰、色彩饱和 | 日常、明亮、开放 | 晴天场景、阳光充沛、色彩饱和 |
| 多云/阴 | 柔光无硬影、色彩稍柔、光线均匀 | 克制、平静 | 阴天柔光、色彩柔和、光线均匀漫射 |
| 薄雾 | 远景虚化、空气有湿度、光晕柔和 | 朦胧、诗意、童话的神秘 | 薄雾场景、远景渐隐、柔和光晕 |
| 小雨 | 雨丝可见、地面反光、玻璃雨痕 | 浪漫、清新、忧郁 | 细雨场景、雨丝、地面柔和反光 |
| 雨后 | 万物湿润、反光清晰、空气清透 | 新生、清透、希望 | 雨后场景、湿润反光、空气清透 |
| 小雪 | 雪花飘落、薄白覆盖、暖光透过雪幕 | 静谧、温柔、童话 | 小雪场景、飘雪、薄白、暖光透过雪幕 |
| 大雪 | 积雪覆盖、世界简化成白色 | 童话、孤寂或浪漫 | 大雪场景、积雪覆盖、世界被白色简化 |

### 天候衍生规则

| 从晴天衍生 | 保持不变 | 变化项 |
|---|---|---|
| 晴→薄雾 | 空间结构、建筑外观 | 增加雾气分层、远景虚化、饱和度略降、光源产生柔和光晕 |
| 晴→小雨 | 空间结构、建筑外观 | 增加雨丝、玻璃雨痕、地面湿润反光、色调微冷 |
| 晴→雪 | 空间结构、建筑外观 | 增加飘雪/积雪、色调偏冷白、暖光源对比提升 |

## 五、单视图规范——所有衍生变体共享

| 项目 | 要求 |
|---|---|
| 空间结构 | 与原场景设定图**同一空间**——建筑/结构/布局原则上不变 |
| 焦段 | 按变体类型使用 24mm/35mm/50mm/85mm |
| 景深 | 广角→全景深；中景→适度浅景深；近景→浅景深 |
| 光源 | 时段对应太阳高度与色温、天气对应大气散射、室内对应窗光与灯光 |
| 色彩 | 明亮饱和、通透干净，由核心色盘驱动 |
| 人物 | **所有变体严禁出现任何人物、人影、人体轮廓** |
| 画面比例 | 16:9 或 3:2，与原场景设定图一致 |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景空间结构在所有衍生变体中必须保持可辨认——同一个地方，不能变成另一个地方 |
| R2 | 时段变体的光源必须符合物理逻辑——太阳高度角决定色温与阴影长度 |
| R3 | 天候变体必须同步适配材质表面的真实变化——雨痕/积水/积雪/雾层 |
| R4 | 必须是「单张全景」——单视图、非2×2四视图、非多角度 |
| R5 | 必须保持「明亮通透、色彩饱和」的风格底线 |
| R6 | **所有变体严禁出现任何人物、人影、人体轮廓** |
| R7 | 必须声明「欧美3D动画电影 + 非真人非实拍」核心锚定 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁空间结构发生不可辨认的改变——换时段/天气/焦段不能"换了地方" |
| X2 | 严禁「真人实拍 / 照片写实 / 真实天气摄影」 |
| X3 | 严禁「低多边形 / 粗糙建模 / 模糊贴图」 |
| X4 | 严禁「2D手绘 / 赛璐璐 / 日式二次元」 |
| X5 | 严禁「灰暗压抑 / 恐怖 / 惊悚 / 哥特」 |
| X6 | 严禁「天空贴图替换式换天 / PS合成感」——天气变化必须是真实的光学变化 |
| X7 | 严禁「出现人物 / 人影 / 人体轮廓 / 剪影」 |
| X8 | 严禁「高饱和荧光色 / 霓虹溢色 / 色彩污染」 |
| X9 | 严禁「水印 / 文字 / LOGO / 签名 / 边框」 |
