# 场景图像生成 · 约束手册（欧美3D动画电影）

---

## 一、场景美学原则

> 欧美3D动画电影的场景是"会讲童话的空间"——明亮通透、色彩饱和、建筑比例夸张有趣、材质丰富清晰。场景不是背景板，而是世界观本身。

1. **明亮童话感** — 场景整体明亮通透，拒绝灰暗压抑。即使是夜晚场景也保持可见度与柔和层次——黑暗是暂时的，色彩永远站在希望一边
2. **夸张建筑比例** — 建筑与空间结构允许夸张变形——胖乎乎的屋顶、高得离谱的塔楼、弯弯曲曲的小巷、巨大的门与小小的窗——比例夸张是童话感的来源
3. **色彩即情绪** — 场景色彩明亮饱和、冷暖互补，情绪通过色彩直接传达——温暖小镇是奶油白+珊瑚橙、奇幻森林是薄荷绿+薰衣草紫
4. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平。前景形成画框感、中景是空间主体、后景向纵深延伸
5. **单视图全景全貌** — 一张画面装下整个场地的完整信息，不是四视图分割、不是多角度拼贴

| 维度 | 约束 | 提示词 |

## 四、空间层次规范

| 项目 | 要求 |
|---|---|
| 空间呈现 | 单张画面完整呈现场景全貌——广度、深度、高度在一张画面中全部可见 |
| 构图 | 前景（门框/树枝/建筑边缘/花丛）形成画框 → 中景是场地主体 → 后景向纵深/天空延伸 |
| 景深 | 全景深 f/8-f/11 或浅景深 f/2.8-f/4（按叙事选择），前中后景层次清晰 |
| 人物 | **严禁出现任何人物、人影、人体轮廓**（场景独立资产） |
| 比例 | 建议 16:9 或 3:2 宽幅 |
| 色彩 | 明亮饱和、通透干净，由核心色盘驱动 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单张全景」——单视图、非2×2四视图、非多角度、非turnaround |
| R2 | 场景必须「明亮通透、色彩饱和」，拒绝灰暗压抑 |
| R3 | 建筑与空间允许「夸张比例/圆润变形」，童话感优先 |
| R4 | 场景必须有前/中/后景空间层次 |
| R5 | 材质必须「纹理清晰、层次丰富」 |
| R6 | **严禁出现任何人物、人影、人体轮廓** |
| R7 | 必须声明「欧美3D动画电影 + 非真人非实拍」核心锚定 |
| R8 | 必须声明「柔和全局光照 + 高精度建模」画质锚定 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「真人实拍 / 照片写实 / 真实建筑摄影」 |
| X2 | 严禁「低多边形 / 粗糙建模 / 模糊贴图 / 塑料死板」 |
| X3 | 严禁「2D手绘 / 赛璐璐 / 日式二次元 / 厚涂」 |
| X4 | 严禁「灰暗压抑 / 恐怖 / 惊悚 / 哥特 / 血腥」 |
| X5 | 严禁「锐利冷硬 / 工业粗野主义 / 尖刺建筑」 |
| X6 | 严禁「高饱和荧光色 / 霓虹溢色 / 色彩污染」 |
| X7 | 严禁「出现人物 / 人影 / 人体轮廓 / 剪影」 |
| X8 | 严禁「四视图 / 2×2网格 / 多角度 / turnaround」——仅单张 |
| X9 | 严禁「过曝死白 / 死黑无层次 / 画面扁平」 |
| X10 | 严禁「水印 / 文字 / LOGO / 签名 / 边框」 |
