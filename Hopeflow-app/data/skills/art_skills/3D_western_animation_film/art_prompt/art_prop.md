# 道具图像生成 · 约束手册（欧美3D动画电影）

---

## 一、道具设计原则

> 欧美3D动画电影的道具是"有表情的器物"——圆润的轮廓、丰富的材质、玩具般的亲和力，每一件道具都像随时会动起来。

1. **玩具感优先** — 动画电影道具普遍带有"玩具/手办"般的质感——圆润饱满的轮廓、友好的比例、仿佛可以捧在手里的尺寸感。禁止工业冷硬的锐利器物
2. **圆润即语言** — 一切道具轮廓去锐角：杯柄是圆润的、边角是弧形的、机械结构也做圆角处理——圆润是动画世界观的一部分
3. **材质即层次** — 道具材质必须丰富可辨：木纹、金属高光、玻璃透光、布料纹理、皮革光泽——材质层次是动画电影道具的"高级感"来源
4. **叙事即功能** — 道具是角色性格与剧情的延伸——一个角色常用的道具必须暗示其身份与故事
5. **单视图产品展示** — 道具以单张静物展示方式独立呈现，非多角度建模展示，非2×2四宫格

## 三、单视图静物展示规范

| 项目 | 要求 |
|---|---|
| 道具呈现 | 道具居中或偏三分线独立陈列，完整入画，无裁切 |
| 背景 | 素灰纯色 #B8B8B8（哑光），或纯色展示台（奶油白/薄荷绿），无多余物体 |
| 光线 | 柔和全局光照：柔光箱主光 + 双侧补光，柔和阴影，无硬光 |
| 景深 | 浅景深 f/2.8-f/4，道具清晰锐利，前后微虚化突出主体 |
| 投影 | 道具与展示台之间的柔和接触阴影，方向与主光源一致 |
| 画面比例 | 建议 1:1 正方形或 4:3 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须是「单件静物展示」——单视图、非多角度、非2×2四宫格 |
| R2 | 必须指定「素灰纯色背景 #B8B8B8」或纯色展示台，禁止复杂场景 |
| R3 | 必须指定光源逻辑——柔和全局光照，光影方向明确、投影自然 |
| R4 | 道具造型必须「圆润饱满、去锐角、玩具般亲和」 |
| R5 | 材质必须「层次丰富可辨」——木纹/金属/玻璃/布料/皮革 |
| R6 | 必须声明「欧美3D动画电影 + 非真人非实拍」核心锚定 |
| R7 | 必须声明「高精度建模 + 柔和全局光照」画质锚定 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「真人实拍 / 照片写实 / 写实道具摄影」 |
| X2 | 严禁「低多边形 / 粗糙建模 / 模糊贴图 / 塑料死板无光影」 |
| X3 | 严禁「2D手绘 / 赛璐璐 / 日式二次元 / 厚涂」 |
| X4 | 严禁「锐利棱角 / 工业冷硬 / 尖刺危险造型」 |
| X5 | 严禁「恐怖 / 惊悚 / 血腥 / 暗黑哥特」 |
| X6 | 严禁「高饱和荧光色 / 霓虹溢色 / 过曝光污染」 |
| X7 | 严禁「多角度 / 四视图 / 2×2网格 / turnaround」——仅单张 |
| X8 | 严禁「出现人物 / 手部 / 手指 / 肢体」 |
| X9 | 严禁「悬浮 / 抠图白底 / 无投影 / 无承载面」 |
| X10 | 严禁「水印 / 文字 / LOGO / 签名 / 边框」 |
