# 材质与质感 · 约束手册（欧美3D动画电影）

> 欧美3D动画电影的质感来自"动画材质的丰富度"——次表面散射（SSS）让皮肤通透有血色、物理毛发让发丝逐缕可见、布料模拟让褶皱自然垂坠。材质是"丰富"而非"写实"——它服务于触感与共情。

---

## 一、材质质感描述（以动画渲染语言说话）

| 质感域 | 动画渲染表达 | 禁止的写实/劣质表达 |
|---|---|---|
| 皮肤 | 次表面散射（SSS）、通透有血色、柔滑卡通肤质 | 写实毛孔、真人皮肤、塑料死白 |
| 毛发 | 物理毛发逐缕可见、蓬松有层次、绒毛碎发 | 塑料发块、无层次贴图、假发感 |
| 布料 | 物理布料模拟、褶皱自然、垂坠柔和、纹理清晰 | 无缝贴图、僵硬平板、样板衣 |
| 材质 | 木纹/金属/玻璃/皮革层次丰富 | 模糊贴图、塑料死板、无光影 |
| 光影 | 柔和全局光照、阴影软而有层次 | 无光影、平光死白、死黑 |

---

## 二、材质锚词清单（可直接注入提示词）

| 材质 | 中文锚词 | 英文锚词 |
|---|---|---|
| 皮肤 | 次表面散射SSS、通透血色、卡通柔滑 | subsurface scattering, soft translucent skin |
| 毛发 | 物理毛发、发丝逐缕、蓬松层次 | physical hair, strand-by-strand, fluffy layers |
| 布料 | 物理布料、自然褶皱、柔和垂坠 | cloth simulation, natural wrinkles, soft drape |
| 毛绒 | 蓬松绒毛、柔软层次、可触摸感 | fluffy fur, soft pile, touchable |
| 木 | 抛光木纹、柔和反光、圆角处理 | polished wood grain, soft reflection |
| 金属 | 暖调光泽、圆润倒角、柔和反射 | warm metal sheen, rounded bevel |
| 玻璃/水晶 | 通透折射、圆润边缘、柔和光斑 | clear refraction, rounded edges |
| 皮革 | 温润光泽、缝线细节、圆润包角 | leather sheen, stitching detail |
| 石头/宝石 | 通透有色、圆润切面、内部光感 | gem translucency, inner glow |

## 三、画质硬约束

| 编号 | 约束 |
|---|---|
| H1 | 皮肤必须声明「次表面散射SSS + 卡通柔滑肤质」，禁写实毛孔/塑料死白 |
| H2 | 毛发必须声明「物理毛发 + 发丝逐缕 + 蓬松层次」，禁塑料发块 |
| H3 | 布料必须声明「物理布料模拟 + 自然褶皱」，禁无缝贴图/样板感 |
| H4 | 材质必须「层次丰富可辨」——至少两种以上材质对比 |
| H5 | 光影必须声明「柔和全局光照 + 高光柔和滚落 + 暗部有层次」 |

---

## 四、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「欧美3D动画电影 + 高精度建模」锚定词 |
| R2 | 材质描述必须用动画渲染语言（SSS/物理毛发/布料模拟），禁止写实摄影词汇 |
| R3 | 材质服务于"触感与共情"——让观众"想摸一下" |
| R4 | 每镜头至少指定 1-2 种核心材质的细节描述 |
| R5 | 禁止"为写实而写实"——丰富但不真实化 |

---

## 五、严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 真人皮肤/写实毛孔/照片级皮肤质感（photorealistic skin） |
| X2 | 塑料死白/无SSS的假皮肤、僵硬发块/无层次毛发 |
| X3 | 低多边形/粗糙建模/模糊贴图/劣质UV |
| X4 | 无缝贴图/样板衣/无褶皱布料 |
| X5 | 2D平涂/赛璐璐/手绘材质（非3D材质语言） |
| X6 | 无光影细节/平光死白/死黑无层次 |
