# 角色衍生资产生成 · 约束手册（欧美3D动画电影）

---

## 一、造型逻辑——给动画角色做造型

> 欧美3D动画电影的衍生造型不是在真人脸上化妆，而是给动画角色"换皮肤、换服装、换造型层"——每一层都必须保持动画角色的圆润语言与夸张表演力。

1. **底模恒定** — 面容、体型、头身比是角色识别的核心锚点，任何造型衍生不得改变底模的结构与比例
2. **造型强化气质** — 服装是角色的第二层性格——一个角色的穿搭必须强化其剪影辨识度与性格标签，而非单纯装饰
3. **材质丰富** — 动画电影服装的材质必须有物理质感——毛呢的绒感、皮革的光泽、针织的线圈纹理——丰富材质是动画电影的基本功
4. **色彩明快** — 衍生服装取色遵循核心色盘，明亮饱和、冷暖互补，禁止灰暗浊色
5. **四角度一致** — 同一角色在不同角度的衍生造型必须完全一致，呈现为同一角色的连续造型记录

---

## 二、造型层级

| 层级 | 内容 | 欧美3D动画电影的理解 |
|---|---|---|
| L0 | 底模 | 基础形象底模——素颜、基础发型、基础服装。不修改 |
| L1 | 面部细节 | 动画角色的表情肌理微调、雀斑/腮红等角色化面部细节 |
| L2 | 发型造型 | 发型师式的造型变化——扎束/编发/定型，保持物理毛发质感 |
| L3 | 内搭 | 贴身层——T恤/衬衫/背心/打底衫，替换基础款 |
| L4 | 主服 | 外套/连衣裙/工装/西装/斗篷等，决定整体造型风格 |
| L5 | 配饰 | 帽子/眼镜/围巾/背包/腰带/首饰——角色标签的最后一步 |

> **范畴边界**：仅造型层面（面部细节+发型+服装+配饰）。不包含道具、场景环境、姿态动作。

## 五、造型组合速查

| 场景 | 发型 | 服装风格 | 配饰 |
|---|---|---|---|
| 日常居家 | 自然散发/随意扎起 | 软萌居家 | 无或极简 |
| 上学/工作 | 利落垂发/碎发 | 学院少女/科学家 | 眼镜+背包 |
| 冒险外出 | 高马尾/束发 | 冒险女孩/冒险向导 | 背包+帽饰 |
| 庆典派对 | 精致卷发/定型 | 童话公主/优雅绅士 | 首饰+精致配饰 |
| 运动场合 | 丸子头/运动束发 | 运动少年/邻家少女 | 发带 |

> **未覆盖场景推断规则**：先判断场景性质（日常→简洁造型、重要场合→精致造型）；再判断角色气质（活泼→明快色、沉稳→深色系）；最后判断叙事功能（造型必须服务角色性格表达）。

## 六、人物肖像系列——四角度规范

| 位置 | 角度 | 景别 | 摄影要求 |
|---|---|---|---|
| 左一 | 正面近景 | 头顶至锁骨 | 面部60%+，SSS肤感、表情肌理、眼睛高光清晰可见 |
| 左二 | 正面0° | 全身 | 穿搭全貌、服装垂坠与层次、配饰完整呈现 |
| 右二 | 右侧90° | 全身 | 侧面轮廓+服装侧面层次、发型侧面状态 |
| 右一 | 后方180° | 全身 | 后脑发型、背部穿搭、背包/帽饰后侧 |

### 画面规范

| 项目 | 要求 |
|---|---|
| 布局 | 同一画面从左至右并排四个角度，间距均匀 |
| 背景 | 素灰纯色 #B8B8B8，无光斑无渐变无投影 |
| 站姿 | 保持底模站姿，带动画角色的生动感，禁止因换装改变体态 |
| 光线 | 前方柔光箱主光 + 双侧补光，柔和全局光照，保留角色立体感 |
| 一致性 | 四角度为同一角色同一次造型的连续记录 |
| 画面比例 | 建议 4:1 或 16:4 |

## 八、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 叠加后面容与体型必须与底模一致——造型服务于角色，不改变识别锚点 |
| R2 | 服装必须取核心色盘明快色，材质有物理纹理（毛呢/皮革/针织/棉质） |
| R3 | 发型必须保持物理毛发质感——发丝逐缕、蓬松层次，非塑料发块 |
| R4 | 配饰必须造型化佩戴且符合角色剪影辨识度 |
| R5 | 必须输出四角度肖像系列（近景特写+正面+侧面+背面全身） |
| R6 | 必须指定「素灰纯色背景 #B8B8B8」，禁止添加场景环境 |
| R7 | 必须指定「四角度为同一角色同一次造型的连续记录」 |
| R8 | **仅输出提示词**——不输出分析过程、方案对比等一切非提示词内容 |
| R9 | **姿态保持不变**——保持底模站姿，不添加动作/体态描述 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁「真人实拍 / 照片写实 / 写实皮肤毛孔 / live-action」 |
| X2 | 严禁「低多边形 / 粗糙建模 / 模糊贴图 / 塑料死板无光影」 |
| X3 | 严禁「2D手绘 / 赛璐璐 / 日式二次元 / 厚涂插画」 |
| X4 | 严禁「锐利棱角 / 冷硬线条 / 尖刺造型」 |
| X5 | 严禁「灰暗浊色 / 高饱和荧光色 / 霓虹溢色」 |
| X6 | 严禁「恐怖谷 / 惊悚 / 血腥 / 暗黑元素」 |
| X7 | 严禁「改变底模面容 / 体型 / 头身比至不可辨认」 |
| X8 | 严禁「道具交互 / 场景环境描述——属于独立资产」 |
| X9 | 严禁「水印 / 文字 / LOGO / 签名 / 边框 / AI生成痕迹」 |
