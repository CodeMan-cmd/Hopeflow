# 道具衍生状态生成 · 约束手册（欧美3D动画电影）

---

## 一、衍生原则

> 欧美3D动画电影的道具衍生不是"材质切换"，而是"同一件动画道具在不同剧情时刻的状态变化"——磨损、破损、魔法激活、岁月旧化，都必须保持道具的圆润造型与动画质感。

1. **造型锚定** — 道具核心造型、轮廓在所有状态中必须可识别。一把被魔法照亮的老钥匙，还是原来那把老钥匙
2. **状态可读** — 新旧、完整/破损、激活/休眠——一眼即可区分。状态差异来自剧情逻辑与物理逻辑
3. **叙事服务** — 道具状态就是一场未拍出的前戏：磨损的剑柄暗示身经百战、碎裂的水晶球暗示一场灾变、蒙尘的怀表暗示封存的时间
4. **动画化处理** — 损伤与旧化以动画电影语言表现——磨损是柔和的圆角磨损、裂纹是卡通化的裂纹，保持"可可爱爱地旧"而非"真实地破败"
5. **单视图静物展示** — 衍生状态仅需一张静物图。与原道具设定图同机位、同光线、同背景——仅状态发生变化

## 二、状态类型

### 2.1 使用-时间状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 崭新 | 刚出厂/刚获得，光亮饱满，无使用痕迹 | 所有道具 | 崭新状态、光泽饱满、无划痕无磨损、出厂品相 |
| 日常使用 | 使用过一段时间——微磨损、触感区包浆、边角圆润微磕碰 | 随身道具/生活道具 | 日常使用痕迹、握持处微包浆、圆润边角微磕碰 |
| 陈旧 | 年代感强——褪色、氧化、包浆厚重、材质老化 | 老怀表/旧地图/祖传器物 | 强烈年代感、自然褪色氧化、厚重包浆、岁月印记 |

### 2.2 损伤状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 微损 | 细微裂纹/浅划痕/局部磨损——不影响主体识别 | 陶瓷杯/玻璃瓶/木盒 | 细微裂纹、浅划痕、圆润缺口、主体完整 |
| 破损 | 明显裂纹/碎裂/局部缺失——结构受损但造型仍可辨认 | 摔裂的杯子/断柄的钥匙 | 卡通化裂纹、碎裂纹路、局部缺口、造型仍可识别 |
| 残片 | 仅剩碎片/核心部分——大面积缺失，保留识别特征 | 碎水晶/半张地图/断裂剑柄 | 残片状态、仅存核心部分、可识别原物轮廓 |

### 2.3 环境痕迹状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 蒙尘 | 放了很久没动——表面薄灰、光泽被灰层柔化 | 阁楼旧物/尘封宝箱 | 表面薄灰覆盖、光泽被柔化、被搁置的痕迹 |
| 淋雨/浸水 | 被雨淋过/泡过水——表面水珠、纸张微皱、金属水渍 | 地图/书/背包 | 表面水珠凝结、纸张浸湿微皱、金属水渍 |
| 魔法侵蚀 | 长期接触魔法能量——柔和光纹、宝石暗淡/明亮 | 魔法书/水晶/法杖 | 柔和魔法光纹、宝石异色、能量残留细节 |

### 2.4 情感-叙事状态

| 状态 | 描述 | 适用道具 | 提示词 |
|---|---|---|---|
| 被珍视 | 反复抚摸把玩——触感区包浆温润、被精心保养 | 怀表/护身符/戒指 | 触感区温润包浆、被精心保养的光泽 |
| 被激活 | 魔法/机械激活状态——柔和光效、部件运转 | 法杖/水晶球/机械装置 | 柔和激活光效、部件发光、能量流转 |
| 被遗弃 | 孤零零的状态——落灰、被遗忘的角落 | 旧玩具/旧信件/旧物 | 落灰的被遗弃感、无人问津的孤寂 |

## 三、单视图展示规范

> 衍生状态仅需单张静物图。同一机位、同一光线、同一背景——仅道具状态变化。

| 项目 | 要求 |
|---|---|
| 背景 | 素灰纯色 #B8B8B8（哑光），或纯色展示台——与原道具设定图完全一致 |
| 光线 | 与原道具设定图完全一致的柔和全局光照。光位、光比、色温不变 |
| 角度 | 与原道具设定图完全一致的机位和角度 |
| 景深 | 浅景深 f/2.8-f/4，与原图一致 |
| 构图 | 道具居中独立陈列，占画面主体70%+，完整入画无裁切 |
| 画面比例 | 1:1 正方形或 4:3，与原图一致 |

## 四、材质状态变化——动画道具的旧化语言

| 材质 | 崭新 → 日常使用 | 日常 → 陈旧 | 损伤表现 |
|---|---|---|---|
| 木 | 抛光鲜亮 → 握持区微包浆 | 色泽暗沉、包浆厚重、边角圆润磨损 | 卡通化裂纹、缺口、剥落 |
| 金属 | 高光明亮 → 微划痕、指纹区包浆 | 氧化暗沉、局部绿锈色点缀 | 凹痕、卡通化断裂 |
| 玻璃/水晶 | 通透无瑕 → 微划痕、边缘圆润磕碰 | 通透度下降、蒙尘 | 卡通化裂裂纹路、崩角 |
| 陶瓷 | 釉面饱满 → 杯口微磨损、釉面柔光 | 釉面暗淡、开片细纹 | 裂纹、圆润缺口 |
| 布料/毛绒 | 鲜亮蓬松 → 微褪色、轻微起球 | 褪色明显、蓬松度下降 | 卡通化撕裂、破洞 |
| 皮革 | 光泽均匀 → 弯折包浆、五金微氧化 | 包浆厚重、色泽暗沉 | 开裂、皮面剥落 |

## 六、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 道具核心造型/轮廓在所有状态中必须可识别 |
| R2 | 状态变化必须符合剧情与物理逻辑，损伤以动画化语言表现（柔和圆润） |
| R3 | 必须是「单张静物展示」——单视图、非2×2四宫格、非turnaround |
| R4 | 必须与原道具设定图保持同一机位、同一光线、同一背景 |
| R5 | 必须声明「卡通化旧化 + 动画电影质感 + 非真人非实拍」 |
| R6 | 激活类状态的光效必须「柔和克制」，禁止霓虹溢色 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 严禁状态变化后道具不可识别，严禁擅自修改核心造型 |
| X2 | 严禁「真实血腥 / 腐烂 / 恶心 / 恐怖」的损伤描绘——保持全年龄友好 |
| X3 | 严禁「真人实拍 / 照片写实 / 真实做旧感」 |
| X4 | 严禁「低多边形 / 粗糙建模 / 模糊贴图」 |
| X5 | 严禁「2D手绘 / 赛璐璐 / 日式二次元」 |
| X6 | 严禁「尖锐破损 / 工业冷硬 / 锐利棱角」 |
| X7 | 严禁「高饱和荧光光效 / 霓虹溢色 / 能量爆炸」 |
| X8 | 严禁「多角度 / 四视图 / 2×2网格 / turnaround」——仅单张 |
| X9 | 严禁「出现人物 / 手部 / 手指 / 肢体」 |
| X10 | 严禁「悬浮 / 抠图白底 / 无投影 / 无承载面」 |
| X11 | 严禁「水印 / 文字 / LOGO / 签名 / 边框」 |
