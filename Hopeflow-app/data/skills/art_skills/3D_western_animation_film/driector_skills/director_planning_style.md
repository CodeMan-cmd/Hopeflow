# 欧美3D动画电影约束 · 动画电影 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以奶油白（#FFF4E0）、晴朗蓝（#5FA8E8）、珊瑚橙（#FF8C5A）为基底色。整体色温偏暖（4800-5500K），饱和度中高（70-85%），呈现"明亮通透、温暖治愈"的动画电影色调——色彩来自核心色盘的冷暖互补，不来自写实还原
- **色彩即情绪** — 情绪色盘绑定叙事段落：温馨日常=奶油白+柠檬黄、冒险旅途=晴朗蓝+薄荷绿、童话梦幻=薰衣草紫+柠檬黄、温馨夜晚=靛青蓝+暖灯点缀
- **冷暖叙事对照** — 暖色（C5柠檬黄/C9珊瑚橙/C8奶油白）用于温情、治愈、庆典段落；冷色（C3晴朗蓝/C10靛青蓝/C7薰衣草紫）用于冒险、夜晚、离别段落。关键转场可通过色温切换暗示情绪转向
- **明亮底线** — 任何段落不得整体滑向灰暗压抑——夜晚场景也必须保持可见度与暖光点缀
- **禁用色域** — 高饱和荧光色、霓虹溢色、廉价电子色、暗黑哥特色调、写实灰调

## 二、光影方案体系

- **光影即叙事** — 柔和全局光照（GI）为基底 + 三点布光塑造主体。导演规划阶段在段落层面确定光影方向，而非逐镜指定
- **动画电影光影特征** — 柔和阴影、高光柔和滚落、暗部有层次不死黑、魔法光效柔和克制——为欧美3D动画电影的核心光影手段

| 方案 | 方案名 | 光源配方 | 光比 | 适用情绪 |
|---|---|---|---|---|
| A | 阳光灿烂 | 大面积暖阳全局光（5000-5500K）+ 天光补光 | 1:1.5 低反差 | 欢乐庆典、日常温馨、明亮治愈 |
| B | 童话晨光 | 低角度暖白晨光（4500-5200K）+ 薄雾漫射 | 1:2 柔和 | 静谧蓄势、童话苏醒、清新希望 |
| C | 金色童话 | 极暖低角度金光（3000-3800K）+ 长影 | 1:3 暖调 | 珍贵时刻、温情回忆、浪漫段落 |
| D | 奇幻魔法 | 柔和魔法光晕（薰衣草紫/柠檬黄光斑）+ 冷底暖点 | 1:4 梦幻 | 魔法时刻、奇幻探索、童话梦境 |
| E | 温馨夜晚 | 月光冷调（6000K）+ 暖灯点缀（3000K） | 1:5 冷主暖点 | 宁静夜晚、家庭温馨、安心入睡 |
| F | 冒险高光 | 通透天光 + 长阴影层次 + 天空冷调 | 1:4 通透 | 冒险旅途、开阔自由、探索发现 |
| G | 淡淡感伤 | 降饱和冷调（5000K）+ 柠檬黄微点缀 | 1:4 克制 | 离别、失去、克制的愁绪 |

- **光影适配要点**：光源名称可被AI理解（"柔和全局光照"优于"物理渲染"）。多光源场景须明确主光+补光+轮廓光的层级。魔法光效必须柔和克制，禁止霓虹溢色

## 三、质感方向——动画材质语言

> 欧美3D动画电影质感的唯一标尺：动画材质的丰富度，不是写实还原度。

- **皮肤质感** — 次表面散射（SSS）通透有血色、卡通柔滑肤质、脸颊自然红晕。提示词用"subsurface scattering, soft translucent skin, cute cartoon complexion"——禁止写实毛孔
- **毛发质感** — 物理毛发逐缕可见、蓬松有层次、绒毛碎发、逆光下毛发边缘透光。提示词用"physical hair, strand-by-strand, fluffy layers, backlit hair glow"
- **布料质感** — 物理布料模拟、褶皱自然、垂坠柔和、纹理清晰可辨。提示词用"cloth simulation, natural wrinkles, soft drape, fabric texture"
- **道具材质** — 木纹/金属/玻璃/皮革/宝石层次丰富、圆润倒角、玩具般亲和。提示词用"rich material detail, rounded edges, toy-like charm"
- **光影材质** — 柔和全局光照、阴影软而有层次、高光柔和滚落。提示词用"soft global illumination, soft shadows, gentle highlight roll-off"
- **禁止写实化** — 材质是"丰富"而非"写实"——禁止真人皮肤/照片级材质/写实做旧

## 四、动画表演与场景元素

- **圆润建筑/夸张比例** — 童话小镇、奇幻城堡、动画都市——建筑允许夸张变形（胖屋顶/高塔/大拱门/圆窗），比例夸张是童话感的来源
- **明亮场景空间** — 场景整体明亮通透，前/中/后景层次完整。前景画框（圆窗/树枝/花丛）→中景主体→后景延伸
- **色彩即场景情绪** — 场景色彩由核心色盘驱动，明亮饱和、冷暖互补——温暖小镇是奶油白+珊瑚橙、奇幻森林是薄荷绿+薰衣草紫
- **动画表演元素** — 角色以夸张表情与弹性肢体表演（大特写瞳孔、形变嘴型、戏剧化手势）；场景可带"活物感"（会眨眼的房子、拟人化的器物）
- **段落间用场景空镜过渡** — 同一空间在不同时段/天气的空镜暗示时间流逝。空镜也必须有光源逻辑与情绪

## 五、动画电影配乐

### 5.1 配乐乐器选择

- **管弦乐组** — 动画电影的核心配乐语言。弦乐组铺底情绪、铜管乐点亮庆典与冒险、木管乐塑造童话俏皮感
- **钢琴** — 温情细腻段落的核心乐器，音符之间的留白与音符本身同样重要
- **竖琴/钟琴** — 奇幻魔法段落的神奇音色——魔法时刻的"叮咚"质感
- **打击乐组** — 冒险/追逐段落的节奏基底——定音鼓、小军鼓的戏剧推动
- **人声合唱** — 庆典/宏大段落的氛围增强——温暖的和声质感
- 慎用：重金属失真、刺耳电子舞曲、恐怖片配乐——这些会破坏全年龄友好的基调

### 5.2 配乐组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 温馨日常 | 钢琴 + 轻弦乐 + 木管点缀 |
| 欢乐庆典 | 铜管乐 + 打击乐 + 人声合唱 |
| 冒险旅途 | 弦乐组 + 定音鼓节奏 + 圆号 |
| 魔法奇幻 | 竖琴/钟琴 + 弦乐高音 + 钢琴 |
| 离别感伤 | 钢琴独奏 + 弦乐低音渐弱 |
| 结局余韵 | 钢琴单音渐疏 → 环境音独奏 |

### 6.4 动画表演具象化

> 动画表演是"夸张的物理"。所有动作须用可执行的形变与幅度描述。

| 场景 | 抽象写法（禁止） | Seedance 2.0 具象写法 |
|---|---|---|
| 惊讶 | 他很惊讶 | 眼睛瞪大至平时的1.5倍，眉毛高挑至额头上方，嘴巴张成圆形，双手捂脸约1秒后放下 |
| 高兴 | 开心地跳 | 双膝弯曲蓄力，向上跳起约0.5米，双臂高举过头左右挥舞，落地后身体弹性起伏两下 |
| 生气 | 气鼓鼓 | 脸颊鼓起如气球，眉头紧锁，双手叉腰，脚掌跺地两次，头顶冒出一小团动画化的白色蒸汽 |
| 哭泣 | 伤心地哭 | 眼眶蓄满大颗泪珠，泪水沿脸颊滑落，嘴型下撇成波浪形，肩膀一抽一抽地耸动 |

### 6.5 空间逻辑具象化

- **水平位置**：画面左侧三分之一处 / 画面中央 / 画面右侧
- **纵深位置**：前景（距镜头1-2米）/ 中景（距镜头3-5米）/ 背景
- **角色与场景关系**：相对于场景固定物的距离和方向
- **站位衔接**：相邻镜头保持角色位置、朝向、姿态的可衔接性

- 角色锚定：必须引用 @ImageX，指定用途。例：@Image1_小英雄_红披风作为角色外观参考，@Image2_童话小镇_彩色圆顶屋作为场景环境参考

## 七、全局叙事约束

- **空镜即情绪** — 每个叙事段落之间建议用场景空镜做情绪缓冲。空镜不是"没东西拍"，是"让观众喘口气"
- **色彩连续性** — 同一空间内的色彩方案应保持稳定。如果一场戏跨越了时段，色彩应随光的物理变化连续过渡
- **角色光源一致性** — 同一镜头内所有角色的面部光源方向必须统一
- **表演优先于一切** — 欧美3D动画电影的价值在"表达"——允许夸张、允许戏剧化、允许打破物理的弹性形变，但必须服务于情绪
- **避免"过度写实"** — 禁止把动画电影拍成真人电影——材质、表演、光影都要保持"动画感"
