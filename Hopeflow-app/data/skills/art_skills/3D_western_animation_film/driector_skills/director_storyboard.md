# 分镜提示词 · 欧美3D动画电影 · 风格专属技法

---

## 适用范围

本 Skill 专用于**欧美3D动画电影**风格的分镜提示词生成，适配冒险、童话、家庭、成长、奇幻等三维动画电影题材的分镜创作。

---

## 一、动画表演的情绪——夸张的面孔、弹性的身体

> 欧美3D动画电影的情绪不来自真人的微表情，而来自夸张的动画表演——形变、弹跳、戏剧化的身体语言。以下映射面向动画表演方式。

| 情绪输入 | 面容描述 | 眼神描述 | 肢体表演补充 |
|---|---|---|---|
| 惊讶 / 震撼 | 眼睛瞪大至1.5倍，眉毛高挑，嘴巴张成圆形 | 瞳孔骤缩，眼中有高光点闪烁 | 身体后仰，双手捂脸或张开 |
| 喜悦 / 欢呼 | 嘴角大咧到脸颊，眼睛弯成月牙 | 眼睛眯成弯月，眼角有笑纹 | 原地弹跳，双臂高举挥舞 |
| 生气 / 气鼓鼓 | 脸颊鼓起如气球，眉头紧锁 | 眼睛半眯，眉毛倒竖 | 双手叉腰，跺脚，头顶白色蒸汽 |
| 悲伤 / 大哭 | 嘴型下撇成波浪形，眼眶蓄泪 | 大颗泪珠沿脸颊滑落 | 肩膀一抽一抽，抱紧自己 |
| 委屈 / 瘪嘴 | 嘴巴抿起瘪成波浪形，眉头微皱 | 眼角下垂，泪光闪烁 | 低头绞手指，身体微缩 |
| 得意 / 骄傲 | 下巴微抬，嘴角一侧上扬 | 眼睛半闭，自信闪光 | 双手叉腰挺胸，尾巴/衣摆翘起 |
| 害怕 / 发抖 | 眼睛瞪圆，眉毛内八，嘴巴微张 | 瞳孔放大，视线游移 | 缩成一团，双手抱头，瑟瑟发抖 |
| 好奇 / 探询 | 眉毛微挑，嘴角微启，头歪向一侧 | 眼睛睁圆，专注注视 | 身体前倾，踮脚或歪头靠近 |
| 感动 / 泪目 | 嘴角微颤，眼睛泛起水光 | 眼神湿润，泛着柔和光泽 | 单手捂嘴，另一只手轻拍胸口 |
| 沉思 / 思考 | 眉毛微皱，眼神放远，嘴微抿 | 目光放远失焦，像在看但不在看 | 单手托腮，另一只手轻点下巴 |

## 二、动画光影——明亮通透的情绪光

### 2.1 时段光效

| 时段 | 光源行为 | 色温与色调 | 空间氛围 |
|---|---|---|---|
| 清晨 | 低角度暖白晨光斜入，薄雾漫射，阴影柔和拉长 | 4500-5200K暖白，空气微凉 | 静谧未醒、童话苏醒、蓄势 |
| 上午 | 日光升高，通透明亮，色彩饱和 | 5000-5500K中性偏暖 | 秩序建立、日常运转、明亮 |
| 正午 | 顶光或近乎顶光，阴影短而柔和 | 5500K明亮通透 | 活力顶点、阳光最盛 |
| 午后 | 日光偏西，暖调渐强，斜光长影 | 4800-5200K渐暖 | 慵懒温暖、一天中最长的一段 |
| 金色时刻 | 极低角度暖金漫射，长影，一切镀金边 | 3000-3800K极暖 | 转瞬即逝的珍贵、温情段落 |
| 夜晚 | 月光冷调+暖色灯光（窗灯/路灯/灯笼） | 6000K月光+3000K暖灯 | 宁静温馨、安心入睡 |
| 奇幻夜 | 月光+柔和魔法光斑（薰衣草紫/柠檬黄） | 冷底+彩色魔法光 | 神秘但明亮的奇幻感 |

### 2.2 情绪光影

| 情绪基调 | 光线配方 | 渲染约束 |
|---|---|---|
| 温馨日常 | 柔和全局光照（5000-5500K）+ 大面积暖光漫射 | 低反差通透，阴影软而有层次 |
| 欢乐庆典 | 高亮全局光（5500K）+ 色彩饱和 | 高调明亮，欢快的色彩氛围 |
| 冒险旅途 | 通透天光 + 长阴影层次 | 开阔通透，天空冷调+地面暖调 |
| 魔法奇幻 | 柔和魔法光晕（薰衣草紫+柠檬黄光斑）+ 冷底暖点 | 梦幻光效柔和克制，禁霓虹溢色 |
| 温馨夜晚 | 月光冷调（6000K）打底+暖灯点缀（3000K） | 冷主暖点，暗部保留可见度 |
| 淡淡感伤 | 降饱和冷调（5000K）+ 柠檬黄微点缀 | 克制柔和，不灰暗不压抑 |

## 四、虚拟摄影机——镜头选择与运动

### 4.1 焦段选择

| 焦段 | 叙事性格 | 适用场景 |
|---|---|---|
| 24-28mm广角 | 环境的辽阔童话感、角色与空间关系 | 小镇全貌、森林纵深、宏大场景 |
| 35mm小广角 | 主观视点、身临其境 | 角色行走跟随、室内对话 |
| 50mm标准 | 客观注视、表演忠实记录 | 动画表演展示、双人对话 |
| 85mm中长焦 | 压缩空间、拉近情感、背景虚化 | 角色特写、情感凝视、夸张表情 |
| 135mm+长焦 | 极端压缩、窥视感 | 远处的秘密、细节发现 |

### 4.2 景别选择

| 景别 | 取景范围 | 叙事功能 |
|---|---|---|
| 大特写 | 眼睛/嘴/手/物件 | 情绪峰值、瞳孔特写、魔法细节 |
| 近景 | 头顶至胸部以上 | 夸张表情表演、情感凝视 |
| 中近景 | 头顶至腰部 | 互动对话、手势表演 |
| 中景 | 头顶至膝盖上下 | 弹性动作展示、角色关系 |
| 全景 | 全身+部分环境 | 角色与场景关系、行动路线 |
| 大全景/空镜 | 空间全貌，无人物 | 世界观展示、情绪缓冲 |

### 4.3 摄影机运动

| 运动方式 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定 | 冷静，让表演自己说话 | 对话、表情表演展示 |
| 缓推 | 注意力聚焦、情绪趋近 | 情绪升温、魔法时刻、真相逼近 |
| 缓拉 | 拉开距离、揭示全貌 | 场景建立、离别、章节收束 |
| 环绕 | 360度展示、戏剧感 | 角色登场、重要道具展示、情感高点 |
| 跟拍 | 与角色同行、冒险陪伴 | 行走跟随、追逐、探索 |
| 升降 | 宏观视角、童话世界俯瞰 | 场景宏伟感、空间关系揭示 |

## 五、固定风格锚定词

**风格锚定（必选）：**

欧美3D动画电影，三维动画电影成片质感，圆润饱满角色造型，夸张生动的动画表演，明亮饱和色彩，柔和全局光照，高精度建模

**角色质感（含角色镜头时必选）：**

次表面散射SSS皮肤通透有血色，卡通柔滑肤质非写实毛孔，物理毛发逐缕可见蓬松层次，布料模拟自然褶皱，夸张可读的动画表情，弹性生动的肢体表演

**场景质感（含场景镜头时必选）：**

欧美3D动画电影场景，明亮通透色彩饱和，圆润建筑夸张比例，材质纹理清晰丰富，柔和全局光照，阴影软而有层次，非真人实拍非写实

**参考图一致性锚定（参考图模式必选）：**

保持角色造型、面容、发型、服饰与参考图完全一致，保持场景风格与参考图一致，保持光影色彩基调统一，所有镜头呈现为同一角色的连续动画记录

**风格收尾（固定）：**

欧美3D动画电影，三维动画电影成片质感，明亮通透，非真人非实拍非2D手绘

**画质锁定词：**

模式A（中文）——默认：
欧美3D动画电影高清画质，电影级动画画面质感，画面无字幕、无水印、无标题叠字、无UI元素

模式B（英文）——默认：
western 3D animation film quality, high detail render, no subtitles, no captions, no watermark, no title overlay, no UI elements

**负向词模板（模式B 必须包含，置于提示词末尾）：**

> ⚠️ Seedream（模式A）不支持负向提示词，负向词仅适用于模式B。模式A 通过正向词中的质感锚定和画质锁定来保证画面质量。

模式B（英文）：
no live-action, no photorealistic, no real human skin, no realistic pores, no real person photo, no 2D cel shading, no anime, no manga, no illustration, no hand drawn, no painting, no low poly, no rough modeling, no blurry texture, no plastic dead, no dark, no gloomy, no horror, no creepy, no gothic, no bloody, no sharp edges, no angular, no neon, no fluorescent, no garish, no wrong anatomy, no deformed face, no broken limbs, no distorted body, no subtitles, no captions, no watermark, no title overlay, no UI text

## 六、美学禁止项

以下词汇/风格不得出现于输出提示词中：

- ❌ 真人实拍 / 照片写实 / 真人演员 / live-action / photorealistic / 写实皮肤毛孔
- ❌ 低多边形 / 粗糙建模 / 模糊贴图 / 塑料死板 / 无光影细节
- ❌ 2D手绘 / 赛璐璐平涂 / 日式二次元 / 厚涂插画 / 漫画描边
- ❌ 恐怖 / 惊悚 / 血腥 / 暗黑哥特 / 阴森瘆人 / 恐怖谷
- ❌ 锐利棱角 / 工业冷硬 / 尖刺造型 / 粗野主义
- ❌ 高饱和荧光色 / 霓虹溢色 / 廉价电子色 / 色彩污染
- ❌ 肢体畸形 / 五官崩坏 / 表情僵死 / 比例失调
