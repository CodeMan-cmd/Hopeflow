# 分镜表欧美3D动画电影约束 · 动画电影 · 技法参考

---

## 一、分镜表定位

分镜表是导演将剧本转化为镜头语言的核心工具。本约束面向 Seedance 2.0 视频生成，所有光影、动作、空间描述均采用模型可执行的具象语言。不做抽象的情感概括，不写模型看不懂的渲染参数。

---

## 二、Seedance 2.0 描述铁律

> 欧美3D动画电影分镜表中所有描述必须遵守以下翻译原则——将"导演意图"翻译为"AI可执行的动画表演指令"。

| 禁止的抽象表达 | Seedance 2.0 具象替换 |
|---|---|
| 他很惊讶 | 眼睛瞪大至平时的1.5倍，眉毛高挑至额头上方，嘴巴张成夸张的圆形，身体微微后仰 |
| 阳光很好 | 午后阳光从画面左侧斜入（约5000K暖白），柔和全局光照，在地面投下柔和的圆角阴影 |
| 小镇很热闹 | 彩色圆顶小屋外墙在阳光下明快通透，三位圆润造型的居民在广场缓步走动，喷泉水珠闪烁 |
| 他高兴地跑了 | 双膝弯曲蓄力后向前弹跳小跑，每步落地身体微弹一下，双臂摆动幅度夸张，红披风在身后飘起 |
| 气氛很神秘 | 奇幻森林中柔和魔法光斑（薰衣草紫+柠檬黄）洒落，树冠光斑缓慢移动，光线通透不阴森 |
| 风吹动披风 | 红披风被微风从背后鼓起约30度角，布料物理摆动，随即回落，约1.5秒一个周期 |

## 三、光影与氛围——动画电影光源描述

### 3.1 同场戏光影统一

一场戏内不应出现两种以上核心光影方案，除非有叙事驱动的光源变化（如魔法激活、日出后天光亮过室内灯、从室内走到室外）。光源变化必须在分镜表中标注触发事件。

### 3.2 光源语句法（每个镜头必须包含）

[光源] 主光：{光源类型}，{方向}，{色温值K}，{软硬}
[光源] 辅光/环境光：{光源类型}，{方向}，{色温值K}
[光比] 约1:{X}

### 3.3 情绪 → 光源矩阵

| 情绪 | 光源配方（Seedance 2.0 可直接填入） | 视觉关键词 |
|---|---|---|
| 温馨日常 | 柔和全局光照（5000-5500K）从大面积方向漫射，阴影软而短。光比约1:1.5 | 通透、明亮、温暖 |
| 欢乐庆典 | 高亮全局光（5500K）+ 色彩饱和，暖色点缀。光比约1:1.5 | 高调明亮、欢快 |
| 冒险旅途 | 通透天光（5500K）+ 长阴影层次，天空冷调地面暖调。光比约1:4 | 开阔、自由、探索 |
| 魔法奇幻 | 柔和魔法光晕（薰衣草紫+柠檬黄光斑）冷底暖点。光比约1:4 | 梦幻、神奇、童话 |
| 温馨夜晚 | 月光冷调（6000K）打底 + 暖色窗灯（3000K）点缀。光比约1:5 | 宁静、安心、温暖 |
| 淡淡感伤 | 降饱和冷调（5000K）+ 柠檬黄微点缀。光比约1:4 | 克制、不舍、不压抑 |

### 3.4 色彩与叙事阶段

- **暖色主导**（3000-5500K）：温馨日常、庆典、金色时刻、家庭段落
- **冷色主导**（5500-6500K）：冒险、夜晚、离别段落
- **魔法色点缀**：薰衣草紫/柠檬黄光斑——奇幻时刻的标志性色彩
- **光源变化 = 叙事信号**：魔法光晕亮起=奇幻时刻开始；窗外从白天变夜晚=时间流逝

### 3.5 Seedance 2.0 光影适配要点

- 色温数字帮助模型校准白平衡倾向：`色温约5000K` 优于 `暖光`
- 光比数字帮助模型建立明暗意识：`光比约1:3` 优于 `柔和的阴影`
- 光源必须有明确来源：`阳光从画面左侧斜入` 优于 `侧光`
- 魔法光效必须声明"柔和"：`柔和魔法光晕` 优于 `发光`

## 四、环境动态——让画面呼吸

### 4.1 动态密度

每 3-4 个镜头至少安排一个有环境动态的镜头。静态对话戏也不例外——至少有一个镜头里窗帘在动、喷泉在响、树叶在晃。

### 4.2 动画环境动态元素（Seedance 2.0 可执行）

| 场景 | 可描述的环境动态 |
|---|---|
| 童话小镇 | 喷泉水珠不断溅起又落下、彩色旗帜被风吹动、窗台上的花盆在微风中轻晃、烟囱偶尔飘出圆环状烟圈 |
| 奇幻森林 | 树冠光斑随风缓慢移动、藤蔓轻微摆动、萤火虫般的魔法光点飘浮、落叶旋转飘落 |
| 温馨室内 | 壁炉火光跳动、台灯光晕温暖稳定、窗帘被微风轻鼓、桌上的热汤冒出圆润的蒸汽团 |
| 奇幻城堡 | 彩绘玻璃透光随云移动而变化、旗帜飘扬、吊灯轻轻晃动、齿轮缓缓转动 |
| 动画都市 | 胖汽车圆润驶过、招牌灯光闪烁、气球缓缓升空、云朵在天空移动 |

### 4.3 Seedance 2.0 环境动态描述规范

- 动态必须有具体轨迹和速度：`旗帜被风吹动，每秒约2-3次摆动` 优于 `旗子在动`
- 光源动态与空间光源逻辑一致：`云朵遮住太阳时，地面光斑面积缩小约40%，持续约3秒后恢复`
- 禁止无来源的动态：没有风=窗帘不动。魔法光效必须由道具或剧情触发

## 五、动画表演节奏——Seedance 2.0 夸张表演具象化

### 5.1 动作描述铁律

所有动画表演必须描述：**夸张幅度 + 速度/时长 + 身体部位协调 + 对周围物体的影响**。

### 5.2 动画表演具象库

| 动作 | Seedance 2.0 可执行描述 |
|---|---|
| 惊讶 | 眼睛瞪大至平时的1.5倍，眉毛高挑至额头上方，嘴巴张成圆形，双手抬起至脸颊两侧——全程约0.8秒，定格约1秒 |
| 弹跳高兴 | 双膝弯曲蓄力，向上跳起约0.5米，双臂高举过头左右挥舞，落地后身体弹性起伏两下——全程约2秒 |
| 气鼓鼓 | 脸颊鼓起如气球，眉头紧锁，双手叉腰，脚掌跺地两次，头顶冒出一小团动画化白色蒸汽——全程约3秒 |
| 大哭 | 眼眶蓄满大颗泪珠，泪水沿脸颊滑落，嘴型下撇成波浪形，肩膀一抽一抽地耸动——持续约4秒 |
| 好奇靠近 | 头歪向一侧约20度，踮起脚尖，身体前倾，双手背在身后，眼睛睁圆缓缓靠近目标——全程约3秒 |
| 得意炫耀 | 下巴微抬约15度，双手叉腰挺胸，一只脚轻踏地面打拍子，眼睛半闭露出自信闪光——全程约2秒 |
| 害怕缩团 | 双手抱头，身体蜷缩成一团，膝盖内收，眼睛瞪圆视线游移，轻微发抖——持续约3秒 |
| 魔法施放 | 双手向前平伸，掌心聚拢，柔和魔法光晕在掌心凝聚旋转（薰衣草紫+柠檬黄），光点缓缓升空——全程约4秒 |

### 5.3 动作节奏与叙事场景

- **温馨日常/文戏**：表演克制但有动画生动感——幅度中等、节奏舒缓
- **喜剧段落**：表演大幅夸张——弹性形变、戏剧化停顿、快慢反差
- **动作/冒险段落**：动作干脆利落——弹跳、翻滚、追逐，保持物理可信的弹性
- 禁止：无叙事理由的快速动作堆砌、无物理逻辑的瞬移、含糊描述

### 5.4 服饰动态

动画角色的服饰动态是表演的一部分——不是"布料模拟参数"，而是"红披风在奔跑时向后飘起约45度角""裙摆随弹跳上下起伏""围巾在风中呈波浪形飘动"。在分镜表画面描述中标注服饰动态细节。

## 六、空间逻辑具象化——Seedance 2.0 空间坐标系统

### 6.1 每镜头必须声明的空间信息

水平位置：画面左/中/右，或画面左侧三分之一处
纵深位置：距镜头{数值}米，前景/中景/背景
角色与场景的关系：距{固定物}{数值}米
（若双人以上）角色A与B的相对距离和朝向

### 6.2 站位衔接示例

【片段A尾部】
小英雄站在喷泉旁，距喷泉约1米，面朝魔法光点，位于画面中央偏右，距镜头约3米。
阳光灿烂全局光，广场彩色圆顶小屋清晰可见。
小英雄右手抬起指向空中的魔法光点。

【片段B开头】
小英雄的右手仍指向魔法光点，位置未变。魔法光点已飘近至距他约0.5米处，柔和光晕照亮他的脸颊。
魔法光晕（薰衣草紫+柠檬黄）在他脸上投下柔和的彩色光斑。

### 6.3 空间变化必须具象

| 抽象（禁止） | Seedance 2.0 具象 |
|---|---|
| 他走近了 | 小英雄从画面背景（距镜头约5米、糖果屋门口）向镜头方向弹跳前行4步（约3米），停在距镜头约2米处——耗时约3秒 |
| 两人面对面 | 小英雄位于画面中央偏左（距镜头约3米），小精灵位于画面中央偏右（距镜头约3米），两人面对面，相距约0.6米 |
| 从室内到室外 | 小英雄从室内（距镜头约3米）走向门口，推开圆木门（门向外旋转约70度），右脚跨出门槛，进入阳光明媚的小镇街道——暖阳全局光瞬间取代室内柔光 |

## 七、运镜规范——Seedance 2.0 虚拟摄影机运动

### 7.1 允许的运镜

| 运镜 | Seedance 2.0 描述 | 适用场景 |
|---|---|---|
| 固定 | 虚拟摄影机固定不动，画面静止 | 对话、表情表演、空镜留白 |
| 缓推 | 摄影机向主体缓慢推进（约每秒0.3米） | 情绪升温、魔法时刻、注意力聚焦 |
| 缓拉 | 摄影机向后缓慢拉远（约每秒0.3米） | 离别、收束、揭示全貌 |
| 环绕 | 摄影机绕主体半环绕（约每秒30度） | 角色登场、重要道具、情感高点 |
| 跟拍 | 摄影机与角色保持约2米距离同步移动 | 行走跟随、追逐、冒险 |
| 升降 | 摄影机垂直升降 | 童话世界俯瞰、场景宏伟感 |

### 7.2 禁用运镜

- 无叙事目的的快速甩镜、急推急拉（速率超过每秒1米）
- 无逻辑花式转场——划屏、旋转、百叶窗、翻页等特效转场
- 恐怖片式的鬼畜运镜、长时间抖动
- 摄影机无理由的360度乱转

### 7.3 欧美3D动画电影运镜哲学

- 固定机位让表演自己说话——动画表演本身就是焦点
- 缓推用于情绪升温、魔法时刻——让观众"靠近奇迹"
- 环绕用于登场与展示——戏剧化的仪式感
- 运动镜头的起幅和落幅必须平稳，运动过程匀速

## 八、转场规范

### 8.1 允许的转场方式

| 转场 | 视觉执行 | 叙事功能 |
|---|---|---|
| 硬切 | 直接切换 | 同场戏内镜头切换（默认） |
| 光影匹配转场 | 两个场景在相近光影逻辑下切换 | 时间流逝、平行叙事。例：A处晨光→B处晨光 |
| 空间匹配转场 | 两个空间在构图或元素上呼应 | 场景跳转。例：城堡大门关上的瞬间→小屋门打开的瞬间 |
| 空镜过渡 | 插入场景空镜（3-5秒） | 情绪缓冲、章节划分、时间流逝暗示 |
| 魔法转场 | 柔和魔法光晕弥漫/消散衔接两镜 | 奇幻叙事专属——光晕扩散覆盖画面→新场景浮现 |

### 8.2 禁止的转场

- 纯视觉特效转场（翻页、划屏、百叶窗、马赛克）
- 无叙事逻辑的旋转/缩放转场
- 恐怖/惊悚式闪切转场

## 九、音画同步规划（Seedance 2.0 专属）

### 9.1 环境音标注规范

每场戏标注 1-2 个核心环境音，写在分镜表的环境音列：

| 场景 | 建议环境音 |
|---|---|
| 童话小镇 | 喷泉水声 / 鸟鸣 / 远处欢乐的市集人声 |
| 奇幻森林 | 树叶沙沙 / 神秘的风声 / 魔法光点的细微"叮"声 |
| 温馨室内 | 壁炉噼啪 / 时钟滴答 / 窗外的风声 |
| 奇幻城堡 | 旗帜猎猎 / 齿轮转动 / 回声脚步 |
| 动画都市 | 胖汽车喇叭 / 街头音乐 / 气球飞起的轻响 |

### 9.2 音画同步标注

在分镜表中对关键音画同步点做标注：
- `t=1s` 魔法光点凝聚时发出轻柔的"叮"声——小英雄抬头
- `t=3s` 小英雄弹跳落地时"砰"的弹性音效——身体起伏
- `t=5s` 喷泉水珠溅落的哗啦声——广场氛围

## 十一、空镜使用规范

### 11.1 空镜不是"没东西拍"

空镜是情绪容器。每个空镜必须有叙事目的和具体的视觉内容：

| 空镜类型 | 叙事目的 | 示例 |
|---|---|---|
| 场景建立 | 新空间首次出现——让观众看清楚这是什么地方 | 童话小镇大全景：彩色圆顶屋、喷泉广场、远处城堡 |
| 情绪缓冲 | 高情绪段落后的喘息 | 魔法光点缓缓飘过夜空，薰衣草紫光晕柔和 |
| 时间流逝 | 暗示时间过去了 | 同一扇圆窗外的天空从午后湛蓝渐变至金色黄昏 |
| 隐喻留白 | 以物代情 | 桌上摆着的小英雄的旧护身符，蒙着薄尘 |
| 转场衔接 | 前后两个空间的自然过渡 | 城堡的彩绘玻璃窗——前一场的小镇，下一场是城堡内 |

### 11.2 空镜 Seedance 2.0 描述规范

空镜也必须遵循光源+材质+动态的描述铁律：
午后阳光从画面左侧斜入（约5000K），在童话小镇广场地面投下柔和的圆角阴影，
喷泉水珠持续溅起又落下，一只圆润的小鸟落在喷泉边缘啄水。
地面石砖纹理清晰，彩色小屋外墙漆面明快饱和。

## 十二、分镜表质量自检清单

每场戏的分镜表完成后，导演逐项自检：

| 检查项 | 通过标准 |
