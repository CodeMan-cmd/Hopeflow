# 欧美3D动画电影风格说明

本手册专为"欧美3D动画电影"题材视觉创作打造，所有美术提示词、视觉规范和生成内容严格限定于皮克斯/迪士尼类欧美三维动画电影美学体系——这是**动画电影**，不是真人写实。

---

## 一、风格核心定义

**欧美3D动画电影**是以皮克斯、迪士尼、梦工厂等欧美三维动画电影为美学基准的视觉风格体系。其核心特征为：

- **动画电影质感**：所有画面明确读作"三维动画电影的成片帧"，而非真人实拍、非照片写实、非2D手绘——角色造型、材质细节、光影渲染都服务于"动画电影"这一媒介身份
- **圆润饱满造型**：角色与器物普遍采用圆润饱满、去锐角的造型语言——大而灵动的眼睛、圆润的脸颊、弹性十足的肢体，线条流畅富有生命力
- **夸张生动表演**：表情与肢体表演大幅夸张化——眉眼、嘴部、手势的形变幅度远超真人，以"可读性"优先，情绪在0.5秒内被观众捕捉
- **明亮饱和色彩**：整体色调明亮通透、色彩饱和度高，善用冷暖互补塑造层次，拒绝灰暗压抑与高对比暗调
- **柔和全局光照**：以柔和的全局光照（Global Illumination）为照明基底，阴影软而有层次，配合三点布光塑造角色立体感，高光柔和滚落
- **丰富材质细节**：次表面散射（SSS）让皮肤通透有血色、逐根可见的毛发（发丝/绒毛）、物理质感的布料褶皱——材质是"丰富"而非"写实"

### 创作理念

1. **"圆润即亲和"** — 一切造型以圆润为第一原则。圆润的轮廓降低攻击性、提升亲和力，是动画电影"全年龄友好"气质的视觉根基
2. **"表演优先于写实"** — 动画电影的价值不在"像真"，而在"表达"。夸张的形变、弹性的运动、戏剧化的表情是叙事的工具
3. **"材质为情感服务"** — 毛发的蓬松感、皮肤的通透感、布料的柔软感不是为了炫技，而是让观众"想摸一下"——触感即共情
4. **"明亮是世界观"** — 即使剧情有危机，画面依然保持整体明亮通透——阴影是柔和的，黑暗是暂时的，色彩永远站在希望一边

## 三、视觉风格定位

**"明亮·圆润·生动的欧美三维动画电影美学"**

| 维度 | 定位标准 |
|---|---|
| 角色造型 | 圆润饱满、头身比偏Q、大眼灵动、夸张生动的表情与肢体 |
| 皮肤质感 | 次表面散射（SSS）通透感，卡通化皮肤——柔滑有光泽但非真人毛孔写实 |
| 毛发质感 | 物理毛发细节——发丝逐缕可见、毛发蓬松有绒毛层次、非塑料发块 |
| 布料质感 | 物理布料模拟——褶皱自然、垂坠柔和、纹理清晰可辨 |
| 场景质感 | 明亮童话感场景、夸张有趣的建筑比例、色彩明快、道具感强 |
| 光影质感 | 柔和全局光照 + 三点布光，阴影软而有层次、高光柔和、无死黑 |
| 色彩质感 | 明亮饱和、冷暖互补、通透干净、拒绝灰暗与荧光溢出 |

## 四、严禁内容（优先级最高）

1. **真人写实质感**：真人实拍、照片写实、写实皮肤毛孔、真人演员照片、photorealistic、live-action——本风格是动画电影，不是真人电影
2. **恐怖/惊悚/暗黑**：恐怖谷面孔、血腥暴力、阴森氛围、暗黑哥特、瘆人畸变——全年龄友好是底线
3. **低多边形粗糙感**：low-poly、粗糙建模、模糊贴图、劣质3D、塑料死板感、无光影细节
4. **2D手绘/日式二次元**：赛璐璐平涂、日系动漫、Q版纸片人、厚涂插画、漫画描边
5. **高饱和荧光色污染**：霓虹溢色、荧光撞色、廉价电子色、色彩过曝失真
6. **肢体畸形/表情僵死**：手指融合、五官崩坏、比例失调、表情僵硬无表演、恐怖谷

## 五、使用说明

### 提示词使用原则

1. **前缀先行**：所有生成内容必须首先加载 `prefix.md` 中的全局风格锚定，锁定欧美3D动画电影质感基线
2. **专项叠加**：在全局前缀基础上，按需叠加角色/场景/道具/分镜专项提示词
3. **负面必加**：每次生成必须附带负面提示词，规避真人写实感、低多边形感与风格偏差
4. **"动画电影"身份恒定**：任何生成都必须明确"三维动画电影成片质感"，禁止滑向真人写实或2D平涂
