# 东方奇幻约束 · 东方神话美学 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片以核心色盘为基底：苍碧（C1 #3E8E7E）、鎏金（C2 #D9A441）、绛紫（C3 #6B3FA0）、玄青（C4 #20364E）、丹砂（C5 #C23B3B）、月白（C6 #E8EAF5）、黛蓝（C7 #2B4C7E）、琥珀（C8 #B97A3E）、翠微（C9 #7FBF7A）、墨灰（C10 #5A5E6B），整体色温偏中性（5000-5600K），饱和度中高（55-75%），呈现东方神话色盘饱满的神秘瑰丽画面
- **冷暖叙事对比** — 暖色（鎏金 C2、丹砂 C5、琥珀 C8）作为神圣/灵契/热血/庆典的视觉信号；冷色（玄青 C4、黛蓝 C7、绛紫 C3）作为妖异/孤寂/肃杀的视觉信号。冷暖切换应与故事弧线同步，而非随意混用
- **冷暖分配策略** — 降妖除魔/夜战孤绝段落使用冷色调（玄青 + 黛蓝 + 绛紫），禁用鎏金/丹砂暖光；仙山秘境/御兽驯灵段落使用柔和暖调（月白 + 苍碧 + 鎏金）；法阵灵光/契约仪式段落使用黛蓝 + 鎏金辉光
- **色盘先行原则** — 段落规划需先绑定情绪场景（御兽驯灵/仙山秘境/妖异志怪/降妖除魔/法阵灵光/夜战孤月等），再确定主色+辅色与光影方案，避免"剧情对了但情绪不对色"
- **禁用色域** — 高饱和荧光色、霓虹色、数码感强色彩均与本风格不兼容（法光特效除外，但须保持东方韵味）。色相偏移容差 ±8°，饱和度偏移 ±10%，明度偏移 ±12%

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同情绪段落，导演规划阶段应在段落层面确定光影基调方向，而非逐镜指定
- **赛璐璐光影为锚** — 所有光影方案必须保持赛璐璐平涂质感，阴影使用同色系加深，禁止黑色硬阴影，允许体积光/景深虚化/灵光光晕等动漫渲染技法
- **光源角度** — 正给镜头默认 38.5° 斜射柔光（赛璐璐平涂质感），侧给镜头可适当调整

| 光影方案 | 方案名 | 色调倾向 | 适用情绪 |
|---|---|---|---|
| A | 仙山天光 | 月白底 + 苍碧清透 | 仙山秘境、晨修、空灵治愈 |
| B | 法阵灵光 | 黛蓝 + 鎏金辉光 | 法阵、结契、施法玄奥 |
| C | 妖雾幽光 | 绛紫主导 + 玄黑暗部 | 妖异志怪、诡谲潜伏、紧张神秘 |
| D | 丹火暖影 | 琥珀 + 丹砂暖光 + 玄黑暗部 | 丹房夜炼、夜行、暖意对峙 |
| E | 月光冷辉 | 玄青 + 月白冷光 | 夜战孤月、思念独处、清冷孤绝 |
| F | 圣祭华辉 | 鎏金 + 月白高光 + 玄黑暗部 | 契约仪式、大典、神圣庄严 |
| G | 降妖肃杀 | 玄青 + 丹砂点缀 + 38.5°侧射冷光 | 降妖除魔、热血壮烈、氛围紧张 |

- **冷暖光分配** — 暖色光（丹砂/鎏金/琥珀）适用于神圣/灵契/热血段落；妖异肃杀/孤绝段落一律冷光。导演可根据叙事需要调整冷暖切换点
- **氛围方向映射** — 每场戏的氛围方向应能映射到上述光影方案（A-G）的某一方向，确保视觉一致性

## 三、质感方向

- **赛璐璐平涂为锚** — 东方奇幻的核心：细腻线条、赛璐璐平涂、动漫渲染、色块平滑渐变、禁止色块断层/色彩溢出
- **细腻笔触 + 影视质感** — 这是画面质感的锚点。不是写实摄影，不是 3D CG，是二次元动漫渲染加东方神话美学的融合
- **材质二次元化** — 所有服化道与灵物的材质必须以赛璐璐平涂呈现：道袍的光泽用平滑色块、法器金属的反光用冷光泽线条、灵玉的润感用内透光色块、灵珠的光晕用柔光渐变。禁止"3D 感"和"写实摄影感"
- **灵物质感** — 灵珠/鳞羽/兽骨等奇幻材质须带「灵光内蕴」的柔光质感，克制不艳俗，保持东方神韵
- **二次元不等于扁平** — 东方奇幻强调在赛璐璐平涂基础上通过光影层次、景深虚化、体积光、灵光光晕等手段增加空间感与影视感，而非扁平无纵深的卡通风格

## 四、东方奇幻场景空间元素

东方奇幻世界观特有的场景元素及其视觉叙事功能：

- **仙山/云海/浮空山/灵泉** — 留白构图的天然载体，景即情：云海翻涌 = 心绪起伏、灵泉泛光 = 机缘将至、仙山渺渺 = 高远志向、迷雾笼罩 = 前路未知
- **洞府/丹房/藏书阁/祭坛法阵** — 天然的框架式构图场景，法阵符文亮起 = 命运转折、丹炉灵火 = 酝酿蜕变、藏书阁竹简 = 求知传承
- **灵光/灵火/月光/妖气** — 东方奇幻世界的光源载体，灵光 = 玄奥/法阵（方案B）、灵火 = 暖/丹房夜炼（方案D）、月光 = 冷/孤绝（方案E）、妖气 = 诡谲/潜伏（方案C）
- **飞檐仙宫/石桥木亭/浮空山/古战场遗迹** — 建筑元素以东方神话美学呈现，细节丰富、赛璐璐线条清晰，材质带自然磨损/岁月包浆感，禁止全新无瑕的"塑料感"
- **段落间用场景空镜过渡** — 本风格有丰富的场景资产（不同时段/天候/景别变体），段落衔接建议用场景空镜做情绪缓冲，不要硬切
- **转折点用视觉而非台词** — 优先使用画面手段（灵光突变、法阵亮起、景别跳切、空镜隐喻）而非依赖对白解释
- **前中后景层次** — 所有场景必须具备前/中/后景，杜绝扁平，室外必须包含空气透视（远山如黛、云海渐隐）

## 五、东方古韵乐器与环境音

东方奇幻世界观下的声音元素约束：

### 乐器选择

- **埙** — 苍凉、远古、秘境召唤的核心乐器，与秘境探险/上古遗秘氛围高度适配
- **箫** — 凄凉、孤寂、月夜段落的核心乐器，与夜战孤月/思念氛围高度适配
- **古琴** — 开场定调 / 平稳段落 / 仙山意境，与箫搭配使用
- **战鼓** — 降妖除魔、大战爆发的节奏推动器，鼓点如心跳，热血壮烈
- **编钟** — 圣祭仪式、大典、契约仪式段落的庄重乐器
- **琵琶** — 紧张、急促段落的点缀，妖异诡谲场景的节奏引导
- 弦乐铺底可增加影视感但不宜喧宾夺主

### 乐器组合策略

| 情绪阶段 | 乐器组合 |
|---|---|
| 平稳/开场/收尾 | 古琴独奏 或 古琴 + 箫 |
| 仙山/空灵/意境 | 箫 + 古琴 + 风铃 |
| 秘境/远古/召唤 | 埙 + 古琴 + 低音弦乐 |
| 妖异/诡谲 | 琵琶点缀 + 低音鼓 + 弦乐衬底 |
| 降妖/大战/爆发 | 战鼓 + 唢呐 + 弦乐铺底 |
| 圣祭/仪式/庄严 | 编钟 + 古筝 + 弦乐铺底 |
| 夜战/孤绝/凄美 | 箫 + 古琴 + 轻铃 |

### 东方奇幻环境音

- **典型环境音层次** — 灵泉潺潺 / 风过松林 / 云海风声 / 御兽低吼 / 铃音轻响 / 丹炉火苗 / 雨打石阶 / 衣料摩擦 / 法阵嗡鸣 / 妖雾流动
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，东方奇幻场景越有沉浸感
