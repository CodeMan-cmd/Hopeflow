# 东方奇幻风格说明

本风格专为"东方奇幻"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **东方奇幻动画**：以东方神话、仙侠志怪、山海经异兽为背景的奇幻二次元动画风格，涵盖御兽、修仙、降妖、寻宝等题材
- **东方神话美学**：山海经异兽、奇珍异宝、仙山楼阁、法术灵光等东方奇幻意象
- **动漫渲染技法**：现代动漫动画的上色与光影技术，赛璐璐平涂结合数字渲染
- **奇幻想象力**：在东方古典审美基础上注入超自然设定——灵兽、法器、阵法、天象异变，奇幻而不失东方韵味
- **细腻笔触**：清晰的线条、精细的细节、精致的角色与场景设计
- **影视质感**：影视级构图、光影层次、动态张力、情绪氛围

## 适用范围

- 东方奇幻题材的AI美术生成（角色、灵兽、场景、道具、分镜等）
- 需要东方神话美学、动漫渲染、奇幻想象力的视觉创作
- 御兽、修仙、仙侠志怪、东方神话等题材的动画、游戏美术、概念设计、插画创作

## 严禁内容

- 完全写实摄影/3D写实渲染
- 西方奇幻（龙与地下城、哥特、维多利亚、北欧神话等）
- 赛博朋克/科幻/过度现代元素
- 粗劣线条/模糊画质/低精度建模
- 色彩混乱/风格不统一/审美崩坏

## 风格体验

在本风格下，您将体验到：

- 角色造型二次元比例，东方奇幻服饰（道袍、法衣、灵甲）精致，线条细腻流畅
- 灵兽异兽造型既有东方神兽意象又有奇幻生物张力，鳞羽皮毛质感清晰
- 场景充满东方神话意境，仙山楼阁、秘境洞府、五行元素丰富，光影渲染精致
- 道具器物考究，法器符箓、灵丹妙药材质质感清晰，色彩和谐统一
- 分镜与渲染均强调影视质感、东方神话审美、动漫动画技法
