# 构图与镜头 · 东方奇幻约束手册

> **本画风构图以东方神话美学为纲**：仙山云海造气势、法阵符文取玄奥、灵兽留白显意境，叠加影视级构图与光影层次（继承 R4/R5），呈现东方奇幻的影视感。

---

## 一、景别

| 景别 | 取景范围 | 用途 | 提示词 |
|---|---|---|---|
| 特写 | 面部/器物/符文局部 | 情绪点、法器、灵契印记 | 东方奇幻特写、符文细节 |
| 近景 | 头部至胸部 | 对话、情绪流转 | 东方奇幻近景、细腻笔触 |
| 中景 | 膝部以上 | 叙事主体、御兽动作 | 东方奇幻中景、动态张力 |
| 全景 | 全身 | 服饰华美、人物与灵兽环境 | 东方奇幻全景、衣袂飘飘 |
| 远景 | 全身 + 仙山云海大环境 | 山河意境、孤寂苍茫 | 东方奇幻远景、仙山留白 |

---

## 二、机位与视角

| 机位 | 适用 | 提示词 |
|---|---|---|
| 平视（默认） | 客观叙事，端正从容 | 平视视角、eye level |
| 仰视 | 仙宫、悬浮山、灵兽威严 | 轻微仰视、仙宫仰拍 |
| 俯视 | 山川、法阵全貌、俯瞰人间 | 俯视、俯瞰法阵 |
| 高机位远望 | 仙山全景、人在画中 | 高机位远望、画中景 |
| 低机位 | 灵草丛、兽迹、草叶视角 | 低机位、秘境视角 |

---

## 三、构图法则（东方神话美学侧重）

| 法则 | 说明 | 提示词 |
|---|---|---|
| 大面积留白 | 云/雾/天光留白，计白当黑 | 大面积留白、云雾留白 |
| 对称构图 | 仙宫/法阵/人物中轴对称 | 对称构图、中轴取景 |
| 三分法与疏密 | 主体偏置 + 疏密对比 | 三分法、疏密有致 |
| 框架构图 | 石洞/回廊/门洞框景 | 框景构图、洞门取景 |
| 对角线/斜势 | 山势/剑气/灵光斜向取势 | 斜势构图、动态取势 |
| 层峦递进 | 远山近水前中后景层次 | 层峦递进、仙山层次 |

---

## 四、镜头语言

| 维度 | 约束 |
|---|---|
| 运动 | 缓慢横移/推拉，如云海流动的节奏 |
| 焦点 | 主体清晰，背景适度虚化（影视质感） |
| 景深 | 影视级景深层次，前景/背景层次分明 |
| 转场 | 云雾遮挡、灵光消散、衣袂翻飞转场 |
| 意境 | 镜头服务于"东方神话画卷"的意境 |

---

## 五、提示词模板（中文）

```
东方奇幻影视构图，赛璐璐平涂+动漫渲染，
{景别}，{机位}，{构图法则}，
{留白/对称描述}，疏密有致，层次递进，
{光源方案}，影视质感光影，细腻笔触，
主体置于{三分线/中轴}，{前景/背景层次描述}，
东方神话色{主色}+{辅色}，{情绪关键词}，意境深远
```

## 六、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「东方奇幻影视风格」（继承 R5） |
| R2 | 必须声明「东方神话美学 + 奇幻想象力」（继承 R3） |
| R3 | 构图必须绑定 1 个东方美学法则（留白/对称/框景等） |
| R4 | 必须声明「细腻笔触 + 影视质感」（继承 R4） |
| R5 | 镜头节奏须如云海流动，克制从容 |
| R6 | 法阵/灵兽类题材构图须体现奇幻纵深（前中后景 + 灵光层次） |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁西方奇幻/哥特/维多利亚构图语言（继承 X3） |
| X2 | 严禁赛博朋克/科幻/过度现代构图（继承 X3） |
| X3 | 严禁粗劣线条/模糊画质/低精度镜头（继承 X4） |
| X4 | 严禁色彩混乱/风格不统一/审美崩坏（继承 X5） |
| X5 | 严禁写实摄影/3D 写实渲染镜头语言（继承 X1） |
