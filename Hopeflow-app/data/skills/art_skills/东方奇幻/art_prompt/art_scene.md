# 场景图生成 · 约束手册

---

## 一、场景美学原则

1. **空间叙事** — 场景承载情绪与叙事功能，不是纯背景板
2. **层次纵深** — 所有场景必须具备前/中/后景，杜绝扁平
3. **奇幻想象** — 在东方自然/建筑美学上注入奇幻设定：悬浮山、灵泉、法阵光纹、异兽栖息痕迹
4. **质感至上** — 木石/灵植/水雾/鳞羽等材质纹理必须超清晰
5. **二次元为锚** — 一切画面以东方奇幻二次元为标准，拒绝3D写实/CG动画质感；追求细腻线条、赛璐璐平涂、动漫渲染

## 三、室内场景（秘境洞府）

### 空间规范

| 维度 | 约束 | 提示词 |
|---|---|---|
| 风格 | 洞府/丹房/藏书阁/祭坛/灵兽居所 | 东方奇幻{场景类型} |
| 材质 | 玉石/木质/石壁/青铜/灵植藤蔓 | 玉石嵌壁、青铜古纹、灵藤垂蔓 |
| 色调 | 东方神话色 + 灵光点缀 | 玄青基调、灵光微亮 |
| 纵深 | 前/中/后景层次 | 前景{元素}、中景{元素}、后景{元素} |
| 质感 | 石壁纹路/玉面光泽/藤蔓脉络可辨 | 纹理清晰、质感细腻 |
| 光照 | 灵火/烛火/天光裂隙，柔和光影 | 灵火摇曳、光影柔和 |
| 镜头感 | 赛璐璐平涂虚化前后景、线条清晰 | cel shading wash, clear lines |
| 瑕疵感 | 石壁风化、玉石包浆、藤蔓自然缠绕 | 岁月痕迹、自然风化、藤蔓缠绕 |

## 五、主视图规范

### 视图定义

> 单画面主视图，从场景中最具代表性的角度拍摄，承载空间叙事与构图重心。

| 项目 | 约束 | 提示词 |
|---|---|---|
| 视角 | 自然观察视角，构图最能体现场景主体与纵深 | hero shot、representative angle |
| 视点高度 | 默认人眼平视高度，特殊场景可俯/仰 | eye level（默认） |
| 构图 | 主体居中或符合三分法，前/中/后景层次清晰 | balanced composition |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 单画面（非拼图、非多视图、非分屏） |
| 人物 | **严禁出现任何人物、人影、人体轮廓** |
| 一致性 | 风格/材质/色调/光线统一 |
| 光线 | 单一光源逻辑，光影方向一致 |
| 画面比例 | 默认 16:9（或按调用方设定） |

## 七、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 场景必须有「前中后景层次」 |
| R2 | 室外必须包含「空气透视」 |
| R3 | 场景图必须为「单画面主视图」，不得拼接多视图/分屏/网格 |
| R4 | 构图须能代表场景主体并展示前/中/后景层次 |
| R5 | 场景图中**严禁出现任何人物** |
| R6 | 必须包含东方奇幻关键词（Eastern fantasy / cel shading / fine brushstrokes） |
| R7 | 必须包含镜头光学特征（赛璐璐平涂 / 细腻线条 / 动漫渲染） |
| R8 | 材质必须带有自然磨损/岁月痕迹，禁止全新无瑕的"CG 感" |
| R9 | 奇幻设定元素（悬浮山/法光/灵泉）必须与场景融合，禁止生硬拼贴 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 背景纯白/纯黑/无场景 |
| X2 | 极端天候（暴风雨/雷电/暴雪，除非剧情需要） |
| X3 | 场景无纵深/无层次 |
| X4 | 植被/天候与季节矛盾 |
| X5 | 出现任何人物、人影、人体剪影或人体轮廓 |
| X6 | 画面被拼接成多视图/网格/分屏布局 |
| X7 | 3D 写实/CG 动画/卡通/游戏引擎质感（禁用 3D render、CGI、Unreal Engine、Unity 等词） |
| X8 | 材质过于干净完美、无任何使用痕迹与岁月感（避免"塑料感"） |
| X9 | 光照过于均匀平坦、无景深虚化、无镜头光学特征 |
| X10 | 西方奇幻场景（欧式城堡/哥特教堂/北欧等，继承 X3） |
| X11 | 赛博朋克/科幻/机械元素混入（继承 X3） |
