# 人物衍生资产生成 · 约束手册

---

## 一、叠加原则

1. **面容不变** — 叠加后五官必须与底模完全一致，禁止面容偏移
2. **姿态不变** — 保持底模自然站立姿态，禁止任何姿态/动作/体态变化
3. **逐层可控** — 每层独立描述，便于按层替换（换装不换妆）
4. **风格统一** — 所有服化元素服从东方奇幻美学体系
5. **质感不降** — 叠加后质感标准不低于底模
6. **纯服化范畴** — 仅叠加妆容/发型/服饰/配饰，禁止引入道具、场景、环境、动作

---

## 二、叠加层级

| 层级 | 内容 | 说明 |
|---|---|---|
| L0 | 底模 | 基础形象底模，不修改 |
| L1 | 妆容（决策层） | 先分析用户线索，再决策「素妆 / 轻妆 / 法纹妆」强度 |
| L2 | 发型造型 | 发髻/束发/编发 + 发饰 |
| L3 | 中衣/内搭 | 替换基础中衣 |
| L4 | 外衣/主服 | 道袍/法衣/劲装/礼服等 |
| L5 | 配饰 | 头饰/耳饰/项饰/腰饰/手饰 + 灵契印记 |

> **范畴边界**：人物衍生资产仅包含 L0–L5 层级（服化妆造），不包含道具（法器/灵珠/符箓等手持物）、场景环境（秘境/仙山/天象等）、姿态动作（御兽/施法/回眸等）。这些属于其他资产类型的范畴。

---

## 三、妆容约束（L1）

### L1 线索分析与妆容决策

| 步骤 | 处理内容 | 决策结果 |
|---|---|---|
| S1 | 提取用户线索：面部状态词、情绪词、强度词 | 形成妆容需求摘要 |
| S2 | 过滤非妆容线索：道具/场景/动作/姿态词不作为上妆依据 | 防止误判 |
| S3 | 匹配妆容风格矩阵并给出强度档 | 素妆 / 轻妆 / 法纹妆 |
| S4 | 生成最终 L1 提示词 | 只输出结论，不输出分析过程 |

### 线索到妆容映射

| 线索类型 | 典型线索 | L1 决策 |
|---|---|---|
| 无明显面部强调线索 | 仅服饰/发型变化 | 素妆（清透自然） |
| 轻微面部线索 | 浅笑、气色微提、清冷 | 轻妆（极淡） |
| 日常/修行线索 | 日常、外出、修行 | 素妆（自然清透） |
| 仪式/法事线索 | 大典、拜师、契约仪式 | 轻妆（精致） |
| 特殊身份线索 | 圣女、大祭司、妖妃 | 法纹妆（眉心/眼尾灵纹） |

> 判定原则：所有衍生资产都要有妆造；先看面部线索决定强度与风格，道具、场景、姿态变化不得单独抬高妆容强度。法纹妆必须克制，禁大面积图腾。

### 通用底肤（所有妆容共享）

| 项目 | 约束 | 提示词 |
|---|---|---|
| 质感 | 赛璐璐平涂、自然透亮 | 赛璐璐质感、自然光泽 |
| 白度 | 通透白皙、不惨白 | 白皙透亮、通透自然 |
| 禁项 | 哑光/死白/蜡感/油光/过曝 | — |

## 四、发型造型约束（L2）

| 造型 | 描述 | 适用 | 提示词 |
|---|---|---|---|
| 束发高马尾 | 高束干练 + 发带 | 御兽使、行动 | 束发马尾、干练利落 |
| 半扎云髻 | 发顶半扎 + 后方垂发 | 修仙者、日常 | 半扎云髻、自然垂发 |
| 高髻灵冠 | 高髻盘发 + 灵冠 | 圣女、大祭司 | 高髻灵冠、精致华美 |
| 披发如墨 | 长发全散、自然 | 夜战、私密 | 长发散落、如墨垂腰 |
| 编发灵饰 | 编发 + 灵珠发饰 | 灵兽驯师 | 编发精致、灵珠点缀 |

> 发饰材质以金银 + 珠玉 + 流苏为主，禁现代发饰。

> **🔍 未覆盖场景推断规则**
>
> 当用户描述的场景/情境不在上表时，根据本风格核心基因自行推断：
>
> | 推断维度 | 东方奇幻基因 |
> |---|---|
> | 妆容强度 | 默认素妆；有仪式/法事关键词→轻妆；有神性/妖异/契约关键词→法纹妆 |

> | 配饰繁度 | 日常→中等；神性/仪式→极繁；夜战/行动→简 |

## 八、四视图设定图规范

> 衍生服化叠加后仍需输出四视图设定图，确保服化妆造在各角度的一致性。

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 | 提示词 |
|---|---|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 面部至锁骨 | 面部占60%+，五官/妆容/法纹清晰 | portrait closeup、face detail |
| 左二 | 正视图 | 正面 0° | 全身立像 | 面对镜头、服饰正面全貌 | front view、height mark |
| 右二 | 侧视图 | 右侧 90° | 全身立像 | 纯侧面轮廓、服饰侧面层次 | side view、profile |
| 右一 | 后视图 | 后方 180° | 全身立像 | 后脑发饰/背部服饰/发尾清晰 | back view、rear view |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图 |
| 背景 | 月白纯色 #E8EAF5 |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂或微展（**禁止任何姿态变化**） |
| 光线 | 均匀柔光，前方主光 + 双侧补光，无硬阴影 |
| 一致性 | 四视图的面容/妆容/发型/服饰/配饰完全一致 |
| 画面比例 | 建议 4:1 或 3:1 |

## 十、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 叠加后面容必须与底模一致 |
| R2 | 服饰必须用「衣服质感清晰 + 赛璐璐平涂」 |
| R3 | 必须输出四视图设定图（人像特写+正视图+侧视图+后视图） |
| R4 | 必须指定「月白纯色背景」与「四视图一致性」 |
| R5 | **仅输出提示词**——禁止输出速查表/分层方案/约束/禁止事项等任何非提示词内容 |
| R6 | **禁止包含场景描述**——人物衍生资产不涉及场景/环境/天气，场景属于独立资产类型 |
| R7 | **禁止道具交互**——不包含任何手持物/交互物（法器/灵珠/符箓等），道具属于独立资产类型 |
| R8 | **姿态保持不变**——必须保持底模自然站立姿态，禁止任何动作/体态/姿势变化 |
| R9 | **L1 必须先分析再决策**——先解析用户面部线索，再确定妆容强度档 |
| R10 | **上妆强度受控**——法纹妆必须克制，禁大面积图腾/浓烈彩妆 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 叠加后面容偏移 |
| X2 | 复杂场景背景（必须纯色） |
| X3 | 四视图间服化妆造不一致 |
| X4 | 输出提示词以外的任何内容（表格/方案/建议/解释/变体等） |
| X5 | 在人物衍生资产中加入场景描述（秘境/仙山/雨雪/天象等环境元素） |
| X6 | 加入任何道具交互（手持法器/灵珠/符箓/御兽铃等物品） |
| X7 | 改变底模姿态（御兽/施法/行走/回眸/举手/奔跑等动作描述） |
| X8 | 未分析用户线索就直接套用固定妆容 |
| X9 | 西式造型/现代元素混入（继承 X3） |
| X10 | 大面积法纹图腾/现代纹身感，破坏东方审美 |
