# 人物基础形象生成 · 约束手册

---

## 一、基础形象原则

1. **身份可读** — 角色身份（御兽使/修仙者/降妖师/江湖客等）必须一眼可辨
2. **奇幻印记** — 可加入灵契印记、法纹、灵珠等奇幻元素作为身份锚点
3. **东方根基** — 服饰/发型/体态必须扎根东方古典审美，禁止西式造型
4. **二次元为锚** — 二次元标准比例，赛璐璐平涂 + 动漫渲染，拒绝3D写实/CG动画质感

---

## 二、面容约束

| 项目 | 约束 | 提示词 |
|---|---|---|
| 五官 | 二次元标准比例，精致清晰 | 二次元五官、精致细腻 |
| 眼睛 | 情绪表达核心，眼型随身份（御兽使温和、降妖师锐利） | 眉眼传神、眼神灵动 |
| 神采 | 东方古典气质 + 奇幻气韵 | 气质出尘、神采奕奕 |
| 表情 | 默认中性淡然，微表情符合身份 | 神色从容、微带英气 |

---

## 三、肤感约束

| 项目 | 约束 | 提示词 |
|---|---|---|
| 质感 | 赛璐璐平涂、自然透亮 | 赛璐璐质感、自然光泽 |
| 白度 | 通透白皙，不惨白 | 肤色白皙、通透自然 |
| 禁项 | 蜡感/死白/油光/过曝/写实质感 | — |

---

## 四、体型约束

| 项目 | 约束 | 提示词 |
|---|---|---|
| 比例 | 二次元标准比例，头身比 5-7 | 标准二次元比例 |
| 姿态 | 自然站立，双腿微分 | 自然站立、姿态端正 |
| 体态 | 身份相符（御兽使挺拔、术士清瘦） | {身份}身姿 |

---

## 五、基础发型约束

| 身份 | 发型倾向 | 提示词 |
|---|---|---|
| 御兽使 | 束发高马尾 / 编发 | 束发马尾、干练利落 |
| 修仙者 | 半扎发髻 / 长发 | 半扎云髻、长发如墨 |
| 降妖师 | 高束 + 发带 | 高束发、发带飘然 |
| 女性角色 | 长发 / 发髻 + 发饰 | 长发及腰、发饰精致 |

> 所有发型必须保持发丝清晰、线条细腻（细腻笔触继承 R4）。

---

## 六、基础服装约束

| 身份 | 基础款 | 提示词 |
|---|---|---|
| 御兽使 | 劲装 + 灵兽徽记 | 御兽劲装、灵兽徽记 |
| 修仙者 | 道袍 + 玉饰 | 素色道袍、玉饰佩身 |
| 降妖师 | 劲装 + 符带 | 劲装束袖、符带缠身 |
| 通用 | 东方古典剪裁 | 东方古风剪裁、纹理超清晰 |

> 服饰基础色以 C1 苍碧 / C6 月白 / C5 丹砂 等东方色为主，禁西式礼服/现代时装。

---

## 七、四视图设定图规范

### 视图定义

| 位置 | 视图 | 角度 | 景别 | 要求 | 提示词 |
|---|---|---|---|---|---|
| 左一 | 人像特写 | 正面平视 | 面部至锁骨 | 面部占60%+，五官/灵契印记清晰 | portrait closeup、face detail |
| 左二 | 正视图 | 正面 0° | 全身立像 | 面对镜头、服饰正面全貌 | front view、height mark |
| 右二 | 侧视图 | 右侧 90° | 全身立像 | 纯侧面轮廓、服饰侧面层次 | side view、profile、height mark |
| 右一 | 后视图 | 后方 180° | 全身立像 | 后脑发饰/背部服饰/发尾清晰 | back view、rear view、height mark |

### 画面规范

| 项目 | 约束 |
|---|---|
| 布局 | 同一画面从左至右并排四视图 |
| 背景 | 月白纯色 #E8EAF5 |
| 站姿 | 自然站立、双脚平行微分、双臂自然下垂或微展 |
| 光线 | 均匀柔光，前方主光 + 双侧补光，无硬阴影 |
| 一致性 | 四视图的面容/发型/服饰/配饰完全一致 |
| 画面比例 | 建议 4:1 或 3:1 |

{身份}，{整体气质}，{面容特征}，{发型描述}，
{服装描述}，{灵契印记/法纹/奇幻元素（如有）}，
四视图设定图（character design sheet），同一画面从左至右：人像特写+正视图+侧视图+后视图，

## 九、约束规则

### 必守

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「东方奇幻」风格锚定词（继承 R1） |
| R2 | 必须声明「赛璐璐平涂 + 动漫渲染」（继承 R2） |
| R3 | 身份必须一眼可读，造型服务于身份 |
| R4 | 服饰/发型必须东方古典根基，禁西式造型 |
| R5 | 必须输出四视图设定图（人像特写+正视图+侧视图+后视图） |
| R6 | 必须指定「月白纯色背景」与「四视图一致性」 |
| R7 | 奇幻元素（灵契印记/法纹）必须克制，服从整体东方审美 |

### 严禁

| 编号 | 严禁 |
|---|---|
| X1 | 写实摄影/3D 写实渲染/照片级真实感（继承 X1） |
| X2 | 西方奇幻造型（西式盔甲/斗篷/龙与地下城等，继承 X3） |
| X3 | 赛博朋克/科幻/过度现代造型（继承 X3） |
| X4 | 粗劣线条/模糊画质/低精度（继承 X4） |
| X5 | 高饱和荧光色/霓虹色大面积滥用（继承 X2） |
| X6 | 复杂场景背景（必须纯色背景） |
| X7 | 四视图间形象不一致 |
| X8 | 输出提示词以外的任何内容（表格/方案/解释等） |
