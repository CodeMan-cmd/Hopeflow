# 光影与氛围 · 东方奇幻约束手册

> **本画风以东方神话灵光 + 影视质感的光影为灵魂**：赛璐璐平涂叠加动漫渲染，天光、灵火、法光、妖气等东方奇幻光效承载意境，整体偏中性色温、东方神话色盘饱满而不艳俗。

---

## 一、光源方案

| 方案 | 光源特征 | 色块/层次建议 | 使用场景 | 提示词 |
|---|---|---|---|---|
| 仙山天光 | 柔和漫射天光，云雾通透 | C1 苍碧主导，低对比 | 仙山、秘境、晨修 | 天光漫射、苍碧通透、柔和赛璐璐 |
| 法阵灵光 | 符文辉光流动，蓝色主光 | C7 黛蓝 + C2 鎏金 | 法阵、结契、施法 | 灵光流动、符文亮起、玄奥辉光 |
| 妖雾幽光 | 幽暗妖气 + 冷焰点缀 | C3 绛紫 + C4 玄青 | 妖域、诡谲、潜伏 | 妖雾幽光、绛紫暗调、冷焰微亮 |
| 灵火/丹火 | 暖橘灵火，明暗层次分明 | C5 丹砂 + C2 鎏金 | 丹房、夜行、祭坛 | 灵火暖光、丹焰跃动、暖调层次 |
| 夜月清辉 | 靛蓝夜空 + 局部月光暖点 | C4 玄青 + C6 月白 + C2 鎏金点缀 | 夜战、月下、诗意 | 月色清辉、玄青夜空、局部灵光 |
| 灵雨蒙蒙 | 雨幕 + 灵光折射，通透湿润 | C1 苍碧 + C7 黛蓝过渡 | 秘境、灵泉、涤尘 | 灵雨如丝、水光莹润、通透清新 |

## 二、光比与明暗对比

| 维度 | 约束 | 说明 |
|---|---|---|
| 整体对比度 | 中高 50-70%（建议区间） | 奇幻光影层次，不做极端大光比 |
| 阴影 | 同色系加深 | 禁黑色硬阴影，禁色块断层（继承硬约束色） |
| 高光 | 平滑渐变高光 | 赛璐璐色块平滑过渡，禁色彩溢出 |
| 层次 | 明暗 3-4 级 | 亮部/中间/影部/灵光点缀逐级铺陈 |

---

## 三、色温约束（继承 prefix）

| 参数 | 值 |
|---|---|
| 整体色温 | 偏中性 5000-5600K（推荐） |
| 对比度 | 中高 50-70%（建议区间） |
| 饱和度 | 中高 55-75%（建议区间） |

> 色相偏移 ±8°、饱和度偏移 ±10%、明度偏移 ±12%。例外镜头（法阵/灵光高光时刻）可临时突破局部色彩，但不得突破严禁项。

## 五、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 每条提示词必须声明「东方奇幻」风格锚定词（继承 R1） |
| R2 | 必须声明「赛璐璐平涂 + 动漫渲染」（继承 R2） |
| R3 | 必须声明「细腻笔触 + 影视质感」（继承 R4） |
| R4 | 阴影必须为「同色系加深」，禁黑色硬阴影（继承硬约束色） |
| R5 | 必须绑定 1 个光源方案并指定主辅色 |
| R6 | 灵光/法光特效必须克制并带东方韵味，禁现代霓虹感 |

### 严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁高饱和荧光色/霓虹色/数码感光效（继承 X2） |
| X2 | 严禁写实摄影/3D 写实渲染/照片级光效（继承 X1） |
| X3 | 严禁西方奇幻/赛博朋克/过度现代光效（继承 X3） |
| X4 | 严禁色块断层/色彩溢出/黑色硬阴影（继承硬约束色） |
| X5 | 严禁色彩混乱/风格不统一的光氛围（继承 X5） |
