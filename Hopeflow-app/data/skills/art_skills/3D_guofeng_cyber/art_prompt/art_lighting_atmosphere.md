# 光影与氛围 · 约束手册

---

## 一、光影基调

1. **电影级顶级光影** — UE5/Blender Cycles 光线追踪渲染，全局光照+光线追踪反射+体积光+环境光遮蔽，氛围感拉满
2. **虚实相生** — 烟雨朦胧的体积光与全息投影交织，水墨意境与赛博光影层次融合
3. **中式低饱和霓虹** — 霓虹光效须取国风赛博专属色（朱砂红霓虹/石青蓝全息/鎏金辉光），杜绝荧光溢色
4. **典雅与未来感兼具** — 光色典雅克制，光影服务于东方美学内核，拒绝西式赛博的粗暴光污染

## 二、光源方案

| 编号 | 光源类型 | 作用 | 提示词 |
|---|---|---|---|
| L1 | 全局光照 | UE5 全局光照打底 | global illumination、全局光照 |
| L2 | 体积光 | 穿透雨雾/云层/屋檐的光柱 | 电影级体积光、光柱穿透雨雾 |
| L3 | 全息投影光 | 全息纹样/法阵/龙舟光效 | 全息投影、全息光影交织 |
| L4 | 中式霓虹光 | 朱砂红/石青蓝/鎏金霓虹点缀 | 朱砂红霓虹、石青蓝全息、鎏金辉光 |
| L5 | 轮廓光/背光 | 勾勒人物与飞檐轮廓 | 轮廓光、逆光勾勒 |
| L6 | 月光/环境光 | 冷调基底 + 环境光遮蔽 | 月光清辉、环境光遮蔽 |

## 三、光比与明暗对比

| 参数 | 约束值 | 说明 |
|---|---|---|
| 光比 | 中高光比、层次丰富 | 霓虹亮部与暗部对比分明但不灰蒙 |
| 对比度 | 中高，禁低对比灰蒙 | 禁「低对比度灰蒙画面」 |
| 阴影 | 暗部带墨黑/靛蓝色相 | 环境光遮蔽自然，禁死黑无细节 |
| 高光 | 鎏金辉光点缀 | 霓虹反光、金属高光，禁溢色 |
| 反射 | 光线追踪反射 | 水面/琉璃/金属倒影霓虹光影 |

## 六、必守

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「电影级体积光 + 环境光遮蔽 + 全局光照」 |
| R2 | 必须包含「光线追踪」渲染光效（UE5/Blender Cycles） |
| R3 | 霓虹光效必须为「中式低饱和」色，杜绝荧光溢色 |
| R4 | 必须体现「虚实相生：水墨意境 + 赛博光影」 |
| R5 | 光色取自国风赛博专属色盘（青绿/朱红/靛蓝/鎏金/墨黑） |

## 七、严禁

| 编号 | 严禁 |
|---|---|
| X1 | 写实摄影/真人照片级打光 |
| X2 | 纯西方赛博朋克霓虹光污染（无国风内核） |
| X3 | 过度饱和荧光色/高溢色/强数码噪点 |
| X4 | 低对比度灰蒙画面/死黑无细节 |
| X5 | 光影错误/穿模/透视错误 |
| X6 | 现代都市日常光源（无中式元素） |
