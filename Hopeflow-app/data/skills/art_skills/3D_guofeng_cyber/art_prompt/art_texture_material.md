# 材质与质感 · 约束手册

---

## 一、渲染质感描述

1. **8K 高精度模型** — 次世代游戏级别拓扑，模型细节纤毫毕现，杜绝低精度/粗糙拓扑
2. **4K 超清 PBR 物理材质** — 金属/织物/玉石/全息材质质感拉满，物理属性反馈光照
3. **国风材质内核** — 榫卯结构、暗纹刺绣、鎏金包边、玉石通透，中式工艺与赛博机能拼接
4. **全息质感** — 全息投影纹样/光效材质，虚实相生，与实体材质叠加层次

---

## 二、材质锚词清单

| 部位 | 锚词（中） | 锚词（英） |
|---|---|---|
| 金属 | 鎏金质感、机械金属光泽 | gold metal texture、mechanical sheen |
| 玉石 | 玉石通透、翡翠质感 | jade translucency、jadeite |
| 织物 | 暗纹刺绣、机能拼接面料 | embroidery texture、tech-fabric |
| 全息 | 全息投影纹样、流光材质 | holographic projection、light-flow |
| 木构 | 榫卯结构、木纹细节 | mortise-tenon structure、wood grain |
| 面部 | 皮肤质感细腻通透、东方古典骨相 | delicate skin、eastern features |
| 发丝 | 发丝根根分明、机械发饰 | hair strands、mechanical hairpin |

---

## 三、画质硬约束

| 参数 | 硬约束 |
|---|---|
| 分辨率 | 8K 高精度模型 + 4K 超清 PBR 材质 |
| 建模精度 | 次世代游戏级别拓扑，禁止低精度模型 |
| 材质体系 | 必须声明 PBR 物理材质渲染 |
| 纹理 | 纹理清晰可辨、细节纤毫毕现 |
| 光照反馈 | 全局光照、光线追踪反射、环境光遮蔽 |
| 色彩 | 国风赛博专属色盘（青绿/朱红/靛蓝/鎏金/墨黑） |

---

## 四、必守

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「8K 高精度模型 + 4K 超清 PBR 物理材质」 |
| R2 | 必须声明「次世代高精度建模 + 纹理清晰」 |
| R3 | 材质锚词至少选用金属/玉石/织物/全息中两类 |
| R4 | 必须体现「国风内核 + 赛博机能」材质融合 |
| R5 | 必须声明「细节拉满 + 质感真实」画质锚定词 |

## 五、严禁

| 编号 | 严禁 |
|---|---|
| X1 | 写实摄影/真人照片级真实感材质 |
| X2 | 低精度模型/粗糙拓扑/贴图模糊/穿模 |
| X3 | 塑料质感/无质感/材质失真 |
| X4 | 过度饱和荧光色/高溢色材质 |
| X5 | 无中式元素的纯科幻机械材质 |
| X6 | 西式建模脸/畸形人体/夸张违和比例 |
