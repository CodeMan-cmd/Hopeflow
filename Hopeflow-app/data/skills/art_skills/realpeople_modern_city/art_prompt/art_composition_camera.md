# 构图与镜头 · 约束手册（真人都市影像）

> 画质不取决于渲染分辨率，取决于「摄影机怎么在场」。固定机位让时间自己说话、手持微晃带进呼吸、斯坦尼康完成都市漫游的诗意、长焦窥视把人物从人群中剥离——这是摄影机语法，不是镜头引擎。

---

## 一、景别体系

| 景别 | 叙事功能 | 真人都市特征 |
|---|---|---|
| 大特写 | 情绪爆发点 | 眼神、手指微动、泪珠、手机屏幕 |
| 近景 | 情感凝视 | 面部微表情、肩部以上 |
| 中近景 | 互动与对话 | 腰部以上，兼顾表情与手势 |
| 中景 | 人物关系 | 全身入画，人物与环境共存 |
| 全景 | 环境氛围 | 人物占比较小，空间叙事为主 |
| 空镜 | 情绪缓冲 | 无人物，城市景观留白 |

## 二、镜头焦段（镜头性格）

| 焦段 | 叙事性格 | 典型应用 |
|---|---|---|
| 24-28mm 广角 | 环境吞噬人物、空间疏离 | 都市空镜、人群中的孤独 |
| 35mm 小广角 | 主观视点、纪实感 | 街头跟随、日常行走 |
| 50mm 标准 | 人眼等价、客观注视 | 肖像、双人对话、情感凝视 |
| 85mm 中长焦 | 压缩空间、背景虚化 | 特写、偷窥视角、街对面望见 |
| 135mm+ 长焦 | 极端压缩、窥视感 | 城市中隔离的个体、远眺 |

## 三、机位与运动（摄影机语法）

| 手法 | 视觉心理 | 使用场景 |
|---|---|---|
| 固定机位 | 冷静、观察 | 日常场景、对话、空镜留白 |
| 手持微晃 | 在场感、呼吸感 | 情绪波动、街头行走、亲密跟随 |
| 稳定器/斯坦尼康 | 优雅流动、都市漫游 | 人物登场、空间展示、过渡 |
| 俯拍 | 命运感、渺小 | 城市俯瞰、结局回望 |
| 仰拍 | 压迫或崇高 | 摩天楼压迫、人物力量感 |
| 焦点偏移 | 注意力转移、关系改变 | 对视时焦点游移、揭示信息 |

## 四、构图法则

| 法则 | 应用 |
|---|---|
| 三分法 | 人物置于交点，都市背景留白 |
| 框架构图 | 门框/车窗/百叶窗/楼梯井套住人物 |
| 引导线 | 街道纵深、玻璃反射、轨道延伸牵引视线 |
| 倒影 | 雨后地面、玻璃幕墙反射的多层空间 |
| 前景遮挡 | 人群虚化前景、植物/栏杆隔出窥视感 |

## 五、镜头语言

- 推：从街景推入人物近景，孤独感放大
- 拉：人物转身汇入人流，镜头拉开留白
- 跟：手持跟随行走，纪实在场感
- 焦点偏移：前景路人虚化 → 主角清晰，叙事重心转移
- 剪影：蓝调时刻/逆光下人物轮廓化，克制的告别

## 七、必守规则

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影/真人实拍」为锚，杜绝"计算机生成感" |
| Q1 | 必须声明摄影机在场方式：固定注视/手持呼吸/稳定器流动/长焦窥视 |
| Q2 | 景深必须有叙事意图，焦点偏移引导注意力 |
| Q3 | 高光不过曝死白、暗部不死黑无层次 |
| Q4 | 必须声明颗粒质感：35mm胶片颗粒 / 数字摄影干净锐利 |
| P8 | 必须指定具体当代中国都市空间，拒绝无国别架空都市 |
