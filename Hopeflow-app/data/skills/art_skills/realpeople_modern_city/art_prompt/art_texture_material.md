# 材质与质感 · 约束手册（真人都市影像）

> 质感来自「胶片对光的记录」，不是材质贴图。皮肤毛孔在 85mm 镜头下清晰可数、风衣领口有穿过一冬的痕迹、玻璃反射里叠着城市的第二层空间——一切质感都以"摄影机拍到过"为准，拒绝任何渲染词汇。

---

## 一、摄影质感描述（以摄影机与胶片说话）

| 质感域 | 摄影表达 | 禁止的渲染表达 |
|---|---|---|
| 皮肤 | 毛孔、细纹、痣、自然肤色不均 | 光滑、磨皮、零毛孔蜡像 |
| 发丝 | 被风吹乱、被雨打湿、碎发自然 | 建模整齐发块、假发感 |
| 面料 | 垂坠与摩擦痕迹、轻微起球、领口变形 | 无缝贴图、完美样板衣 |
| 环境 | 桌面散落、墙面生活痕迹、地面不完美 | 样板间、出厂新物 |
| 颗粒 | 35mm 胶片颗粒（细腻不规则） | 数字噪点爆炸、伪影 |

## 二、材质锚词清单（可直接注入提示词）

| 材质 | 中文锚词 | 英文锚词 |
|---|---|---|
| 玻璃幕墙 | 反射多层空间、天空倒影 | glass reflections, layered reflections |
| 混凝土/水泥 | 米灰/冷灰、水渍青苔斑痕 | concrete texture, weathering |
| 沥青路面 | 雨后镜面反射 | wet asphalt, mirror reflections |
| 金属/不锈钢 | 冷银灰、拉丝、氧化划痕 | brushed metal, oxidation |
| 针织/棉麻 | 绒感、肌理、垂坠 | knit texture, cotton texture |
| 皮质 | 纹路、使用折痕 | leather grain, creases |
| 屏幕玻璃 | 反光、指纹、灰尘 | screen glare, fingerprints |

> 材质色值锚定城市材料色谱：玻璃幕墙青灰→深蓝、混凝土米灰→雨后深灰、红砖赭红→暗砖红、行道树春新绿→秋焦糖。

## 三、画质硬约束

| 编号 | 约束 |
|---|---|
| H1 | 皮肤必须「真人毛孔可见」，禁磨皮/蜡像/塑料感/AI假面 |
| H2 | 发丝自然状态优先，禁建模感整齐发块 |
| H3 | 服饰必须有"穿过"痕迹：褶皱、起球、领口变形、裤脚磨损 |
| H4 | 场景必须有"被使用过"的证据，禁样板间 |
| Q4 | 必须声明颗粒质感偏好：35mm 胶片颗粒 / 数字摄影干净锐利 |

## 四、必守规则

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影/真人实拍」为锚——画面读作"摄影机拍下的" |
| P3 | 皮肤保留真实质感，杜绝塑料磨皮与 AI 感假面 |
| P4 | 发丝呈现自然状态，杜绝建模感整齐发块 |
| P5 | 服饰体现"穿过"的痕迹，杜绝全新样板衣感 |
| P6 | 场景有"被使用过"的证据，杜绝样板间 |

## 五、严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁 CG 术语：3D渲染/CG/UE/Blender/次世代建模/PBR材质/体积光/环境光遮蔽（AO） |
| X2 | 卡通/插画/动画/二次元质感（赛璐璐色块、描边） |
| X3 | 过度磨皮/塑料假人感/零毛孔蜡像脸/AI感假面/对称僵笑 |
| X4 | 全新道具感、样板间感、无生活痕迹 |
| X5 | 低分辨率/模糊/噪点爆炸/严重伪影/抠图白边/拼接断层 |
