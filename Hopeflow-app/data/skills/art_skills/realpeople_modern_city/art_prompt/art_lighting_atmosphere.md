# 光影与氛围 · 约束手册（真人都市影像）

> 光不是"打上去的"，是"从城市里长出来的"。晨光从地铁口斜射、金色时刻镀上写字楼玻璃、蓝调时刻的天空比路灯更亮、屏幕光在深夜照亮半张脸。本画风用光与摄影机说话，不用渲染引擎——光必须有出处、有方向、有色温，画面必须读作"摄影机拍下的"。

---

## 一、光源方案（城市光源色谱）

| 编号 | 光源 | 色温（K） | 光色特征 | 都市场域 |
|---|---|---|---|---|
| L1 | 晨光（日出后1h） | 3500-4500 | 低角度暖金漫射、薄雾扩散 | 早班地铁、早餐摊热气 |
| L2 | 上午天光 | 5500-6000 | 冷白清澈、阴影锐利 | 写字楼玻璃反射、通勤人流 |
| L3 | 金色时刻（日落前1h） | 2800-3500 | 珍贵暖调、长阴影、材质镀金边 | 一切温情与回忆段落首选 |
| L4 | 蓝调时刻（日落后20min） | 8000-10000 | 深邃蓝紫、城市灯光弱于天光 | 独处、内心独白、尾声 |
| L5 | 街灯（高压钠灯/LED） | 2000-2200 / 4000-5000 | 暖橙黄 vs 冷白，城市夜晚的两种体温 | 老城巷弄、新城区高架 |
| L6 | 屏幕光（手机/电脑/广告屏） | 变化（冷蓝/暖白） | 面光照亮一侧脸颊，孤独的陪伴者 | 独处时刻、失眠、深夜便利店 |

> 光源规则：每镜必选一个主光源并说清"光从哪来"；霓虹/招牌光仅作背景环境光，禁作主光直射人物。

## 二、光比与明暗对比

| 参数 | 约束 | 说明 |
|---|---|---|
| 对比度 | 电影级强反差（可局部） | 高光滚落柔和、暗部不压死 |
| 高光 | 不过曝死白 | ARRI/Sony Venice 色彩科学的柔和高光 |
| 暗部 | 有层次不纯黑 | 夜景保留暗部细节，禁死黑 |
| 人面光比 | 主光:环境光自洽 | 光源方向、色温、软硬须物理自洽 |

## 三、色调情绪与画面关键词

| 情绪场景 | 光的配方 | 画面关键词 |
|---|---|---|
| 清晨启程 | 晨光45°斜入 + 薄雾漫射 | 通透、希望、安静、蓄势 |
| 职场日常 | 窗光为主 + 屏幕冷光补面 | 秩序、专注、克制、疏离 |
| 暧昧靠近 | 暖光源侧光 + 暗部保留细节 | 温度、距离消融、未说出口的话 |
| 雨夜独行 | 湿地面反射街灯 + 雨幕散射 | 孤独、沉思、城市与个体的关系 |
| 深夜脆弱 | 单光源孤岛式照明 | 脆弱、真实、卸下伪装 |
| 告别时刻 | 逆光剪影 + 蓝调时刻天空 | 不舍、释然、一个篇章的结束 |

## 四、必守规则

| 编号 | 规则 |
|---|---|
| P1 | 必须以「真人摄影/真人实拍」为锚，画面读作"摄影机拍下的" |
| P2 | 必须指定光源出处、方向、色温、软硬（窗/灯/天空/屏幕） |
| P3 | 必须从城市光源色谱取光（晨光/金色时刻/蓝调时刻/街灯/屏幕光等） |
| Q3 | 高光不得过曝死白、暗部不得死黑无层次 |
| Q5 | 色彩调性与情绪匹配：温暖不溢色、冷冽不灰败 |

## 五、严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 严禁一切 CG 术语：3D渲染/CG/UE/Blender/次世代建模/PBR材质/体积光/环境光遮蔽（AO） |
| X2 | 卡通/插画/动画/二次元光效 |
| X3 | 荧光色/霓虹溢色/电子合成色/高饱和廉价色调 |
| X4 | 无源均匀光、全局亮、说不清光从哪来 |
| X5 | 古风/古装/汉服等非当代都市光环境；仙侠玄幻发光体 |
