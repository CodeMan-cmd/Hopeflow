# 光影与氛围 · 约束手册（真人古风写实）

> 古风光影以「自然烛火与天光」为唯一光源逻辑，拒绝现代灯光语言。所有光都必须说得出出处：窗棂透光、烛台暖光、夕照金边、月华清辉。整体遵循「冷中带暖、疏中见密」——冷色铺底，暖光只落在人物关系焦点。

---

## 一、光源方案（按场景与情绪取用）

| 编号 | 光源 | 色温区间 | 光质特征 | 适用场景 |
|---|---|---|---|---|
| L1 | 天光（昼） | 5800-7000K | 冷白漫射、纱幔/窗棂柔化、阴影柔和 | 初见、庭院对坐、室内晨读 |
| L2 | 夕照（C7 琥珀暖） | 2800-3500K | 低角度暖金、长影、轮廓镀金边 | 黄昏重逢、廊下相望、离别回望 |
| L3 | 烛光 | 1800-2200K | 点状暖光源、火苗明灭、暗部浓重 | 暧昧升温、夜谈耳语、独处心事 |
| L4 | 月光（C1 月白/C6 青黛） | 7500-9000K | 冷青清辉、漫射无影、疏离诗意 | 分离误会、窗边思念、月下独步 |
| L5 | 灯会/夜宴流光 | 暖 2800K 主导 | 暖光源主导、背景冷色托举、灯笼点点 | 夜宴、灯会、人潮中对视 |

> 光源使用规则：单镜头主光源不超过 1 个（灯会/夜宴可多灯位叠加）；所有光源必须有物理出处，严禁"全局均匀亮"的无源光。

## 二、光比与明暗对比

| 参数 | 约束 | 说明 |
|---|---|---|
| 对比度 | 强（必守 R2） | 明暗反差鲜明，剪影与高光并存 |
| 高光 | 不过曝死白 | 珠光金/肤光保留滚落层次 |
| 暗部 | 不压死无层次 | 墨玉黑中仍可辨衣纹与轮廓 |
| 人面光比 | 主光:补光 ≈ 3:1 | 古典仕女画式柔润，禁舞台式硬反差 |

## 三、色温范围（对齐 prefix 全局色彩盘）

| 维度 | 基准 | 说明 |
|---|---|---|
| 整体色温 | 偏冷 5800-7000K | 清冷仙气主基调 |
| 肤色色温 | 微暖 5200-5600K | 冷白但有生命感 |
| 暖光落点 | C7 琥珀暖 #C9A96E | 烛光/夕照/灯会统一使用 |
| 冷光落点 | C1 月白 #D6E4EC / C6 青黛 #4A6670 | 天光/月光/远景 |

## 四、色调情绪与画面关键词

| 情绪场景 | 光配方 | 画面关键词 |
|---|---|---|
| 初见心动 | 天光冷底 + 局部烛暖高光 | 清冷、呼吸感、微甜 |
| 暧昧升温 | 烛光近景、背景降饱和 | 软焦、耳语感、贴近 |
| 分离误会 | 月光冷青、阴影加深 | 距离感、克制、静压 |
| 重逢释怀 | 夕照暖光渐进、湿润空气 | 回温、释然、湿润 |
| 大婚喜庆 | 烛火+珠光金暖调（禁荧光红） | 华贵、庄重、甜喜 |
| 夜宴灯会 | 灯笼暖光 + 夜色冷托举 | 流光、灯影、人潮中对视 |

## 五、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「真人写实摄影」锚定词 + 指定光源出处（窗/烛/月/夕照/灯会） |
| R2 | 必须声明「强对比度 + 极致细节」 |
| R3 | 冷中带暖：冷色铺底，暖光（C7）只落人物关系焦点 |
| R4 | 高光保留滚落、暗部保留衣纹细节，禁过曝死白与死黑 |
| R5 | 夜戏暖光源主导时，背景以冷色（C6 青黛）托举 |

## 六、严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 卡通/动漫/二次元/插画光效（轮廓光描边、赛璐璐色块） |
| X2 | 高饱和荧光色/霓虹灯效/电子屏幕光 |
| X3 | 现代光源入镜（电灯/路灯/LED/车灯/手机屏） |
| X4 | 过度磨皮塑料感、蜡像脸（光越柔越要保留皮肤纹理） |
| X5 | 无源均匀光、舞台追光式生硬光斑 |
