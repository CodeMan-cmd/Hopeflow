# 材质与质感 · 约束手册（真人古风写实）

> 质感来自「摄影机的光学记录」，不是渲染引擎的材质贴图。皮肤要看得到毛孔与绒毛、绸缎要看得到经纬反光、木器要看得到包浆与划痕——一切材质都必须"被穿过、被用过、被时间抚摸过"。

---

## 一、摄影质感描述（替代渲染术语）

| 质感域 | 摄影表达 | 禁止的渲染表达 |
|---|---|---|
| 皮肤 | 可见毛孔、绒毛、自然血色、微瑕 | 光滑、完美皮肤、蜡像质感 |
| 发丝 | 根根分明、受光面与背光面层次 | 建模发块、塑料发片 |
| 面料 | 经纬纹理、褶皱符合身体动态与重力 | 无缝贴图、完美垂坠 |
| 环境 | 墙面斑驳、地面磨损、器物使用痕迹 | 全新样板间、出厂新物 |
| 金属 | 氧化、包浆、手工痕迹、划痕 | 纯镜面反射、CG高光点 |

## 二、材质锚词清单（可直接注入提示词）

| 材质 | 中文锚词 | 英文锚词 |
|---|---|---|
| 丝绸 | 缎面光泽、丝质反光、垂坠顺滑 | silk sheen, flowing fabric |
| 刺绣 | 金线绣纹、针脚细密、珠光金 | gold embroidery, fine stitches |
| 纱/幔 | 纱质轻薄、半透光、飘动 | sheer gauze, translucent veil |
| 玉器 | 温润半透、油脂光泽 | jade, warm translucent luster |
| 金银器 | 珠光金/霜雪银、錾刻纹 | gold/silver ornaments, engraved |
| 木作 | 木纹、包浆、漆面岁月痕 | wood grain, patina |
| 瓷器 | 釉面温润、开片细纹 | porcelain, crackle glaze |

> 材质色值锚定：暖光材质用 C7 琥珀暖 #C9A96E、C3 珠光金 #E8D5B0；冷光材质用 C8 霜雪银 #C0C7CE、C6 青黛 #4A6670。

## 三、画质硬约束

| 编号 | 约束 |
|---|---|
| H1 | 皮肤必须「毛孔级真实」：细腻但保留纹理，禁磨皮/蜡像/塑料感 |
| H2 | 发丝必须「根根分明 + 发丝细腻渲染」（R4） |
| H3 | 面料/器物/墙面必须「纹理细节超清晰」（R5） |
| H4 | 古风器物须有岁月感：包浆、磨损、手工痕迹，禁崭新道具感 |
| H5 | 严禁 AI 感：过度锐化、塑料光泽、对称完美、无呼吸感 |

## 四、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「真人写实摄影」锚定词 |
| R2 | 必须声明「强对比度 + 极致细节」 |
| R3 | 面部必须「面容细腻渲染 + 皮肤细腻」且保留毛孔微质感 |
| R4 | 服饰必须指定真实材质锚词（丝绸/刺绣/纱/棉麻等），禁无质感色块 |
| R5 | 环境必须带使用痕迹，禁样板间式干净 |

## 五、严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 卡通/动漫/插画质感（赛璐璐色块、描边、平面贴图感） |
| X2 | 高饱和荧光色/霓虹材质（荧光纱、发光刺绣） |
| X3 | 现代材质入镜（塑料制品、不锈钢、人造革、电子屏反光） |
| X4 | 过度磨皮塑料感、零毛孔蜡像脸、AI 假面 |
| X5 | 纯镜面反射/金属 CG 高光/无来源的辉光 |
