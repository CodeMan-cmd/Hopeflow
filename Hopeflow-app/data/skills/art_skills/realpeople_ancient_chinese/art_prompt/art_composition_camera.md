# 构图与镜头 · 约束手册（真人古风写实）

> 古风镜头以「摄影机的凝视」替代「渲染器的取景」——固定机位等人物入画、长焦窥视隔着花窗、焦点偏移在两人之间游移。构图服务于「疏中见密」：画面留白疏朗，人物关系却近在咫尺。

---

## 一、景别体系

| 景别 | 叙事功能 | 古风特征 |
|---|---|---|
| 大特写 | 情绪爆发点 | 眼波、指尖、泪珠、玉佩轻晃 |
| 近景 | 情感凝视 | 面部微表情，强调心动与克制 |
| 中近景 | 互动与试探 | 腰部以上，袖口相触、并肩而行 |
| 中景 | 人物关系与空间 | 廊柱、花窗界定两人的距离 |
| 全景 | 环境氛围 | 庭院、长街，人物疏落其中 |
| 空镜 | 情绪缓冲 | 无人物，纱幔、烛火、檐角雨丝 |

## 二、机位与视角（摄影机语法）

| 手法 | 视觉心理 | 古风使用场景 |
|---|---|---|
| 固定机位 | 冷静观察、让时间说话 | 庭院对坐、品茶博弈、空镜留白 |
| 手持微晃 | 在场感、情绪介入 | 奔跑追逐、情绪起伏、慌乱心动 |
| 长焦窥视 | 拉近情感、隔景偷看 | 隔着花窗/廊柱望见对方 |
| 俯拍 | 命运感、克制疏离 | 檐下独坐、低头垂眸、结局回望 |
| 仰拍 | 尊崇或压迫 | 登楼望月、高门府邸、人物力量感 |
| 焦点偏移 | 注意力转移、关系变化 | 对视时焦点游移、揭示隐藏物件 |

## 三、构图法则

| 法则 | 应用 | 提示词示例 |
|---|---|---|
| 三分法 | 人物置于交点，留出呼吸空间 | 三分法构图、人物居画面右侧 |
| 对称 | 宫殿/府邸正门、仪式感 | 对称构图、中轴对称 |
| 框架构图 | 花窗/廊柱/纱幔/门框套住人物 | 以花窗为前景框架 |
| 留白写意 | 疏中见密，大面积留白衬人物 | 大面积留白、人物疏落 |
| 对角线 | 阶梯、回廊、视线牵引 | 斜线构图、回廊纵深 |

## 四、镜头语言

- 推：从全景推至近景，情绪从疏到密
- 拉：人物转身离去，镜头拉开留白
- 摇：横摇扫过庭院/长街，交代空间关系
- 焦点偏移：前景纱幔虚化 → 人物清晰，暧昧递进
- 剪影：逆光夕照/烛火前，人物轮廓化，含蓄藏情

## 五、中文提示词模板

```
真人写实摄影，古风写实纪实，强对比度，极致细节，
{景别}，{机位手法}，{构图法则}，
{光源出处与色温，如：窗棂透入的天光，冷调基底}，
{人物关系与情绪}，冷中带暖、疏中见密，
浅景深/深景深（按叙事选择），前景{纱幔/花窗/廊柱}虚化，
画面留白{比例}，{场景空间描述}，
面容细腻渲染，皮肤细腻，发丝根根分明，纹理细节超清晰
```

## 六、必守规则

| 编号 | 规则 |
|---|---|
| R1 | 必须声明「真人写实摄影」锚定词 + 指定景别与机位 |
| R2 | 必须声明「强对比度 + 极致细节」 |
| R3 | 构图须体现「疏中见密」：留白/框架/对称至少择一 |
| R4 | 机位须有叙事意图：固定/手持/长焦窥视/俯仰拍/焦点偏移择一 |
| R5 | 画面严禁文字/水印/LOGO，保证可直用 |

## 七、严禁项

| 编号 | 严禁 |
|---|---|
| X1 | 卡通/动漫/二次元分镜感（广角夸张透视、鱼眼畸变、Q版比例） |
| X2 | 现代机位语言（无人机航拍、GoPro 视角、监控视角） |
| X3 | 现代元素入镜（电线杆/广告牌/现代建筑出现在画面） |
| X4 | 人物面部变形/多指/肢体异常 |
| X5 | 人物正对镜头僵硬摆拍、对称傻站（须自然重心偏移） |
