# 田园治愈 · 导演叙事手法技能包

## 简介

本技能包为 **田园治愈** 类型故事提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。适用于任何视觉风格。

## 核心理念

- **慢节奏** — 时间是治愈的载体，画面允许留白，日常细节值得被好好观看
- **日常的诗意** — 平凡琐事拍出美感：炊烟、劳作、饭菜、黄昏，生活本身就是最好的剧本
- **邻里人情** — 人情温暖是治愈的核心，一顿饭、一次帮忙、一句问候都是治愈的剂量
- **治愈情绪曲线** — 从低谷到释然：逃离 → 适应 → 疗愈 → 和解，情绪缓坡而上，不急于到达

## 技能文件说明

### 1. 叙事规划手法 (`director_planning_narrative.md`)

导演在 **叙事规划阶段** 使用的技法参考，定义田园治愈在主题立意、节奏结构、治愈情绪设计与声音方向上的整体规划方法。

| 章节 | 内容概要 |
|---|---|
| 主题立意与情感内核 | 回归本真、烟火气、微小幸福、慢不是拖 |
| 叙事结构与节奏规划 | 四季循环、日常碎片串珠、治愈情绪曲线、呼吸感 |
| 分场景情绪设计 | 抵达/晨起/劳作/邻里/夜独/和解六大段落、食物与手部镜头 |
| 声音与音乐方向 | 自然声为主、人声烟火气、舒缓民谣、低覆盖率 |
| 构图与景别叙事 | 横幅田园大远景、暖色调、框景、俯视烟火 |
| 镜头运动与节奏 | 极缓慢运动、固定机位长镜、跟拍日常行走 |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)

导演在 **分镜表制作阶段** 使用的技法参考，定义田园治愈在分镜表中的景别选择、运镜节奏、时长把控、镜头合并与转场逻辑。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 分镜表作为镜头语言核心工具的定位说明 |
| 景别选择 | 大远景治愈底色、手部特写烟火气、餐桌俯拍、定场精简 |
| 运镜节奏 | 固定机位为主、极缓慢运动、跟拍日常行走 |
| 时长把控 | 日常镜头从容时长、空镜价值、黄金 6 秒规则 |
| 镜头合并策略 | 去 AI 感、劳作连续动作合并、日常碎片整合 |
| 一镜到底 | 厨房到院子的日常动线、田间归途、标注方式与风险 |
| 人物互动设计 | 生活化动作、单镜头动作限制、邻里互动分寸 |
| 台词与留白 | 家常对话、留白给风景、温情旁白 |
| 转场设计 | 自然元素转场、四季更替、淡入淡出 |

## 使用方式

本技能包作为 Hopeflow 导演 AI 的叙事手法参考，在故事创作流程中自动加载，指导：

1. **叙事规划** — 确定治愈内核、四季节奏、场景情绪与音乐方向
2. **分镜表生成** — 根据叙事规划输出具体的景别、运镜、时长与转场方案

两个文件分工明确、逐层递进，从"为什么这样拍"到"具体怎么拍"形成完整闭环。
