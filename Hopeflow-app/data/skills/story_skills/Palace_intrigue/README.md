# 宫斗权谋 · 导演叙事手法技能包

## 简介

本技能包为 **宫斗权谋** 类型故事提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。适用于任何视觉风格。

## 核心理念

- **人心博弈** - 宫斗的战场不在朝堂在后宫，不在刀剑在人心。每一次请安、每一次送礼、每一次示弱都是博弈的一步棋，叙事张力来自"看不见的交锋"
- **步步为营** - 宫斗权谋的叙事节奏如同下棋，每一步都为下一步铺路。没有废笔，每个细节都是布局的一部分，伏笔的连锁回收制造"原来如此"的震撼
- **笑里藏刀** - 宫斗的核心美学是"看不见的刀"。最致命的攻击藏在最温柔的笑容里，最危险的对手永远是最恭顺的姿态，台词与行为的表里落差就是戏剧张力
- **权力更迭** - 宫斗的终极叙事不是"谁赢了"而是"权力如何转移"以及"赢家付出了什么代价"。每一次权力更迭都伴随人性的异化与牺牲

## 技能文件说明

### 1. 叙事规划手法 (`director_planning_narrative.md`)

导演在 **叙事规划阶段** 使用的技法参考，定义宫斗权谋在主题立意、权力博弈、悬念节奏、场景氛围与声音方向上的整体规划方法。

| 章节 | 内容概要 |
|---|---|
| 主题立意与权谋内核 | 权力即人性、表面恭顺暗藏杀机、利益驱动、笑里藏刀、赢家代价 |
| 叙事结构与博弈节奏 | 布局破局反杀循环、信息即权力、联盟与背叛、紧松更紧节奏、伏笔回收 |
| 分场景氛围设计 | 六大典型宫斗段落设计、空间即等级、道具即暗语、隐藏式镜头意图 |
| 声音与音乐方向 | 古典器乐主导、寂静即压迫、环境音暗示、琵琶即杀机、音乐情绪模型 |
| 构图与景别叙事 | 对称秩序感、景别信息操控、大特写证据放大、门框内外之别 |
| 镜头运动与节奏 | 缓推窥探、正反打博弈、环绕围困、突然静止、运镜即权力关系 |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)

导演在 **分镜表制作阶段** 使用的技法参考，定义宫斗权谋在分镜表中的景别策略、运镜逻辑、时长把控、博弈分镜设计与转场手法。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 分镜表作为权力博弈可视化设计核心工具的定位说明 |
| 景别选择 | 全景殿堂等级、中景对话博弈、近景微表情、特写道具线索 |
| 运镜节奏 | 缓推窥探、正反打博弈、环绕围困、突然静止、跟拍命运 |
| 时长把控 | 铺垫蓄力、反转瞬间、沉默博弈、节拍控制、道具特写计时 |
| 博弈分镜设计 | 对话对决、道具暗示、空间权力、反转镜头、信息差分镜 |
| 多人场景调度 | 朝堂群戏、后宫站位、视线交织、焦点转移 |
| 台词与留白 | 弦外之音、未说完的话、沉默即表态、旁白功能、称呼即权力 |
| 转场设计 | 场景等级切换、时间压缩、道具转场、蒙太奇并列对比 |

## 使用方式

1. **叙事规划阶段** - 加载 `director_planning_narrative.md`，在构思主题立意、设计博弈节奏、规划场景氛围与声音方向时参考对应章节
2. **分镜表制作阶段** - 加载 `director_storyboard_table_narrative.md`，在确定景别、运镜、时长、转场等分镜细节时参考对应章节
3. **组合使用** - 两份文件互为补充：规划文件提供宏观叙事方向，分镜文件提供微观执行技法。建议先读规划文件确定整体方向，再用分镜文件指导具体镜头设计
4. **风格适配** - 本技能包聚焦宫斗权谋的叙事手法，不限定视觉风格。可与任意美术风格（写实、国风、二次元等）组合使用
