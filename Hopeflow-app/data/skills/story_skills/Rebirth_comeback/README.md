# 重生逆袭 · 导演叙事手法技能包

## 简介

本技能包为 **重生逆袭** 类型故事提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。适用于任何视觉风格。

## 核心理念

- **信息差即爽点** — 主角带着前世记忆回到过去，观众与主角共享"先知"优势，每一次预判兑现都是爽点
- **打脸节奏** — 装 → 蓄 → 打 → 踩 的四拍循环，一轮比一轮狠，节奏越快越爽
- **今昔反差** — 前世屈辱 vs 今生翻盘，反差越大，情绪越足
- **爽点密度** — 快节奏叙事，保证高频的情绪高点，不给观众喘息降温的机会

## 技能文件说明

### 1. 叙事规划手法 (`director_planning_narrative.md`)

导演在 **叙事规划阶段** 使用的技法参考，定义重生逆袭在主题立意、爽点节奏、打脸情绪设计与声音方向上的整体规划方法。

| 章节 | 内容概要 |
|---|---|
| 主题立意与情感内核 | 逆袭快感为本、信息差金手指、今昔对照 |
| 叙事结构与节奏规划 | 爽点密度模型、打脸四拍节奏模型、阶梯式情绪曲线 |
| 分场景情绪设计 | 六类典型情绪段落设计、反应镜头放大爽感、反派嚣张前置 |
| 声音与音乐方向 | 节奏音乐支撑、静默反差、今昔双音乐主题、打脸骤停 |
| 构图与景别叙事 | 俯仰角权力关系、今昔对照构图、中心构图登场时刻 |
| 镜头运动与节奏 | 以快制快、骤停运镜、拉升翻盘、运镜即情绪 |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)

导演在 **分镜表制作阶段** 使用的技法参考，定义重生逆袭在分镜表中的景别节奏、打脸运镜、时长把控、镜头合并与转场逻辑。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 分镜表作为镜头语言核心工具的定位说明 |
| 景别选择 | 打脸景别递进、反应镜头必给、俯仰角标注、定场精简 |
| 运镜节奏 | 快切为主、甩镜对决、骤停凝固、缓推逼近 |
| 时长把控 | 快节奏时长基准、爆发前骤停、黄金 6 秒规则 |
| 镜头合并策略 | 去 AI 感、打脸连续动作合并、群像反应合并 |
| 一镜到底 | 亮相登场长镜、标注方式、时长与风险 |
| 人物互动设计 | 单镜头动作限制、利落打脸动作、反派失态拆解 |
| 台词与留白 | 金句短而硬、爆发前留白、先知内心独白 |
| 转场设计 | 今昔叠化对照、硬切保节奏、时间元素快转 |

## 使用方式

本技能包作为 Hopeflow 导演 AI 的叙事手法参考，在故事创作流程中自动加载，指导：

1. **叙事规划** — 确定爽点内核、打脸节奏曲线、场景情绪与音乐方向
2. **分镜表生成** — 根据叙事规划输出具体的景别、运镜、时长与转场方案

两个文件分工明确、逐层递进，从"为什么这样拍"到"具体怎么拍"形成完整闭环。
