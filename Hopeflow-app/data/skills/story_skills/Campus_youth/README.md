# 青春校园 · 导演叙事手法技能包

## 简介

本技能包为 **青春校园** 类型故事提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。适用于任何视觉风格。

## 核心理念

- **纯粹即力量** - 青春叙事的核心力量来自"纯粹"：喜欢就是喜欢，讨厌就是讨厌，没有成年世界的权衡利弊。导演要保护这种纯粹感，不让世故污染青春
- **成长即阵痛** - 成长不是线性的进步而是伴随着失去：失去天真、失去友情、失去初恋。叙事的弧线是"从不知道自己是谁到知道了自己是谁"的痛苦过程
- **遗憾即美好** - 青春的最高境界不是圆满而是遗憾。没有说出口的告白、没有赴约的承诺、没有道别的离别——遗憾让青春成为永远的记忆
- **群体记忆** - 青春不是一个人的事而是群体的记忆：宿舍、社团、班级、死党。叙事应以群体关系为容器，承载个体的成长

## 技能文件说明

### 1. 叙事规划手法 (`director_planning_narrative.md`)

导演在 **叙事规划阶段** 使用的技法参考，定义青春校园在主题立意、情感节奏、校园氛围、成长弧线与声音方向上的整体规划方法。

| 章节 | 内容概要 |
|---|---|
| 主题立意与青春内核 | 纯粹即力量、成长即阵痛、遗憾即美好、群体记忆、暗恋心理 |
| 叙事结构与情感节奏 | 日常-悸动-冲突-成长弧线、四季叙事、考试/赛事节点、节奏模型、伏笔与回忆 |
| 分场景氛围设计 | 氛围用具象词、六大典型校园段落设计、空间即记忆、时间标记、镜头意图写情绪 |
| 声音与音乐方向 | 青春配乐、环境音怀旧、歌曲叙事功能、音乐情绪模型、沉默即心动 |
| 构图与景别叙事 | 三大核心构图、中心构图的孤独感、景别即亲密度、大特写记忆碎片、框中框窥视青春 |
| 镜头运动与节奏 | 跟拍奔跑、缓推心动放大、手持真实感、运镜即情绪、升格美好定格、定格记忆封存 |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)

导演在 **分镜表制作阶段** 使用的技法参考，定义青春校园在分镜表中的景别策略、运镜逻辑、时长把控、情感分镜设计与转场手法。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 分镜表作为青春情感节奏设计核心工具的定位说明 |
| 景别选择 | 全景校园定场、中景日常互动、近景心动捕捉、特写细节记忆 |
| 运镜节奏 | 跟拍奔跑、缓推心动、手持日常、定格记忆、升格美好 |
| 时长把控 | 日常轻快节奏、心动延长瞬间、留白回忆静止、考试赛事快切 |
| 情感分镜设计 | 暗恋视线结构、群体活动孤独、独处内心留白、冲突正反打 |
| 多人场景调度 | 教室群戏座位关系、社团群体热血、视线追逐暗恋图谱、集体照站位 |
| 台词与留白 | 青春对白真诚、未说出口的话、沉默心动、旁白回忆回望 |
| 转场设计 | 时间流逝标记、季节切换映射、回忆闪回触发、道具连接时空 |

## 使用方式

本技能包作为 Hopeflow 导演 AI 的叙事手法参考，在故事创作流程中自动加载，指导：

1. **叙事规划** - 确定青春内核、情感节奏曲线、校园场景氛围与音乐声音方向
2. **分镜表生成** - 根据叙事规划输出具体的景别、运镜、时长与转场方案

两个文件分工明确、逐层递进，从"为什么这样拍"到"具体怎么拍"形成完整闭环。
