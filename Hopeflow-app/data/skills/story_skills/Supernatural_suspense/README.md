# 悬疑灵异 · 导演叙事手法技能包

## 简介

本技能包为 **悬疑灵异** 类型故事提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。适用于任何视觉风格。本类型以"悬疑推理 + 灵异"为核心：既要有可推理的谜题链条，又要保留不可解释的超自然压迫感。

## 核心理念

- **悬念先行** — 谜题驱动叙事，观众带着疑问被一路拖着走，答案晚一分钟给，恐惧就多一分
- **惊吓有节奏** — 张弛交替，惊吓点密集但不过载，每次惊吓后留出缓冲呼吸
- **氛围即恐怖** — 声音、光线、构图共同营造不安感，恐怖在"看见"之前已经发生
- **日常中的异常** — 越日常的场所（走廊、电梯、镜子、邻居家）越恐怖，异常藏在熟悉里

## 技能文件说明

### 1. 叙事规划手法 (`director_planning_narrative.md`)

导演在 **叙事规划阶段** 使用的技法参考，定义悬疑灵异在主题立意、悬念结构、恐惧情绪设计与声音方向上的整体规划方法。

| 章节 | 内容概要 |
|---|---|
| 主题立意与情感内核 | 未知即恐惧、悬疑推理 + 灵异、恐怖递进、现实锚点 |
| 叙事结构与节奏规划 | 螺旋式悬念结构、张弛节奏、惊吓点分布、线索管理 |
| 分场景情绪设计 | 异常初现/调查/逼近/惊吓/推理/揭示六大段落、恐怖递进模型 |
| 声音与音乐方向 | 低频恐怖、环境音异常、骤停骤响、声音远近 |
| 构图与景别叙事 | 窥视视角、前景遮挡、暗部留黑、空镜的恐怖 |
| 镜头运动与节奏 | 缓慢推进逼近、静止长镜屏息、突然快切惊吓 |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)

导演在 **分镜表制作阶段** 使用的技法参考，定义悬疑灵异在分镜表中的悬念景别、惊吓运镜、时长把控、镜头合并与转场逻辑。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 分镜表作为镜头语言核心工具的定位说明 |
| 景别选择 | 惊吓点景别、暗部留黑、窥视视角、空镜恐怖 |
| 运镜节奏 | 缓慢推进逼近、静止长镜、突然快切 |
| 时长把控 | 悬念镜头时长、惊吓前后节奏、黄金 6 秒规则 |
| 镜头合并策略 | 去 AI 感、惊吓连续动作合并、铺垫镜头整合 |
| 一镜到底 | 跟随进入未知空间、标注方式与风险 |
| 人物互动设计 | 单镜头动作限制、惊吓反应的真实感 |
| 台词与留白 | 少台词多环境、不可说破、沉默的恐怖 |
| 转场设计 | 黑暗转场、渐隐渐显、回声衔接 |

## 使用方式

本技能包作为 Hopeflow 导演 AI 的叙事手法参考，在故事创作流程中自动加载，指导：

1. **叙事规划** — 确定悬念内核、恐怖递进曲线、场景氛围与音乐方向
2. **分镜表生成** — 根据叙事规划输出具体的景别、运镜、时长与转场方案

两个文件分工明确、逐层递进，从"为什么这样拍"到"具体怎么拍"形成完整闭环。
