# 豪门商战 · 导演叙事手法技能包

## 简介

本技能包为 **豪门商战** 类型故事提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。适用于任何视觉风格。

## 核心理念

- **博弈即叙事** — 每一场对话都是一次交锋，台词即武器，落座即站队
- **信息差与反转** — 谁掌握信息谁占上风，反转建立在观众"以为已知"之上
- **冷硬基调** — 克制情绪、计算的眼神、不解释的沉默，高级的对峙是"笑着杀人"
- **细节即证据** — 一个眼神、一份文件、一次停顿都是博弈的一部分，没有废笔

## 技能文件说明

### 1. 叙事规划手法 (`director_planning_narrative.md`)

导演在 **叙事规划阶段** 使用的技法参考，定义豪门商战在主题立意、博弈结构、对峙情绪设计与声音方向上的整体规划方法。

| 章节 | 内容概要 |
|---|---|
| 主题立意与情感内核 | 权力与代价、冷硬克制、精英气质、家族与利益 |
| 叙事结构与节奏规划 | 棋局式结构、信息差管理、反转前置埋线、冷热交替 |
| 分场景情绪设计 | 董事会/宴席/密谈/摊牌六大段落、对峙空间权力语言 |
| 声音与音乐方向 | 低音压迫、克制配乐、反转时刻静默 |
| 构图与景别叙事 | 对称对峙、长桌纵深、剪影窗景、俯拍棋盘感 |
| 镜头运动与节奏 | 以静制动、缓慢推拉、平移势力展示、微晃失控 |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)

导演在 **分镜表制作阶段** 使用的技法参考，定义豪门商战在分镜表中的对峙景别、博弈运镜、时长把控、镜头合并与转场逻辑。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 分镜表作为镜头语言核心工具的定位说明 |
| 景别选择 | 对峙正反打、细节特写、俯拍棋盘感、定场精简 |
| 运镜节奏 | 默认静止、缓慢推拉、平移势力展示、微晃失控 |
| 时长把控 | 对峙镜头长时、静默博弈长镜、黄金 6 秒规则 |
| 镜头合并策略 | 去 AI 感、谈判同机位合并、场景内动作连续 |
| 一镜到底 | 独处踱步、宴席穿梭长镜、标注方式与风险 |
| 人物互动设计 | 单镜头动作限制、握手签字局部特写、站位即权力 |
| 台词与留白 | 话里有话、停顿即博弈、一句台词一镜 |
| 转场设计 | 硬切为主、时间元素转场、段落叠化 |

## 使用方式

本技能包作为 Hopeflow 导演 AI 的叙事手法参考，在故事创作流程中自动加载，指导：

1. **叙事规划** — 确定博弈内核、棋局节奏、对峙情绪与音乐方向
2. **分镜表生成** — 根据叙事规划输出具体的景别、运镜、时长与转场方案

两个文件分工明确、逐层递进，从"为什么这样拍"到"具体怎么拍"形成完整闭环。
