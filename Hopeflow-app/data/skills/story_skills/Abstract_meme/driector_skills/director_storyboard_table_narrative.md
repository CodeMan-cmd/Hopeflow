# 分镜表叙事手法 · 抽象视频 · 技法参考

---

## 一、景别选择

### 抽象视频通用景别原则

- **特写是核心** - 物品拟人面部是画面焦点，70%以上镜头为特写/近景
- **物品全景定场** - 开场用全景展示物品日常环境，建立"这是普通物品"的认知
- **反应特写放大** - 情绪转折点用极近特写捕捉面部微表情变化
- **禁止大远景** - 抽象视频不需要大场景，保持亲密视角

### 模板特有景别

| 模板 | 推荐景别 | 说明 |
|------|---------|------|
| 物品噩梦 | 特写为主，噩梦段落可用倾斜/扭曲构图 | 放大恐惧面部表情 |
| 物品说话 | 固定特写，直视镜头 | 独白对话感 |
| 拟人短剧 | 近景+中景交替，对话用双人近景 | 展现角色互动 |

## 二、运镜节奏

### 物品噩梦运镜

| 段落 | 运镜 | 说明 |
|------|------|------|
| 日常 | 固定 | 平静稳定 |
| 坠入 | 缓推+画面扭曲 | 不安递进 |
| 噩梦 | 手持晃动+急推 | 恐慌失控 |
| 惊醒 | 突然静止+微抖 | 反差释放 |

### 物品说话运镜

| 段落 | 运镜 | 说明 |
|------|------|------|
| 揭示 | 固定，面部缓缓出现 | "活过来"的惊喜 |
| 独白 | 固定特写 | 保持对话感 |
| 爆发 | 缓推至极近特写 | 放大情绪 |
| 金句 | 固定，直视镜头 | 留白冲击 |

### 拟人短剧运镜

| 段落 | 运镜 | 说明 |
|------|------|------|
| 登场 | 固定中景 | 角色介绍 |
| 冲突 | 双人近景切换 | 对话节奏 |
| 反转 | 急推特写 | 放大震惊 |
| 高潮 | 快切/手持 | 混乱感 |
| 收尾 | 固定定格 | 梗落地 |

## 三、时长把控

| 模板 | 总时长 | 单镜时长 | 分镜数 |
|------|--------|---------|--------|
| 物品噩梦 | 10-15s | 2-5s | 3-4个 |
| 物品说话 | 8-15s | 2-6s | 3-4个 |
| 拟人短剧 | 15-30s | 2-5s | 5-6个 |

### 时长原则

- **单镜不超过8秒** - 抽象视频节奏快，单镜过长观众流失
- **情绪镜头给够** - 恐惧/爆发/金句特写至少2秒，让观众消化
- **转场要快** - 段落间转场不超过1秒，保持节奏

---

## 四、转场手法

### 噩梦模板转场

| 转场点 | 手法 |
|--------|------|
| 日常->坠入 | 画面扭曲渐变，色彩偏移 |
| 坠入->噩梦 | 突然切黑+恐惧元素闪现 |
| 噩梦->惊醒 | 白光闪过+画面抖动 |

### 说话模板转场

| 转场点 | 手法 |
|--------|------|
| 揭示->独白 | 无转场，面部自然开始说话 |
| 独白->爆发 | 色调加暖/加暗，表情递进 |
| 爆发->金句 | 突然静止，画面留白 |

### 拟人剧转场

| 转场点 | 手法 |
|--------|------|
| 登场->冲突 | 角色B切入，对话开始 |
| 冲突->反转 | 突然静音+表情特写 |
| 反转->高潮 | 快切加速 |
| 高潮->收尾 | 定格/慢镜头 |
