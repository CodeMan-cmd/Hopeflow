# 叙事规划 · 抽象视频 · 技法参考

---

## 一、模板选择与叙事核心

### 物品噩梦模板

- **叙事核心** - 物品最恐惧的事在梦中成真，惊醒后发现是梦但已遍体鳞伤
- **情绪弧线** - 安全感 -> 不安 -> 恐惧高潮 -> 惊醒释然 -> 余悸未消
- **笑点机制** - 恐怖到荒谬的程度就是笑点（鸡胸肉梦到被猫啃、数据线梦到被巨嘴咬）
- **关键反转** - 惊醒后发现"伤痕"还在（物品上真的有牙印/裂痕），暗示噩梦"成真"

### 物品说话模板

- **叙事核心** - 日常物品突然开口说话，对自身存在进行讽刺独白
- **情绪弧线** - 意外揭示 -> 平静抱怨 -> 逐渐激动 -> 金句爆发
- **笑点机制** - 物品视角的荒谬合理性（牙刷嫌你口臭、枕头嫌你流口水）
- **关键金句** - 收尾一句让观众记住的"物品哲学"（"我是你的牙刷，我每天忍受你的口臭，这就是爱"）

### 拟人短剧模板

- **叙事核心** - 物品拟人化演绎离谱剧情（出轨/怀孕/离婚/宫斗），越狗血越好
- **情绪弧线** - 角色登场 -> 冲突爆发 -> 反转惊喜 -> 狗血高潮 -> 梗收尾
- **笑点机制** - 物品特性与剧情的荒诞映射（香蕉出轨草莓生了个橘子、iPhone嫌弃充电慢出轨三星）
- **关键反转** - 生下来的孩子不是自己的种类（香蕉生了草莓、iPhone生了三星）

## 二、剧情骨架构建

### 物品噩梦骨架

```
1. 日常引入（2-3s）
   - 物品在日常生活中静止存在
   - 拟人面部平静，半闭眼
   - 暖色调，安全感

2. 坠入噩梦（2-3s）
   - 画面开始扭曲，色彩偏暗
   - 物品面部出现不安表情
   - 环境异变，恐惧元素浮现

3. 噩梦高潮（4-5s）
   - 物品最恐惧的场景完全展开
   - 面部极度惊恐，嘴巴张大
   - 深黑/暗紫背景，高对比恐怖

4. 惊醒回神（2-3s）
   - 突然白光闪过，切回日常
   - 物品剧烈颤抖，冷汗
   - 表情从恐惧变为劫后余生
   - 彩蛋：发现"伤痕"还在
```

### 物品说话骨架

```
1. 揭示登场（2s）
   - 物品突然"活过来"，面部出现
   - 眼睛缓缓睁开，看向镜头
   - "哦，你来了。"

2. 独白抱怨（4-6s）
   - 嘴型同步独白，表情逐渐变化
   - 从平静叙述到逐渐激动
   - 列举"罪状"（如牙刷列举主人的坏习惯）

3. 情绪爆发（3-4s）
   - 语速加快，面部扭曲
   - 眼睛瞪大，嘴巴大张
   - 核心抱怨爆发

4. 金句收尾（2s）
   - 突然放慢，直视镜头
   - 一句话总结"物品哲学"
   - 意味深长，留白
```

### 拟人短剧骨架

```
1. 角色登场（3s）
   - 物品A拟人化登场，自我介绍
   - 交代设定（"我是香蕉先生，八块腹肌"）

2. 冲突开始（4-5s）
   - 物品B登场，冲突关系建立
   - "香蕉先生，我知道你和草莓的事了"

3. 离谱展开（5-6s）
   - 剧情急转直下，越来越离谱
   - 多个角色卷入，关系混乱

4. 意外反转（4-5s）
   - 真相揭露，出人意料
   - "孩子不是你的，是三星的"

5. 狗血高潮（4-5s）
   - 所有角色正面冲突
   - 表情夸张，动作激烈

6. 梗收尾（2-3s）
   - 定格或金句
   - "这就是为什么我不买安卓"
```

## 三、节奏控制

### 通用节奏原则

- **前3秒抓眼球** - 开场必须有视觉冲击（物品"活过来"/画面扭曲/突然说话）
- **每5秒一个情绪点** - 不超过5秒没有变化（表情变化/转场/剧情推进）
- **结尾留梗** - 最后2秒必须有记忆点（金句/反转/彩蛋）

### 噩梦模板节奏

| 时间 | 节奏 | 动作 |
|------|------|------|
| 0-2s | 缓慢 | 日常静止，酝酿 |
| 2-4s | 加速 | 扭曲坠入，不安升级 |
| 4-9s | 高潮 | 噩梦冲击，恐怖到荒谬 |
| 9-12s | 释放 | 惊醒反转，劫后余生 |

### 说话模板节奏

| 时间 | 节奏 | 动作 |
|------|------|------|
| 0-2s | 停顿 | 揭示，"活过来" |
| 2-7s | 渐快 | 独白递进 |
| 7-10s | 爆发 | 情绪最高点 |
| 10-12s | 骤停 | 金句，留白 |

### 拟人剧节奏

| 时间 | 节奏 | 动作 |
|------|------|------|
| 0-3s | 正常 | 角色介绍 |
| 3-8s | 加速 | 冲突升级 |
| 8-13s | 急转 | 反转 |
| 13-18s | 高潮 | 狗血爆发 |
| 18-20s | 收束 | 梗落地 |
