# 武侠江湖 · 导演叙事手法技能包

## 简介

本技能包为 **武侠江湖** 类型故事提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。适用于任何视觉风格。

武侠江湖是中国独有的叙事类型，其核心不在"武"而在"侠"——侠义精神、恩怨情仇、江湖规矩共同构成了一个自洽的叙事宇宙。本技能包帮助 AI 导演在分镜与叙事层面准确把握武侠的节奏韵律、意境美学与情感浓度，让每一场打斗都有叙事重量，每一次拔剑都有道德分量。

## 核心理念

- **侠义精神** - 武侠的叙事引擎是"该不该出手"的道德抉择，而非单纯的武力炫耀。侠客的每一次拔剑都是一次价值判断，叙事张力源于"义"与"利"的永恒冲突。
- **恩怨驱动** - 武侠叙事的燃料是恩怨：父仇、师恩、兄弟义、江湖债。每条恩怨线都是一根引线，何时点燃、何时引爆决定了全篇的叙事节奏与情感烈度。
- **以武论道** - 武打不是动作奇观而是价值表达。招式即性格、兵器即身份、胜负即立场，每一场对决都在回答一个叙事问题，胜者未必是"对"的一方。
- **侠骨柔情** - 纯打斗让人疲劳，在刀光剑影中埋入柔情，让铁血中露出柔软——刚柔反差是武侠最有力的情感武器，也是区别于普通动作片的关键所在。

## 技能文件说明

### 1. 叙事规划手法 (`director_planning_narrative.md`)

本文件从宏观层面定义武侠江湖类型的叙事规划方法，覆盖主题立意、叙事结构、分场景设计、声音方向、构图景别与镜头运动六大维度。适用于导演在前期规划阶段确立全片的叙事基调、节奏模型与视听方向。

| 章节 | 主题 | 核心内容 |
|------|------|----------|
| 第一章 | 主题立意与侠义内核 | 侠义精神、恩怨驱动、以武论道、江湖规矩、侠骨柔情 |
| 第二章 | 叙事结构与武打节奏 | 恩怨铺陈与对决爆发、武打叙事功能、招式即性格、节奏张弛模型、伏笔与传承 |
| 第三章 | 分场景江湖设计 | 具象江湖词、六大典型段落、空间武打舞台、意境营造、镜头意图写侠气 |
| 第四章 | 声音与音乐方向 | 民乐主导、兵器节奏化、留白意境、音乐情绪模型、箫声即心声 |
| 第五章 | 构图与景别叙事 | 三大核心构图、中心对峙感、景别即节奏、大特写招式放大、留白意境 |
| 第六章 | 镜头运动与节奏 | 跟拍武打、急推招式、横移对峙、升格决断、运镜即招式、旋转混战 |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)

本文件从微观层面定义武侠江湖类型在分镜表中的具体执行方法，覆盖景别选择、运镜节奏、时长把控、武打分镜设计、多人群打调度、台词节奏与转场设计七大维度。适用于导演在分镜执行阶段将叙事意图转化为可操作的分镜指令。

| 章节 | 主题 | 核心内容 |
|------|------|----------|
| 一 | 分镜表定位 | 分镜表作为武侠动作设计核心工具的功能定义 |
| 二 | 景别选择 | 全景定场、中景对峙、近景反应、特写招式细节的叙事功能与搭配逻辑 |
| 三 | 运镜节奏 | 跟拍、急推、横移、升格、缓拉五种核心运镜的武打应用场景 |
| 四 | 时长把控 | 蓄力镜头、爆发镜头、留白意境、招式节拍的时长配比模型 |
| 五 | 武打分镜设计 | 对决结构、兵器交锋、内力外化、一招制胜的分镜拆解方法 |
| 六 | 多人群打调度 | 混战全景、重点近景、连锁反应、以一敌多的调度策略 |
| 七 | 台词与节奏 | 侠客对白、沉默力量、招式命名、旁白叙事的节奏处理 |
| 八 | 转场设计 | 位移转场、季节变化、意境转场、动作匹配剪辑的转场手法 |

## 使用方式

1. **前期规划阶段**：优先加载 `director_planning_narrative.md`，确立全片的主题立意、恩怨结构、武打节奏模型与声音方向。第一章至第三章帮助定义"讲什么故事、怎么讲"，第四章至第六章帮助定义"怎么听、怎么看"。

2. **分镜执行阶段**：加载 `director_storyboard_table_narrative.md`，将叙事规划转化为具体的分镜指令。景别、运镜、时长三章解决"每个镜头怎么拍"，武打分镜、群打调度两章解决"打斗怎么设计"，台词与转场两章解决"镜头之间怎么连"。

3. **联合使用**：两个文件配合使用效果最佳。规划文件定义"为什么这样拍"，分镜文件定义"具体怎么拍"。当分镜执行中出现叙事意图不明确时，回溯规划文件确认主题方向；当规划文件中的抽象概念需要落地时，查阅分镜文件获取操作方法。

4. **风格适配**：本技能包的叙事手法适用于任何视觉风格——无论是水墨国风、写实武侠还是赛博江湖，侠义内核与叙事节奏模型保持一致，仅在视觉呈现层面根据具体风格调整。
