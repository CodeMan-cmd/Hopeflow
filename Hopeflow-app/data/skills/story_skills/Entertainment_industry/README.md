# 娱乐圈 · 导演叙事手法技能包

## 简介

本技能包为 **娱乐圈** 类型故事提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。适用于任何视觉风格。

## 核心理念

- **台前幕后** - 娱乐圈叙事的核心张力是"台前的光鲜"与"幕后的残酷"之间的落差，叙事要不断在舞台与现实之间切换，让观众看到光环背后的代价
- **名利博弈** - 娱乐圈的权力货币是流量与关注度，谁的流量大谁就有话语权，叙事的博弈核心始终围绕"关注度争夺"展开
- **人设与真实** - 每个明星都活在"人设"与"真实自我"的撕裂中，戏剧张力来自"人设崩塌"的瞬间——当面具脱落的刹那，真实暴露
- **追梦与代价** - 得到多少名利就失去多少自由、隐私与真情，叙事不是展示成功而是揭示代价，弧线是"从追梦到妥协到找回初心"或"从追梦到妥协到彻底迷失"

## 技能文件说明

### 1. 叙事规划手法 (`director_planning_narrative.md`)

导演在 **叙事规划阶段** 使用的技法参考，定义娱乐圈在主题立意、名利博弈、追梦弧线、舞台与现实反差与声音方向上的整体规划方法。

| 章节 | 内容概要 |
|---|---|
| 主题立意与名利内核 | 台前vs幕后、人设与真实、名利代价、追梦与妥协、流量即权力 |
| 叙事结构与博弈节奏 | 低谷到蜕变弧线、舆论反转、日常爆发余波节奏、伏笔回旋、双线叙事 |
| 分场景氛围设计 | 具象氛围词、六大典型段落设计、舞台日常反差、空间即身份、镜头意图 |
| 声音与音乐方向 | 舞台音乐、日常安静、媒体噪音、音乐情绪模型、寂静即崩塌 |
| 构图与景别叙事 | 聚光灯/偷拍/镜子构图、中心聚光灯效应、景别即关注度、人设裂痕特写、框中框 |
| 镜头运动与节奏 | 舞台运镜、偷拍跟拍、缓推揭幕、运镜即注视、急拉曝光、手持真实感 |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)

导演在 **分镜表制作阶段** 使用的技法参考，定义娱乐圈在分镜表中的景别策略、运镜逻辑、时长把控、舞台分镜设计与转场手法。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 分镜表作为舞台与现实反差设计核心工具的定位说明 |
| 景别选择 | 全景舞台、中景社交、近景表情管理、特写细节暴露 |
| 运镜节奏 | 舞台运镜、跟拍偷拍感、缓推揭幕、急拉曝光、手持真实感 |
| 时长把控 | 舞台快切、日常中速、危机骤变、留白内心 |
| 舞台分镜设计 | 表演结构、后台反差、镜头注视、人设崩塌 |
| 多人场景调度 | 群演舞台、社交场合、媒体围堵 |
| 台词与留白 | 台前私下双面语言、媒体话术、沉默独处、旁白功能 |
| 转场设计 | 舞台日常切换、时间压缩、新闻转场、蒙太奇 |

## 使用方式

本技能包作为 Hopeflow 导演 AI 的叙事手法参考，在故事创作流程中自动加载，指导：

1. **叙事规划** - 确定娱乐圈内核、名利博弈节奏曲线、舞台与现实反差关系与声音方向
2. **分镜表生成** - 根据叙事规划输出具体的景别、运镜、时长与转场方案

两个文件分工明确、逐层递进，从"为什么这样拍"到"具体怎么拍"形成完整闭环。
